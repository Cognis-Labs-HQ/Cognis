# Cognis ACL Matrix (Initial)

Initial scope only distinguishes baseline `user` and `admin` API privileges.

| Capability | user | admin |
|---|---:|---:|
| View own profile | ✅ | ✅ |
| Configure own progress visibility | ✅ | ✅ |
| Submit content for review | ✅ | ✅ |
| Review/approve global content | ❌ | ✅ |
| Install module (zip) | ❌ | ✅ |
| Enable/disable non-core module | ❌ | ✅ |
| Toggle core module | ❌ | ❌ |
| Manage auth provider config | ❌ | ✅ |
| System diagnostics endpoints | ❌ | ✅ |

> Teacher-specific permissions are intentionally deferred and will extend this matrix later.
