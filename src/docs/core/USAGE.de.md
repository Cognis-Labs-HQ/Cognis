# Anwendung

Praktische Abläufe für Core.

## Voraussetzungen

Verwaltungsänderungen benötigen ein berechtigtes Konto.

## Beispiele

Prüfe Status und Abhängigkeiten in Administration und lies vor Aktivierung oder Konfiguration die Dokumentation.

## Erwartete Ergebnisse

Core koordiniert Funktionen; privater Zugriff bleibt Aufgabe der zuständigen Operation.

## Fehlerbehebung

Ein Abhängigkeitsfehler kann mehrere Aktionen verbergen. Behebe den Anbieter statt Zugriffskontrollen zu umgehen.
