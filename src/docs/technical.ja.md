## 設定

このドキュメント自体には実行時の設定はありません。運用の設定は該当するコンポーネントが管理します。

## 動作

### 概要

これはCognis開発者ドキュメントのルートナビゲーション文書です。このセットのすべてのドキュメントは、`/docs` のアプリ内ドキュメントブラウザと `GET /api/v1/docs` を通じて提供されます。

これらのドキュメントはエンドユーザーではなく開発者向けに書かれています。コードベースが初めての場合は、概要とプラットフォーム機能のドキュメントから始めてください。

### プラットフォーム

| ドキュメント                               | 説明                                                           |
| ------------------------------------------ | -------------------------------------------------------------- |
| [概要](/docs/overview)                     | Cognisとは何か、レイヤーがどう組み合わさるか                   |
| [プラットフォーム機能](/docs/features)     | 組み込み機能とアダプターカバレッジ                             |
| [ドキュメント標準](/docs/standard)         | このコードベースでのドキュメントの書き方                       |

| [コンポーネントバージョン](/docs/versions) | すべてのゲートウェイ、アダプター、モジュールの現在のバージョン |
