# Korrektur des Meeting-Chat-Lebenszyklus

## Beendete Meetings entladen den Chat sofort

Beim Beenden oder Verlassen eines Jitsi-Meet-Meetings wird nun das Chat-Polling gestoppt, der aktive Raum samt Verschlüsselungsschlüssel und Teilnehmerstatus geleert und der sichtbare Chat entfernt, bevor die Meeting-Anwesenheitsanfrage abgeschlossen ist.
