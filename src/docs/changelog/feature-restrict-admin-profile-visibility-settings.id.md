# Profil administrator yang dapat ditemukan

## Administrator tidak dapat lagi menyembunyikan profil

Profil pengajar, administrator, dan pemilik kini menggunakan visibilitas Teman secara default. Mengubah akun ke salah satu peran tersebut juga memperbarui profilnya menjadi Teman. Editor profil menonaktifkan pilihan yang tidak kompatibel, dan API menolak upaya untuk melewati batasan tersebut.
