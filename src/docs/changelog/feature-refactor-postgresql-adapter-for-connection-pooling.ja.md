# PostgreSQL接続プール

## PostgreSQLが上限付き接続プールを使用

通常のデータベース操作は `pg.Pool` で並行実行され、各トランザクションはコミットまたはロールバックまで同じクライアントを使用します。環境設定でプールサイズ、接続、アイドル、および任意のステートメントタイムアウトを制限できます。

## サーバー終了時に接続を排出

PostgreSQLアダプターは ctx のライフサイクル機能にプール終了処理を登録し、サーバーが新しい要求の受付を停止してからプールを安全に閉じます。

## Dockerセットアップが明示的な環境プロファイルを使用

共通、PostgreSQL、開発、本番用のEnvファイルがコンテナのデフォルト値を保持します。Composeは未設定のプール変数を補間せずに適切なプロファイルを選択するため、空変数の警告が解消されます。
