# アクションメニューの有効期間

**機能ブランチ:** feature-hamburger-lifetime641

## メニューをページの有効期間に結び付ける

準備中と表示中のアクションメニューは、ページの中止、開いたボタンの削除、新しいメニューへの置き換えで閉じます。古い操作要素から操作を返すことはできません。ユーザーとモジュールは後続の操作を変更せずに、現在のページの有効期間を渡します。

## キーボードで操作を選択する

メニューは最初の有効な操作にフォーカスし、矢印キー、Home、End、Escape、Tab を使用できます。Escape は現在の開いたボタンにフォーカスを戻し、外側のポインター操作による終了では新しいフォーカスを維持します。共通のフローティングメニューと一時領域の契約により、バンドル経由と直接配信の呼び出しでもチュートリアル予約を維持します。

## ダイアログのフォーカス管理を維持する

準備中のメニューもフォーカスが離れると中止され、遅れて準備が完了してもフォーカスを奪い返しません。ダイアログ内のメニューは既存のフォーカス管理の委譲を利用します。移動キーや Escape で親を閉じず、別の操作要素へ移動したフォーカスを維持し、新しい子ダイアログを開くか親を閉じるとメニューを閉じます。
