# プロフィールの確認

**機能ブランチ:** feature-profile-confirmation-integration

## プロフィール操作の確認

削除、フォロー解除、ブロックには破壊的な操作を示す確認ボタンを使用し、内容や関係を維持するキャンセルは中立の表示にしました。ブロック解除も中立の操作です。繰り返された操作は保留中の確認とリクエストを共有します。画面遷移、アカウントやセッションの変更、プロバイダーの削除により古い操作部品は無効になります。

## 明確な結果表示と再試行

拒否された操作や未送信と判明した操作はエラーを表示し、新たな確認を許可します。送信結果が不明な場合は現在のページで繰り返しません。プロフィールを開き直して結果を確認してください。後続の表示更新が失敗しても、受け付けられた変更はそのまま維持されます。

## 共有キューのキャンセル

ページのキャンセルが、送信前に共有リクエストと永続バッファーの境界へ届くようになりました。任意の送信シグナルと送信キュー契約は、受け付け済みレコード、シグナルなしの既存呼び出し、再送を維持します。共有UIアセットをProfile 4.0.1と一緒に配布してください。
