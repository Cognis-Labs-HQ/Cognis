# Font Orbitron Dipulihkan

## Font Orbitron Kini Ditampilkan dengan Benar

Font Orbitron muncul di pemilih font tetapi tidak dirender karena font tersebut tidak pernah dimuat ke browser. Import Google Fonts telah ditambahkan ke stylesheet dasar sehingga Orbitron (dan font aplikasi lainnya seperti Audiowide, Rajdhani, Exo 2, dan Inter) kini dimuat dengan benar dan tersedia untuk dipilih di Pengaturan.
