# Sign-In Shortcut on Register

**Feature Branch:** copilot/add-sign-in-instead-button

## Added a direct Sign in instead action

The registration page now includes a dedicated "Sign in instead" button that takes users directly to `/login`. This gives users a fast way to return to the login flow without completing registration.

## Standardized Register Button Capitalization

The register submit label now uses Title Case as "Create Account" so it is consistent with the "Sign In Instead" button style on the same page.
