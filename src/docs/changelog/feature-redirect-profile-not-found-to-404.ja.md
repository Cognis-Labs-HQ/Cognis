# 表示範囲によるプロフィールアクセス

**機能ブランチ:** feature-redirect-profile-not-found-to-404

## フォローには表示可能な申請者が必要

ユーザーが別のプロフィールをフォローするには、自分のプロフィール公開範囲を少なくとも非公開に設定する必要があります。これにより、非表示プロフィールは新しいフォロー関係を作成できません。

## 非表示プロフィールは404ページを使用

表示範囲ルールによって現在のユーザーからプロフィールが見えない場合、プロフィールアプリはページ内の未検出メッセージではなく、標準の404エラーページへ遷移するようになりました。

## エラー表示が保存済みテーマに対応

エラーページと実行時エラーポップアップは、描画前に保存済みテーマを適用するようになりました。これにより、ルートが早期に失敗した場合でもライトテーマのユーザーには一致したエラー表示が出ます。

## ルーターがエラー遷移のルートを保護

アプリルーターはルートをマウントする前にダッシュボードのルート要素を解決するようになりました。これにより、ダッシュボードシェルがルーターを初期化する前でも、プロフィールから404ページへの遷移が機能します。
