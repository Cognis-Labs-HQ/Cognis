# Änderungsindex

**Feature Branch:** feature-generate-complete-changelog-index

## Alle Einträge Anzeigen

Die Seite für Änderungsprotokolle baut ihre Navigation jetzt aus jedem Markdown-Eintrag im gemeinsamen Änderungsprotokoll-Verzeichnis auf, damit zukünftige Dateien automatisch erscheinen.

## Feature-Branch Anzeigen

Gerenderte Änderungsprotokolle zeigen jetzt den Feature-Branch an, der aus dem Dateinamen des Änderungsprotokolls abgeleitet wird.
