# PiP の最小サイズを向きに対応

**機能ブランチ:** feature-allow-resizing-pip-windows-by-dimensions

## サイズ変更時に PiP の最小寸法を切り替え

PiP ウィンドウを最小幅より狭くしながら最小高さより高くドラッグすると、最小寸法が既定の横向きから縦向きへ切り替わるようになりました。逆の操作を行うと横向きに戻ります。

## ページ操作を PiP ウィンドウより前面に維持

ページ操作ボタンがフローティング PiP ウィンドウより高い重なり順を使用するようになり、引き続き操作できます。
