# PiP の最小サイズを向きに対応

**機能ブランチ:** feature-allow-resizing-pip-windows-by-dimensions

## サイズ変更時に PiP の最小寸法を切り替え

PiP の最小寸法が、サイズ変更操作の相対的な幅と高さに応じて素早く切り替わるようになりました。ヒステリシス領域により、境界付近の小さなポインター移動で横向きと縦向きが繰り返し振動することを防ぎます。

## ページ操作を PiP ウィンドウより前面に維持

PiP ウィンドウがドキュメントの重なりコンテキスト内に留まるようになり、より高い重なり順のページ操作ドックのボタンを確実に利用できます。
