# Penyuntingan Preferensi Aman

## Sunting JSON preferensi lengkap

Preferensi Lanjutan kini memungkinkan pengguna berpengalaman menyunting seluruh dokumen preferensi antarmuka setelah menyetujui peringatan keamanan. Perubahan divalidasi, dilacak, disimpan, dan diterapkan melalui sistem preferensi yang ada.

## Dokumen preferensi lebih rapi

Riwayat pengakuan catatan rilis kini disimpan terpisah dari preferensi antarmuka yang bermakna.
