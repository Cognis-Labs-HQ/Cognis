# 個人のセッションタイムアウトを尊重

## グローバル上限内で個人のタイムアウト設定を維持

ユーザーのセッションタイムアウトが管理者の上限より短い場合は、個人設定が優先されます。ログインまたはリセット時には現在のグローバルタイムアウトが個人値として採用され、その後の引き上げには追従しません。グローバル上限が短くなった場合は個人値を引き下げて保存し、長くなった場合は変更しません。期間コントロールには上限内に収まる単位のみが表示され、各単位の数値欄は許可される最大の整数値に制限されます。

## より長いタイムアウトを安全に適用

個人のタイムアウトを延長しても現在のセッションは維持され、変更が次回のログイン時に適用されることが通知されます。カウントダウンの色は期間に応じた緊急度でリアルタイムに更新され、短いセッションでも有用な予告時間を確保し、4週間以上のセッションでは最後の1日にオレンジ色、最後の1時間に赤色へ変わります。
