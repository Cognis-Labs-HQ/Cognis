# Pembaruan Profil Langsung

## Informasi profil seketika

Nama tampilan dan informasi profil lain yang disimpan kini muncul tanpa memuat ulang halaman.

## Pembaruan sosial andal

Jumlah pengikut dan yang diikuti kini diperbarui langsung bersama kartu pengguna terkait.

## Satu pemilih gambar

Interaksi avatar dan banner kini mencegah dialog pemilihan ganda dan unggahan yang bertumpuk.

## Jumlah sosial langsung

Mengikuti dan berhenti mengikuti kini memperbarui jumlah profil yang terlihat serta kartu sosial terkait segera setelah permintaan berhasil, tanpa menunggu permintaan daftar lanjutan.

## Tata letak banner langsung

Mengubah tinggi banner profil kini langsung menggambar ulang banner sebelum penyimpanan preferensi selesai.

## Penyegaran langsung seluruh composer

Penyegaran Page Composer kini secara bawaan merender ulang kartu yang sudah ada sehingga konten lama hilang dari halaman biasa. Sematan rapat berstatus tetap memilih parkir DOM.

## Sumber daya komponen andal

Halaman profil kini memiliki teks untuk tindakan pesannya sendiri dan tidak lagi meminta sumber daya dari adapter yang dapat dinonaktifkan secara terpisah. Pemeriksaan jalur browser kini memvalidasi impor statis dan dinamis, jalur bahasa yang disajikan, batas adapter yang dapat dinonaktifkan, serta jalur relatif di dalam paket UI adapter.

## Kartu profil tetap interaktif

Pembaruan profil terarah kini dijalankan melalui penyusun halaman sehingga media sematan lain tetap dipertahankan dan interaksi formulir serta kartu dipulihkan setelah digambar ulang.

## Jumlah pengikut langsung berubah

Saat mengikuti profil yang sedang dilihat, akun saat ini kini ditambahkan ke daftar pengikut sementara sebelum penyelarasan server selesai.
