# Responsive Workspace

**Feature Branch:** feature-responsive-page-composer

## Readable Across Devices

Page Composer stacks narrow content areas without changing saved desktop profiles. Width constraints fit small grids, nested editors use the full available width, and responsive updates retain existing nested form controls.

## Accessible Layout Controls

Touch controls stay visible, available widgets have an Add button, and keyboard users can move and resize focused widgets. Interrupted pointer gestures do not commit changes.

## Consistent Navigation

Navigation and toolbar drawers provide focus containment, Escape dismissal and complete lifecycle cleanup. Filters remain usable while the toolbar is open. Shared scroll locking supports nested search and popup surfaces; safe-area sizing, wrapping and larger touch targets preserve the Cognis theme.
