# Responsive Cognis

**Feature Branch:** feature-responsive-page-composer

## Responsive Workspaces

Core pages adapt to phone, tablet and desktop viewports through Page Composer, including Calendar agendas, readable conversations, Study cards and consistent sidebars.

## Reliable Feature Integration

Offline preparation, provider contracts, account boundaries and lifecycle cleanup support enabled components without coupling their implementations.

## Structured Documentation

Component documentation separates introductory information, usage procedures and technical contracts. Core topics use directory entries. The reader switches among three views of one complete versioned bundle; compliance checks enforce structure, localization, manifests and asset ownership.
