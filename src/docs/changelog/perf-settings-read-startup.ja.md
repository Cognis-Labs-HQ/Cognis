# 設定画面の起動高速化

**機能ブランチ:** perf-settings-read-startup

## 独立した読み取りの並行実行

設定画面はアカウントの設定、エディターの確認状態、初期設定の状態を並行して読み取ります。初期設定への転送を確認した後、セクションの記述子と翻訳を並行して取得します。マウントのたびに最新のデータを取得し、設定や非公開応答のキャッシュは追加しません。

## 言語と初期設定の規則を維持

保存済みの言語設定を適用してから翻訳を開始します。必要な初期設定への転送はセクションの取得や画面表示より先に完了します。動作テストでは明示的な依存関係の契約を通じて実際のマウント初期化を実行し、繰り返しアカウントを変更する場合も検証します。
