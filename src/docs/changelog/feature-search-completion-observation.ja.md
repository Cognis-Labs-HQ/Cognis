# 検索テストの信頼性

**機能ブランチ:** feature-search-completion-observation

## 検索画面の終了を確認

検索の選択テストは、非同期の選択処理と終了アニメーションが固定の待ち時間で終わると仮定せず、制限時間内に検索オーバーレイが削除されるまで待つようになりました。コールバックの呼び出し回数、選択した値、キャンセルの所有関係、移動先の検証は維持しています。完了が遅れても成功し、検索画面が開いたままの場合は削除の検証に失敗します。
