# 読者アバターと既読詳細

**機能ブランチ:** feature-message-receipt-integration

## 統一された読者アバター

Profile 4.1.0 は `buildContent` に `tiny`（1.22rem、頭文字0.5rem）と `compact`（1.65rem、頭文字0.6rem）を追加します。変更できない `contentSizes` 配列が対応する5つの名前を公開します。これは画像の表示サイズで、操作領域の大きさではありません。呼び出し元は別のアクセシブルな操作領域、間隔、外側の区切り線を管理します。`small`、`medium`、`large` と `buildMarkup` の各オプションの意味は変わりません。新しいサイズを使う側は公開リストを確認し、対応する Profile の JavaScript と CSS を同時に配布してください。Messages 2.9.0 は両サイズを使うため、アセットをまとめて公開します。既存の Profile チュートリアルの操作要素とサイズは維持します。

## 操作しやすい読者パネル

送信済みメッセージの既読人数ボタンを選ぶと、読んだ人と時刻を確認できます。タップ、クリック、キーボードで開けます。「閉じる」または Escape で現在のボタンにフォーカスが戻ります。プロフィールのプレビューが開いている場合、Escape は先にそちらを閉じます。Tab は通常のページ順序で移動します。読者のアバターにポインターを合わせるかフォーカスすると標準のプロフィールプレビューが表示され、選択するとプロフィールを開きます。プロフィールのハンドルがない記録は、名前付きのリンクなしアバターになります。在席表示は付けません。小さい円の表示サイズは維持し、重ならない44pxの操作領域を用意します。長い一覧は折り返し、詳細パネルは画面内でスクロールできます。
