# プロバイダー読み込みの高速化

**機能ブランチ:** perf-production-provider-assets

## 本番バンドルの解決

別のエントリーポイントがインポートする場合も、ビルドにホストスクリプトのリテラル参照を含めます。登録済みゲートウェイとアダプターの静的ディレクトリは、独自の URL プレフィックスを生成されたバンドルに解決します。API バージョンは 0.6.22 になります。

## ホストの並行ダウンロード

認証済みの検出後、不変のホストバンドルを並行して先読みし、プロバイダーのインポートとマウントの順序は維持します。完了時や失敗時にリンクを削除し、有効なプロバイダーは再読み込みしません。外部、ソース、リビジョン付きモジュール URL の読み込み動作は維持します。

## 実行時の境界を維持

回帰テストでモジュールの同一性、認可、有効化とアンインストールの絞り込み、外部リソースの経路、マウント順序、後処理、再試行を検証します。非公開の応答や言語データに新しいキャッシュは追加しません。
