# 安定したモジュールナビゲーション

## SPA ナビゲーション中の再マウントを解消

モジュールページで、直接ページ読み込み用の共通マウントガードを使用するようにしました。ダッシュボードルーター経由の読み込みで二重マウントが発生せず、ナビゲーションコンポーネントの重複や後続の SPA ナビゲーションの不具合を防ぎます。

## ナビゲーション中のページスタイルを分離

ダッシュボードルーターは、移動先ページをマウントする前に前のページのスタイルを削除するようになりました。Meetings から Messages へ移動する際、会議固有のスタイルが構築中の Messages レイアウトを崩すことを防ぎます。
