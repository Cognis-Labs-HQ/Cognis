# レスポンシブなコンポーネント操作

**機能ブランチ:** feature-administration-control-layout

## 内容に合わせた管理画面の行

管理画面の操作部の余白を減らし、狭い行でも名前、翻訳された状態ラベル、バージョン情報を折り返します。展開中や無効な行でも、詳細を開く操作と電源スイッチは独立しています。

## キーボードとタッチ操作

コンポーネントのスイッチは翻訳された名前と見えるフォーカスを備えたネイティブのキーボード操作を維持します。スイッチと詳細を開く操作領域は高さ 44 ピクセル以上です。ヘルス表示とキーボード操作の説明はドイツ語、英語、インドネシア語、日本語に対応します。
