# Titel für neue Termine

**Feature-Zweig:** fix-calendar-new-event-title

## Klare Bezeichnung beim Anlegen

Popups für neue Kalendertermine tragen den Titel „Neuer Termin“. Englisch, Indonesisch und Japanisch verwenden entsprechende Übersetzungen. Beim Bearbeiten bleiben Titel und Bedienelemente erhalten.
