# Meeting-Chat-Avatare

**Feature Branch:** copilot/add-participant-avatars-scrollbar

## Teilnehmer-Avatare im Chat

Im Chatbereich der Meetings wird jetzt direkt unter dem Titel eine horizontal scrollbare Avatar-Leiste angezeigt. Ein Klick auf einen Teilnehmer-Avatar öffnet den privaten Chat des aktuellen Nutzers mit dieser Person, ohne die Meetings-Seite zu verlassen.

## Zurück zum Meeting-Chat

Sobald ein privater Chat über die Avatar-Leiste geöffnet wurde, erscheint ein Rückkehr-Button zum Meeting-Chat. Der zuletzt geladene Meeting-Chat bleibt auch nach dem Verlassen des Meetings aktiv.
