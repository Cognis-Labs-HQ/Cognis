# Notifikasi aktivitas mengikuti sosial

## Tombol mengikuti menampilkan aksi berhenti mengikuti

Tombol profil dalam status mengikuti kini berubah ke label berhenti mengikuti dan gaya batal saat diarahkan kursor, sehingga aksi destruktif lebih jelas sebelum diklik.

## Aktivitas mengikuti memakai kelas notifikasi Social

Aksi mengikuti kini mendaftarkan dan mengirim lewat kategori notifikasi Social sehingga penerima dapat menerima notifikasi aktivitas mengikuti melalui penyedia notifikasi yang dikonfigurasi.

## Inisial profil mengutamakan nama profil

Inisial untuk fallback avatar profil kini memakai nama tampilan profil sebelum nama pengguna dan dapat menampilkan satu huruf awal untuk nama satu kata.
