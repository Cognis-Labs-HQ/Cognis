# カレンダー返信

**Feature Branch:** feature-improve-calendar-event-response-messages

## 招待返信をより自然に

カレンダー通知は、招待、返信、リマインダー、キャンセルでより親しみやすい文面を使い、未回答の招待リンクを保持し、招待者または返信者を送信者として表示し、イベントポップアップで参加者の返信状態をまとめて表示し、ポップアップ表示中は参加者の返信を1分ごとに更新するようになりました。
