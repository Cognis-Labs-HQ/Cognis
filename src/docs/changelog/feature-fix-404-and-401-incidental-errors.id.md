# Perbaikan galat insidental

## Sumber daya bahasa yang andal

Teks autentikasi dua faktor SMTP dalam bahasa Jerman, Indonesia, dan Jepang kini lengkap sehingga permintaan lokal yang didukung tidak lagi gagal.

## Rute catatan perubahan bertitik

Rute dokumentasi kini menerima slug catatan perubahan yang valid dengan tanda titik pada nama host registry.

## Telemetri peramban terautentikasi

Pengiriman data kinerja peramban kini menyertakan token bearer aktif dan dilewati saat pengguna keluar.

## Pencarian pesan global yang andal

Impor klien API terautentikasi yang digunakan penyedia pencarian pesan global dipulihkan sehingga kegagalan penyedia tidak lagi berulang.
