# LDAP-Anmeldung prüfen

## Flexible Quellenauswahl

Benannte LDAP-Quellen bleiben oberhalb des Benutzernamens und passen sich an die verfügbare Breite an. Weitere Quellen sind über eine scrollbare Überlaufauswahl erreichbar.

## Echten Benutzer prüfen

Die LDAP-Einrichtung endet nun mit einer erforderlichen Prüfung von Benutzerzugangsdaten. Vor dem Speichern werden Verzeichnisidentität, Gruppen und die resultierende Cognis-Rolle angezeigt.
