# プロバイダー中立のフォーカス制御

## 宣言済み共同作業画面をフォーカス

安全なマニフェスト契約、段階フロー、Composer 管理の操作、同期オーバーレイをプロバイダーへの結合なしで追加しました。

## 共同作業ペインをフォーカス

フォーカス可能な Composer 要素に全画面アイコンが表示されるようになりました。アクティブなフォーカスセッションでは、発表者を追従したり、会議チャットやプロバイダーが作成するホワイトボードなどの宣言済みサーフェスへ直接切り替えたりできます。

## 移動可能な会議のピクチャーインピクチャー

フォーカスプロバイダーはピクチャーインピクチャーモードを宣言でき、サイズ変更可能な会議ペインを移動しながら他のダッシュボード内容を利用できます。

## 安定した主要ナビゲーション

主要ナビゲーションはアプリケーションが定めた順序を維持するようになりました。ページシェルを簡潔で安定した状態に保つため、ドラッグ操作とユーザー固有の並べ替えを削除しました。

## 外部コンポーネントのページ

外部モジュールは利用可能な SPA ページを明示的に公開できます。他のコンポーネントは提供元コードをインポートしたり Asset パスを推測したりせず、不変のモジュール UUID と安定したルート ID でページを要求できます。

## 組み込みページも Broker を使用

Cognis Dashboard と Study のページが、UUID に所有された安定したコンポーネントページ宣言を公開するようになりました。これにより組み込みページと外部ページは同じ要求および Focus Control 経路を使用します。

## 認証済みモジュール文字列

保護された Marketplace 文字列バンドルが認証済み API クライアントを使用するようになりました。モジュールドキュメントでは、ローカライズキーの単語区切りにアンダースコアやハイフンではなくピリオドを使うことも明記しました。

## おすすめを最新に維持

キャッシュ済み Marketplace 応答でもページ更新後に Cognis のおすすめが維持されるようになりました。モジュールページはマウント中、15秒ごとに Cognis をポーリングします。
