# プロバイダー中立のフォーカス制御

## 宣言済み共同作業画面をフォーカス

安全なマニフェスト契約、段階フロー、Composer 管理の操作、同期オーバーレイをプロバイダーへの結合なしで追加しました。

## 共同作業ペインをフォーカス

フォーカス可能な Composer 要素に全画面アイコンが表示されるようになりました。アクティブなフォーカスセッションでは、発表者を追従したり、会議チャットやプロバイダーが作成するホワイトボードなどの宣言済みサーフェスへ直接切り替えたりできます。

## 移動可能な会議のピクチャーインピクチャー

フォーカスプロバイダーはピクチャーインピクチャーモードを宣言でき、サイズ変更可能な会議ペインを移動しながら他のダッシュボード内容を利用できます。

## 安定した主要ナビゲーション

主要ナビゲーションはアプリケーションが定めた順序を維持するようになりました。ページシェルを簡潔で安定した状態に保つため、ドラッグ操作とユーザー固有の並べ替えを削除しました。

## 外部コンポーネントのページ

外部モジュールは利用可能な SPA ページを明示的に公開できます。他のコンポーネントは提供元コードをインポートしたり Asset パスを推測したりせず、不変のモジュール UUID と安定したルート ID でページを要求できます。

## 組み込みページも Broker を使用

Cognis Dashboard と Study のページが、UUID に所有された安定したコンポーネントページ宣言を公開するようになりました。これにより組み込みページと外部ページは同じ要求および Focus Control 経路を使用します。

## 認証済みモジュール文字列

保護された Marketplace 文字列バンドルが認証済み API クライアントを使用するようになりました。モジュールドキュメントでは、ローカライズキーの単語区切りにアンダースコアやハイフンではなくピリオドを使うことも明記しました。

## おすすめを最新に維持

キャッシュ済み Marketplace 応答でもページ更新後に Cognis のおすすめが維持されるようになりました。モジュールページはマウント中、15秒ごとに Cognis をポーリングします。

## バランスの取れたモジュールカード

モジュールグリッドで各カードの幅を広く確保し、ライフサイクル操作を均等な行に配置することで、一般的なデスクトップ幅でも操作項目が密集したり重なったりしないようにしました。

## ナビゲーションを常に五十音順に

モジュールやその他の UI プロバイダーが項目を追加するたびにダッシュボードのナビゲーション項目を並べ替え、更新後の順序からコンパクトナビゲーションドロワーを再描画するようにしました。

## 対象指定コンポーネントウィンドウ

コンポーネントページの検出だけでは UI をマウントしないようにしました。明示的かつユーザー操作中の Spawn Capability が、呼び出し元所有のステージ内にナビゲーション保護されたウィンドウを開き、中断時と各 SPA ルート切り替え前に自動クリーンアップされる破棄可能なハンドルを返します。

## 安定したユーザーメニュー

Cognis Shell がプロバイダーの読み込み時にユーザーメニューへの追加項目を調整し、外部ページとナビゲーションバーの同時更新によって生じた同じ移動先の重複項目を削除するようになりました。

## プライベートリポジトリのスキャン設定を検証して保持

Marketplace のソース設定は、再起動後もプライベートリポジトリのスキャン設定を保持するようになりました。有効化すると、保存前に設定済み PAT がプライベートリポジトリを一覧表示し、その内容を読み取れることを検証します。カタログ更新では、認証情報の不足、プライベートリポジトリへのアクセス拒否、内容へのアクセス拒否を、キャッシュ済みモジュールを破棄せずに報告します。

## コンポーネントページのエントリ評価を保護

コンポーネントページブローカーは、SPA ナビゲーションと同じ参照カウント式のインポートガードを通してプロバイダーのエントリモジュールを評価するようになりました。`mountWhenDirect(mount)` を呼び出すエントリモジュールは、インポート中にホストページを置き換えられません。ブローカーが要求されたウィンドウへコンポーネントをマウントする前にガードは解除されます。

## ミーティングの PiP ウィンドウを移動およびサイズ変更

Focus Control の PiP ペインは、再利用可能なフローティングウィンドウコントローラーを使用するようになりました。ミーティングペインはヘッダーからドラッグおよびサイズ変更でき、表示領域内に保たれ、閉じる際にすべての操作リソースを解放します。

## PiP サポートを読み込み、埋め込みクロームを非表示

ページエントリーホストは外部ページのマウント前にフローティングウィンドウ機能を登録するようになり、Jitsi Meet が移動可能なミーティング PiP を確実に作成できます。コンポーネントウィンドウ内のページコンポーザーは、入れ子のトップバー、ナビゲーション、言語・テーマ操作、フッター、設定読み込み、アカウント拡張を自動的に省略します。

## 非公開リポジトリ用 PAT 権限を説明

モジュールソースの項目に、GitHub の fine-grained PAT と classic PAT の正確な要件を示す情報ツールチップを追加しました。外部モジュールの文書では、Resource owner、リポジトリ選択、Metadata と Contents の読み取り専用権限、承認と SSO の要件を示し、選択可能な GitHub Organization permission は不要であることを明記しました。

## スライダーのラベルとヘルプボタンを分離

Form Builder は情報ツールチップボタンを、入力に関連付けられたラベルの内側ではなく隣に表示するようになりました。非公開リポジトリのスライダーをクリックするとチェックボックスが切り替わり、隣の情報ボタンは独立したヘルプ操作として機能します。

## スライダー操作とソースフォームの均衡を復元

スライダーのトラックを明示的な入力ラベルにしたため、プライベートリポジトリのスイッチ上をクリックすると、隣接するヘルプを開かず確実にチェックボックスが切り替わります。モジュールソースのポップアップ項目も本来のグリッド幅に戻り、認証情報の操作欄が整列して均衡の取れた表示になります。

## 認証済み GitHub アカウント経由でプライベートリポジトリを検出

GitHub のプライベートソーススキャンは、組織のリポジトリ一覧と認証済みアカウントがアクセスできるプライベートリポジトリを統合し、設定された組織に結果を限定するようになりました。GitHub が組織一覧から省略した場合でも、きめ細かい PAT で選択済みのプライベートモジュールリポジトリを検出できます。

## Cognis でミーティング PiP 表示を提供

Cognis がミーティングプロバイダー用のフローティングウィンドウの完全なスタイルシートを所有して読み込むようになりました。ホワイトボードを有効にすると、ミーティングはコンポーネントキャンバスより前面に固定され、表示されたまま移動とサイズ変更ができる PiP になります。終了時にはミーティング要素の元のインラインレイアウトが復元されます。

## 枠なしコンポーネントウィンドウに対応

コンポーネントページの呼び出し元は、ウィンドウ外側の間隔を除去して親ステージ全体を使用する枠なし生成を要求できます。コンテンツ内部の間隔は引き続きプロバイダーが制御します。

## 枠なしキャンバスを全面表示しミーティング PiP を維持

枠なしコンポーネントウィンドウは Page Composer のワークスペースと外側コンテンツカードの間隔も除去するため、キャンバスが下端で切れず親の全辺まで広がります。フローティングミーティングウィンドウは描画範囲が制限されたコンポーネントステージを基準に座標を補正し、ステージの有効化を監視することでキャンバスより前面に PiP を維持します。
