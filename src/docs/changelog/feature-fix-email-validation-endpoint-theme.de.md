# E-Mail-Bestätigung im Design

## Cognis-Design und Bestätigungsanimation

Die Seite zur E-Mail-Bestätigung verwendet jetzt das gemeinsame Cognis-Design einschließlich der gespeicherten hellen oder dunklen Darstellung und der bevorzugten Anwendungsschrift. Eine kurze, einmalige Hakenanimation bestätigt den Erfolg und berücksichtigt Einstellungen für reduzierte Bewegung.
