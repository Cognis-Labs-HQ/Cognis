# エラーページへのライトモードサポート追加

## エラーページがライトモードに正しく対応

エラーページはダークモードとライトモードの両方で正しく表示されるようになりました。
アニメーショングラデーション見出しはすでにライトモード向けの明るいカラーパレットを
使用していましたが、今回の変更によって周囲のシェル要素もライトモードに対応しました。

シェルコンテナ（ワークスペースパネルと浮動フッター）は以前、ガラス効果のために
ハードコードされたダークネイビーの色調を使用していました。ライトモードでは
半透明の白い背景に切り替わり、明るいページグラデーション上に現れていた
くすんだグレーのオーバーレイが解消されます。

ナビゲーションとドロップダウンのホバー状態は、ライトモードで視認しやすいスレート色の
ハイライトを表示するようになりました。以前はホバー背景がほぼ見えないほど薄い白で、
インタラクティブな要素が平坦に見えていました。

ブラウザのテーマカラー（モバイルのアドレスバー）は、ユーザーがテーマを切り替えると
動的に更新されるようになり、ダークネイビーと明るい青白いページカラーの間で
切り替わります。
