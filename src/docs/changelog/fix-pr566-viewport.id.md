## Konten Desktop Tetap Terlihat

Tombol bilah alat seluler tetap tersembunyi di desktop meskipun gaya tombol bersama dimuat belakangan. Tombol ini tidak lagi menempati kolom konten atau mendorong konten halaman ke bawah bilah alat. Pada ponsel dan tablet, tombol panel mempertahankan area sentuh 44 piksel dan ikon di tengah.
