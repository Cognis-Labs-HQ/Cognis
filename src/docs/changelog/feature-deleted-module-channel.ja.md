# モジュールチャンネルの復旧

**機能ブランチ:** feature-deleted-module-channel

## カタログ内容の整合性を維持

カタログ更新でマニフェストとアセットを同じコミットに固定し、マージ済みブランチの削除によってモジュールと翻訳が分離する問題を防ぎます。 チャンネル一覧には40文字または64文字の完全な16進コミット ID が必要です。省略された ID はカタログ内容の読み取り前に拒否します。

## 削除された選択を復旧

削除されたチャンネルは現在の既定ブランチに切り替わります。有効な選択とインストール済みバージョンの来歴は維持されます。取得が不完全または形式不正の場合は以前の完全なカタログを維持し、再試行できます。 非公開リポジトリーのブランチ、リリース、マニフェストの読み取りが拒否された場合もアクセスエラーを表示し、キャッシュ内容と保存済みチャンネルを維持します。
