# Provider-Scoped SSO Names

**Feature Branch:** provider-scoped-sso-identities

## Distinct External Usernames

New external accounts and profile handles now include their provider namespace. For example, an X handle becomes `x:firehawksystems`, allowing it to coexist with `line:firehawksystems` and the local username `firehawksystems`.
