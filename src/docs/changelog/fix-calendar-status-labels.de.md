# Kalenderstatus übersetzen

**Feature-Zweig:** fix-calendar-status-labels

## Lokalisierter Ereignisstatus

Beim Erstellen und Bearbeiten von Terminen werden die vorhandenen Übersetzungen Belegt und Frei verwendet. Das Formular lässt sich in jeder unterstützten Sprache öffnen. Statuswerte und Einladungsantworten bleiben unverändert.
