# 安定した UI アセット読込

## アセットエラーのキャッシュを防止

Web プロキシと API は、見つからないフィンガープリント付き JavaScript および CSS の応答が不変アセットとしてキャッシュされないようになりました。デプロイの切り替えが重なっても、アセット URL の JSON 404 応答を保持せず、クライアントが正常に復旧できます。

## ログインページの描画を復旧

ページコンポーザーがすべてのレイアウト処理に要素レンダラーを渡すようになり、スタイルと内容の読み込みが完了する前にログインページが `renderElementContent is not defined` エラーで停止する問題を解消しました。

## 安定したコンテナ起動を復元

実績のある Docker ワークフローを復元しました。`setup.sh` がアプリケーション用と Web 用の環境ファイルを分離して生成し、Cognis のエントリポイントが設定検証、`DATABASE_URL` の生成、ライフサイクルイベントの記録、終了シグナルの転送を行います。確立済みのアプリケーション起動契約を変更せず、`cognis-web` イメージを独立したキャッシュおよび TLS 境界として引き続き利用できます。
