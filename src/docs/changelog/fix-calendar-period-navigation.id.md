# Periode Kalender Saat Ini

**Cabang Fitur:** fix-calendar-period-navigation

## Tandai Periode Saat Ini

Hari Ini, Minggu Ini, Bulan Ini, dan Tahun Ini ditandai aktif saat periode yang dipilih mencakup tanggal saat ini dalam zona waktu pengaturan. Status diperbarui pada tengah malam dan saat kembali ke halaman. Minggu kalender tetap dimulai pada hari Minggu.

## Ratakan Kontrol Bulanan

Tampilan bulan meratakan tombol penambahan acara dan menghapus kotak di sekitar angka tanggal. Pada tata letak sempit, tombol ditempatkan di bawah tanggal agar keduanya mudah digunakan.
