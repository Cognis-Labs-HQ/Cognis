# 明確な登録設定

**機能ブランチ:** registration-radio-layout

## 統一された登録ポリシー

管理画面の登録および招待ポリシーを、コンパクトな「はい」または「いいえ」のラジオグループで表示するようになりました。共通フォームコンポーザーと変更追跡機能により、値、保存、破棄を他の管理設定と一貫して扱います。
