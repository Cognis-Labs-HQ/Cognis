# Halaman Pengguna langsung diperbarui

**Cabang Fitur:** feature-fix-user-updates-not-reflecting-immediately

## Perubahan pengguna tampil tanpa memuat ulang halaman

Menghapus pengguna atau mengubah peran maupun status akun kini langsung memperbarui tabel Pengguna, bukan mempertahankan tabel lama hingga halaman dimuat ulang sepenuhnya.
