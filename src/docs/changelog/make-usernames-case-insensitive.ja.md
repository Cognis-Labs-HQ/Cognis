# ユーザー名とパスワードポリシー更新

**Feature Branch:** copilot/make-usernames-case-insensitive

## ユーザー名が大文字小文字を区別せず ASCII のみに

ユーザー名は登録・ログイン時に小文字に正規化されます。使用できるのは印刷可能な ASCII 文字のみで、最大 25 文字までです。無効なユーザー名は明確なエラーコードで拒否されます。

## パスワードポリシーを管理 → セキュリティで設定可能に

管理者は管理 → セキュリティでパスワードポリシーを設定できるようになりました。設定できる基準：最小文字数、大文字、小文字、数字、特殊文字。ポリシーは登録とパスワード変更の両方に適用されます。

## 登録・パスワードリセット時のリアルタイム条件チェック

登録時、パスワード欄に入力するとポリシー基準を満たしているかリアルタイムで表示されます。パスワードが一致しない場合、確認フィールドにリアルタイムでメッセージが表示されます。

## 再利用可能な条件チェックモジュール

`src/ui/reuse/criteria-check.js` の新しい `attachCriteriaCheck` 関数は、任意のフォームフィールドに柔軟でアクセシブルなリアルタイム検証を提供します。各条件に独自のエラーメッセージを設定でき、設定可能な汎用メッセージをフォールバックとして使用します。
