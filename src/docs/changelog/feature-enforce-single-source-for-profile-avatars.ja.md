# 一貫したプロフィールアバター

**Feature Branch:** feature-enforce-single-source-for-profile-avatars

## プロフィールが所有する単一のアバター情報源

プロフィールアバターの読み込み、代替表示、イニシャル生成、イニシャルの色は、プロフィールアダプターの UI CTX ケイパビリティから提供されるようになりました。UI の呼び出し元はコアの reuse にプロフィール抽象化を導入せず、CTX を介してアダプターのコントリビューションを直接参照するため、どの画面でも同じ名前から同じアバターが生成されます。

## 残りの利用箇所を監査

メッセージ、カレンダー、Jitsi Meet、Nextcloud Whiteboard、共有、プレゼンス表示、教室アバターは、CTX ケイパビリティのみを介してプロフィールアダプターを利用するようになりました。旧 Social ゲートウェイの再エクスポートを削除し、新たなイニシャル実装、プロフィールファイルの直接取得、旧プロバイダーのインポートを回帰テストで防止します。

## Study でもナビゲーションバーのアバターを維持

プロフィールのナビゲーションバープラグインは、レイアウト状態をインポートせず UI CTX を介してアバタープロバイダーを提供するようになりました。ダッシュボードシェルの再利用時も、プラグインの読み込み中は解決済みのアバターを維持するため、Study のサブページ間を移動してもプロフィール画像が一時的に置き換わりません。

## ルーム表示前にプロフィールアバター機能を読み込み

メッセージページを直接開いた場合でも、登録済みのナビゲーション拡張を待つようになりました。これにより、アバターやイニシャルを含むルームを表示する前にプロフィールアバター capability が利用可能になります。

## Study 教室でプロフィール UI コンテキストを正しく参照

教室ページが UI コンテキストを実行可能なモジュールコードとしてインポートするようになり、教師や使用中の座席のイニシャルを未定義変数エラーなしで表示できます。
