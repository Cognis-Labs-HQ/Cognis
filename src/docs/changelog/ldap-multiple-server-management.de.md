# Mehrere LDAP-Server

## Mehrere Verzeichnisse verwalten

Administratoren können benannte LDAP-Server auf einer LDAP-Konfigurationsseite speichern, bearbeiten, löschen und neu anordnen.

## Darstellung bei der Anmeldung wählen

LDAP-Quellen können einzeln auf der Anmeldeseite erscheinen oder zu einer LDAP-Quelle vereinigt werden, die Server in der festgelegten Reihenfolge prüft.

## Mitgliedschaft erzwingen

Wenn eine LDAP-Gruppe der Benutzerrolle zugeordnet ist, wird eine erfolgreiche Anmeldung nur für Mitglieder dieser Gruppe akzeptiert.
