# 構成可能なログ出力

## コンソールとファイルで独立したログレベル

管理者は、ロギングゲートウェイが定義する対応レベルから、コンソールログとファイルログに別々の重大度しきい値を選択できるようになりました。

## 環境設定へリセットできる実行時上書き

ロギングアダプターは、コンソール形式やローテーションなどの Docker 環境値を実行時に上書きし、環境設定へリセットできます。ログファイルのパスは引き続き環境が管理します。上書きはデータベースに保存され、コンテナの再起動後に復元されます。

## 常時有効なアダプターの設定

Console Logging と File Logging の行は、無効化できない必須アダプターであっても設定ポップアップを開くようになりました。

## 同期されたライブ出力

設定した重大度と形式が、その後に読み込まれるすべてのゲートウェイで初期ブートストラップロガーを置き換えるため、Docker 出力へコンソールの変更が即座に反映されます。環境値の上書き警告は、各フィールド見出しの横にオレンジ色で表示されます。

## より明確な設定ラベル

上書き警告は「環境変数を上書きしています」と表示され、ファイルアダプターの圧縮オプション名は「Log Compression」になりました。

## アダプター所有の検証済み設定

コンソールおよびファイルアダプターが設定の検証とロガーへの変換を所有するようになりました。ファイル設定の上書きは、安全でないローテーションサイズや保持数を適用前に拒否します。

## 翻訳されたログ設定

設定項目のラベルはアダプター所有のドイツ語、英語、インドネシア語、日本語リソースを使用し、管理画面は設定フォームの表示前にそれらを読み込みます。

## 依存関係を考慮したゲートウェイ起動

ゲートウェイのブートストラップは優先順位より先に宣言済みの依存関係を適用し、データベース保存されたログ設定をロギングゲートウェイの起動前に利用できるようになりました。
