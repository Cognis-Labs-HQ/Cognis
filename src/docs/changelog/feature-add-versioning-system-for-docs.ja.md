# 閲覧可能な Docs 履歴

**Feature Branch:** feature-add-versioning-system-for-docs

## バージョン付きドキュメントのスナップショット

Cognis は起動時に、各コンポーネントの manifest に記載されたバージョンを使ってドキュメントを保存するようになりました。ドキュメント URL では既定で特別な `latest` バージョンを使用し、以前のスナップショットも引き続き参照できます。

ドキュメントまたは changelog の索引が利用できない場合や不正な場合でも、ページの読み込みに失敗しないようになりました。

ローカル開発では現在のユーザーの Cognis ディレクトリにスナップショットを保存し、パッケージ版サーバーにはルートドキュメントのバージョン管理に必要なプラットフォーム manifest を含めるようになりました。実行時の構成がソースツリーと異なる場合に Docs API が `400` を返す問題を防ぎます。

## バージョンブラウザー

ドキュメントのタイトル上部に横スクロール可能なバージョンバーを表示し、最新および過去の内容を切り替えられるようになりました。

## 削除された文書も引き続き利用可能

ソースファイルが名前変更または削除された後も、アーカイブ済みの文書がドキュメント索引に表示され、保存されたすべてのバージョンを引き続き閲覧できます。
