# Vereinfachte Benutzerrollen-Badges

## Hover-Tooltip-Bubbles bei Rollen-Badges entfernt

Rollen-Badges auf Profil-Avataren und Benutzerkarten zeigen keine nativen Hover-Tooltip-Bubbles mehr. Dadurch gibt es weniger visuelle Ablenkung beim Erkennen von Rollen.

## Rollen-Semantik ohne Hover-Hinweise beibehalten

Die Rollen-Badges nutzen weiterhin Accessibility-Labels, aber ohne Tooltip-Affordance, damit das Rollen-Symbol klar und unüberdeckt sichtbar bleibt.
