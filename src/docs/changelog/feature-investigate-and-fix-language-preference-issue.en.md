# Language Preferences Fix

**Feature Branch:** feature-investigate-and-fix-language-preference-issue

## Dragging Languages Is More Reliable

The Settings language preference tables now resolve drop targets from pointer coordinates when the browser reports a nearby child or surrounding element as the drop target. This makes moving a language from Available Languages to Preferred Languages complete on the first drop more consistently.
