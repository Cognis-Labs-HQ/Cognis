# 読み取り結果の取得元

**機能ブランチ:** feature-read-response-provenance

## クライアント側の取得元を識別

コンポーネントが宣言し、読み取りキャッシュで処理されるセッション GET 応答の `x-cognis-read-source` は、通信を開始した呼び出しに `live`、その進行中の読み取りに合流した呼び出しに `shared`、保存済みまたは復元された結果に `cached` を示します。後の新しい読み取りは、ペイロードが同一でも `live` です。キャッシュの利用側も、戻り値を変更せずに任意の `onSource` コールバックで成功した読み取りの取得元を受け取れます。

## 既存の読み取り境界を維持

これらの値はクライアント側の読み取り結果を表し、サーバーのリビジョン、データの最新性の保証、認可の判断を表しません。既存の所有者、アカウント・セッション、アクセスの確認は引き続き適用されます。応答ペイロード、キャッシュの実行タイミング、キャッシュを経由しない読み取りやエラーの動作は、追加の取得元表示を除いて変更しません。所有者の中断時にはスナップショットを解放し、進行中の読み取りが結果を公開しないようにします。

未宣言のリクエスト、ゲストの認証情報、明示的な Authorization ヘッダー、`bufferOffline: false` による読み取りでは、元の Response を変更せずに返します。ステータスが 0 のエラー応答や不透明な Response も、追加の取得元表示なしでそのまま返します。管理対象の HTTP エラーを共有する各呼び出しは、独立して読める本文ストリームを受け取ります。
