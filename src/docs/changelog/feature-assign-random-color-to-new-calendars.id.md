# Warna beragam untuk kalender baru

**Feature Branch:** feature-assign-random-color-to-new-calendars

## Kalender baru dimulai dengan warna acak

Kalender baru kini menerima warna yang dipilih secara acak dari palet Kalender, bukan selalu dimulai dengan warna biru. Dialog pembuatan menampilkan warna yang dipilih sebelum disimpan dan tetap memungkinkan warna tersebut diubah.
