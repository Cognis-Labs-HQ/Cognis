# Modul-Laufzeitzugriff

**Feature-Zweig:** feature-allow-importing-cognis-internals-via-privileged-flag

## Cognis-Laufzeitressourcen erlauben

Die Modulaktivierung lehnt gewöhnliche Importe offengelegter Cognis-Browserressourcen, direkte API-URLs oder gemeinsame Stilklassen nicht mehr ab. Betriebliche Aktivierungsprüfungen werden weiterhin ausgeführt, während sicherheitsrelevante Routen- und Fähigkeitsregistrierungen weiterhin das Manifest-Flag `privileged` erfordern.
