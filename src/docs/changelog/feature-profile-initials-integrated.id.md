# Inisial Profil Seragam

**Cabang Fitur:** feature-profile-initials-integrated

## Seragamkan Tampilan Avatar

Navigasi, pratinjau, dan kepala Profile kini memakai aturan inisial, warna, dan ukuran eksplisit milik Profile. Setelah kesalahan gambar, gambar yang dipertahankan menampilkan inisial nama terbaru yang diotorisasi. Avatar pratinjau menautkan profil tanpa membuka ulang pratinjau.

## Tingkatkan Aset Yang Sesuai

Profile 4.0.0 membutuhkan kontrak penyedia navigasi kerangka yang sesuai. Terbitkan keduanya bersama. Penyedia menghasilkan konten secara sinkron, sementara kerangka mempertahankan tombol, menu, dan ketersediaan. Opsi renderer avatar khusus yang ada tetap tersedia. Batas teruji Messages dan Calendar meningkat ke 4.0.0; kompatibilitas modul eksternal dan tata letak browser native belum diverifikasi.
