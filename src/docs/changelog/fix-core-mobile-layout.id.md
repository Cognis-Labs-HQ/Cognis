# Tata Letak Inti Seluler

**Cabang Fitur:** fix-core-mobile-layout

## Kontrol Bersama yang Ringkas

Header ponsel memakai dua baris. Tombol bilah alat bergulir di belakang header, kontrol tutorial tetap ringkas, dan sasaran yang disorot lebih jelas. Penjelasan dapat memakai ruang header pada layar pendek; preferensi font dan sasaran sentuh tetap dapat digunakan.

## Halaman Bawaan yang Terbaca

Administrasi memisahkan nama gateway dari kontrolnya. Kode kesalahan muat dalam kolom konten. Tampilan bulan dan minggu kalender bergulir horizontal dengan kontrol hari yang terbaca, sedangkan tampilan tahun muat dalam kolom sempit. Halaman modul eksternal dikecualikan.
