Page composer kini membangun ulang konten halaman secara bawaan agar DOM yang diparkir tidak menutupi data yang diperbarui pengguna. Halaman dapat mengaktifkan parkir secara eksplisit untuk media berstatus.

Halaman Jitsi Meet tersemat mengaktifkan parkir DOM penuh agar iframe berstatusnya bertahan selama penyegaran tata letak composer tanpa menyambung ulang.
