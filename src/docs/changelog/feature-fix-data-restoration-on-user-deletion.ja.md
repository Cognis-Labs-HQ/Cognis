# 安全なアカウント削除

## 削除済みアカウントの活動を消去

ユーザーを削除すると、メッセージのメンバー情報と在席情報、フォロー関係と投稿、教室の記録、カレンダーデータ、会議への参加情報が完全に削除されるようになりました。同じユーザー名を再作成しても、削除したアカウントの非公開活動は復元されません。

## カレンダーを確実に消去

アカウントを削除すると、ユーザーのカレンダーと予定が永続ストレージと稼働中のカレンダーサービスの両方から削除されるようになりました。また、グローバルなファイルサイズ設定をユーザー所有の設定として誤って削除しないため、成功したアカウント削除が不正なリクエストとして報告されることもありません。

## 会話と通知を安全に消去

削除されたユーザーは、グループ会話を暗黙に削除するのではなく、表示可能な退出イベントを残して退室するようになりました。残りのメンバーが1人になるとチャットは自動的にアーカイブされ、誰も残らない場合は完全に削除されます。再作成されたアカウントでは既存の1対1の会話を再利用して重複を防ぎ、アカウント削除時にはアプリ内通知もすべて消去されます。
