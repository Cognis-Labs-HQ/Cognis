# 安全なアカウント削除

**Feature Branch:** feature-fix-data-restoration-on-user-deletion

## 削除済みアカウントの活動を消去

ユーザーを削除すると、メッセージのメンバー情報と在席情報、フォロー関係と投稿、教室の記録、カレンダーデータ、会議への参加情報が完全に削除されるようになりました。同じユーザー名を再作成しても、削除したアカウントの非公開活動は復元されません。

## カレンダーを確実に消去

アカウントを削除すると、ユーザーのカレンダーと予定が永続ストレージと稼働中のカレンダーサービスの両方から削除されるようになりました。また、グローバルなファイルサイズ設定をユーザー所有の設定として誤って削除しないため、成功したアカウント削除が不正なリクエストとして報告されることもありません。

## 会話と通知を安全に消去

削除されたユーザーは、グループ会話を暗黙に削除するのではなく、表示可能な退出イベントを残して退室するようになりました。残りのメンバーが1人になるとチャットは自動的にアーカイブされ、誰も残らない場合は完全に削除されます。同じユーザー名を使用していても、新しく作成されたアカウントが削除済みアカウントの1対1の会話へ再びアクセスすることはありません。現在の両アカウントがメンバーである会話だけを照合して、重複する有効な会話を防ぎます。アカウント削除時にはアプリ内通知もすべて消去されます。

## メッセージリクエストを明確に分離

同じ保留中の会話を繰り返し開始しても、リクエスト通知が重複して送信されなくなりました。また、処理中はクライアントが重複送信を防ぎます。リクエスト通知には専用の「メッセージリクエスト」カテゴリが使用され、保留中のリクエストは会話と混在せず、メッセージのサイドバーに専用の見出しで表示されます。

## 拒否したリクエストを安全に閉じる

メッセージリクエストを拒否すると、退出したばかりのルームの暗号化キーを読み込まず、そのルームから別の画面へ移動するようになりました。拒否されたルームには通常のチャットライフサイクルが適用され、残ったリクエスト送信者向けにアーカイブされるか、空の場合は削除されます。
