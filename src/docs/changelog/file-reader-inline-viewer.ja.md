# インラインビューアとチャット

## 授業教材がアジェンダタイル内に表示される

選択した授業教材がアジェンダタイル内で直接開いて表示されるようになりました。テキストおよびMarkdownファイルはフル書式でレンダリングされます。画像は教師が操作できるパン・ズームコントロール付きで表示され、生徒はリアルタイムで教師の画面を追従します。

## ファイルリーダーゲートウェイとアダプター

新しいファイルリーダーゲートウェイは、プラグイン可能なファイルレンダリングアーキテクチャを提供します。テキストアダプター（旧スタディノートパッドアダプター）はMarkdownとプレーンテキストを処理します。新しい画像アダプターは、ポインターイベントベースのパン・ズームビューアで画像形式を処理し、教師のビューポートをクラスルームレイアウトAPIを通じて生徒にブロードキャストします。

## CTX経由のアプリ全体のファイルタイプレジストリ

`src/ui/reuse/file-reader.js`は`registerFileType`、`canRender`、`renderFileContent`、`showUnsupportedToast`を公開します。アダプターはブートストラップ時にサポートするファイルタイプを登録します。非対応タイプを開こうとするとトースト通知が表示されます。

## 生徒はいつでもチャットタイルを開ける

生徒のインタラクションロックがチャットタイルをブロックしなくなりました。生徒は教師の状態に関わらず、いつでもクラスチャットに切り替えることができます。

## クラスチャットがメッセージスタイル設定を尊重する

ネイティブのクラスルームチャットパネルが、メッセージページと同様に、ユーザーが設定したメッセージスタイル（吹き出しやIRCスタイルなど）を適用するようになりました。
