# Beberapa Server LDAP

## Kelola beberapa direktori

Administrator dapat menyimpan, mengubah, menghapus, dan mengurutkan ulang server LDAP bernama dari satu halaman utama konfigurasi LDAP.

## Pilih tampilan masuk

Sumber LDAP dapat tampil secara terpisah pada halaman Masuk atau disatukan sebagai satu sumber LDAP yang mencoba server sesuai urutan konfigurasi.

## Terapkan keanggotaan grup

Saat grup LDAP dipetakan ke peran pengguna, autentikasi yang berhasil hanya diterima bagi anggota grup tersebut.
