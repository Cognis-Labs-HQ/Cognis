# アダプター操作の整理

**Feature Branch:** feature-remove-config-popup-from-adapters

## 空の設定ポップアップを削除

電源状態以外に設定可能な項目がないアダプターでは、設定ポップアップが開かなくなりました。この行をクリックするとマニフェスト詳細が展開され、行の電源コントロールでアダプターを有効化または無効化できます。

## LDAP 電源コントロール

LDAP 認証の設定ポップアップに電源コントロールを追加し、管理者が設定画面を離れずにアダプターを有効化または無効化できるようになりました。

## コンポーネント制御の同期

管理画面では有効なコンポーネントの表記を統一し、ロックされた設定スイッチを無効化しました。電源状態の変更後にコンポーネントのヘルス状態とナビゲーションを更新し、設定のないアダプターではマニフェスト詳細を表示し、Share の方式を無効化できるようにしました。Authenticator App の既定アルゴリズムは SHA-256 です。アダプター設定のタイトルにはマニフェストのバージョンを重複表示しません。

## Shareアダプター状態の永続化

無効にしたShareアダプターはサーバー再起動後も無効のまま維持されます。アダプターが無効な間は、発行済みの共有も解決されません。
