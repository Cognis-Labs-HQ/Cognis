# モジュール設定ガイダンス

**機能ブランチ:** module-activation-guidance

## 有効化後の明確な手順

モジュールは、1 つ以上のアダプター対象を含むローカライズ済みの有効化ガイダンスを宣言できるようになりました。有効化後、Cognis はモジュールの次の手順を表示し、Core がプロバイダー固有の名前を認識することなく管理画面へ直接移動する選択肢を提示します。
