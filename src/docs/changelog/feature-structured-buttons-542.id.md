# Gaya Tombol Terstruktur

**Cabang Fitur:** feature-structured-buttons-542

## Kontrol Netral Bersama

Tombol terstruktur bawaan dan netral kini menerima kelas netral baku, termasuk gaya bersama untuk pembungkusan teks, fon, dan ukuran perangkat penunjuk kasar. Varian konfirmasi dan bahaya mempertahankan kelas masing-masing serta semua atribut bawaan.

## Cakupan dan Kontrak

Pengujian renderer publik dan Administrasi sintetis mencakup varian, escaping, status nonaktif, perenderan berulang, dan keamanan formulir. Dokumentasi UI menjelaskan kontrak dalam keempat bahasa; langkah tutorial yang ada tidak berubah. Ini merupakan bagian terbatas dari #542, bukan penyelesaian seluruh audit tombol.
