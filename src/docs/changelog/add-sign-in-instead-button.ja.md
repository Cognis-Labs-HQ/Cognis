# 登録画面のサインイン導線

**Feature Branch:** copilot/add-sign-in-instead-button

## 「代わりにサインイン」操作を追加

登録ページに「代わりにサインイン」ボタンを追加し、ユーザーが `/login` へ直接戻れるようにしました。登録を完了せずにログイン導線へ素早く戻れます。

## 登録ボタンの表記を統一

同じページ内での表記ルールをそろえるため、登録送信ラベルを Title Case の「Create Account」に統一しました。
