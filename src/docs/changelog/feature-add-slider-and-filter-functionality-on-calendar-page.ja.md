# カレンダーを素早く確認

## 今後の予定を絞り込み

「今後の予定」にカレンダーの色付きドットを横並びで表示するようにしました。ドットにポインターを合わせるとカレンダー名が表示され、選択すると一覧がすぐに絞り込まれ、キャンセルボタンで解除できます。

コンパクトなドット一覧は、カレンダーを作成するとすぐに更新されます。上に重ねる解除ボタン用の領域を確保することで、サイドメニューの幅が変わらないようにしました。

カレンダー専用のサイズ指定により、ドットと解除操作がツールバー内で全幅のメニューボタン表示を継承せず、コンパクトに保たれます。

## 現在をすぐに表示

日表示と週表示は現在時刻付近を自動表示し、月表示と年表示では今日の日付と現在の月を青色で強調します。

強調された日には「今日」のツールチップを表示し、年表示で予定がある日にポインターを合わせると予定名を一覧表示します。

## カレンダー配置を固定

専用のカレンダー配置を維持するため、カレンダーページのレイアウト編集を無効にしました。
