# 共有エラーを共有ページに表示

**機能ブランチ:** `work`

## セッション期限切れではなく共有アクセスエラーを表示

共有されたミーティングコンテンツの表示中に発生したアクセスエラーは、アカウントセッション期限切れ監視が応答する前に共有ゲートウェイが処理するようになりました。ホストがミーティングを終了した場合や共有リソースが利用できなくなった場合、ゲストはアカウントセッションの復旧処理によってリダイレクトされず、適切な共有エラーを確認できます。

## 削除されたミーティング共有を404へリダイレクト

ミーティングのクリーンアップによってアクティブな共有が削除された場合、共有ステータス監視はポーリングを停止し、削除済みの共有を再度解決しようとせず、ゲストを公開404ページへ直接移動させるようになりました。
