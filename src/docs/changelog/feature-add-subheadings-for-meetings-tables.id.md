# Subjudul tabel rapat administrasi

**Cabang Fitur:** feature-add-subheadings-for-meetings-tables

## Bagian rapat aktif dan mendatang lebih jelas

Tampilan Administration → Meetings kini menambahkan subjudul eksplisit di atas tabel Jitsi Meet aktif dan mendatang sehingga administrator dapat membedakan aktivitas rapat langsung dari rapat terjadwal dengan lebih cepat.

## Detail rapat mendatang yang seimbang

Baris rapat mendatang kini menjaga kolom ID tetap ringkas sambil menyeimbangkan kolom detail lainnya, menampilkan nama tampilan pembuat beserta tanggal pembuatan di bidang Dibuat Oleh, dan menamai kolom terakhir Tanggal Jadwal agar mencerminkan waktu mulai rapat yang dijadwalkan.

## Tampilan kolom URL rapat

Kolom rapat kini memakai label URL Rapat dan menampilkan URL sebenarnya, sementara kolom ID tetap ringkas agar hanya memakai lebar yang dibutuhkan.
