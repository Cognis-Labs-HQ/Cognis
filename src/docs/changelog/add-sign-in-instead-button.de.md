# Anmelden statt Registrieren

## Direkte Aktion „Stattdessen anmelden" hinzugefügt

Die Registrierungsseite enthält jetzt eine eigene Schaltfläche „Stattdessen anmelden", die Benutzer direkt zu `/login` führt. So können Benutzer schnell zur Anmeldung zurückkehren, ohne die Registrierung abzuschließen.

## Einheitliche Großschreibung beim Registrieren-Button

Die Beschriftung des Registrierungs-Buttons verwendet nun die einheitliche Schreibweise „Create Account“, damit sie auf derselben Seite zur Stilführung von „Stattdessen anmelden“ passt.
