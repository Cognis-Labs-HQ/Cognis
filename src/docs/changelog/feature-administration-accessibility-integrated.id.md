# Nama Kontrol Administrasi

**Cabang Fitur:** feature-administration-accessibility-integrated

## Hubungkan label Keamanan

Batas waktu sesi, mode validasi, dan kontrol persetujuan memakai label terjemahan yang terlihat. Pemilih Satuan memiliki label sendiri dan tetap memakai judul durasi sebagai konteks. Tombol informasi tetap terpisah dari aktivasi kotak centang.

## Ekspos sakelar asli

Input sakelar Administrasi tetap berupa kotak centang asli dengan status tercentang dan nonaktif. Input transparan tetap dapat menerima fokus, dan penggeser yang terlihat memiliki garis fokus. Ukuran baris komponen, kontrol terlindungi, label Siaran, serta perilaku draf dalam memori dan Buang tetap dipertahankan.

## Periksa kontrol hasil render

Pengujian perender publik mencakup keempat bahasa, render berulang, penggunaan bahasa Inggris pengganti yang ketat, dan kedua urutan gaya. Langkah dan target tutorial yang ada tidak berubah. Pemeriksaan DOM dan CSS tidak menggantikan verifikasi papan ketik asli, pembaca layar, atau perangkat.
