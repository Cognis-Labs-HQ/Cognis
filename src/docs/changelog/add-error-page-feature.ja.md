# エラーページ

**Feature Branch:** copilot/add-error-page-feature

## アニメーショングラデーション見出し付きのエラーページ

専用の `/error` ページが追加されました。`?code=` クエリパラメーターを付けて
直接アクセスすることも（例: `/error?code=404`）、認識されない URL に移動した
際に自動的に表示されることもあります。

ページにはグローバルナビゲーションバーと同じ teal-to-navy のカラーブレンドを
使用した、流れるようなアニメーショングラデーションの大きなエラーコード見出しが
表示されます。見出しの下には一般ユーザー向けのエラー説明と、ダッシュボードに
戻るボタンが配置されています。

ログイン済みのユーザーにはナビゲーションバー・トップバー・フッターを含む
完全なダッシュボードシェル内に表示されます。未ログインのユーザーにはシェルを
持たないフルスクリーンメッセージとして表示されます。見出しはレスポンシブに
スケーリングされ、小さな画面でも読みやすくなっています。
