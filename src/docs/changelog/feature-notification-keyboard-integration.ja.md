# 通知のキーボード操作

**機能ブランチ:** feature-notification-keyboard-integration

## 通知のリンク先を開く

受信トレイの行と新着ポップアップに、名前とフォーカス表示を備えた標準のリンクまたはボタンを追加しました。コマンドと閉じる操作は独立しています。リンクのない新着通知を開いても受信トレイは閉じません。

## 移動処理の所有権を維持

内部通知 0.5.37 は修飾キー付きクリックと中央クリックの標準動作、キャンセル可能な通知移動、確認済みの既読応答、現在のアカウントとプロバイダーの有効期間を維持します。未対応の URL スキームは有効なリンクにしません。4 言語のガイドと公開プロバイダー経由の回帰テストを更新しました。
