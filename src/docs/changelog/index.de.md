# Changelog

## Überblick

Dieses Verzeichnis enthält Changelog-Einträge als eine Markdown-Datei pro Pull
Request. Jede Datei beschreibt genau einen PR, damit die Änderungshistorie
modular und gut prüfbar bleibt.

## Eintragsformat

- Dateiname: `<branch-name-without-copilot-prefix>.de.md` (z. B. Branch
  `copilot/fix-auth-bug` wird zu `fix-auth-bug.de.md`)
- Eine Datei pro PR
- Enthält:
    - PR-Titel
    - Zusammenfassung
    - Geänderte Komponenten/Dateien
    - Commit-Links
