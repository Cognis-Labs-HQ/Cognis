# オフラインナビゲーション

**機能ブランチ:** feature-offline-navigation

## オフライン対応の契約

本番ビルドは中立的な復旧ページを準備します。ライセンスとエラーページはオフラインで動作し、利用できないルートのリンクは無効になります。利用できないページへの直接移動ではエラーポップアップを表示しません。ブラウザーが接続中と表示していても、実際のサーバー接続失敗で代替動作を開始します。

SPA ルートで `public: true` と `offline: { assets: [...] }` を宣言してください。言語カタログとデータファイルを含むすべての公開実行時依存関係を列挙します。API 要求、非公開のアカウントデータ、ホスト全体のプロバイダー検出なしで動作する必要があります。非公開ルートは対応を宣言できません。移動にはルートリンクを使用してください。未知または未取得の依存関係は利用できません。

Service Worker は API 応答、認証情報、認証済み HTML を保存しません。モジュールの無効化で公開ルートカタログとモジュールアセットを削除し、リビジョン付きアセットは現在のカタログと一致する必要があります。切断中はリモートの変更を検知できず、最後に確認した公開リビジョンのみ利用できます。復旧時はカタログを更新し、未保存の変更を確認して再読み込みし、最新のサーバー認可に戻ります。Worker の更新は既存タブが閉じるまで待機し、復旧アセットを準備してから有効になります。Worker が未導入の初回アクセスではオフライン起動できません。

## リマインダーの選択

標準のチェックボックスで複数のリマインダーを選択し、まとめて保存できます。すべての選択を解除すると、カレンダーに既定値があってもリマインダーは無効になります。既存の独自の通知間隔も編集時に保持されます。

## オフライン学習

設定のオフラインモードは既定で有効です。無効にすると従来の接続警告とエラー通知に戻り、ワーカーの代替表示を停止します。有効な場合は接続が切れるとエラー通知なしでオフラインモードに切り替わり、利用できない移動はエラーポップアップを出さずに制限します。

Study は現在のタブ内に容量制限付きの軽量 JSON スナップショットを保持します。対象はスキーマ、許可された文字・カードデータ、保存先、閲覧済み ID、お気に入り、以前開いたデッキです。言語スキーマは `metadata.offline: { cache: "lightweight" }` で対応を宣言します。Library キャッシュは最大 16 MB・100 件、その他の読み取りキャッシュは最大 4 MB・100 件です。音声バイト、辞書応答、認証情報、認証済み文書は永続保存しません。

Explore のプレビューは認可済みのキャッシュ行から関係を解決します。描画は新しいガイドでローカル動作し、フラッシュカード練習もローカルで進められます。音声、辞書、ElevenLabs への要求は停止し、オフライン練習では進捗、XP、報酬、お気に入り、編集を保存しません。以前読み込んだ、容量制限内のコンテンツだけが利用でき、不足する依存データは利用できません。

非公開の Study では、同じタブ内で以前検証済みの、有効期限内の同じアカウントセッションが必要です。再読み込みと初回訪問では引き続き公開ページ専用のオフライン契約が適用されます。アカウント・セッション、設定、モジュールの状態が変わるか、プロバイダーが破棄されると非公開スナップショットを無効化します。切断中はサーバーでのアクセス取り消しを検知できません。復旧時には未保存変更を確認してから再読み込みし、サーバーの認可を更新します。
