# オフラインナビゲーション

**機能ブランチ:** feature-offline-navigation

## オフライン対応の契約

本番ビルドは中立的な復旧ページを準備します。ライセンスとエラーページはオフラインで動作し、利用できないルートのリンクは無効になります。直接移動すると実行時エラーポップアップが開きます。ブラウザーが接続中と表示していても、実際のサーバー接続失敗で代替動作を開始します。

SPA ルートで `public: true` と `offline: { assets: [...] }` を宣言してください。言語カタログとデータファイルを含むすべての公開実行時依存関係を列挙します。API 要求、非公開のアカウントデータ、ホスト全体のプロバイダー検出なしで動作する必要があります。非公開ルートは対応を宣言できません。移動にはルートリンクを使用してください。未知または未取得の依存関係は利用できません。

API 応答、認証情報、認証済み HTML は保存しません。モジュールの無効化で公開ルートカタログとモジュールアセットを削除し、リビジョン付きアセットは現在のカタログと一致する必要があります。切断中はリモートの変更を検知できず、最後に確認した公開リビジョンのみ利用できます。復旧時はカタログを更新し、未保存の変更を確認して再読み込みし、最新のサーバー認可に戻ります。Worker の更新は既存タブが閉じるまで待機し、復旧アセットを準備してから有効になります。Worker が未導入の初回アクセスではオフライン起動できません。
