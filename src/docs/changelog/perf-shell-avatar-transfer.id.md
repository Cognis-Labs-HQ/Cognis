# Avatar Shell Lebih Ringan

**Cabang Fitur:** perf-shell-avatar-transfer

## Gunakan Gambar yang Dioptimalkan

Shell halaman bersama kini memakai gambar WebP yang tersedia untuk avatar akun sementara. Transfer gambar berkurang saat profil dimuat, sementara dimensi gambar, penggantian oleh penyedia profil, dan perilaku navigasi tetap terjaga.

## Lindungi Anggaran Gambar

Uji regresi rute memastikan avatar sementara mengarah ke gambar yang dapat disajikan dalam batas anggaran transfer. Autentikasi, data pribadi, aset modul, dan kebijakan cache tidak berubah.
