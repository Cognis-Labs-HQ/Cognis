# プロバイダー別 SSO 名

**機能ブランチ:** provider-scoped-sso-identities

## 区別できる外部ユーザー名

新しい外部アカウントとプロフィールハンドルにプロバイダーの名前空間が含まれるようになりました。たとえば X のハンドルは `x:firehawksystems` となり、`line:firehawksystems` やローカルユーザー名 `firehawksystems` と共存できます。
