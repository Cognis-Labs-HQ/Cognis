# TFA再送信の結果表示

**機能ブランチ:** feature-tfa-resend-integration

## 再送信の結果を説明

ログインの期限切れでは、やり直す方法を表示します。その他の拒否や不確かな結果では、何も表示せず再送信リンクに戻る代わりに、翻訳されたエラーを表示します。配信確認のない有効な応答では、メール送信済みと断定せず中立的な情報を表示します。

## 待機時間の管理を維持

サーバーの期限、処理中の操作ロック、明示的な再試行を維持します。不正な成功応答でも発行済みコードの制約を保持します。自動再送信、サーバーポリシーの変更、配信保証は追加しません。

## 結果の所有者を維持

アカウントやセッションが変わると、古い再送信操作と結果表示を停止します。必須の翻訳がない場合は、別のメッセージに置き換えずエラーを明示します。

## 古い画面のリソースを解放

ログイン画面を離れる、置き換える、キャンセルに成功する場合、保留中の要求を待たずに再送信リスナーとタイマーを直ちに解除します。キャンセルに失敗した場合は現在の画面を引き続き利用できます。UIの破棄は送信済み要求の効果の取り消しを保証しません。

## 中断した再送信から復帰

保留中の再送信には翻訳済みの処理中ラベルを表示します。キャンセルに失敗した場合は、自動再試行せず結果とサーバー期限の残り時間を反映します。Auth 2.2.14とTFA 1.3.14は同じバージョン付きブラウザー有効期間契約を必要とします。JavaScriptとアセットを同時に更新し、古いログインタブを再読み込みしてください。

## 再送信の確認を一度だけ表示

認証方法に戻ると、完了した各再送信の確認を一度だけ表示します。別の方法へ切り替えて再び戻っても、同じ確認は繰り返しません。
