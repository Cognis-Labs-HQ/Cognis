# Pintasan Masuk di Daftar

## Aksi Masuk saja langsung ditambahkan

Halaman pendaftaran sekarang memiliki tombol "Masuk saja" khusus yang langsung membawa pengguna ke `/login`. Ini memberi jalur cepat untuk kembali ke alur masuk tanpa menyelesaikan pendaftaran.

## Kapitalisasi Tombol Daftar Diseragamkan

Label tombol kirim pendaftaran kini memakai Title Case menjadi "Create Account" agar konsisten dengan gaya tombol "Sign In Instead" pada halaman yang sama.
