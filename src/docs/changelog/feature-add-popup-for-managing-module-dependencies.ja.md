# 外部モジュールの依存関係

## 依存関係を考慮したインストール

外部モジュールは、非推奨のハード依存関係と任意のソフト依存関係を宣言できます。インストール時にすべての依存関係を表示し、未充足のハード要件をブロックし、管理者が任意のオプションを選択して有効化できるようになりました。

## 信頼性の高い有効化とリリースチャンネル

モジュールの整合性警告をキャンセルすると、依存関係の有効化と必須設定フローも停止するようになりました。選択したリリースチャンネルはサーバーに保存され、インストール前でも再起動後に維持されます。

## 安全なシンボリックリンク整合性検証

モジュールの SHASUM 検証は、`AGENTS.md` から `.github/copilot-instructions.md` へのエイリアスを含め、モジュール内部のファイルを指すシンボリックリンクを追跡するようになりました。壊れたリンク、ディレクトリ、モジュール外の参照先は拒否します。

## 検証済みエイリアスとキャンセル通知

未宣言のシンボリックリンクエイリアスが、宣言済みで検証されたモジュールファイルを指す場合は SHASUM 警告を発生させなくなりました。インストールをキャンセルすると明確な通知が表示されます。

## インストールと有効化の依存関係カード

依存関係の確認画面に、必須、任意、推奨のラベルと詳細への直接リンクを備えた完全なモジュールカードを表示するようになりました。確認はインストールと有効化の前に実行され、すべての依存関係が有効な場合は省略されます。

## 一貫した依存関係コントロール

依存関係カードは、アプリで確立されたステータスピルの配色を再利用するようになりました。詳細ナビゲーションにはテキスト矢印ではなく、既存のテーマ対応 SVG シェブロンを使用します。

## 依存関係の即時有効化

未充足の各依存関係カードに、読み込み表示付きの SVG ダウンロードアクションを追加し、その依存関係をインストールして有効化できるようになりました。主操作はインストールまたは有効化を示し、必須依存関係が不足している間は無効、任意依存関係が残っている間はアプリのニュートラル操作となり、すべてが有効になると確認スタイルに切り替わります。

## 進行表示前の依存関係準備確認

インストールと有効化は、ライフサイクル操作が読み込み状態に入る前に、同じ完全な依存関係準備ゲートを実行するようになりました。依存関係ポップアップをキャンセルすると、モジュール操作のスピナーを残さず直ちに終了します。

## ハード依存関係の連鎖無効化

モジュールを無効化すると、そのモジュールをハード依存関係として宣言している有効なモジュールも再帰的に無効化されます。ソフト依存のモジュールは有効なままです。依存関係カードには、汎用の下向き矢印ではなくトレイ付きの専用ダウンロード SVG を使用します。

## テーマ対応の依存関係操作

依存関係のダウンロードと再生コントロールに、専用のライト／ダーク SVG アセットを使用するようになりました。インストール済みで無効な依存関係にはダウンロードではなく再生を表示し、ステータスピルの背景は維持しながらテキスト色を現在のテーマに合わせます。

## 両テーマで正しいアイコンコントラスト

依存関係のダウンロードと再生コントロールは、明るい表面では暗いアイコン、ダークモードでは明るいアイコンを使用し、どちらのテーマでも操作が見えるようになりました。

## 有効化前の依存関係設定

初期設定が必要な依存関係は、有効化を試みる前に依存関係マネージャーの上へ設定ダイアログを開くようになりました。有効な設定を保存すると、サーバー側の設定エラーに至ることなく有効化を続行できます。

## モジュール状態を復元

更新、強制更新、リリースチャンネル変更のための一時的な無効化で、更新対象モジュールと有効な必須依存モジュールの有効状態を保持するようになりました。実行中に更新できる場合は依存モジュールを再び有効にし、サーバーの再起動が必要な場合は起動時に同じ状態を復元します。

## 完全なマニフェスト型

標準モジュールマニフェスト契約に必須および任意の外部依存関係を追加し、TypeScript モジュールの作成者とコア利用側が安全でない型変換なしで依存関係メタデータを利用できるようになりました。

## 検証済みの依存関係復元

起動時と更新後の復元では、ハード依存関係または有効化検証に失敗したモジュールを無効のままにします。外部マニフェストの依存関係フィールドは、不正な値が管理画面に届く前に拒否します。
