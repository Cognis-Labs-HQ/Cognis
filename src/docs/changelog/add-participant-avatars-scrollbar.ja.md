# ミーティングチャットのアバター

**機能ブランチ:** copilot/add-participant-avatars-scrollbar

## 参加者アバターの横並び表示

Meetings のチャットパネルでは、Meeting Chat タイトルの直下に参加者アバターの横スクロールバーが表示されるようになりました。参加者アバターをクリックすると、Meetings ページを離れずにその参加者とのプライベートチャットを開けます。

## ミーティングチャットへ戻る

アバターからプライベートチャットを開いた場合、ミーティングチャットへ戻るボタンが表示されます。最後に読み込んだミーティングチャットは、ユーザーがミーティングを離れた後もアクティブなまま維持されます。
