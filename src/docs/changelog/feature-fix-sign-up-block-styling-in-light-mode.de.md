# Login-Hinweis verbessert

## Besserer Kontrast für den Registrierungs-Hinweis im hellen Modus

Der Registrierungs-Hinweis auf der Login-Seite nutzt im hellen Modus jetzt dunklere blaue Texte, eine klarere Symbolfarbe und einen kräftigeren hellblauen Hintergrund, damit Titel, Beschreibung und Registrierungslink gut lesbar bleiben.
