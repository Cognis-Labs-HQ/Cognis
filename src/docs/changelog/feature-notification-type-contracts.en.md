# Typed Delivery Contracts

**Feature Branch:** feature-notification-type-contracts

## Notify 2.2.10

Sender queue inspection is optional and typed by the Notify contract. Bootstrap loads the gateway-owned store directly and exposes its email and preference operations without partial constructor assertions. Broadcast validation returns validated roles and scheduling values before persistence.

## Internal 0.5.34

Internal delivery obtains the structured database executor through ctx. Its logging contract uses the supported bootstrap severity levels. Encryption, inbox authorization and always-on delivery remain unchanged.

## SMTP 0.5.3

SMTP queue entries retain their required subject through delivery and retries. TLS connection options carry the cancellation signal for direct TLS and STARTTLS; certificate policy, timeout handling and connection cleanup remain unchanged.
