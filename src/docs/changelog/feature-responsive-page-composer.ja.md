# 画面に適応する Cognis

**機能ブランチ:** feature-responsive-page-composer

## 画面に合わせた作業領域

コア画面は Page Composer を通じてスマートフォン、タブレット、デスクトップに対応します。カレンダーの予定一覧、読みやすい会話、学習カード、統一したサイドバーを含みます。

## 機能の確実な連携

オフラインの準備、プロバイダー契約、アカウントの境界、終了時の解放により、実装を密結合せずに有効なコンポーネントを連携させます。

## 構造化されたドキュメント

紹介、使用手順、技術契約を分離します。コアの各トピックはディレクトリのエントリーを使います。閲覧画面は完全なバージョン単位の三つの表示を切り替え、検証は構造、翻訳、マニフェスト、アセットの所有を確認します。 Markdown のセキュリティ回帰テストは、エスケープされた不正な HTML と保持された入れ子のコードフェンスを、エンコード済みの出力で直接検証します。 各表示は担当機能の具体的な作業、前提、確認できる結果、問題への対処を説明します。技術情報は実装済みの契約と設定に従い、クライアント注入が必要な連携の制限も明示します。検証は定型の空欄代替文と存在しないソースへの参照を拒否します。 GitHub のソースリンクは保存済みの資料からも既定ブランチの別名 `blob/HEAD` または `raw/HEAD` を使います。変更履歴のコミットリンクは固定したコミットを指します。
