# レスポンシブなワークスペース

**機能ブランチ:** feature-responsive-page-composer

## 端末に合わせた表示

Page Composer は保存済みのデスクトップ配置を変更せず、狭い領域の内容を一列に表示します。幅の制約は小さいグリッドに収まり、入れ子の編集画面は全幅を使い、サイズ変更時も既存のフォームを保持します。

## 利用しやすい配置操作

タッチ用の操作部を表示し、利用可能なウィジェットには追加ボタンを設けます。キーボードでもフォーカス中のウィジェットを移動し、サイズを変更できます。中断されたポインター操作は反映しません。

## 一貫したナビゲーション

ナビゲーションとツールバーは開いたパネル内にフォーカスを保ち、Escape で閉じ、終了時にリソースを解放します。フィルター操作ではツールバーを開いたままにします。検索やポップアップとスクロール制御を共有し、安全領域、テキストの折り返し、大きなタッチ領域を Cognis のテーマに統合します。
