# Kalenderantworten

## Freundlichere Einladungsantworten

Kalenderbenachrichtigungen verwenden jetzt freundlichere Texte für Einladungen, Antworten, Erinnerungen und Absagen, behalten Links zu ausstehenden Einladungen bei, zeigen den Einladenden oder Antwortenden als Absender und fassen den Antwortstatus der Teilnehmenden in Ereignis-Popups zusammen.
