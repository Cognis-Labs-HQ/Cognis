# 管理画面への分析セクション追加

## サンプル分析モジュールを管理画面の本格的な分析セクションに昇格

サンプル分析モジュールが完全なユーザー活動分析ツールへと成熟しました。
旧来のダッシュボードプレースホルダー要素は削除されました。

## 管理画面の分析タブで実際のユーザー指標を表示

管理画面 → 分析 では、統計カード（総ユーザー数、過去7日間のアクティブユーザー数、
選択期間内の新規登録数）、過去7・30・90日間の登録トレンドを示す棒グラフ、
およびパーセントバー付きのロール別内訳を表示します。

## 時間範囲フィルターがすべてのグラフと統計をリアルタイムで更新

時間範囲フィルターにより、管理者は7日・30日・90日のウィンドウを切り替えられます。
「更新」をクリックすると、ページをリロードせずに統計カード・棒グラフ・
イベントログがその場で更新されます。

## カスタムイベント記録 API

新しいエンドポイント `POST /api/v1/modules/analytics/activity-log` により、
管理者は任意の名前付きカスタムイベント（オプションのメタデータ付き）を
分析イベントテーブルに記録できます。記録されたイベントは管理画面の
分析セクション内のイベントログに表示されます。

## 指標と時系列データ向けの新しい API エンドポイント

3つの管理者認証済み API ルートが従来のスタブ指標エンドポイントに代わります：
`/api/v1/modules/analytics/metrics`（概要とロール内訳）、
`/api/v1/modules/analytics/series`（日別登録時系列）、
`/api/v1/modules/analytics/activity-log`（最近のカスタムイベントログ）。
