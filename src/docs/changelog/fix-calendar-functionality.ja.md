# 共有カレンダーリンク

**Feature Branch:** copilot/fix-calendar-functionality

## 複数リンク表示が復活

カレンダー編集ポップアップは、生成した共有リンクを最新の1件で上書きせず、
すべて保持するようになりました。各リンクは名前付きの折りたたみブロックと
して表示され、CalDAV と ICS のコピー欄を個別に確認できます。

## 非公開リンクにパスフレーズ

非公開カレンダーの共有では、リンクごとに専用のパスフレーズが生成されます。
ポップアップにはそのパスフレーズが URL と一緒に表示され、Cognis の
カレンダー共有で CalDAV / ICS アクセスに利用できます。

## 共有リンクの有効期限を復元

生成したリンクは再び選択した有効期限に従い、期限を過ぎると無効になります。
公開カレンダーでも個別の共有 URL を発行するため、各リンクを独立して期限切れ
にできます。

## 共有ユーザーカードを新しい操作に整列

各共有ユーザー項目は、プロフィールカード・権限選択・有効期限選択を同じ行に
並べ、右上にはコンパクトな閉じるボタンを配置するようになりました。権限変更
では実際に変わった項目だけを PATCH するため、読み取り専用と読み書きの切り替え
時に出ていた bad request が解消されます。

## 無効な共有カレンダーが即座に削除されます

カレンダーの共有が削除または期限切れになると、次の更新時に受信者のカレンダー
一覧から即座に消えます。受信者がカレンダーを読み込むたびにハンドシェイクが
実行され、バッキングの共有レコードが存在しないエントリが削除されます。

## 共有カレンダーのイベントでカレンダー選択ポップアップが表示されなくなりました

共有カレンダーにすでに存在するイベントへの出席承認時に、「承認済みイベントの
追加先」カレンダー選択ポップアップが表示されなくなりました。レスポンスは
共有カレンダーに直接記録されます。

## 辞退するとイベント参加者から永久に削除されます

ユーザーがイベントを辞退すると（定期イベントの「すべてに返信」も含む）、
影響するすべての発生から参加者リストが削除されます。主催者が明示的に
再招待するまで、カレンダーや保留中イベントの一覧に表示されなくなります。

## 保留中イベントのボタンがレスポンスポップアップのスタイルに統一されました

保留中イベントセクションのクイックレスポンスボタンが、イベントコンポーザーの
レスポンスセクションと同じアウトラインスタイルとホバーアニメーションを使用
するようになりました。承認は緑、辞退は赤、仮承諾はニュートラルの枠線です。

## 保留中イベントがレスポンス選択時に即座に更新されます

クイックレスポンスボタンをクリックすると、ネットワークリクエストの完了を
待たずにリストから項目が即座に削除されます。

## 過去のイベントが今後の予定として表示されなくなりました

終了時刻が過ぎたイベントへの保留中の招待は、招待リストに表示されなくなりました。
以前は、終了済みのイベントでも未回答のまま「今後の予定」として表示される場合が
ありました。
