# Mobiles Core-Layout

**Feature-Zweig:** fix-core-mobile-layout

## Kompakte gemeinsame Bedienung

Smartphone-Kopfbereiche nutzen zwei Zeilen. Werkzeugleistenschalter scrollen hinter der Kopfzeile, Tutorialaktionen bleiben kompakt und hervorgehobene Ziele sind deutlicher sichtbar. Erklärungen dürfen auf niedrigen Bildschirmen den Kopfbereich nutzen; Schriftpräferenzen und Touchflächen bleiben bedienbar.

## Lesbare integrierte Seiten

Die Administration trennt Gatewaynamen von ihren Steuerelementen. Fehlercodes passen in ihre Inhaltsspalte. Monats- und Wochenansichten des Kalenders scrollen horizontal mit lesbaren Tagessteuerelementen; Jahresansichten passen in eine schmale Spalte. Seiten externer Module sind ausgeschlossen.
