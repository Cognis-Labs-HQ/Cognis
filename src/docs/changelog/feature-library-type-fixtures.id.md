## Data Uji Library Bertipe

Pengujian Library kini membuat metadata entri dan skema yang lengkap serta memakai kapabilitas berkas, audio, dan basis data bertipe. Alur terdaftar dan ekspektasi perilaku yang ada tetap dijalankan. Basis data uji milik komponen memeriksa penyimpanan gambar tanpa mengimpor implementasi pengujian komponen lain.
