# Sicherere Chatraum-Bereinigung

**Feature-Zweig:** work

## Autorisiertes Löschen von Chaträumen

Eine Messages-Funktion wurde veröffentlicht, die einen Chatraum und seine abhängigen Datensätze dauerhaft löscht, wenn der Raumeigentümer oder der einzige verbleibende Teilnehmer dies anfordert.

## Korrekte Filterung der Benutzersuche

Der von Modulsuchdialogen verwendete singuläre Benutzer-Ergebnisfilter wird nun normalisiert und auf registrierte sowie gruppierte Ergebnisse angewendet. Dadurch erscheinen Benutzer ohne unpassende lokale oder API-Kategorien.

## Themenfähige Suchsteuerung

Die zeichenbasierte Schließen-Schaltfläche des Suchfensters und die browserseitige Eingabelöschung wurden durch einheitliche SVG-Symbole für helle und dunkle Designs ersetzt. Das Löschsymbol im Eingabefeld ist kleiner und teilweise transparent; Auswahlkästchen stehen nun neben den Benutzerdetails statt darüber.
