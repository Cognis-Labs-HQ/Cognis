# パスワード変更の強化

## 現在のパスワード必須

ユーザー設定でのパスワード変更は、現在のパスワード入力を常に必須にし、新しいパスワードを受け付ける前にサーバー側で検証するようになりました。

## 再利用パスワードを拒否

ローカル認証はハッシュ化されたパスワード履歴を保存し、新しいパスワードが過去に使われたものと一致する場合は変更を拒否します。

## Reset を Change に変更

セキュリティ設定のセクション名、アクションボタン、ポップアップタイトルを「パスワードをリセット」から「パスワードを変更」に変更しました。

## 検証と移行の端ケース修正

現在のパスワード検証では前後の空白を保持するようにし、移行済みアカウントは更新前に回転前ハッシュを履歴へ追加し、2 引数の既存認証アダプター互換を維持しつつ、DB と揮発ストアの履歴保持上限を一貫して適用するようにしました。
