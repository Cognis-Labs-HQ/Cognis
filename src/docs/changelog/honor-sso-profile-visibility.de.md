# SSO-Profilsichtbarkeit

**Feature-Zweig:** honor-sso-profile-visibility

## Vom Anbieter gewünschte Sichtbarkeit

Externe Authentifizierungssitzungen und aufgelöste externe Profile können nun `profileVisibility` zurückgeben. Cognis prüft unterstützte Werte und speichert die gewünschte Sichtbarkeit nach der Erstellung oder Synchronisierung des Profils, statt stets den Standardwert beizubehalten.
