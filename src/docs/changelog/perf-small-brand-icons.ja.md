# ブランドアイコンの軽量化

**機能ブランチ:** perf-small-brand-icons

## 表示箇所ごとの解像度

ページのファビコン、ダッシュボードのウィジェット、認証画面、エラー画面、ショートカットには384pxの画像を使用し、ページのヘッダーには既存の512pxアイコンを使用します。通常版とマスク可能版の384px画像は、それぞれの512px画像からLanczos方式で決定的に縮小し、構図、縦横比、アルファを保持します。元画像とプラットフォーム用のインストールアイコン（192px/512pxおよびApple Touch用180px）は引き続き利用できます。

## 起動時の画像転送

Service Workerは大きな元画像を取得せず、通常版の192px、384px、512pxアイコンを事前にキャッシュします。キャッシュのバージョン更新により、既存クライアントのアセット一覧も更新されます。ルートとインストールのテストでは、永続トークンを作成せずに認証契約を注入し、画像寸法と画質を優先して拡大した転送量の上限を検証します。
