# ブランドアイコンの軽量化

**機能ブランチ:** perf-small-brand-icons

## インストール用アイコンの再利用

ページのファビコン、共通ヘッダー、ダッシュボードのウィジェット、認証画面、エラー画面で既存の正方形のインストール用アイコンを再利用します。元の画像は従来の URL で引き続き利用できます。画像変換や新しいアセット依存関係は追加しません。

## 起動時の画像転送量の制限

Service Worker のインストール時には既存の大小のインストール用アイコンを事前にキャッシュし、大きな元画像の追加取得を省きます。キャッシュのバージョンを更新して、既存クライアントの共通画面用アセット一覧を更新します。非公開 API やモジュールのリビジョンの扱いは変更しません。ルートと Worker インストールの回帰テストで画像転送量の上限を検証します。
