# Responsive Component Controls

**Feature Branch:** feature-administration-control-layout

## Content-sized Administration rows

Administration reclaims unused control space and wraps names, localized status labels and version details within narrow component rows. Disclosure remains separate from the power switch, including expanded and disabled rows.

## Keyboard and touch access

Component switches remain native keyboard controls with localized names and visible focus. Switches and disclosure targets are at least 44 pixels high. Health labels and the keyboard tutorial are localized in German, English, Indonesian and Japanese.
