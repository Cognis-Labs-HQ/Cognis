# 信頼性の高い LDAP ディレクトリ設定

## OpenLDAP と FreeIPA のライブ検出

LDAP 設定は、構成を続行する前に設定済みディレクトリへバインドし、実際のユーザーとグループを読み取るようになりました。ユーザー名属性、上限付きページ検索、ネストされたメンバーシップ、より安全なフィルターに対応します。

## 明確なロールマッピングと書き戻し制御

管理者は、検出された LDAP グループを Cognis の各ロールへ表形式で割り当てられます。パスワード書き戻しの詳細は、書き戻しを有効にするまで非表示になります。

## 対象を絞ったディレクトリ検索と明確なログイン選択

任意のユーザー DN とグループ DN で LDAP 検索を絞り込め、ベース DN はフォールバックとして使用されます。グループ選択はアルファベット順で短い名前を表示します。ログイン元のコントロールは認証情報欄の前に表示され、アクティブな選択が明確になります。

## プロバイダー固有のアカウント操作と安定した LDAP セッション

各ログイン元が固有の復旧操作を管理するようになり、LDAP を選択するとローカルパスワードの忘れた場合のリンクが消えます。パスワード変更は、アクティブなプロバイダーが対応する場合のみ表示され、LDAP では書き戻しが有効な場合が該当します。LDAP セッションは、一致するローカルアカウントレコードに依存しなくなりました。

## 永続的な外部アカウント識別情報

LDAP ログインが成功すると、プロファイルを作成する前に共通アカウントレコードと LDAP 識別情報が作成されるようになりました。これによりデータベースの外部キー整合性が保たれ、ローカルパスワード認証情報を作成することなく、LDAP アカウントにローカルアカウントと同じプロファイルとセッションの基盤が提供されます。

## 安定したログインモードの切り替え

パスワード復旧から戻る際は、保持されたページ内容を再読み込みする代わりに、認証情報フォームをその場で復元するようになりました。これにより、認証元セレクターが重複しません。二要素認証チャレンジ中は、認証情報のソースセレクターも非表示になります。

## 正確で繰り返し可能なディレクトリ検出

「テストして検出」を実行するたびに、ロールマッピングを再構築する前に以前のサンプルが置き換えられます。ユーザー検索とグループ検索は常にそれぞれの DN を使用し、個別にベース DN へフォールバックします。グループではない LDAP オブジェクトはグループ選択肢から除外されます。

## 検出範囲の強制と識別情報スキーマ

検出では、DN が設定済みのユーザーまたはグループ検索ベースの範囲外にあるディレクトリエントリを拒否するようになりました。これにより、サーバーが予期しない結果を返した場合でも、ユーザーコンテナーのレコードがグループマッピングに入ることはありません。認証ブートストラップは、LDAP ログインが識別情報を保存する前に外部識別情報テーブルも作成します。

## LDAP メールアドレスのプロビジョニングと即時確認

LDAP ログインでは、ログイン中のユーザーとしてバインドした状態で、登録されているすべてのメールアドレスを読み取り、ローカル認証情報を作成せずに Cognis に登録します。最初のアドレスがプライマリになります。メール確認が必須の場合は、確認メッセージがただちに送信され、ログインフローはコード確認へ直接進みます。

## アダプター所有設定の確実な読み込み

認証ゲートウェイが LDAP 設定画面をアダプターアセットレジストリ経由で公開するようになり、スクリプト不足によって LDAP 設定を開けない問題を解消しました。

## 設定拡張の明示的な検出

管理画面は、アダプターが独自の設定画面を通知した場合にのみ読み込みます。SMTP などの標準アダプターは、失敗するスクリプト要求を発生させずに共通フォームを使用します。

## 複数の名前付き LDAP 接続元

管理者は複数の名前付き LDAP サーバーを管理し、並べ替えられます。接続元をログインページに個別表示するか、設定順にサーバーを試す一つの LDAP 選択肢として統合できます。

## 必須のユーザー認証情報検証

LDAP 設定の最後に、実際のディレクトリユーザーの認証情報による必須バインドを行います。サーバーを保存する前に識別情報、グループ、Cognis ロールを表示し、割り当て済みユーザーグループの制限も適用します。

## 可変幅のログイン元配置

ローカルと LDAP の接続元選択欄をログイン見出しとユーザー名欄の間に直接配置しました。ボタンは利用可能な幅に合わせて調整され、収まらない接続元はスクロール可能な一覧から選択できます。

## ログイン接続元のメタデータを維持

公開ログイン設定で、名前付き LDAP サーバーごとの認証情報接続元メタデータを維持するようにしました。これにより、ローカルと設定済みのすべての LDAP 接続元が選択行に実際に並んで表示されます。
