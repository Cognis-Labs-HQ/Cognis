# 信頼性の高い LDAP ディレクトリ設定

## OpenLDAP と FreeIPA のライブ検出

LDAP 設定は、構成を続行する前に設定済みディレクトリへバインドし、実際のユーザーとグループを読み取るようになりました。ユーザー名属性、上限付きページ検索、ネストされたメンバーシップ、より安全なフィルターに対応します。

## 明確なロールマッピングと書き戻し制御

管理者は、検出された LDAP グループを Cognis の各ロールへ表形式で割り当てられます。パスワード書き戻しの詳細は、書き戻しを有効にするまで非表示になります。

## 対象を絞ったディレクトリ検索と明確なログイン選択

任意のユーザー DN とグループ DN で LDAP 検索を絞り込め、ベース DN はフォールバックとして使用されます。グループ選択はアルファベット順で短い名前を表示します。ログイン元のコントロールは認証情報欄の前に表示され、アクティブな選択が明確になります。

## プロバイダー固有のアカウント操作と安定した LDAP セッション

各ログイン元が固有の復旧操作を管理するようになり、LDAP を選択するとローカルパスワードの忘れた場合のリンクが消えます。パスワード変更は、アクティブなプロバイダーが対応する場合のみ表示され、LDAP では書き戻しが有効な場合が該当します。LDAP セッションは、一致するローカルアカウントレコードに依存しなくなりました。
