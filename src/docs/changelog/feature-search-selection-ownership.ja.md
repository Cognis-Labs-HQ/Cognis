# 検索結果選択の管理

**機能ブランチ:** feature-search-selection-ownership

## 選択結果の確定を待つ

検索は非同期の選択処理を待ち、処理中のコールバックの重複を防ぎます。所有元が有効な間に限り、失敗しても検索語、カテゴリ、複数選択を維持します。厳密なfalseは所有元が有効な間はエラーなしで開いたままにし、undefinedは成功を示します。標準のフッタークリックはキーボードやブラウザーの操作に対応します。

## 選択の有効期間を守る

任意の所有者シグナル、プロバイダーの削除、アカウント変更によって古いUI結果の反映を防ぎますが、送信済みの操作は取り消しません。翻訳されたワークスペースのチュートリアルは、従来の進行と再実行を維持し、待機と再試行前の操作先確認を説明します。

ナビゲーションバーからの選択は、ルート破棄前に`navigateTo`が返した`false`を伝え、移動が拒否された場合はエラーなしで検索を維持します。`route-will-change`または`pagehide`が発生すると、移動先の表示に後で失敗しても、検索は有効期間の終了として閉じます。その後の結果通知は、閉じた検索ポップアップではなく移動先またはルーターが担当します。
