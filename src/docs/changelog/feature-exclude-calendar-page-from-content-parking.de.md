# Kalendernavigation

**Feature-Zweig:** feature-exclude-calendar-page-from-content-parking

## Kalender ohne Content-Parking

Die Kalenderseite deaktiviert jetzt das Content-Parking des Page-Composers, sodass Wechsel zwischen Kalenderansichten die aktiven Bedienelemente neu aufbauen und die Navigation reaktionsfähig bleibt. Ganztägige Ereignis-Datumsfelder werden außerdem geleert, bevor von Datum-Uhrzeit- auf Datumsmodus gewechselt wird, damit sich Browser-Formatwarnungen bei Kalenderaktualisierungen nicht wiederholen.
