# Libraryテスト契約

**機能ブランチ:** feature-library-type-fixtures

## 型付きLibraryテストデータ

Libraryのテストは完全なエントリとスキーマのメタデータを生成し、型付きのファイル・音声・データベース機能を使用します。登録済みフローと既存の動作検証は維持されます。画像の永続化は、他のコンポーネントのテスト実装を取り込まず、Libraryが所有するテスト用データベースで検証します。
