# Module Auth Providers

**Feature Branch:** feature-expose-capability-for-modules

## Modules can register authentication providers

The Authentication gateway now exposes `auth:registerProvider`, allowing lifecycle-managed modules such as LINE integrations to contribute providers through the system capability bus.
