# Shareの型付き契約

**機能ブランチ:** feature-share-type-contracts

## 型付きトークン結果

Share 1.9.9では、発行・更新・一覧取得の機能が返すトークンのフィールドを定義します。メタデータ、有効期限、受信者、付与された権限を含みます。ブートストラップのコールバックと構造化クエリのテストデータには明示的な契約を使用します。所有者の確認と、空の権限配列による取り消しは維持されます。

## テストと安全性

合成データを使ったテストで、保存されたトークン結果、所有者以外による更新の拒否、ゲストプロフィールの削除を確認します。受信者、パスワード、アダプター、有効期限の検証動作は変わりません。
