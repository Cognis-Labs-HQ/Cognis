# 古いカレンダー読み込みを中止

**機能ブランチ:** fix-calendar-navigation-cancellation

## 古いカレンダー読み込みを中止

カレンダーから移動すると、古い初期化処理はページやURLを変更する前に停止します。ルートのシグナルをページ構成処理に渡し、カレンダー、予定、招待の遅延応答によって移動先が古い画面に置き換わることを防ぎます。中止した初期化処理は遅れてエラー通知を表示したり、空き状況のタイマーを再開したりしません。
