# モジュールケイパビリティ更新

**機能ブランチ:** fix-external-module-capability-refresh

## 公開ケイパビリティの取得

外部モジュールが現在のシステム ctx から提供側の公開ケイパビリティを取得できるよう修正しました。非公開ケイパビリティを隠したまま、会議側が Whiteboard 所有のボードデータを取得できます。

## 更新の順次実行

後処理とケイパビリティ登録が重複しないようモジュール更新を順番に実行します。別々のレジストリ、検証済みの提供側、繰り返し更新、無効化と再有効化、同時要求、失敗後の復旧を回帰テストで確認します。API Server を 0.6.4 に更新しました。
