# 安定した接続復旧

**機能ブランチ:** work

## 接続中断を確認

接続警告を表示する前に同一オリジンのヘルスチェック失敗を確認するため、無関係な API 応答やエラーによる誤検知を防ぎます。復旧状態は Cognis のオリジンごとに分離され、別々の環境が互いに影響しません。

## 復旧後に更新

中断確認後にサービスの復旧を監視し、警告を復旧案内の情報トーストに置き換え、そのトーストが消えた時点でページを更新します。
