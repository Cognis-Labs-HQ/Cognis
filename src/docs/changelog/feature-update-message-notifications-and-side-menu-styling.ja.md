# 未読ルームをより分かりやすく表示

**機能ブランチ:** feature-update-message-notifications-and-side-menu-styling

## ページに応じた通知

メッセージやカレンダーなど、通知を担当するページを表示中は、新着通知のポップアップが抑制されるようになりました。

## 未読チャットを強調

未読のルームはメッセージのサイドメニューでわずかに丸みを帯びた輪郭とともに穏やかに点滅し、赤い未読件数を表示します。長いチャット名は1行に省略され、マウスを重ねると全文を確認できます。

## 明確なルーム退出操作

メッセージのヘッダーに「ルームから退出」ボタンを表示し、ルーム関連の文言を「ルーム」に統一しました。
