# 非公開モジュールを確実に検出

## 再起動後も非公開リポジトリのスキャン設定を維持

Cognis Labs HQ マーケットプレイスソースは、非公開リポジトリのスキャン設定を既定ソースのレコードに保存するようになりました。これにより、サーバーの再起動後も設定済みの非公開モジュールを検出できます。

## バックグラウンドスキャンでキーリングを解除しない

マーケットプレイスの自動ポーリングは認証済みソースの検出を実行し、キーリングがすでに解除されている場合にのみ PAT を読み取るようになりました。キーリングリゾルバーは、アカウントのキーリングパスワードを予期せず要求することなく、保存済みの認証情報を検証して無効な値を削除します。明示的な更新では引き続きアクセスを要求できます。

## アクセス可能なすべての非公開リポジトリを対象にする

非公開リポジトリの検出では、GitHub の認証済みリポジトリ一覧を所属関係で制限しなくなりました。この制限によって、fine-grained PAT で明示的に許可されたリポジトリが除外される場合がありました。スキャンログではカタログの結果とインストール済みモジュールを区別し、無効なマニフェストや追加情報の取得失敗によって除外されたリポジトリを特定します。

## ソース設定にコンテナの永続ストレージを使用

本番コンテナは、マーケットプレイスのソースレコードを置き換え可能なサーバービルド配下ではなく、マウント済みの設定ボリュームへ保存するようになりました。このレコードには非公開スキャンのスイッチと、再起動後に暗号化されサーバー同期されたユーザーキーリングから PAT を解決するための識別子が保持されます。
