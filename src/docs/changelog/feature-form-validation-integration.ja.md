# 利用しやすいフォーム検証

**機能ブランチ:** feature-form-validation-integration

## 検証済みのエラーを説明

独自の検証に失敗した入力を識別し、呼び出し元の説明を置き換えずに、満たされていない要件の既存の翻訳文を関連付けます。修正すると自身のエラー参照を解除します。ブラウザー標準の制約、必須マーカー、タブ移動、送信動作の契約は維持します。

## 検証リスナーを解除

フォーム接続の解除や中止により、入力、変更、フォーカス離脱のリスナーと自身の ARIA 状態を削除します。再接続で古いリスナーが重複することはありません。明示的な検証呼び出しは引き続き利用できます。

## 共通の案内を文書化

4 言語の UI ガイドで検証と既存のチュートリアル対象を説明します。テストはフォームビルダーの公開入口と実際のパスワードダイアログの条件を、合成したポリシー読み取りとキャンセルだけで確認します。

## 呼び出し元の最新のエラーを保持

無効な入力を繰り返し検証しても、呼び出し元が最後に設定または削除した ARIA エラーの状態を保持します。修正、接続解除、中止では他の説明を置き換えずにその状態を復元します。同じ true 値の書き込みを別の所有元によるものと判別することはできません。

## 中断された表示更新を停止

独自の条件がフォーム接続を解除または中止した場合、実行中の項目検証やフォーム全体の検証は、解除後に表示を復元せずに結果を返します。その後の明示的な検証は引き続き利用でき、再度の解除でその状態を消去できます。
