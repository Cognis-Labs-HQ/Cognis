# Search Options

## Expanded Search Index

The global search popup now includes a dynamic registration utility so pages, visible page content, posts, chats, messages, and component-owned UI surfaces can contribute searchable result categories.

## Match Controls

Search popups now include controls for whole-word matching, regular expressions, and case-sensitive matching.

## Clearer Results

Search results now favor content names and descriptions, highlight exact matches, and show surrounding text snippets when content text is matched.
