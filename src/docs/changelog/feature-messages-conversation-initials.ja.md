# メッセージのアバター統一

**機能ブランチ:** feature-messages-conversation-initials

## プロフィールの表示を共用

メッセージの送信者には、現在のProfileレンダラーによるイニシャル、色、小サイズ（32px）のアバターを使用します。イニシャルは表示名、次にハンドルに従い、どちらもない場合はアカウント識別子をラベルとして保持します。アバターを表示するスタイルでは、既存の画像とプロフィールへのリンクを維持します。マウスポインターを重ねると標準のプロフィールプレビューが開き、クリックするとプロフィールに移動します。IRCでは引き続きアバターを表示しません。

## 会話の動作を維持

設定のメッセージスタイルのプレビューも同じ小サイズでサンプルデータを表示し、プロフィールへのリンク、画像、アバターの追加読み込み、書き込みは行いません。Profileプロバイダーがない場合、無効な場合、または必要な機能がない場合はプレビューを利用できず、復帰すると再表示します。会話行はページとアカウントの所有関係、テキスト選択、下書き、読み取り結果を維持します。ルームのヘッダー、参加者一覧、その他のアバター表示は変更せず、全体のアバター監査は引き続き一部未完了です。

Messages 2.8.3 / Profile 4.0.0.
