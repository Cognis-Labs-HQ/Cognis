# Perbaikan Preferensi Bahasa

**Feature Branch:** feature-investigate-and-fix-language-preference-issue

## Menyeret bahasa lebih andal

Tabel preferensi bahasa di Pengaturan kini menentukan target pelepasan dari posisi penunjuk ketika browser melaporkan elemen anak atau area sekitar sebagai target pelepasan. Dengan begitu, memindahkan bahasa dari Bahasa Tersedia ke Bahasa Pilihan lebih konsisten selesai pada pelepasan pertama.
