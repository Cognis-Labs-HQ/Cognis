# Library-Testverträge

**Feature-Zweig:** feature-library-type-fixtures

## Typisierte Library-Testdaten

Library-Tests erzeugen jetzt vollständige Eintrags- und Schema-Metadaten und verwenden typisierte Datei-, Audio- und Datenbankfähigkeiten. Registrierte Abläufe und bestehende Verhaltenserwartungen bleiben erhalten. Eine komponenteneigene Testdatenbank prüft die Bildspeicherung ohne die Testimplementierung einer anderen Komponente zu importieren.
