# Telemetri Kinerja Aman

## Telemetri peramban diperkuat

Pengiriman kinerja peramban kini memerlukan sesi terautentikasi, menerapkan batas per akun, membatasi ukuran kumpulan metrik, mempertahankan metrik dokumen saat navigasi SPA, dan menghitung CLS memakai jendela sesi Web Vitals.

## Bawaan edge lebih aman

Origin mode tertunda kini terikat ke loopback secara bawaan dan mempertahankan header penerusan tepercaya. Penyiapan menyediakan sertifikat awal yang ditandatangani sendiri, dan aset ber-hash memakai seluruh alfabet hash esbuild.
