# Status ketersediaan

## Lihat ketersediaan sekilas

Lampu status kini tampil di navigasi, pratinjau profil, pesan, dan avatar rapat. Acara kalender aktif mengatur status kosong atau sibuk secara otomatis.

## Pilih status manual
