# Pembaruan CLI dan Health

## Namespace CLI Komponen

CLI operasional kini memakai namespace `component:*` untuk operasi siklus hidup modul dan dapat menargetkan modul, gateway, serta adapter gateway dari satu permukaan kendali.

## Kontribusi Health Modul

Laporan health sistem kini dapat memuat kontribusi komponen, termasuk informasi keterjangkauan Jitsi Meet untuk instansi yang dikonfigurasi.
