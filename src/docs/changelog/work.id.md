# Pengaturan log waktu proses yang lebih aman dan diterjemahkan

## Adaptor log kini memiliki aturan konfigurasinya

Adaptor konsol dan file menentukan validasi serta pemetaan konfigurasi logger sendiri, sehingga pengaturan khusus adaptor tidak berada di rute gateway.

## Penggantian log file kini dibatasi

Formulir waktu proses tidak lagi mengizinkan perubahan jalur log milik lingkungan dan menolak ukuran rotasi serta jumlah retensi yang tidak aman sebelum penggantian diterapkan.

## Pengaturan log telah diterjemahkan

Label pengaturan konsol dan file kini menggunakan sumber daya bahasa Jerman, Inggris, Indonesia, dan Jepang milik komponen.

Popup Administrasi kini memuat sumber daya bahasa yang diumumkan oleh setiap adaptor sebelum merender bidang konfigurasinya.
