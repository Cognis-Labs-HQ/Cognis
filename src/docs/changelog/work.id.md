# Skema bahasa berversi

**Cabang Fitur:** work

## Kontrak paket netral

Paket bahasa eksternal dapat menetapkan skema yang tidak dapat diubah dengan lapisan bebas, metadata bertipe dan terlokalisasi, peran semantik, batas relasi, petunjuk tampilan, tag aktivitas, jalur minat, serta aset goresan opsional tanpa menyimpan rekaman bahasa di inti Cognis.

## Pemasukan deterministik

Prapemeriksaan memvalidasi identitas, versi semantik, lisensi, jalur aman, kepemilikan namespace, skema, graf rekaman lengkap, dan aset rujukan sebelum transaksi menulis konten.
