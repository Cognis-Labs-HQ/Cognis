# Pembersihan ruang obrolan aman

**Cabang Fitur:** work

## Penghapusan ruang obrolan terotorisasi

Kapabilitas Messages kini dapat menghapus ruang obrolan beserta data terkait secara permanen saat diminta oleh pemilik ruang atau satu-satunya peserta yang tersisa.

## Pemfilteran pencarian pengguna yang benar

Filter hasil pengguna bentuk tunggal yang digunakan dialog pencarian modul kini dinormalisasi agar API pencarian mengembalikan pengguna, bukan semua kategori hasil.
