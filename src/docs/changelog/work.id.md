# Visibilitas Versi Adapter

## Pengaturan adapter kini menampilkan versi

Kontrol adapter di Administration kini menampilkan versi setiap adapter di samping nama adapter, dan dialog konfigurasi adapter menyertakan versi yang sama pada heading saat metadata versi tersedia.

## Status dan interaksi komponen yang jelas

Komponen aktif kini menampilkan lampu kesehatan hijau, oranye, atau merah di samping pil Aktif. Status diperbarui setelah aktivasi, komponen yang perlu disiapkan menjelaskan alasan aktivasi diblokir, dan panah detail selalu memiliki area klik tersendiri.
