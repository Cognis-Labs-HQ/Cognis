# Penyempurnaan hidrasi dasbor

## Data dasbor opsional tidak lagi menghambat navigasi

Dasbor kini menyelesaikan pemasangan segera setelah tata letak dasar dirender, sementara data akun, kalender, dan ekstensi tetap dimuat secara independen.

## Permintaan kalender tetap berada di Gateway Kalender

Dasbor menggunakan fungsi acara mendatang yang diekspor Gateway Kalender sehingga detail endpoint dan respons tetap berada dalam komponen pemiliknya.

## Pelaporan versi autentikasi konsisten

Pendaftaran runtime autentikasi kini melaporkan versi yang sama dengan manifes komponennya.
