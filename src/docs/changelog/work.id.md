# Menghormati batas waktu sesi pribadi

## Mempertahankan pilihan batas waktu pribadi dalam batas global

Preferensi batas waktu sesi pengguna tetap diutamakan saat lebih singkat daripada batas administrasi. Kontrol durasi kini hanya menawarkan satuan yang sesuai dan membatasi kolom angka setiap satuan pada nilai bulat terbesar yang diizinkan.
