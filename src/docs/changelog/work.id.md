# Ruang Kerja Berkas Lengkap

**Cabang Fitur:** work

## Organisasi berkas virtual

Ruang kerja Berkas responsif kini memiliki navigasi kategori, pil ruang nama, pemilihan penyedia, folder virtual, favorit, item terkini, tindakan destruktif, dan menu konteks yang dapat digunakan kembali tanpa memindahkan objek penyedia.

## Integrasi kelas dan berbagi

Folder kelas pengajar disinkronkan melalui kapabilitas `ctx`. Berkas mengikuti alur pengguna dan tautan gateway Share dengan pilihan pembaca/editor serta akses yang kompatibel bagi tamu.

## Pembukaan berkas dan administrasi

Gateway Render Berkas baru menyediakan kontrak pembukaan netral-perender, termasuk penerusan paksa “Buka Dengan...”, serta penetapan penyedia dan kontrol kuota gabungan di Administrasi.
