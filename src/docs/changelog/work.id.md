# Status Akun

## Kontrol siklus hidup lebih jelas

Tindakan akun di zona berbahaya kini memakai gaya tombol batal yang konsisten, peringatan penonaktifan tidak lagi menyebut perlu bantuan administrator, dan popup konfirmasi dikirim dengan tombol Enter.

## Status admin lebih jelas

Halaman Pengguna kini menampilkan status akun yang diarsipkan dan dinonaktifkan secara eksplisit serta memberi label tindakan pemulihan sebagai Aktifkan Kembali.

## Kesalahan login siklus hidup

Percobaan login untuk akun yang diarsipkan dan dinonaktifkan kini mengembalikan kesalahan siklus hidup yang ditangani agar halaman login dapat menampilkan toast kesalahan yang sesuai.
