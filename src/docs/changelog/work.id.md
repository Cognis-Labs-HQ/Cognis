# Frasa Sandi Pakai Ulang

## Kapabilitas frasa sandi untuk modul

Menambahkan generator frasa sandi berbasis kata yang acak secara kriptografis dengan jumlah kata, pemisah, dan kapitalisasi yang dikendalikan pemanggil. Runtime API mengekspornya melalui `ctx` agar modul seperti Jitsi Meet dapat menghasilkan rahasia yang mudah dibaca tanpa mengimpor internal API.
