# Default profil yang lebih ramah

## Profil baru dimulai dengan visibilitas Teman

Setiap profil baru kini dimulai dengan visibilitas Teman agar pengguna baru dapat ditemukan oleh koneksi mereka tanpa terlihat oleh seluruh komunitas. Pengguna biasa dan moderator tetap dapat memilih visibilitas Privat atau Tersembunyi kapan saja.
