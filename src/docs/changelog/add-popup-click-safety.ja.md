# フォームポップアップの閉じる安全機能

## 未保存の変更を破棄する前に確認ダイアログを表示

フォーム入力を含むポップアップで、フィールドが編集されている場合、背景クリック・×ボタン・Escapeキーによる閉じる操作をブロックし、確認ダイアログを表示するようになりました。「破棄」でフォームを閉じ、「キャンセル」で入力画面に戻ります。

## 対象ポップアップ

プロフィール編集、パスワード変更、アダプター設定、招待メール、ユーザー入力、教師申請、生徒招待の各ポップアップがこの保護を受けます。`openPopup` API に新しい `closeConfirm` オプションが追加され、i18n で解決された文字列を渡すことで任意のフォームポップアップに適用できます。
