# Abwechslungsreiche Farben für neue Kalender

**Feature Branch:** feature-assign-random-color-to-new-calendars

## Neue Kalender beginnen mit einer zufälligen Farbe

Neue Kalender erhalten jetzt eine zufällig ausgewählte Farbe aus der Kalenderpalette, anstatt immer blau zu beginnen. Der Erstellungsdialog zeigt die ausgewählte Farbe vor dem Speichern an und ermöglicht weiterhin ihre Änderung.
