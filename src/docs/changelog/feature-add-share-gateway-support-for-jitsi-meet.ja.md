# ゲスト向け共有コンポーネントウィンドウ

## 共有ページが同期コンポーネントウィンドウを自動的に開くようになりました

共有ゲストは、ブラウザーの操作ジェスチャーなしでも、マウントされた共有ページが要求するコンポーネントウィンドウを受け取れるようになりました。これにより、ミーティングのホワイトボードと同期する周辺動作が、サインイン済みの Cognis 参加者と同様にゲストにも開きます。コンポーネントページブローカーは、要求されたホスト要素とライフサイクルシグナルの検証を引き続き行います。

## 連携境界の明確化

コンポーネントウィンドウの認可は、子コンポーネントの API へのアクセスを許可するものではありません。同期を一貫して動作させるには、Jitsi Meet がホワイトボード状態ルートで共有ゲストを受け入れてミーティングとホワイトボードの関連付けを公開し、Nextcloud Whiteboard が検証済みミーティング共有からの委譲アクセスを受け入れる必要があります。
