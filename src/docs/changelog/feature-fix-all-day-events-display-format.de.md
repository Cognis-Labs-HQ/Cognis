# Kalender-Ganztag-ICS

**Feature Branch:** feature-fix-all-day-events-display-format

## Echte Ganztagsexporte

Kalenderfeeds exportieren ganztägige Ereignisse jetzt auch dann als ICS-Datumswerte, wenn der Browser einen lokalen Mitternachtsbereich mit UTC-Versatz gespeichert hat. So zeigen Kalenderclients sie als Ganztagstermine und nicht als Zeitblöcke von 00:00 bis 24:00 an.
