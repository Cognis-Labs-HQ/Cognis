Die Tabelle „Verfügbare Sprachen“ bleibt jetzt auch ohne Einträge als aktive
Drop-Zone erhalten, und die Schaltfläche „Mit Browser synchronisieren“ steht nun
direkt neben der Überschrift „Bevorzugte Sprachen“.

Beide Sprachkarten verwenden nun identische Überschriftenabstände, sodass sie
optisch konsistent aussehen. Außerdem wird die grüne Drag-over-Hervorhebung jetzt
korrekt angezeigt, wenn die erste Sprache zurück in eine leere Tabelle
„Verfügbare Sprachen“ gezogen wird.
