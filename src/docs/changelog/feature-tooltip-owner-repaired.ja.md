# コンテキストヘルプの表示維持

**機能ブランチ:** feature-tooltip-owner-repaired

## フォーカスやホバーでヘルプを読む

共通の情報ボタンは、フォーカスがある間、またはポインターがボタンかパネル上にある間、ヘルプを表示し続けます。ボタン間の移動では現在の説明を選び、古いポインターイベントによる誤終了を防ぎます。テーマに従う固定パネルは配置を維持し、隙間を越えてポインターを移動できます。 ポインターが共通パネル上にあるままキーボードのフォーカスで説明を切り替えると、そのホバー操作は新しく表示された説明に引き継がれ、ポインターが離れるかヘルプを閉じるまで続きます。

## 閉じる操作と後片付け

Escape はフォーカスを移動せずにヘルプを閉じ、他の Escape 操作と既存の説明を維持します。新しい操作で再び開けます。ボタンの削除やページ変更では表示中のヘルプを解除します。既存の翻訳文とチュートリアルの操作部は変わりません。
