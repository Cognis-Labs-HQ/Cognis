# Wiederherstellung des Chats in der Meeting-Seitenleiste

## Meeting- und Direktchats werden in Meetings geladen

Die Seitenleiste von Meetings stellt fehlende Raumschlüssel jetzt über den Ladeablauf von Social Messages wieder her. Dadurch werden Unterhaltungen in Meeting-Räumen und Direktnachrichten mit Teilnehmenden genauso wie auf der Seite Nachrichten geladen.
