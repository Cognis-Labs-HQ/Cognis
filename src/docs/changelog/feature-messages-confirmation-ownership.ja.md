## 元の対象に選択を限定

メッセージ2.8.2は退出とテンプレート確認を元の対象に限定します。安全な閉じ方では変更せず、重複や古い操作で書き込みを繰り返しません。新しいルーム、アカウント、セッション、テンプレート設定を維持します。
