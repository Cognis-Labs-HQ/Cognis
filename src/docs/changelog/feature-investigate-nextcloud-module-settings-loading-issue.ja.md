# モジュール設定ポップアップをアダプターに合わせました

**Feature Branch:** feature-investigate-nextcloud-module-settings-loading-issue

## モジュール行から統一設定を開けるようになりました

Jitsi Meet と Nextcloud Whiteboard は、個別の歯車ではなくモジュール行そのものから設定を開くようになり、アダプター設定と同じ操作感になりました。

## 設定にモジュールの電源操作を追加しました

モジュール設定ポップアップに有効化トグルを追加し、管理者が設定と電源状態をまとめて調整できるようにしました。

## 不足している依存関係は明確な設定エラーとして表示されます

Nextcloud Whiteboard は、必要な実行時依存関係が利用できない場合でも設定エンドポイントを登録し続けます。これにより、管理者はルート未検出の 404 ではなく、サービス利用不可レスポンスを受け取ります。

## シークレット設定前でも部分更新を保存できます

Nextcloud Whiteboard 設定は、API キー欄を意図的に空のままにした場合でも、サーバー URL とアップロード上限の更新を受け付けます。有効なキーが設定されるまでは、モジュールは引き続き未完了として扱われます。

## フィールド単位の検証で設定を開いたままにします

モジュール設定の検証エラーは、無効なフィールドを示すようになりました。共有設定ポップアップは開いたまま該当入力をマークし、有効な管理者入力を失わないようにします。
