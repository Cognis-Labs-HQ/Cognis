# Shell Pesan yang Andal

**Cabang Fitur:** feature-fix-messages-page-missing-navigation-items

## Memuat shell dasbor lengkap

Halaman Pesan kini menggunakan siklus hidup halaman bersama yang sama seperti semua halaman dasbor lainnya. Siklus hidup tersebut memuat penyedia kapabilitas sebelum pemasangan dan plugin bilah navigasi setelah shell dasbor tersedia, sehingga semua item navigasi ditampilkan dan navigasi aplikasi satu halaman berikutnya tetap memiliki elemen yang diperlukan.
