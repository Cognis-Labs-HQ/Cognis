# Akses Runtime Modul

**Cabang Fitur:** feature-allow-importing-cognis-internals-via-privileged-flag

## Izinkan sumber daya runtime Cognis

Pengaktifan modul tidak lagi menolak impor biasa sumber daya browser Cognis yang tersedia, URL API langsung, atau kelas gaya bersama. Pemeriksaan pengaktifan operasional tetap dijalankan, sedangkan pendaftaran rute dan kapabilitas yang sensitif terhadap keamanan tetap memerlukan flag `privileged` pada manifes.
