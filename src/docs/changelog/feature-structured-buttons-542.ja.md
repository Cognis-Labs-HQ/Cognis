# 構造化ボタンのスタイル

**機能ブランチ:** feature-structured-buttons-542

## 共通の中立ボタン

既定および中立の構造化ボタンに標準の中立クラスを付与し、既存の折り返し、フォント、精度の低いポインター向けサイズの共通スタイルを適用します。確認と危険のバリアントは、それぞれのクラスとすべてのネイティブ属性を保持します。

## 検証と契約

公開レンダラーと合成データによる管理画面のテストで、バリアント、エスケープ、無効状態、繰り返し描画、フォームの安全性を確認します。共通 UI のドキュメントは四言語で契約を説明し、既存のチュートリアル手順は変更しません。これは #542 の限定的な対応であり、全ボタンの監査完了ではありません。
