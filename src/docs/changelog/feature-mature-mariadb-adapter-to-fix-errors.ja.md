# 安定したMariaDB起動

## MariaDBの準備完了を待機

Cognisは、データベース初期化中にマイグレーションを失敗させるのではなく、制限された起動時間内で一時的なMariaDB接続障害を再試行するようになりました。デプロイはMariaDBコンテナの最新安定版を追跡し、ヘルスチェックではMariaDBの初期化時間を長く確保します。新しいコンテナでは常にランダムなrootパスワードを生成し、データベースのシステムテーブルを自動更新します。ユーザーが指定したrootパスワードはデプロイで受け付けません。 MariaDBは外部キー列にインデックス可能な文字列型を生成するようになり、MariaDBとPostgreSQLのスキーマ修復は制約を維持して修復失敗を報告します。
