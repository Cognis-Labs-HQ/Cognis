# Sprachpräferenzen korrigiert

## Sprachen lassen sich zuverlässiger ziehen

Die Tabellen für Sprachpräferenzen in den Einstellungen ermitteln Ablageziele jetzt anhand der Zeigerposition, wenn der Browser ein benachbartes Kind- oder Umgebungselement als Ablageziel meldet. Dadurch wird eine Sprache aus „Verfügbare Sprachen“ zuverlässiger beim ersten Ablegen in „Bevorzugte Sprachen“ verschoben.
