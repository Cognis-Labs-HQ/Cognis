# メッセージスタイルが全体に適用

**Feature Branch:** copilot/respect-user-preferences-message-style

## スピーチバブルおよびIRCスタイルがミーティングチャットでも反映

ミーティングページのミニチャットパネルが、ユーザーのメッセージスタイル設定（デフォルト、スピーチバブル、IRC）を読み取り、チャットメッセージに適用するようになりました。これはスタンドアロンのメッセージページの動作と同じです。

## 入力中インジケーターを正しい位置に移動

メッセージページの「入力中…」通知が、メッセージスレッドの上部から作成エリアの入力欄の直上へ移動しました。これは次の受信メッセージが表示される位置です。

## IRC既読表示とリアクションを改善

メッセージページのIRC表示では、既読表示をメッセージ行内に保ち、既読アバターを中央揃えに修正しました。スピーチバブルの視認性も向上しています。さらに、ミーティングのミニチャットに、メッセージページと同じフローティングのリアクションメニューと絵文字ピッカーを追加しました。

## 吹き出しの視認性を強化

吹き出しスタイルのメッセージは、暗い背景でも見やすいように、より浮き上がるサーフェストークンと強めのシャドウを使うようになりました。

## ダークモードの吹き出し配色

ダークモードでは、自分のメッセージが濃紺（#1d2f4a）、相手のメッセージが暗いティール（#1a3336）で表示されます。

## SVG配信状態アイコン

円形インジケーターがSVGアイコンに置き換わりました。送信直後は「?」ボックスアイコン、配信確認後はチェックマークボックスアイコンが表示されます。

## 既読アバターのスタック表示

複数の既読者アバターが右から左へ重なって表示されます。未読時の空白円は削除されました。アバター上にカーソルを合わせると、各既読者の名前と既読時刻がポップアップ表示されます。ステータスアバターはプロフィールプレビューカードを表示しなくなりました。

## 吹き出し外へのリアクション移動

リアクションは吹き出しの外側（下部）に表示され、リアクションチップがある場合は背景に淡い陰影がつきます。

## IRCハンドル形式

IRCレイアウトでは、送信者が `{{handle}}` の二重波括弧形式で表示されます。

## スピーチバブル送信者アバター

スピーチバブルモードでは、自分のメッセージの右上隅に送信者アバターが重なって表示されます。

## 自分のメッセージの水平オーバーフロー修正

自分のメッセージバブルは、テキスト本文またはメタデータ行（タイムスタンプ＋ステータスアイコン）の広い方に合わせてサイズが調整されるようになりました。短いメッセージで水平スクロールバーが表示されなくなりました。

## ページスクロールなしのビューポート高さレイアウト

メッセージスレッドパネルがビューポートの全高を正しく埋めるようになりました。メッセージリストは内部でスクロールし、コンポーザーは下部に固定されたままです。ページレベルのスクロールバーは表示されず、他のページに移動するとそのページの通常のスクロール動作が復元されます。

## 既読表示ホバーポップアップを修正

既読アバターにカーソルを合わせると表示される「N人に既読」ポップアップが正しい位置に表示されなかった問題を修正しました。ポップアップ要素に `position: fixed` を追加し、ホバーしたアバターに正確にアンカーするようにしました。

## 自分のメッセージの水平オーバーフローを解消（レイアウト修正）

`max-width` をバブル自体ではなくメッセージラップのフレックスアイテムに適用するように変更し、パーセンテージがスレッド幅に対して正しく解決されるようになりました。

## コンポーザーが画面外に切れなくなりました

ビューポートからコンテンツパネルまでの高さチェーン全体で `height: 100%; overflow: hidden` を適用するようにし、`.content-panel` も含めたことでコンポーザーが常に完全に表示されます。

## IRC: 自分のメッセージを全体で左揃えに

IRCスタイルでは、自分のメッセージの絵文字リアクションチップ、リアクションピッカー、既読ステータスがすべて受信メッセージと同様に左揃えになりました。メッセージ間の間隔が読みやすさのために広げられました。

## スピーチバブルのアバターがコーナーに重なって表示

スピーチバブルスタイルの送信者アバターが、自分のメッセージは右上コーナー、受信メッセージは左上コーナーにバブルと重なって表示されるようになりました。

## スピーチバブルの外に既読表示を移動

スピーチバブルスタイルでは、タイムスタンプと既読表示の行がバブルの内側ではなく下に表示されるようになりました。

## 絵文字クイックデッキは常に5つの選択肢を表示

提案された絵文字をリアクションとして使用すると、絵文字プールから補充されるためピッカーバーは常に5つの提案を維持します。

## ページコンポーザーの `contentScrolling` オプション

`createPageComposer` に新しい `contentScrolling` オプション（デフォルト `true`）を追加しました。`contentScrolling: false` を渡すことでページを塗りつぶし高さモードに切り替えられます。コンテンツグリッドはコンテンツパネルを利用可能なビューポートに制限し、独自のスクロールを無効にすることで、ページが内部スクロールを独立して管理できるようになります。

## 長いスレッドでもコンポーザーを常時表示

メッセージページは高さ固定のコンテンツモードで動作するようになり、履歴が長い場合でもスレッド領域が制限されてコンポーザーが見えなくならなくなりました。

## 「その他のリアクション」で名前と時刻を横並び表示

その他のリアクションのポップアップは、各行を「絵文字 + ユーザー名 + リアクション時刻」の1行表示に変更しました。

## 「X人が既読」ヘッダーにアバター表示を追加

既読ポップアップのヘッダーに、人数テキストに加えて読者アバターのストリップを表示します。

## IRCスタイルの間隔を拡大

IRCスタイルでメッセージ間隔を広げ、フローティングのリアクションピッカーとツールチップ領域が重ならずに表示されるようにしました。
