# メッセージスタイルが全体に適用

## スピーチバブルおよびIRCスタイルがミーティングチャットでも反映

ミーティングページのミニチャットパネルが、ユーザーのメッセージスタイル設定（デフォルト、スピーチバブル、IRC）を読み取り、チャットメッセージに適用するようになりました。これはスタンドアロンのメッセージページの動作と同じです。

## 入力中インジケーターを正しい位置に移動

メッセージページの「入力中…」通知が、メッセージスレッドの上部から作成エリアの入力欄の直上へ移動しました。これは次の受信メッセージが表示される位置です。

## IRC既読表示とリアクションを改善

メッセージページのIRC表示では、既読表示をメッセージ行内に保ち、既読アバターを中央揃えに修正しました。スピーチバブルの視認性も向上しています。さらに、ミーティングのミニチャットに、メッセージページと同じフローティングのリアクションメニューと絵文字ピッカーを追加しました。

## 吹き出しの視認性を強化

吹き出しスタイルのメッセージは、暗い背景でも見やすいように、より浮き上がるサーフェストークンと強めのシャドウを使うようになりました。

## ダークモードの吹き出し配色

ダークモードでは、自分のメッセージが濃紺（#1d2f4a）、相手のメッセージが暗いティール（#1a3336）で表示されます。

## SVG配信状態アイコン

円形インジケーターがSVGアイコンに置き換わりました。送信直後は「?」ボックスアイコン、配信確認後はチェックマークボックスアイコンが表示されます。

## 既読アバターのスタック表示

複数の既読者アバターが右から左へ重なって表示されます。未読時の空白円は削除されました。アバター上にカーソルを合わせると、各既読者の名前と既読時刻がポップアップ表示されます。

## 吹き出し外へのリアクション移動

リアクションは吹き出しの外側（下部）に表示され、リアクションチップがある場合は背景に淡い陰影がつきます。

## IRCハンドル形式

IRCレイアウトでは、送信者が `{{handle}}` の二重波括弧形式で表示されます。

## スピーチバブル送信者アバター

スピーチバブルモードでは、自分のメッセージの右上隅に送信者アバターが重なって表示されます。
