# メッセージスタイルが全体に適用

## スピーチバブルおよびIRCスタイルがミーティングチャットでも反映

ミーティングページのミニチャットパネルが、ユーザーのメッセージスタイル設定（デフォルト、スピーチバブル、IRC）を読み取り、チャットメッセージに適用するようになりました。これはスタンドアロンのメッセージページの動作と同じです。

## 入力中インジケーターを正しい位置に移動

メッセージページの「入力中…」通知が、メッセージスレッドの上部から作成エリアの入力欄の直上へ移動しました。これは次の受信メッセージが表示される位置です。

## IRC既読表示とリアクションを改善

メッセージページのIRC表示では、既読表示をメッセージ行内に保ち、既読アバターを中央揃えに修正しました。スピーチバブルの視認性も向上しています。さらに、ミーティングのミニチャットに、メッセージページと同じフローティングのリアクションメニューと絵文字ピッカーを追加しました。
