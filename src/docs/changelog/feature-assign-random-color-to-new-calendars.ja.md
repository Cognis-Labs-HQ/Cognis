# 新しいカレンダーの多彩な色

**Feature Branch:** feature-assign-random-color-to-new-calendars

## 新しいカレンダーはランダムな色で始まります

新しいカレンダーには、常に青色ではなく、カレンダーパレットからランダムに選ばれた色が設定されるようになりました。作成ダイアログでは保存前に選択された色が表示され、引き続き変更できます。
