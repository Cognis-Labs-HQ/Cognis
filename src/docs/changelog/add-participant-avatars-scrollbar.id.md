# Avatar Chat Rapat

**Cabang Fitur:** copilot/add-participant-avatars-scrollbar

## Avatar Peserta di Chat

Panel chat Meetings sekarang menampilkan avatar peserta dalam bilah gulir horizontal tepat di bawah judul Chat Rapat. Menekan avatar peserta akan membuka chat pribadi pengguna saat ini dengan peserta tersebut tanpa keluar dari halaman Meetings.

## Kembali ke Chat Rapat

Saat chat pribadi dibuka dari bilah avatar, tombol untuk kembali ke chat rapat akan ditampilkan. Chat rapat terakhir yang dimuat tetap aktif meskipun pengguna meninggalkan rapat.
