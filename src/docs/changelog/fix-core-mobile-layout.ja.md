# モバイル向けコア配置

**機能ブランチ:** fix-core-mobile-layout

## 共通操作部の省スペース化

スマートフォンのヘッダーを二段にまとめます。ツールバーボタンはヘッダーの背後をスクロールし、ガイドの操作部は小さく、強調対象は見やすく表示します。縦の短い画面では説明にヘッダー領域も使い、フォント設定とタッチ操作を維持します。

## 組み込みページの可読性

管理画面ではゲートウェイ名と操作部を分けます。エラーコードはコンテンツ列に収まります。カレンダーの月・週表示は操作しやすい日付ボタンを維持して横スクロールでき、年表示は狭い一列に収まります。外部モジュールのページは対象外です。
