# 招待メールの入力案内

**機能ブランチ:** feature-invitation-email-validation

## 送信前に招待先を修正

Registration 1.2.10 は共通フォームビルダーとブラウザー標準のメール形式検証を使い、必須の招待先アドレスを確認します。翻訳されたトーストで無効な欄を示し、フォーカスを移して入力を修正できるように保持します。クリックと Enter キーは同じ検証を行います。

## 招待操作の有効範囲を維持

進行中の試行で操作を繰り返しても、リクエストを重複送信しません。閉じる操作、Escape キー、ページ移動でメールフォームを解放し、遅れて届いた結果で移動先ページを更新しません。サーバーの方針と既存の招待結果は変わりません。招待ガイドは四言語で入力の修正を説明します。

## 検証の境界を維持

検証用の翻訳が不足している場合は、一般的な招待失敗に置き換えず、明示的なアプリケーションエラーとして扱います。前のダイアログが閉じる途中でも、新しいダイアログのラベルとエラーはそのダイアログの入力欄に関連付けられます。プロバイダーのエラー詳細を検証文として表示しません。
