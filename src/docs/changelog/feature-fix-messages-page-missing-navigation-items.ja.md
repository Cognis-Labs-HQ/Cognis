# 安定したメッセージ画面

**機能ブランチ:** feature-fix-messages-page-missing-navigation-items

## 完全なダッシュボードを読み込む

メッセージページは、ほかのすべてのダッシュボードページと同じ共通ページライフサイクルを使用するようになりました。このライフサイクルはマウント前に機能プロバイダーを、ダッシュボードシェルの生成後にナビゲーションバーのプラグインを読み込むため、利用可能なナビゲーション項目がすべて表示され、その後の SPA ナビゲーションでも必要な要素が維持されます。
