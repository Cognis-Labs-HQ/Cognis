# Pembaruan keandalan Nextcloud Whiteboard

## Pembukaan whiteboard dibatasi pemeriksaan awal websocket

Whiteboard kini menunggu pemeriksaan ketersediaan HTTP dan autentikasi websocket sebelum kanvas yang dapat diedit dibuat atau dibuka.

## Peningkatan penggunaan kanvas

Bilah alat kini memiliki kunci alat, perilaku kursor pilih lebih jelas, avatar kehadiran mengutamakan foto profil, dan daftar whiteboard menampilkan waktu pembaruan terakhir.
