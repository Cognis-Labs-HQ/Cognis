# Indeks Perubahan

## Tampilkan Semua Entri

Halaman log perubahan kini membangun navigasinya dari setiap entri Markdown log perubahan yang ditemukan di direktori log perubahan bersama, sehingga file mendatang muncul otomatis.

## Tampilkan Branch Fitur

Halaman log perubahan yang dirender kini menyertakan branch fitur yang diambil dari nama file log perubahan.
