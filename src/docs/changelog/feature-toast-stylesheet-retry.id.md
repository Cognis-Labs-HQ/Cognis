# Pemulihan Gaya Toast

**Cabang Fitur:** feature-toast-stylesheet-retry

## Pulihkan gaya pemberitahuan

Permintaan gaya toast berbagi maksimal dua percobaan per siklus, masing-masing dibatasi lima detik. Percobaan gagal melepaskan pendengar peristiwa dan tautan miliknya; pemberitahuan berikutnya dapat mencoba lagi. Lembar gaya yang sudah ada tetap dimiliki pemuat asalnya. Menutup toast saat gaya dimuat tidak membukanya kembali.
