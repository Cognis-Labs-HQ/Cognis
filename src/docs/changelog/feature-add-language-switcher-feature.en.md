# Quick Language Switching

## Optional dashboard switcher

The language switcher is enabled by default and controlled by Show Language Switcher in one continuous settings block above the side-by-side language tables. The dashboard reads and normalizes the saved language priority, and only displays the switcher when at least two languages can be cycled. Each click previews the next preferred language; after five seconds without another click, Cognis promotes that language to first preference and reloads the page.
