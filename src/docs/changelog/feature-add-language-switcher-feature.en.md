# Quick Language Switching

## Optional dashboard switcher

The language switcher is shown by default and controlled by Show Language Switcher in one continuous settings block above the side-by-side language tables. The dashboard reads and normalizes the saved language priority, and the enabled switcher remains visible even when only one language is preferred. Each click previews the next preferred language; after five seconds without another click, Cognis promotes that language to first preference and reloads the page.
