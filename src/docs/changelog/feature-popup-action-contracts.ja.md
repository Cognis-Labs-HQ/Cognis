# ダイアログ操作

**機能ブランチ:** feature-popup-action-contracts

## フォーカス中の操作を尊重

Enterとスペースはフォーカス中のコントロールに従います。単一行の作成・保存操作を維持し、CSSクラスや操作IDだけで既定の操作を決めません。標準フォームの検証、編集、IME入力、チュートリアルのフォーカス、入れ子の有効期間を保ちます。

## 下書きを安全に保持

未保存の変更の確認では安全な「キャンセル」にフォーカスし、「破棄」を破壊的な操作として表示します。繰り返し、処理中、古い操作によるコールバックの重複を防ぎ、明示的な終了は維持します。

## フッター操作を統一

初期表示、差し替え、追加されたフッターで同じ標準ボタン描画処理と結果のクラスを使用し、「完了」も中立にします。中立の操作はダイアログの外観を維持し、共通の折り返しとタッチ領域の規則を使用します。#542と#330の共通ダイアログ部分を対象とし、全呼び出し側の監査と実ブラウザーのレイアウト検証は別途必要です。
