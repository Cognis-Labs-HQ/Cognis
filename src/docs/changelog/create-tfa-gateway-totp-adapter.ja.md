# TFAゲートウェイとTOTP

## 新しいTFAゲートウェイ

`src/adapters/tfa/*` 配下のアダプター検出、ユーザー方式API、復旧コードAPI、管理者リセットAPIを備えた専用 `tfa` ゲートウェイを追加しました。

## TOTPアダプターを追加

`src/adapters/tfa/totp` に、セットアップ検証とログインコード検証を行う `totp` アダプターを追加しました。

## ログインとセキュリティ統合

二要素プロンプト、設定強制リダイレクト、Administration の TFA 強制トグル、ユーザー単位の TFA リセット操作に対応するようログイン/セキュリティ動作を更新しました。
