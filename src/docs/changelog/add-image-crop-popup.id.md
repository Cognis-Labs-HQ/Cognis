# Popup Potong Gambar

## Potong Sebelum Unggah

Unggahan avatar dan banner profil sekarang membuka popup terlebih dahulu agar pengguna bisa menggeser dan menyesuaikan gambar sesuai proporsi bingkai yang terlihat di aplikasi.

## Grid Panduan Diperluas

Popup pemotongan sekarang menyediakan grid panduan yang dapat diperluas serta kontrol zoom agar penyesuaian bingkai sebelum unggah lebih mudah.
