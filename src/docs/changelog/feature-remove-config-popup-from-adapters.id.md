# Kontrol Adapter Lebih Rapi

## Popup Pengaturan Kosong Dihapus

Baris adapter tidak lagi membuka popup pengaturan jika adapter tidak memiliki bidang yang dapat dikonfigurasi selain status daya. Gunakan kontrol daya yang sudah tersedia pada baris adapter untuk mengaktifkan atau menonaktifkannya.

## Kontrol Daya LDAP

Popup pengaturan Autentikasi LDAP kini memiliki kontrol daya agar administrator dapat mengaktifkan atau menonaktifkan adapter tanpa meninggalkan konfigurasinya.
