# SMTP配信修正

## EHLOフォールバック改善

SMTPアダプターは EHLO ホスト名を、設定された SMTP リレーホストから解決するようになり、リレーホストがない場合のみ `localhost` を使います。

これにより、`EHLO localhost` を受け付けないサーバーでのSMTP拒否を減らせます。

## SMTP回帰テスト

テストメール送信が送信元ドメインではなく、リレーホストの EHLO 識別子を使うことを確認する SMTP アダプター重点テストを追加しました。

## SMTP試験エラー明確化

SMTPテスト用エンドポイントは、汎用的な bad request にフォールバックする代わりに、ユーザーに安全な構造化エラー詳細を返すようになりました。`RCPT TO` 拒否のようなSMTPコマンド失敗では、失敗したSMTPコマンドとサーバー応答コードがAPIに含まれます。

Administration のテストメール処理はこのAPIエラー内容を読み取り、具体的な失敗メッセージをトーストに直接表示するため、運用者は配信拒否の理由をすぐに把握できます。

## HELO識別子の委譲

SMTP配信は、EHLO/HELO 識別子を `HOST` や `from` の送信元ドメインから導出しないようになりました。アダプターは設定された SMTP リレーホスト名で名乗り、リレーホストがない場合のみ `localhost` にフォールバックします。

これにより、送信者識別ポリシーは隣接するメールサーバー側に委譲され、SPF `helo` 拒否を招くアプリ側 HELO 識別子の強制を避けられます。
