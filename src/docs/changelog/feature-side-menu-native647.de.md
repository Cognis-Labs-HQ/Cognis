# Seitenmenü-Aktionen

**Feature-Zweig:** feature-side-menu-native647

## Auswahl ohne Absenden

Auswahlen im gemeinsamen Seitenmenü verwenden jetzt ausdrücklich Schaltflächen ohne Formularabsendung, sowohl in festen als auch in aufklappbaren Gruppen. Auswahlrückrufe, aktiver Zustand, Scrollen zu Überschriften, Gruppenspeicherung und Lebenszyklusbereinigung bleiben unverändert.
