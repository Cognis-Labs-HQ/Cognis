# Suchoptionen

## Erweiterter Suchindex

Das globale Such-Popup enthält jetzt ein dynamisches Registrierungswerkzeug, damit Seiten, sichtbare Seiteninhalte, Beiträge, Chats, Nachrichten und andere UI-Bereiche durchsuchbare Ergebniskategorien beitragen können.

## Treffersteuerung

Such-Popups enthalten jetzt Steuerungen für Ganzwortsuche, reguläre Ausdrücke und Groß-/Kleinschreibung.
