# Panduan Penyiapan Modul

**Cabang Fitur:** module-activation-guidance

## Langkah Jelas Setelah Aktivasi

Modul kini dapat mendeklarasikan panduan aktivasi yang dilokalkan dengan satu atau beberapa target adaptor. Setelah aktivasi, Cognis menampilkan langkah berikutnya dari modul dan menawarkan akses langsung ke Administrasi tanpa membuat core mengetahui nama khusus penyedia.
