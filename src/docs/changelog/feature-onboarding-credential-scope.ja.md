# 制限された登録

**機能ブランチ:** feature-onboarding-credential-scope

## 制限されたオンボーディング

登録は通常のセッションではなく、宣言された本人向け操作に有効期限付きAuth権限を使用します。Notifyは新しいアカウントに限定され、通常のログインは引き続きTFAを適用します。

## 明示的な完了処理

完了、キャンセル、通常のログインで権限を失効させます。存続や保存の失敗時は追加アクセスを拒否しますが、完了済みの外部変更を一括で取り消すことはできません。

## 拡張機能の移行

完了処理の拡張機能は宣言された操作を使用します。Terms of Service 1.6.13と公開を調整し、実際の同意と文書バージョン確認を維持してください。

必須の完了処理、宣言、フォーム項目が利用できない場合、登録の送信を拒否します。操作の宣言は拡張機能の呼び出し前に固定され、確認画面を離れるとポップアップを閉じて資格情報を失効させます。
