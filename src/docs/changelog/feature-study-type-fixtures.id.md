# Kontrak Pengujian Study

**Cabang Fitur:** feature-study-type-fixtures

## Data Uji Study Bertipe

Pengujian Classes dan Flashcards kini menolak operasi bootstrap yang tidak digunakan secara eksplisit tanpa membuat gateway komponen lain. Peran akses kelas mempertahankan tipe literalnya, dan pengujian persistensi papan peringkat memeriksa bentuk skor sebelum mengakses indeksnya. Pemeriksaan perilaku dan alur terdaftar yang ada tetap dipertahankan.
