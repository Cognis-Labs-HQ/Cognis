# Mode gelap untuk kotak centang popup catatan perubahan

## Visibilitas kotak centang yang lebih baik dalam mode gelap

Kotak centang “jangan tampilkan lagi” pada popup catatan perubahan rilis kini menggunakan skema warna aktif dan warna aksen aplikasi sehingga kontrol tetap jelas dan mudah dibaca dalam tema gelap maupun terang.
