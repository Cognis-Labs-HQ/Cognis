# Studyテストの契約

**機能ブランチ:** feature-study-type-fixtures

## 型付きStudyテストデータ

ClassesとFlashcardsのテストは、他のコンポーネントのゲートウェイを生成せず、未使用の初期化操作を明示的に拒否します。クラスのアクセスロールはリテラル型を保持し、ランキングの永続化テストは添字アクセス前にスコアの形式を検証します。既存の動作検証と登録済みフローは維持されます。
