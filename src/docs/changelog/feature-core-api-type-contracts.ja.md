# Core と API の型契約

**機能ブランチ:** feature-core-api-type-contracts

## 公開型契約

アクセスロールを統一し、モジュールの機能要件とアカウント識別子を宣言して、型付きコンポーネントメタデータを保持します。機能の取得とディレクトリ検出を実行時の契約に合わせます。

名前空間のアクセスリストは読み取り専用のコンポーネント ID を受け入れ、Files ゲートウェイの変更不可能な登録情報を維持します。フロー結果ヘルパーはステージ結果が undefined の場合も受け入れ、既存の実行時動作と同様に null を返します。

## 型付き API テストデータ

完全なモジュールデータ、登録済み機能ストア、API が所有する文書データベースのテスト実装を使用します。ルートのペイロードを変更せず、テスト内のアカウント作成ロールとソース認証情報の応答を修正します。

## バージョン

Core を 0.6.3、API を 0.13.32 に更新し、ワークスペースのロック情報と Core 依存関係の上限を同期します。
