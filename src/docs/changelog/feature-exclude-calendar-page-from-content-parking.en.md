# Calendar Navigation

**Feature Branch:** feature-exclude-calendar-page-from-content-parking

## Calendar content parking opt-out

The Calendar page now disables page composer content parking so switching calendar views rebuilds the active controls and keeps navigation responsive. All-day event date inputs are also cleared before switching from date-time to date mode, preventing repeated browser format warnings during calendar refreshes.
