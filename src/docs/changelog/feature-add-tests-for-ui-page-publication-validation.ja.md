# UI再利用を強制
**機能ブランチ:** feature-add-tests-for-ui-page-publication-validation

## ページ構成を保護
マウント関数を公開しながら Cognis ページコンポーザーを使用しないコアページとインストール済み外部モジュールページを、自動アーキテクチャ検査が拒否するようになりました。

## 再利用ユーティリティを保護
外部ブラウザモジュールは Cognis UI 再利用面がすでに提供する関数を再宣言できなくなり、マウントルートへの直接描画もコンポーザーの未使用とともに報告されます。


## フォーム構成を保護
コアおよび外部モジュールのブラウザーコードは、フォームを公開または送信を処理する場合に Cognis フォームビルダーを使用する必要があります。ビルダーは信頼済みの複雑な内容と検証済みフォーム属性に対応し、独自フォームでも共通ラッパーを維持します。

## 匿名向けモジュールページを公開
有効なモジュールは、利用規約などのコンテンツ用に公開 SPA ルートを明示的に登録できるようになりました。匿名クライアントには公開ルート記述子だけが提供され、認証済みルートは保護されたままです。また、公開ルートで匿名アクセスとロール制限を併用することはできません。
