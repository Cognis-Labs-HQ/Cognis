# メッセージ：テンプレートサイドバー

**Feature Branch:** copilot/create-message-template-screen

## テンプレート管理をサイドバーに移動

メッセージテンプレートは、コンポーザーツールバーからサイドバーで管理するよう変更されました。テンプレートセクション上部のラベル付きボタンが作成・編集ポップアップを開き、保存済みテンプレートはリストに表示され、使用・編集・削除の操作が可能です。

## ポップアップをエディタのみに簡素化

テンプレートポップアップはエディタフォームのみを表示するようになりました。ポップアップ内のリストからテンプレートを選択する方式は廃止され、サイドバーのテンプレートタイトルをクリックすると直接コンポーザーに読み込まれます。

## ポップアップ送信ボタンの「作成」と「保存」ラベル

ポップアップの送信ボタンは、新しいテンプレートを追加する際は「作成」、既存のテンプレートを編集する際は「保存」と表示されるようになりました。

## チャットリストとテンプレートリストが独立してスクロール

会話リストとテンプレートリストはそれぞれ独自のスクロール領域を持つようになり、会話が多くてもテンプレートセクションが画面外に押し出されることがなくなりました。

## テンプレートをアカウントごとに分離

保存済みメッセージテンプレートは、作成したアカウントのみに限定されるようになりました。共有デバイスでアカウントを切り替えると、そのアカウント自身のテンプレートのみが表示され、前のセッションのテンプレートは表示されません。

## レイアウト再描画時にコンポーザーのテキストを保持

レスポンシブな列のブレークポイントを超えるなど、ページコンポジターがレイアウトグリッドを再構築する際に、メッセージコンポーザーで入力中の未送信テキストが失われなくなりました。
