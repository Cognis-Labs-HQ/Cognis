# 検索可能な管理者プロフィール

**Feature Branch:** feature-restrict-admin-profile-visibility-settings

## 管理者はプロフィールを非表示にできなくなりました

教師、管理者、所有者のプロフィールは、公開範囲がデフォルトで「友達」になります。アカウントをこれらの役割に変更した場合も、プロフィールが「友達」に更新されます。プロフィール編集画面では互換性のない選択肢が無効になり、API も制限を回避する操作を拒否します。
