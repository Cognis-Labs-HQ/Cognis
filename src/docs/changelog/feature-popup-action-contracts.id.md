# Tindakan Dialog

**Cabang Fitur:** feature-popup-action-contracts

## Hormati Tindakan Terfokus

Enter dan Spasi tetap mengikuti kontrol yang difokuskan. Tindakan konstruktif satu baris tetap tersedia tanpa menjadikan kelas CSS atau ID tindakan sebagai kewenangan. Validasi formulir asli, penyuntingan, masukan IME, fokus tutorial, dan siklus hidup bertingkat tetap dipertahankan.

## Pertahankan Draf dengan Aman

Konfirmasi perubahan yang belum disimpan memfokuskan Batal yang aman dan menampilkan Buang sebagai tindakan merusak. Tindakan berulang, tertunda, dan lama tidak memanggil callback dua kali; penutupan langsung tetap tersedia.

## Satukan Kontrol Bawah Dialog

Bagian bawah awal, pengganti, dan yang baru ditambahkan menggunakan perender tombol asli dan kelas akibat yang sama, termasuk Selesai yang netral. Kontrol netral mempertahankan tampilan dialog serta memakai aturan pembungkusan dan target sentuh bersama. Perubahan ini mencakup bagian dialog bersama dari #542 dan #330; audit seluruh pemanggil dan verifikasi tata letak browser asli tetap terpisah.
