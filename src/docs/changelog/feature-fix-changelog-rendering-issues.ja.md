# 完全なリリース変更履歴の要約

## リリースポップアップに詳細を表示

リリース通知で見出しだけでなく、各変更見出しの下に説明内容も表示されるようになりました。

## インストール済み外部モジュールを含める

リリースフィードがインストール済み外部モジュールのローカライズされた変更履歴ファイルを検出し、各項目をモジュールの変更履歴ページへリンクするようになりました。

## リンクおよび分類された変更履歴

リリースポップアップの見出しから、Cognis Core の完全な変更履歴へ直接移動できるようになりました。外部モジュールの変更履歴はモジュール名を分けて表示し、完全な変更履歴インデックスにも取り込まれます。

## リポジトリ参照を更新

過去のコミットリンクが現在の Cognis-Labs-HQ/Cognis リポジトリを参照するようになりました。
