# 完全なリリース変更履歴の要約

**Feature Branch:** feature-fix-changelog-rendering-issues

## リリースポップアップに詳細を表示

リリース通知で見出しだけでなく、各変更見出しの下に説明内容も表示されるようになりました。

## インストール済み外部モジュールを含める

リリースフィードがインストール済み外部モジュールのローカライズされた変更履歴ファイルを検出し、各項目をモジュールの変更履歴ページへリンクするようになりました。

## リンクおよび分類された変更履歴

リリースポップアップの見出しから、Cognis Core の完全な変更履歴へ直接移動できるようになりました。外部モジュールの変更履歴はモジュール名を分けて表示し、完全な変更履歴インデックスにも取り込まれます。

## リポジトリ参照を更新

過去のコミットリンクが現在の Cognis-Labs-HQ/Cognis リポジトリを参照するようになりました。

## 変更履歴の出所を完全化

自動チェックにより、ローカライズされたすべての変更履歴に Feature Branch と正規のコミットリンクが必須になりました。過去のいずれのリポジトリにも対応付けられない項目には、空のコミット一覧とともに N/A を明記します。

## 短いコミット参照

変更履歴ページでは各コミットリンクを7文字の参照として表示し、リンク先には完全な正規コミット URL を保持するようになりました。

## リリース画面でも短い参照

リリース変更履歴ポップアップにも完全な変更履歴ページと同じ短縮参照フォーマッターを適用し、完全なコミット URL をリンク先として保持します。

## コミット来歴の手順

AI コントリビューション手順では、実装前に要求された場合、直前の実装コミットを記録する変更履歴のみの最終管理コミットが必須になりました。
