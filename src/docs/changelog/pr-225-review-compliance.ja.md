# PR 225 レビュー準拠

**機能ブランチ:** pr-225-review-compliance

## より安全な外部アカウント

外部アカウント名の生成時にプロバイダー境界を維持し、不適切なプロバイダー表示には検証済みのアダプター名前空間を使用するようになりました。また、登録確定に失敗した場合のロールバックでは、認証済み ID を意図的な削除として記録しません。

## 正しいフォーム動作

必須ラジオグループは選択されるまで無効のままになります。プロフィール同期はプロフィールデータを置き換える可能性があるため、破壊的操作のスタイルを使用します。

## バージョン準拠

API 契約と影響を受けるすべてのコンポーネントで、バージョンと検証済み依存関係の上限を整合させました。認証オーケストレーションもレビュー可能なソースファイルに分割し、LDAP 管理テストでは正規のプロバイダー別アカウント名を使用します。
