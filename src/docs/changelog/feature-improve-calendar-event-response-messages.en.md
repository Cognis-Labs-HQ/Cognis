# Calendar Replies

**Feature Branch:** feature-improve-calendar-event-response-messages

## Friendlier Invite Responses

Calendar notifications now use friendlier invitation, response, reminder, and cancellation wording, preserve pending invite links, show the inviter or responder as the sender, combine participant response status in event popups, and refresh participant responses once per minute while the popup is open.
