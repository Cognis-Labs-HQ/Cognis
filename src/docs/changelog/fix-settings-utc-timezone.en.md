# UTC in Settings

**Feature Branch:** fix-settings-utc-timezone

## Choose UTC Explicitly

Date and Time settings always offer UTC, including browsers that omit it from their timezone list. Auto-detect, regional choices and saved timezone values remain available. UTC uses the existing save, discard and timestamp display behavior.
