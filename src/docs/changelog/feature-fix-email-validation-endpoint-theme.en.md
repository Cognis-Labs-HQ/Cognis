# Themed Email Verification

**Feature Branch:** feature-fix-email-validation-endpoint-theme

## Cognis styling and confirmation motion

The email verification page now uses the shared Cognis theme, including the saved light or dark appearance, preferred application font, standard neutral action styling, and Cognis branding used by share-password prompts. The standalone hourglass was removed in favor of the standard shared loading wheel, which is reliably dismissed after validation completes or fails. Short, one-time tick and cross animations distinguish successful and invalid verification while respecting reduced-motion preferences.
