# Themed Email Verification

## Cognis styling and confirmation motion

The email verification page now uses the shared Cognis theme, including the saved light or dark appearance, preferred application font, standard neutral action styling, and Cognis branding used by share-password prompts. Its standalone result view is marked ready so the shared page-loading wheel does not cover completed validation messages. Short, one-time tick and cross animations distinguish successful and invalid verification while respecting reduced-motion preferences.
