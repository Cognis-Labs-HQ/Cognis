# UTC di Pengaturan

**Cabang Fitur:** fix-settings-utc-timezone

## Pilih UTC Secara Langsung

Pengaturan tanggal dan waktu selalu menyediakan UTC, termasuk pada peramban yang tidak mencantumkannya dalam daftar zona waktu. Deteksi otomatis, zona regional, dan nilai tersimpan tetap tersedia. UTC menggunakan perilaku penyimpanan, pembatalan perubahan, dan tampilan waktu yang sudah ada.
