# モジュール認証プロバイダー

**Feature Branch:** feature-expose-capability-for-modules

## モジュールから認証プロバイダーを登録可能に

Authenticationゲートウェイが`auth:registerProvider`を公開し、LINE連携などのライフサイクル管理対象モジュールがシステムのケイパビリティバス経由でプロバイダーを提供できるようになりました。
