# Verifikasi Masuk LDAP

## Pemilihan sumber responsif

Sumber LDAP bernama tetap berada di atas nama pengguna dan menyesuaikan diri dengan lebar yang tersedia. Sumber tambahan tersedia melalui pemilih luapan yang dapat digulir.

## Verifikasi pengguna nyata

Penyiapan LDAP kini diakhiri dengan pengujian wajib kredensial pengguna yang menampilkan identitas direktori, grup, dan peran Cognis sebelum server dapat disimpan.
