# Anbieternamen für SSO

**Feature-Zweig:** provider-scoped-sso-identities

## Eindeutige externe Namen

Neue externe Konten und Profilnamen enthalten jetzt den Anbieter-Namensraum. Beispielsweise wird ein X-Name zu `x:firehawksystems` und kann neben `line:firehawksystems` sowie dem lokalen Benutzernamen `firehawksystems` bestehen.
