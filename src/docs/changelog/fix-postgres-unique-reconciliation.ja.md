# PostgreSQL の一意キー

**機能ブランチ:** fix-postgres-unique-reconciliation

## 一意キーの整合

PostgreSQL の `ensureTable()` は、新規テーブルと既存テーブルの両方で、列の `unique: true` と複合 `uniqueKeys` 宣言を反映します。有効で即時適用される非部分一意インデックスをキー列から認識し、不足分のみ作成します。NULL は引き続き複数保存できます。既存の主キーは置き換えません。

スキーマ初期化はテーブル単位のアドバイザリロックを持つトランザクション内で実行され、既存の executor トランザクション内からの呼び出しにも対応します。値の重複やインデックス名の衝突がある場合、初期化は失敗し、スキーマ変更はロールバックされます。レコードの削除や再割り当ては行いません。エラーはトランザクション境界で記録されます。
