# 画像切り抜きポップアップ

**Feature Branch:** copilot/add-image-crop-popup

## アップロード前に切り抜き

プロフィールのアバターやバナーをアップロードすると、保存前にポップアップが開き、アプリで見える表示比率に合わせて画像位置を調整して切り抜けるようになりました。

## 拡張できるガイドグリッド

切り抜きポップアップに拡張可能なガイドグリッドとズーム操作を追加し、アップロード前の構図調整をしやすくしました。
