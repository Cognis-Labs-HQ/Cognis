# メール確認のテーマ対応

**機能ブランチ:** feature-fix-email-validation-endpoint-theme

## Cognis デザインと確認アニメーション

メール確認ページで、保存済みのライトまたはダーク表示、選択したアプリフォント、標準の中立アクションデザイン、および共有パスワード画面と同じ Cognis ブランド表示を含む共通テーマを使用するようになりました。独自の砂時計を標準の共通読み込みホイールに置き換え、確認の完了時または失敗時に確実に閉じるようにしました。動きを抑える設定を尊重しつつ、成功と無効な確認を区別する短いチェックマークとクロスのアニメーションが一度だけ再生されます。
