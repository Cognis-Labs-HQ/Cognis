# Responsives Layout repariert

**Feature-Zweig:** fix-pr566-viewport

## Desktopinhalte sichtbar halten

Der mobile Werkzeugleistenschalter bleibt auf dem Desktop ausgeblendet, auch wenn gemeinsame Schaltflächenstile später geladen werden. Er belegt nicht mehr die Inhaltsspalte und verschiebt Seiteninhalte nicht unter die Werkzeugleiste. Auf Smartphones und Tablets behält der Schalter seine 44 Pixel große Bedienfläche und ein zentriertes Symbol.
