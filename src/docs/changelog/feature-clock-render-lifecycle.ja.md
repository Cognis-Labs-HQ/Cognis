# 時計のライフサイクル

**機能ブランチ:** feature-clock-render-lifecycle

## 各表示で一つの時計を維持

ダッシュボードの再描画では動作中の時計を再利用します。表示の置き換えや非表示化では古いタイマーとイベントリスナーを解放し、削除済みの内容を更新し続けることを防ぎます。

## 画面移動時に更新を停止

ダッシュボードのマウントは、画面移動の中断や置き換えに合わせて管理されます。デジタル時計とアナログ時計のタイムゾーン、時刻形式、テーマ、アクセシビリティ、保存済み配置の動作は維持されます。
