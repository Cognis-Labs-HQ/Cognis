# Profilidentität freigeben

## Kanonische Handle-Auflösung teilen

Der Social-Profile-Adapter stellt nun die kanonische Normalisierung einzelner und mehrerer Handles sowie die Auflösung von Konto-IDs in Handles über die öffentliche Capability `social:profile:identity` für vertrauenswürdige Modul-Orchestrierung bereit.
