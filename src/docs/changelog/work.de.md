# Die Benutzerseite wird sofort aktualisiert

## Benutzeränderungen erscheinen ohne Neuladen der Seite

Wenn ein Benutzer gelöscht oder die Rolle beziehungsweise der Status eines Kontos geändert wird, aktualisiert sich die Benutzertabelle jetzt sofort, statt bis zum vollständigen Neuladen der Seite den vorherigen Stand anzuzeigen.
