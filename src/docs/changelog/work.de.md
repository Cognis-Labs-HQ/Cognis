# Sichere Leistungsmetriken

## Abgesicherte Browser-Telemetrie

Browser-Leistungsdaten erfordern nun eine authentifizierte Sitzung, werden pro Konto begrenzt, beschränken die Stapelgröße, bewahren Dokumentmetriken bei SPA-Navigationen und berechnen CLS mit Web-Vitals-Sitzungsfenstern.

## Sicherere Edge-Vorgaben

Nachgelagerte Ursprungsserver binden standardmäßig an Loopback und bewahren vertrauenswürdige Weiterleitungsheader. Die Einrichtung erzeugt ein erstes selbstsigniertes Zertifikat und gehashte Assets verwenden das vollständige esbuild-Hashalphabet.
