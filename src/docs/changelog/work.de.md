# Freundlichere Profilstandards

## Neue Profile beginnen mit der Sichtbarkeit „Freunde“

Jedes neue Profil beginnt jetzt mit der Sichtbarkeit „Freunde“. Dadurch sind neue Benutzer für ihre Kontakte auffindbar, ohne für die gesamte Community sichtbar zu sein. Normale Benutzer und Moderatoren können weiterhin jederzeit „Privat“ oder „Verborgen“ auswählen.
