# Composer-Bearbeiten-Menü

## Stil der Verwerfen-Aktion

Das Bearbeiten-Menü des Seitenkomponisten zeigt die Verwerfen-Aktion jetzt als Link mit Gefahr-Umrandung und gemeinsamer Abbrechen-Schaltflächenoptik, damit das Zurücknehmen von Layoutänderungen leichter von neutralen Aktionen zu unterscheiden ist.
