# Verfügbarkeitsstatus

## Verfügbarkeit auf einen Blick

Statusanzeigen erscheinen jetzt in der Navigation, in Profilvorschauen sowie bei Nachrichten- und Besprechungsavataren. Aktive Kalenderereignisse setzen die Verfügbarkeit automatisch auf frei oder beschäftigt.

## Status manuell wählen

Über die Statusanzeige am Navigationsavatar kann Verfügbar, Beschäftigt, Vorläufig oder Automatisch gewählt werden.
