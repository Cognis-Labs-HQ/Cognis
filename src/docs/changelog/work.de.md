# Versionierte Sprachschemata

**Feature-Zweig:** work

## Neutrale Paketverträge

Externe Sprachpakete können unveränderliche Schemata mit beliebigen Ebenen, lokalisierten typisierten Metadaten, semantischen Rollen, Beziehungsbedingungen, Darstellungshinweisen, Aktivitätsmerkmalen, Interessensadern und optionalen Strich-Assets definieren, ohne Sprachdaten in Cognis Core abzulegen.

## Deterministische Aufnahme

Die Vorprüfung validiert Identität, semantische Versionen, Lizenzen, sichere Pfade, Namensraumbesitz, Schemata, vollständige Datengraphen und referenzierte Assets, bevor eine Transaktion Inhalte schreibt.

## Härtung nach Prüfung

Lokalisierte Schemabezeichnungen werden im Library-Browser dargestellt, vollständige semantische Versionen werden akzeptiert, das Löschverhalten ist im Typvertrag erforderlich, Paket-Assets bleiben nach der Aufnahme abrufbar und die Abhängigkeitsobergrenze des Gateway-Pakets ist synchronisiert.
