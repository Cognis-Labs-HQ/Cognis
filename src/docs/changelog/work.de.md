# Jitsi-Freigabegenehmigung

## Jitsi Meet kann Freigaben genehmigen lassen

Das Share-Gateway stellt seine Genehmigungsanfrage jetzt als Capability `share:requestApproval` bereit. Dadurch kann das Jitsi-Meet-Modul erfolgreich aktiviert werden und den vorhandenen Genehmigungsablauf für Teilnehmende verwenden.
