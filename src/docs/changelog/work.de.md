# Persönliche Sitzungszeitlimits berücksichtigen

## Persönliche Zeitlimit-Auswahl innerhalb der globalen Grenze beibehalten

Persönliche Sitzungszeitlimits haben weiterhin Vorrang, wenn sie kürzer als die Administrationsgrenze sind. Die Dauersteuerung bietet jetzt nur passende Einheiten an und begrenzt das Zahlenfeld für jede Einheit auf den größten zulässigen ganzzahligen Wert.
