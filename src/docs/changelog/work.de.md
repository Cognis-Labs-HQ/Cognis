# Zuverlässige externe Profile

**Feature-Zweig:** work

## Stabile externe Konten

Externe Identitäten werden nun vor Registrierung, Speicherung, Token-Ausgabe und Profilerstellung einem einzigen normalisierten lokalen Konto zugeordnet.

## Profilerlebnis mit Anbieter

Externe Konten verwenden in der Administration aufgelöste Benutzernamen und Anbietersymbole und können im Profilbanner eine Aktualisierung des Anbieterprofils anfordern. Anbietermedien werden in Cognis gespeichert.
