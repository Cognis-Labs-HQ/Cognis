# Benachrichtigungen für soziales Folgen

## Folgen-Schaltflächen zeigen Entfolgen-Aktionen an

Profil-Schaltflächen im Zustand „Folge ich“ wechseln beim Darüberfahren zur Entfolgen-Beschriftung und zur Abbruch-Formatierung, damit die destruktive Aktion vor dem Klick klarer ist.

## Folgeaktivität nutzt die Social-Benachrichtigungsklasse

Folgeaktionen registrieren und senden jetzt über die Social-Benachrichtigungskategorie, damit Empfänger Folgeaktivitäten über konfigurierte Benachrichtigungsanbieter erhalten können.
