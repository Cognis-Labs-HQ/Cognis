# 読みやすいメッセージ

**機能ブランチ:** feature-message-text-wrapping

## 利用可能な幅に合わせた折り返し

文字数で折り返しの可否を決める処理をなくしました。短い段落、幅の広い文字、絵文字、CJK文字も、会話欄が狭くなったり文字サイズが大きくなったりした際に、既存のメッセージ幅の中で折り返せます。

## 会話機能の維持

標準、吹き出し、IRCの各スタイルで、明示的な改行、Markdown、エスケープされたHTMLに似た文字列、空白のない長い文字列の折り返しを維持します。送受信メッセージのアバター、リアクション、既読表示、メタデータの位置も維持します。依存関係の上限とドキュメントを同期し、Messagesを2.7.41に更新します。
