# 会議共有を修正

## 参加者も共有を管理可能

Jitsi Meet の現在の参加者は、会議共有リンクを一覧表示、作成、取り消しできるようになりました。会議の所有者だけに限定されず、会議に含まれていない利用者は引き続き forbidden 応答を受け取ります。

## 承認依頼は在席参加者だけ

会議共有の承認依頼は、現在その場にいる参加者だけを対象にするようになりました。オフラインの参加者や期限切れの在席情報によって共有作成が遅れたり止まったりしなくなります。

## 会議再開時に共有を失効

会議共有リンクは、現在の会議インスタンスに結び付けられるようになりました。会議を再開するとインスタンス ID が更新されるため、古いリンクは自動的に失効し、新しいセッションへ持ち越されません。
