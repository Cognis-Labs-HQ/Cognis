# Besprechungseinladungen

## Teilnehmersuche folgt jetzt Beziehungen

Die Teilnehmersuche für Besprechungen fragt nun die Social-Profile-Komponente nach Profilen ab, denen die aktuelle Person folgt, damit nicht verbundene Nutzer nicht an Einladungs- oder Aktivteilnehmerlisten zurückgegeben werden.
