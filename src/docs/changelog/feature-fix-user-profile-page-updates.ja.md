# プロフィール即時更新

**機能ブランチ:** feature-fix-user-profile-page-updates

## プロフィール情報を即時反映

保存した表示名などのプロフィール情報が、ページを再読み込みせずに表示されるようになりました。

## 確実なフォロー更新

フォロワー数とフォロー数が、対応するユーザーカードとともにリアルタイムで更新されます。

## 画像選択を一度だけ表示

アバターとバナーの操作で、選択画面の重複表示や同時アップロードを防ぐようになりました。

## ソーシャル件数の即時更新

フォローとフォロー解除が成功すると、後続の一覧取得を待たずに、表示中のプロフィール件数と関連カードが更新されるようになりました。

## バナー配置の即時更新

プロフィールバナーの高さを変更すると、設定の保存完了を待たずにバナーが再描画されるようになりました。

## Composer 全体の即時更新

Page Composer の更新時に既存カードが既定で再レンダリングされ、通常ページの古い表示が解消されます。状態を持つミーティング埋め込みでは引き続き DOM パーキングを明示的に使用します。

## 信頼できるコンポーネント資源

プロフィールページのメッセージ操作用テキストをプロフィール側で所有し、個別に無効化できる別アダプターの資源を要求しないようにしました。ブラウザーパス検査では、静的・動的インポート、配信される言語パス、無効化可能なアダプター境界、アダプター UI パッケージ内の相対パスを検証します。

## カード操作を維持

対象を限定したプロフィール更新をページコンポーザー経由で行い、無関係な埋め込みメディアを維持しながら、再描画後のフォームとカード操作を復元します。

## フォロワー数を即時更新

表示中のプロフィールをフォローすると、サーバーとの同期完了前に現在のアカウントを暫定フォロワー一覧へ追加します。
