# Stabiles Bearbeitungslayout im Seitenkomponisten

## Der Bearbeitungsmodus hält die Rasterplatzierung stabil

Karten im Seitenkomponisten verwenden im Ansichtsmodus nun dieselbe feste Rasterspurgröße und denselben Rasterabstand wie die Zieh- und Größenänderungsüberlagerung im Bearbeitungsmodus. Dadurch verschieben sich Karten nicht mehr horizontal und schrumpfen nicht mehr vertikal, wenn Benutzer die Layoutbearbeitung öffnen oder schließen.
