# Studyのモバイル操作

**機能ブランチ:** fix-study-mobile-navigation

## コンパクトな操作部

メインナビゲーションにメニューアイコンを使用します。Studyのページリンクを横スクロール可能な1行にまとめ、画面サイズやフォントの変更後も選択中のリンクを表示します。言語、辞書検索、設定は2行目に配置します。小さな画面では辞書検索をダイアログで開き、元のフォームと入力内容を保持してフォーカスを戻します。ページ移動やデスクトップサイズへの変更時には閉じます。

## 見やすいStudyページ

Studyのカードを狭い列に収め、概要は通常の文書スクロールを使用します。コンパクトなStudyページのスクロール中はブランド行を折りたたみ、メインナビゲーションを利用可能に保ちます。Flashcardsの別名URLは、読み込み中の同じモジュールへの移動を待たずに選択言語を表示します。チュートリアルの辞書対象は表示中の操作部に追従します。

## 狭い画面のフォームと絞り込み

Studyの閲覧操作部を狭い内容列の中で折り返します。ログインと登録のブランド表示と入力欄は、幅253ピクセルを含む利用可能な幅に収まります。

## 安全なブラウザ試験入力

Chromium試験は認証情報、セレクター、移動先を構造化したプロトコル引数として渡し、値からJavaScriptを組み立てません。回帰試験は特殊な入力、直接アクセスとSPA移動、データ入りのStudyページ、スマートフォンとタブレットの縦横画面、デスクトップを確認します。外部モジュールの実装は変更対象外です。
