# Safer Preference Editing

**Feature Branch:** feature-add-warning-popup-for-preferences-editing

## Edit complete preference JSON

Advanced Preferences now allows experienced users to edit their complete UI preference document after acknowledging a safety warning. Changes are validated, tracked, saved, and applied using the existing preference system.

## Cleaner preference documents

Release changelog acknowledgement history is now stored separately from meaningful UI preferences.
