# 登録時のメールアドレス任意化

**機能ブランチ:** copilot/update-registration-email-requirement

## ユーザー検証方式が「なし」に設定されている場合、メールアドレスは必須ではなくなりました

管理 > セキュリティのユーザー検証方式が「なし」に設定されている場合、登録ページのメールアドレス欄は任意入力になりました。このモードではメール確認の通知も非表示になります。また、検証モードが「なし」の場合、サーバーはメールアドレスのないアカウントのメール確認を強制したり、登録後のアカウントを削除したりしなくなりました。
