# 共有管理を改善

## 1 件の共有だけを管理

共有ページから、選択した共有のフォームだけを含む簡潔な編集画面を開けるようになりました。共有方式は固定され、更新対象はそのデータベースレコードだけです。また、アプリ内移動時にダイアログが二重に開く問題も解消しました。

## 共有操作の外観を統一

共有ページのカード外側に余分な縦方向の空間を追加しないようにしました。アクセスを減らす可能性がある共有ボタンには、常にキャンセル用の表示を使用します。

## 共有コンテンツのルートを復元

登録されたゲートウェイおよびモジュールのページは、ブラウザーの再読み込み時とアプリ内移動時の両方で、それぞれのダッシュボード用エントリーポイントと完全なスタイルシート一式を読み込むようになりました。これにより、共有、ミーティング、ホワイトボードの各ページでトップバー、フッター、レイアウト、コンポーネントのスタイルが維持されます。

## 設定された有効期間中はミーティング共有を維持

ミーティング共有は、ミーティングのインスタンスが変わった場合やセッションが終了した後も解決できるようになりました。共有自体が期限切れ、拒否、または取り消しになるまでアクセスを維持し、認証フローが繰り返された場合は、解決済みの共有セッションを再利用します。
