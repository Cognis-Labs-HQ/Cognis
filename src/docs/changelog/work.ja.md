# 信頼性の高い言語切り替えコントロール

## フローティングコントロールの重なりを防止

ページのカスタマイズが利用できる場合、言語スイッチャーがレイアウト編集コントロールの上に移動するようになりました。

## 言語同期を維持

スイッチャーの表示設定だけを変更しても、ブラウザー同期の言語優先順位が手動モードへ変わらなくなりました。

## 遅延切り替えをライフサイクルに対応

ダッシュボードの再マウント時に古い言語確定処理を取り消し、最終選択を拡張可能な段階的 UI フローで実行するようになりました。

## 設定マークアップを分離

言語設定画面は、JavaScript 内の埋め込みマークアップではなく専用 HTML テンプレートから構築されるようになりました。

## 言語フラグを追加

ダッシュボードのスイッチャーと言語設定テーブルに、インストール済みの各 UI 言語の SVG フラグが表示されるようになりました。
