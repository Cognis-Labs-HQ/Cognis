# コンパクトな学習ライブラリレイヤー

**機能ブランチ:** work

## 最小表示のレイヤー

ライブラリスキーマは、エントリの主要コンテンツだけを表示するコンパクトなカードをレイヤーごとに有効化できます。クリック、右クリックによる選択、長押しによるバリアント表示、表示された子カードでは、既存の操作モデルが引き続き使用されます。

## 設定に応じたポップアップのタイポグラフィ

詳細ポップアップの文字サイズはユーザーが選択したアプリケーションのフォントサイズを基準とし、過大な固定ライブラリ見出しではなく、比例した見出し階層を使用するようになりました。CSS の絶対フォントサイズを使用する外部モジュールは、アクティベーション前の境界検証で拒否されます。

## ライブラリの不要な横方向オーバーフローを解消

非表示の方向付きバリアントカードがスクロール領域に含まれないようにしました。意図的に表示されるまでレイアウトから除外することで、カード幅の空白領域と横スクロールバーをなくし、長押しおよびディープリンクによる表示は維持します。

## 一貫したライブラリ操作と文の検証

ログアウトのホバー表示は赤いキャンセル表示だけになりました。最小表示カードでは主要値の横に発音とローカライズ済み定義を維持し、詳細タイトルと音声エラーには修正済みの相対サイズを使用します。コンテンツパックの取り込みでは、リンクされた語彙単位または助詞のエントリで裏付けられていないテキストを含む順序付き文を拒否します。
