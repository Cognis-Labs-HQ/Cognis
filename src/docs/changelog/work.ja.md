# ライブラリと安全性の修正

**機能ブランチ:** work

## 集約されたライブラリUI

Study Libraryブラウザーのエントリポイントを小さなページ調整役にしました。カード描画、階層グリッド、詳細ポップアップ、選択、ブラウザー操作、バリアント操作を約100～200行の役割別モジュールに分割し、既存のUI動作を維持しています。

## アトミックな進捗修正

通常の進捗イベントから補償識別子を挿入できなくなりました。修正は専用操作を使用し、永続イベントストアは各対象の修正が最大1件であることをアトミックに保証します。

## 認可された削除

ライブラリ削除では、最終カスケードの解決と影響を受ける全エントリの認可を削除トランザクション内で行い、認可と同時関係変更の競合を防ぎます。

## 強化されたモジュール境界

外部モジュール検証は、ソースのシンボリックリンク、ピリオドを含む名前のディレクトリリンク、モジュール境界外を指すアセットリンクを拒否します。安全なモジュール内アセットリンクは引き続き利用できます。クラス属性セレクターで指定された保護対象UIクラスも検出します。

## タイトル内の副表記

単語と文の別表記を、主要な表記の直下に移動可能な副タイトル内容として表示するようにしました。文字のような構造上のバリアントは、詳細本文に重複表示されません。

## 明確な発音タイトル

主要表記と副表記を発音メタデータとして重複表示しないようにしました。発音は通常のタイトルテキストのままとし、表記単位へのリンクへ推測変換しません。これにより、表示される関係はモジュールが提供したライブラリグラフだけを反映します。

## ライブラリ関係とコンテンツパックの整合性

削除プレビューが、依存項目を明示的な削除対象に変えることなく、カスケード、切り離し、制限の各方針を尊重するようになりました。非表示または配置済みの項目はポップアップの移動順序から除外され、コンテンツパック更新時には新しい版から省かれた提供元レコードが削除されます。

## 永続的で決定的な進捗動作

進捗の再試行ではイベントを構造的に比較し、同一時刻ではイベントIDを決定的な副キーとして使用します。安全でない極端な日時は保存前に拒否し、不正なJSONはクライアントエラーを返し、無効化されたアダプターでは機能とフローフックを停止します。

## 完全なモジュールスタイルシート検証

外部モジュール検証が、スクリプトだけでなくCSSのインポートとアセットURLに含まれるCognis内部への直接URLも検出するようになりました。
