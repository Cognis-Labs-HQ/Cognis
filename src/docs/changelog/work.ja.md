# Whiteboard 共有修正

## Whiteboard 共有ゲストを修正

Whiteboard の共有セッションは、リンク用に Share ゲートウェイが生成したゲストプロフィールを使うようになりました。表示可能なプロフィールを要求せず、安定した自動生成名を使えます。

## 共有の取り消しを修正

Whiteboard 共有の削除は、他モジュールの revoke フックがあっても動作し、Meeting 共有と同じ所有者コンテキストを送るようになりました。

## 中クリックのパンを追加

Whiteboard Canvas は、ツール変更やオブジェクト選択をせずに、中クリックドラッグで拡張された Canvas 領域をパンできるようになりました。
