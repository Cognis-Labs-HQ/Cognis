# モジュール構成の所有権を統一

## モジュール所有の構成エンドポイントを使用

Cognis はモジュールマニフェストで宣言されたフィールドを描画し、各モジュール所有の `GET` および `PUT` 構成エンドポイントを通じて値を読み書きするようになりました。運用設定の検証、適用、永続化は引き続きモジュールが担い、Cognis は設定ストアを使った並行構成を保持しません。

## モジュールにホストのログ記録とフィードバック機能を提供

モジュールのサーバーコンテキストは、モジュールに関連付けたエントリをアプリケーションログへ書き込むようになりました。ブラウザーモジュールは、運用上の障害をブラウザーコンソールだけに残さず、認証済みサーバーログ、テーマ対応トースト、ランタイムエラーポップアップのホスト機能を使用できます。
