# 安定した外部プロフィール

**機能ブランチ:** work

## 安定した外部アカウント

外部 ID は、登録、保存、トークン発行、プロフィール作成の前に、正規化された単一のローカルアカウントへ解決されるようになりました。

## プロバイダープロフィール体験

外部アカウントは管理画面で解決済みのハンドルとプロバイダーアイコンを使用し、プロフィールバナーからプロバイダープロフィールの更新を要求できます。プロバイダーのメディアは Cognis に保存されます。
