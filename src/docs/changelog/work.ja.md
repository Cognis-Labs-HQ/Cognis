# 一貫したプロフィールアバター

## プロフィールが所有する単一のアバター情報源

プロフィールアバターの読み込み、代替表示、イニシャル生成、イニシャルの色は、プロフィールアダプターの UI CTX ケイパビリティから提供されるようになりました。共通 UI の呼び出し元は異なる実装を保持せず、このケイパビリティへ委譲するため、どの画面でも同じ名前から同じアバターが生成されます。

## 残りの利用箇所を監査

メッセージ、カレンダー、Jitsi Meet、Nextcloud Whiteboard、共有、プレゼンス表示、教室アバターは、共通 CTX クライアントのみを介してプロフィールアダプターを利用するようになりました。旧 Social ゲートウェイの再エクスポートを削除し、新たなイニシャル実装、プロフィールファイルの直接取得、旧プロバイダーのインポートを回帰テストで防止します。

## Study でもナビゲーションバーのアバターを維持

プロフィールのナビゲーションバープラグインは、レイアウト状態をインポートせず UI CTX を介してアバタープロバイダーを提供するようになりました。ダッシュボードシェルの再利用時も、プラグインの読み込み中は解決済みのアバターを維持するため、Study のサブページ間を移動してもプロフィール画像が一時的に置き換わりません。
