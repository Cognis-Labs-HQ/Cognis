# アカウント状態

## ライフサイクル操作を明確化

危険ゾーンのアカウント操作は一貫してキャンセル形式のボタンを使い、無効化の警告は管理者対応が必要とは説明しなくなり、確認ポップアップはEnterキーで送信できます。

## 管理画面の状態を明確化

ユーザーページはアーカイブ済みと無効化済みのアカウント状態を明示し、既存の無効化/有効化トグルでアカウントをアーカイブおよび再有効化します。

## ログイン時の状態エラー

アーカイブ済みアカウントへのログイン試行は処理済みのライフサイクルエラーを返し、無効化済みアカウントはユーザーが再度ログインすると再有効化されます。

## 管理者の無効化でアーカイブ

管理者ユーザー画面の無効化/有効化操作は、ライフサイクルフローを通じて対象プロフィールをアーカイブまたは再有効化し、トークンのクリーンアップを自己アーカイブ時の動作とそろえます。

## 無効化で休止状態に

自己無効化はアカウントをやり取りから隠し、ユーザーが再度ログインするとアクセスを復元できるようにしました。また、危険ゾーンのポップアップは中立的なキャンセルボタンを使います。
