# Share 承認の安全性と段階的処理を改善

**機能ブランチ:** work

## 承認ポップアップのコンテキストをエスケープ

申請者、操作、対象の値は、承認者のダッシュボードに表示される前に HTML エスケープされるようになりました。

## 承認オーケストレーションを Flow として公開

Share 承認機能は、対象解決、申請作成、応答待機、決定の明示的なステージを持つ名前付き Flow を実行するようになり、コンポーネントが取り外し可能なフックを挿入できます。
