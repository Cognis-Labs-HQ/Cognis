# 安定したモジュール検出

## 無効なリポジトリを除外

モジュールマーケットは、完全で有効なモジュールマニフェストを提供しないリポジトリを無視するようになりました。設定済み組織内の無関係なリポジトリや利用できないソースが、モジュールページの読み込みを妨げることはありません。

## 不足アイコンの代替表示

モジュールカードは、利用できない外部画像をテーマ対応の疑問符アイコンに置き換え、実行時エラーのポップアップを表示しないようになりました。

## モジュールソースを更新

モジュールページの「モジュールソース」の隣に更新操作を追加し、設定されたすべてのプロバイダーを再照会して表示中のカタログを再構築できるようになりました。

## ソースの管理と段階的な検出

モジュールソースは、専用の一覧・編集マネージャーとして開くようになりました。既定の信頼済み組織は表示されたまま読み取り専用となり、カスタムソースは追加、編集、削除できます。モジュールページは既知のモジュールですぐに表示され、設定済みソースから応答が届くたびに検出結果を個別に追加します。

## ブランチ選択と更新検出

マーケットプレイスの詳細にリポジトリの全ブランチを表示し、既定ブランチを自動選択するようになりました。インストール時に選択したブランチとコミットを記録し、そのブランチが進んだ場合はモジュールカードと詳細に更新操作を表示します。

## Marketplace 画像を安全に配信

Marketplace 画像はサーバーが取得し、推測困難な同一オリジン URL で配信します。画像がない場合は Content Security Policy を緩和せず、同梱の疑問符アイコンを使用します。

## おすすめモジュールを管理

おすすめ状態はモジュールマニフェストではなく、管理者が設定できる公開 UUID リストから取得します。Marketplace 設定でおすすめとソースの両方を管理できます。

## モジュール導入を完了

導入したモジュールは直ちにランタイムへ取り込み、管理者が有効化するまで無効のままにします。Marketplace 画像は推測困難な公開同一オリジン URL から読み込みます。

## Marketplace 詳細を改善

ライセンスをタグから分離し、詳細画面は結果領域の全幅を使用します。戻る操作と更新操作は簡潔な SVG コントロールになりました。

## インストールと有効化を分離

インストールしたモジュールは、管理者が明示的に有効化するまで無効のままになります。有効化または無効化するとブラウザーのナビゲーションプラグインを直ちに更新し、再読み込みなしで新しいナビゲーション項目を表示します。

## Marketplace 操作をテーマ対応

戻る操作と更新操作は、現在のダッシュボードテーマに応じて専用のライトおよびダーク SVG アセットを使用します。

## 検出済みモジュールを維持

Marketplace マニフェストを設定済みソースごとにキャッシュします。アンインストールしたモジュールは直ちに利用可能へ戻り、一時的なソース障害ではキャッシュを維持し、すべての設定済みソースが不在を正常に確認した場合のみ一覧から消えます。

## Core をモジュールから除外

プラットフォームの Core はインストール可能なモジュールではないため、Cognis Core をモジュール管理一覧から除外しました。

## 宣言済みライセンスを検証

リポジトリ直下に認識可能なライセンスファイルがある場合のみライセンス情報を表示します。その証拠がないライセンス宣言はインストール検証で拒否します。

## モジュール導入時間を確保

Marketplace のインストール要求を 10 分間待機し、Jitsi Meet のような大きなリポジトリのクローンと検証が共通 API の 30 秒タイムアウトで失敗しないようにしました。

## 最初にすべてのモジュールを表示

モジュール状態フィルターに「すべて」を追加して既定値とし、ページを開いた際にインストール済み、利用可能、おすすめのモジュールをまとめて表示します。

## 進行状況を表示してリリースをインストール

モジュール検出でブランチに加えてリポジトリのタグも取得するようになりました。詳細画面の選択肢は引き続き既定ブランチを初期値にします。ライフサイクル操作ボタンには処理中のスピナーが表示され、インストール要求は2分で適切に制限されます。

## Marketplace 設定を統合

モジュールソースは Marketplace 設定ダイアログ内の専用セクションに集約されました。提供元とバージョンはカテゴリタグから分離して表示され、設定アイコンはライトテーマとダークテーマの両方に対応します。

## 有効化前にモジュールをテスト

モジュールを有効化するとき、実行状態を変更する前に、そのチェックアウトが提供する標準の JavaScript および TypeScript テストをすべて実行するようになりました。テストの失敗またはタイムアウト時は有効化を拒否し、モジュールテストの失敗を報告します。

## Core のテストコマンドに外部モジュールを追加

ルートの `npm test` は Cognis のソースツリーと、設定された外部モジュールのチェックアウトルートの両方からテストを検出するようになりました。`COGNIS_EXTERNAL_MODULES_ROOT` を使ったリポジトリ外のチェックアウトにも対応します。
