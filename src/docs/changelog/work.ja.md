# デプロイとデータベースプールの追加修正

## リリース用アセットバージョンの維持

Docker イメージがビルド時に渡されたアセットバージョンを保持し、更新後のデプロイでキャッシュ済み静的リソースを確実に無効化するようになりました。

## データベース URL の安全な構築

コンテナのエントリーポイントは、PostgreSQL と MariaDB の認証情報を接続 URL に含める前にパーセントエンコードするようになりました。

## データベースコンポーネントの分離とバージョン管理

プール設定の検証を各データベースアダプターに移し、アダプターとゲートウェイのワークスペースバージョンおよび依存関係の上限を同期しました。
