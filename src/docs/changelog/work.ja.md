# ゲストのプレゼンス ID 修正

## ゲスト表示名をプロフィールエラーなしで読み込み

共有ゲストは、ダッシュボードシェルと同じセッション ID 経路で生成済みのゲスト表示名を受け取るようになり、一時ユーザーのプロフィール検索エラーを避けられます。

## 古い Whiteboard プレゼンスをすばやく非表示

Whiteboard のプレゼンスは、ハートビートが期限切れになったエントリを無視するようになり、突然切断されたゲストセッションがアクティブ参加者として残り続けなくなります。

## 共同選択インジケーター

Whiteboard の選択範囲が、強調アウトラインとフローティング名ラベル付きで他のアクティブユーザーにも表示され、キャンバス上のオブジェクト選択がポインタープレゼンスと一緒に共有されます。
