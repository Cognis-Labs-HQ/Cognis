# ゲストの本人表示とプレゼンスの修正

## ゲスト表示名をプロフィールエラーなしで読み込む

共有ゲストは、ダッシュボードシェルと同じセッション識別経路で生成済みのゲスト表示名を受け取るようになり、一時ユーザーのプロフィール取得エラーを回避します。

## 古いホワイトボードプレゼンスをすばやく非表示

ホワイトボードのプレゼンスは、ハートビートが期限切れになったエントリを無視するようになり、突然切断されたゲストセッションがアクティブ参加者として残り続けません。

## 共同選択インジケーター

ホワイトボードの選択範囲が、強調表示の枠線と浮動する名前ラベル付きで他のアクティブユーザーに表示され、キャンバス上のオブジェクト選択がポインタープレゼンスと一緒に共有されます。

## 応答性の高いポーリングとツールバーのプレゼンス

プレゼンス更新は、アクティビティ後に高速化し、静かな状態では低速化する適応型ポーリングヘルパーを使用するようになりました。ホワイトボードのツールバーには専用のプレゼンス領域もあり、ツールバーが再描画されても再接続されます。

## テキスト編集とユーザー別履歴

テキストボックスは安全なインプレースエディターをすぐに開き、パンされたキャンバスにオーバーレイを合わせ、浮動するフォント／スタイル操作を表示します。Undo/Redo はローカルユーザーが変更したオブジェクトだけを再適用するため、共同編集者の変更を上書きしません。
