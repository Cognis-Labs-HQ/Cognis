# ホワイトボード同期

## ライブ共同編集を修正

ホワイトボードの変更は Nextcloud Whiteboard の Socket.IO プロトコルを使うようになり、所有者と共有ゲストは Cognis のスナップショットだけでなく、設定済みの共同編集サーバー経由でシーン更新を受け取ります。

## ページプレゼンスを追加

Page Composer はコンテンツグリッドの上にコンパクトなプレゼンスバーを表示できます。ホワイトボードページでは所有者とゲストのイニシャル、アクティブ状態のリング、サインイン済みユーザーのプロフィールプレビューを表示します。

## 共有セッションを改善

ホワイトボード共有ゲストは、Share Gateway が生成した表示名をプレゼンスと共同編集セッションで維持します。
