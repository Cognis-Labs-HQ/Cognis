# 信頼性の高いモジュール管理の起動

## 起動準備を担当モジュールに限定

すべての API リクエストを遅延させるのではなく、Nextcloud Whiteboard 内で起動の信頼性を確保します。これにより、共通サーバーのライフサイクルを変更せずに、対象の管理ルートをプロフィールサービスから独立して利用できます。

## 設定をプロフィールサービスから独立

Nextcloud Whiteboard は、データベースストレージが利用可能になり次第、設定と有効化のエンドポイントを登録するようになりました。ホワイトボード共同作業に必要な別のプロフィールサービスが利用できない場合でも、管理者はモジュールを設定できます。
