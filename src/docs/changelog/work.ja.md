# Namespace File Clients

## Namespace-bound file clients

ファイルゲートウェイは `files:namespace` を公開するようになりました。これはコンポーネントと名前空間にバインドされたクライアントを返す `ctx` 機能で、通常のファイル操作で各呼び出し地点が名前空間と呼び出し元メタデータを繰り返す必要をなくします。

## Share gateway controls

Share ゲートウェイが、読み取り/書き込み権限、アプリ内ユーザー、グループ/クラス、メール受信者、パスワード保護リンク、自動生成パスワード、編集可能な期限/権限更新、読み取り専用共有のウォーターマークメタデータを所有するようになりました。Jitsi Meet と Nextcloud Whiteboard は、モジュール固有の共有エンドポイントではなく、Share ゲートウェイの汎用トークンルートで共有を作成・一覧表示・削除するようになりました。
