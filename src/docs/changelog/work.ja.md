# LDAP 有効化の安全性向上

## 有効化前にサーバーを設定

LDAP サーバーが少なくとも 1 台設定されるまで、LDAP アダプターの有効化スライダーを無効にし、不正な有効化リクエストを防止します。

検証済みサーバーを追加した後にアダプターを有効化すると、保留中のサーバー設定が自動的に保存されます。ユーザー検証手順で Enter キーを押すと認証テストが実行され、未保存の新規サーバーを破棄する際には確認が必要になりました。

ユーザー検証手順で保存すると、必要な場合は認証テストが自動的に実行されます。認証テストに失敗した場合、修正できるよう管理者を LDAP バインド項目に戻します。
