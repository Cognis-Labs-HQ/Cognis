# 完全なファイル画面

**機能ブランチ:** work

## 仮想ファイル整理

プロバイダーのオブジェクトを移動せず、カテゴリーナビゲーション、名前空間ピル、プロバイダー選択、仮想フォルダー、お気に入り、最近使用した項目、破壊的操作、再利用可能なコンテキストメニューを備えたレスポンシブなファイル画面を追加しました。

## クラスと共有の統合

教師のクラスフォルダーは `ctx` Capability を通じて同期されます。ファイルは、閲覧者・編集者の選択とゲスト対応アクセスを備えた Share ゲートウェイのユーザー共有およびリンク共有フローに参加します。

## ファイル表示と管理

レンダラーに依存しないファイル表示ゲートウェイのオープン契約と、強制的な「アプリで開く...」処理を追加しました。また、管理画面にプロバイダー割り当てと共有容量制御を追加しました。
