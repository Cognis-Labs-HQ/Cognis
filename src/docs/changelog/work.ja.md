# SMTP TFA メール連携

## TFA メールコードは中立的な件名を使用

二要素認証コードだけを含む SMTP メッセージは、メールアドレス確認の見出しではなく、中立的な確認コードの件名を使うようになりました。確認リンクを含むメールアドレス確認メッセージは、従来のメール確認件名を維持します。

## メール確認は SMTP TFA のコード長に従います

メールアドレス確認コードは、SMTP TFA アダプターで設定されたコード長を使うようになり、管理者は SMTP 確認コードの長さを一か所で管理できます。SMTP 通知送信者と SMTP TFA アダプターは、有効/無効状態も双方向で同期します。
