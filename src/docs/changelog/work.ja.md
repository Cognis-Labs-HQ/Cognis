# 信頼性の高いモジュール設定

## 有効化前に無効なモジュールを設定

モジュール所有の設定ルートが利用できない場合、Cognis はマニフェストの既定値で設定フォームを開き、保存時にのみモジュールを有効化します。値は登録されたモジュールルート経由で直ちに書き込まれるため、ブラウザーに一時保存することなく、必須の API キーを 404 エラーなしで保存できます。

## 空の有効化応答後も必須設定を完了

有効化エンドポイントが正常な空の成功応答を返した場合でも、有効化フローが必須設定を続行するようにしました。設定はモジュール詳細の歯車アイコンから引き続き開け、必須設定が失敗またはキャンセルされた場合はモジュールを無効に戻します。
