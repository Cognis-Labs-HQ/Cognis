# アカウント状態

## ライフサイクル操作を明確化

危険ゾーンのアカウント操作は一貫してキャンセル形式のボタンを使い、無効化の警告は管理者対応が必要とは説明しなくなり、確認ポップアップはEnterキーで送信できます。

## 管理画面の状態を明確化

ユーザーページはアーカイブ済みと無効化済みのアカウント状態を明示し、復元操作のラベルを再有効化に変更しました。

## ログイン時の状態エラー

アーカイブ済みおよび無効化済みアカウントへのログイン試行は処理済みのライフサイクルエラーを返し、ログインページで適切なエラートーストを表示できます。

## 管理者の無効化でアーカイブ

管理者ユーザー画面の無効化操作は、ライフサイクルフローを通じて対象プロフィールをアーカイブし、トークンのクリーンアップを自己アーカイブ時の動作とそろえます。
