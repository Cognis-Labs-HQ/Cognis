# プロフィールの保持と暗号化会話の安定化

## キーリングのリセットでソーシャル ID を保持

キーリングを破棄しても、メッセージルームのメンバーシップを削除しなくなりました。プロフィールを利用するソーシャル操作では、認証済みアカウントのプロフィールが欠けている場合に使用前に再作成するため、以前の破壊的リセットの影響を受けたアカウントでも実行者名が空になりません。

## ダイレクト会話を冪等化

同じダイレクト会話を開始する同時リクエストを直列化し、既存ルームを再確認します。素早い操作や重複したリクエストで複数のルームが作成されることを防ぎます。

## メッセージは進行中のキー読み込みを待機

同じルームの同時キー解決を調整し、すでに解除済みのキーリングがルームキーを解決中なのに、SPA 遷移直後に古い解除要求メッセージが表示されないようにしました。
