# 即時プロフィール反映

## ソーシャル件数の即時更新

フォローとフォロー解除が成功すると、後続の一覧取得を待たずに、表示中のプロフィール件数と関連カードが更新されるようになりました。

## バナー配置の即時更新

プロフィールバナーの高さを変更すると、設定の保存完了を待たずにバナーが再描画されるようになりました。

## Composer 全体の即時更新

Page Composer の更新時に既存カードが既定で再レンダリングされ、通常ページの古い表示が解消されます。状態を持つミーティング埋め込みでは引き続き DOM パーキングを明示的に使用します。

## 信頼できるコンポーネント資源

プロフィールページのメッセージ操作用テキストをプロフィール側で所有し、個別に無効化できる別アダプターの資源を要求しないようにしました。ブラウザーパス検査では、静的・動的インポート、配信される言語パス、無効化可能なアダプター境界、アダプター UI パッケージ内の相対パスを検証します。
