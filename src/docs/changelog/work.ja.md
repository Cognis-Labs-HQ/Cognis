# 非公開モジュールを確実に検出

## 再起動後も非公開リポジトリのスキャン設定を維持

Cognis Labs HQ マーケットプレイスソースは、非公開リポジトリのスキャン設定を既定ソースのレコードに保存するようになりました。これにより、サーバーの再起動後も設定済みの非公開モジュールを検出できます。

## バックグラウンドスキャンでキーリングを解除しない

マーケットプレイスの自動ポーリングは、キーリングがすでに解除されている場合にのみ PAT を読み取ります。プロバイダーの認証失敗時にアカウントのキーリングパスワードを予期せず要求せず、エラーを通知します。明示的な更新では引き続きアクセスを要求できます。
