# より安全で翻訳された実行時ログ設定

## ログアダプターが設定規則を所有

コンソールおよびファイルアダプターが検証とロガー設定への変換を定義し、アダプター固有の設定をゲートウェイルートから分離しました。

## ファイルログの上書きを制限

実行時フォームでは環境が所有するログパスを変更できなくなり、安全でないローテーションサイズや保持数を適用前に拒否します。

## ログ設定を翻訳

コンソールとファイルの設定ラベルに、コンポーネントが所有するドイツ語、英語、インドネシア語、日本語のリソースを使用するようになりました。

管理ポップアップは、設定フィールドを表示する前に各アダプターが通知した言語リソースを読み込むようになりました。
