# ライブラリと安全性の修正

**機能ブランチ:** work

## 集約されたライブラリUI

Study Libraryブラウザーのエントリポイントを小さなページ調整役にしました。カード描画、階層グリッド、詳細ポップアップ、選択、ブラウザー操作、バリアント操作を約100～200行の役割別モジュールに分割し、既存のUI動作を維持しています。

## アトミックな進捗修正

通常の進捗イベントから補償識別子を挿入できなくなりました。修正は専用操作を使用し、永続イベントストアは各対象の修正が最大1件であることをアトミックに保証します。

## 認可された削除

ライブラリ削除では、最終カスケードの解決と影響を受ける全エントリの認可を削除トランザクション内で行い、認可と同時関係変更の競合を防ぎます。

## 強化されたモジュール境界

外部モジュール検証は、ピリオドを含むディレクトリ名を含め、すべてのシンボリックリンクを拒否します。また、クラス属性セレクターで指定された保護対象UIクラスも検出します。
