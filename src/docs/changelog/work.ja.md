# 安定したCIチェック

## ソースファイルをサイズ制限内に維持

セッションロック解除の永続化、カレンダー詳細スタイル、会議ページ要素、ホワイトボードの検索と状態管理、ページコンポーザーのDOM保持を、それぞれ責務の明確な隣接モジュールへ分割し、各ソースファイルを1000行以内に収めました。

## 制限されたパスでもDockerプロファイルテストを実行

Dockerプロファイルテストが対応する絶対パスからBashを検出し、最小構成のCIイメージにBashがインストールされていない場合は、誤解を招く起動エラーではなくシェル実行チェックを明示的にスキップするようにしました。

## SMTPテーマテストの受信者を分離

既定テーマのメールテストで専用の受信者IDを使用し、隣接するSMTPテストの受信者レート制限によってテストスイート全体が断続的に失敗しないようにしました。
