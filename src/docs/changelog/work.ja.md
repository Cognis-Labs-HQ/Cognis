# アダプターのバージョン表示

## アダプター設定にバージョンを表示

Administration のアダプター操作では、各アダプター名の横にアダプターのバージョンを表示するようになりました。バージョンメタデータが利用できる場合は、アダプター設定ダイアログの見出しにも同じバージョンを表示します。

## 明確なコンポーネント状態と操作

有効なコンポーネントでは、［有効］ピルの横に緑、オレンジ、または赤の状態ランプが表示されます。有効化後に状態を再取得し、事前設定が必要な場合は通知し、詳細矢印には常に独立したクリック領域を設けました。

## 確実なアダプターパブリッシャー表示

管理画面が認証アダプターを含むすべてのアダプターゲートウェイからパブリッシャー情報を受け取るようになり、アダプター詳細には不明な値ではなく宣言済みのパブリッシャーが表示されます。
