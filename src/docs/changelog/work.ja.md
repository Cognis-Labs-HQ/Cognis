# ホワイトボードのプレゼンスと選択を修正

## プレゼンスが正しく終了します

ホワイトボードページのプレゼンスは、ページを非表示、アンロード、または離脱したときに訪問者を非アクティブとして送信し、ゲストアバターのイニシャルでは先頭のハッシュ記号を無視します。

## キャンバス描画がより安定します

ホワイトボードのキャンバスは描画中に描画面の寸法を安定させ、選択以外のツールを使うと以前の選択をすぐ解除します。

## 選択は表示された描画内容を基準にします

ホワイトボードのクリック判定と範囲選択は、要素全体の境界領域ではなく、表示されている描画内容を基準にします。

## ホワイトボード操作のダークモード対応を改善しました

線の太さドロップダウンに theme-select スタイルを追加し、ネイティブのカラーピッカーは対応ブラウザーでライト/ダークの配色に従います。
