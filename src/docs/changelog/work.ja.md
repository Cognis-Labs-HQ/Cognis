# 安定した子カード移動

**機能ブランチ:** work

## 安定した子カード配置

深い分岐を開いても、子カードは配置済みの位置を維持します。新しい子孫は深さ順に、衝突余白を確保した表示領域内の空きスロットへ配置されるため、カードや接続線の跳躍と重なりを防ぎます。

## 安定したポインター移動

斜め経路に広く連続したヒット領域を設け、分岐切り替えに短いホバー待機を加え、選択中カードの脈動を廃止しました。代替方向の順序も優先軸の近傍を先に選び、初期の子カード配置をコンパクトに保ちます。
