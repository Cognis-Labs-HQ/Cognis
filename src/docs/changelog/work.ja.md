# バージョン付き言語スキーマ

**機能ブランチ:** work

## 中立なパッケージ契約

外部言語パッケージは、任意レイヤー、翻訳済み型メタデータ、意味役割、関係制約、表示ヒント、アクティビティ検出タグ、興味系統、任意の筆順アセットを持つ不変スキーマを定義でき、言語レコードをCognisコアに置く必要がありません。

## 決定的なアトミック取込

パッケージ事前検査は、トランザクションが内容を書き込む前に、識別情報、セマンティック版、ライセンス、安全なパス、名前空間所有権、スキーマ、完全なレコードグラフ、参照アセットを検証します。

## レビュー後の強化

翻訳済みスキーマラベルをLibraryブラウザーで表示し、完全なセマンティック版を受理し、削除動作を型契約で必須にしました。パッケージアセットは取込後も取得でき、ゲートウェイパッケージの依存上限も同期されます。
