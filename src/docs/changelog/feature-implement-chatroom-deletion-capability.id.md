# Pembersihan ruang obrolan aman

**Cabang Fitur:** feature/implement-chatroom-deletion-capability

## Penghapusan ruang obrolan terotorisasi

Kapabilitas Messages kini dapat menghapus ruang obrolan beserta data terkait secara permanen saat diminta oleh pemilik ruang atau satu-satunya peserta yang tersisa.

## Pemfilteran pencarian pengguna yang benar

Filter hasil pengguna bentuk tunggal kini dinormalisasi dan diterapkan pada hasil terdaftar maupun hasil berkelompok, sehingga dialog pencarian modul menampilkan pengguna tanpa kategori lokal atau API yang tidak terkait.

## Kontrol pencarian yang mendukung tema

Kontrol tutup berbasis karakter pada popup pencarian dan kontrol hapus bawaan peramban diganti dengan ikon SVG yang konsisten untuk tema terang dan gelap. Ikon hapus pada kolom masukan dibuat lebih kecil dan sebagian transparan, sedangkan kotak pilihan kini berada di samping detail pengguna, bukan di atasnya.
