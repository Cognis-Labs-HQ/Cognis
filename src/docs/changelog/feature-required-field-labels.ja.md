# 必須マークを見出し内に表示

**機能ブランチ:** feature-required-field-labels

## 必須マークを見出しとまとめる

共有画面のパスワード保護を含め、共通項目の見出しと必須の星印を同じテキスト領域に保持します。長いラベルは折り返し、マークを別のグリッド項目として配置しません。

## 必須状態を一貫して更新する

動的な必須状態の変更では、対応するすべての項目型で同じ見出しを使います。未選択の必須ラジオグループも、入力が見つからないエラーを起こさず検証できます。ラベルと入力の関連付け、書式付きラベル、独立した補足説明ボタンを維持します。

ラジオボタンの選択を変更すると、値やフォーカスを変えずにグループ全体のエラー表示を解除します。
