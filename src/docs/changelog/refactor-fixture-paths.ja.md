# 簡潔なテストパス

**機能ブランチ:** refactor-fixture-paths

## ビルド用データの配置を簡素化

UIビルドのテストデータを簡潔なディレクトリに保存し、一時的なビルドテスト内でのみ本番の構造を組み立てます。エントリーポイントの共有、スタイルシートの公開、静的アセットの処理を維持します。

未使用のSQLiteテストデータの複製を削除します。PostgreSQLのテストデータでは、データベース検出に必要なプロバイダーとSQLフェーズのディレクトリを維持します。

## 関連テストを分類

関連テストを対象別のディレクトリにまとめ、ファイル名を短縮します。インポートとリソース参照を更新し、再帰的なテスト検出を維持します。

## パス規約の適用

正規のAI指示とリポジトリ検査で、テストデータ内の冗長なソースツリーとテスト名の重複した接頭辞を禁止します。意味のあるプロバイダーやパッケージの構造は引き続きサポートします。
