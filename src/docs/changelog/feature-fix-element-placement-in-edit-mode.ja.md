# page composer の編集レイアウト安定化

## 編集モードが通常モードの寸法を使用

page composer の編集オーバーレイは、通常モードと同じコンテンツセクション寸法から列を測定し、行の高さは通常モードの行サイズに固定するようになりました。iframe、画像、動画、音声、canvas コンテンツ、object/embed コンテンツ、明示的に保持対象にした要素などのメディア要素は、composer の再レンダー時に再作成されるのではなく一時退避して再接続されるため、進行中のミーティングのような埋め込みウィンドウが維持されます。API ラッパー側で復旧を管理する必要があるコンポーネントは、引き続き `data-composer-preserve="false"` で対象外にできます。
