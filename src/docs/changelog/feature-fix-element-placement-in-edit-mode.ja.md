# page composer の編集レイアウト安定化

**機能ブランチ:** feature-fix-element-placement-in-edit-mode

## 編集モードが通常モードの寸法を使用

page composer の編集オーバーレイは、通常モードと同じコンテンツセクション寸法から列を測定し、行の高さは通常モードの行サイズに固定するようになりました。iframe、画像、動画、音声、canvas コンテンツ、object/embed コンテンツ、明示的に保持対象にした要素などのメディア要素は既存のカード内に残し、その周囲に編集コントロールを重ねるため、進行中のミーティングのような埋め込みウィンドウを再読み込みさせる iframe の付け替えを避けられます。API ラッパー側で復旧を管理する必要があるコンポーネントは、引き続き `data-composer-preserve="false"` で対象外にできます。

## ミーティング中の更新保護

進行中のミーティングでは実際の更新や移動に対して引き続きブラウザーのアンロード確認を使いますが、Cognis は `beforeunload` 中に共通の読み込み状態を変更しなくなりました。読み込みオーバーレイは `pagehide` を待つため、ブラウザーの更新確認をキャンセルしても現在のミーティングページと埋め込みセッションは表示され、操作可能なままです。
