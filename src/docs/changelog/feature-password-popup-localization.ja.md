# 共有パスワード文言

**機能ブランチ:** feature-password-popup-localization

## パスワード文言を共有

パスワード要件と一致確認を共有ホスト XML カタログへ移し、セキュリティと登録の両方を更新します。セキュリティは任意の Registration カタログを読まずにフォームを開けます。四言語の翻訳、既存の検証、同じ英語キーへの厳密なフォールバックを維持します。

## フォームの動作を維持

回帰テストは登録済み Auth 設定構築、実際にマウントしたセキュリティ、ポップアップ、フォームビルダー、XML 解決器、および登録ページを実行します。繰り返しの開閉と再マウント、破棄判断、選択言語の維持、検証、合成の成功と失敗、英語欠落時の明示的エラーを確認します。すべてゼロのポリシー入力でも実際の最小文字数の既定値を維持します。別途注入する条件なしのケースは防御的経路の検証であり、対応するサーバーポリシーではありません。

## カタログを同時にリリース

Auth 2.2.13 と Registration 1.2.9 は対応する共有ホストカタログが必要です。UI 固有のパッケージバージョンや Auth/Registration のロックファイル依存上限はありません。連携は新しい共有キーを使用してください。新規依存、サーバールート、パスワードポリシー、認証契約の変更はありません。プログラムによる DOM テストはブラウザーの表示や配置先のインシデント解消を保証しません。
