# 大容量プロフィール画像

**機能ブランチ:** feature-fix-large-file-upload-failure

## プロフィール画像に容量枠を適用

アバターとバナーのアップロードには、ファイル単位の個別サイズ上限が適用されなくなりました。大きな画像やアニメーション GIF バナーも、ユーザーのプロフィール名前空間および全体のストレージ容量枠内であれば保存できます。

## Web プロキシがアップロードを通過させるようになりました

同梱の nginx 設定は、Cognis がユーザーのストレージ容量枠を適用する前に大きな API リクエスト本文を拒否しなくなりました。バナーのアップロードでは、レイアウト設定の保存時にも切り抜き位置が保持されます。
