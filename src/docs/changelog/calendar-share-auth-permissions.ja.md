# カレンダー共有の安全性

## 認証を引き続き必須化

パスワード保護された ICS と CalDAV のアドレスから派生認証情報を削除しました。カレンダーデータを取得するには、設定した共有パスワードでの認証が必要です。

## 標準に基づく権限

CalDAV 検出で RFC 定義の現在のユーザー権限と対応する VEVENT コンポーネントを公開します。購読フィードは書き込み非対応のため、ICS の WebDAV 確認では読み取り専用権限を返します。

## アドレス内のカレンダー名

CalDAV 形式のアドレスにエンコード済みのカレンダー名を含め、認証情報を公開せずにコレクション URI から分かりやすい名前を取得できるようにしました。
