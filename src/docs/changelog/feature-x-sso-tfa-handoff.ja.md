# SSO検証の継続

**機能ブランチ:** feature-x-sso-tfa-handoff

## 発行済みの認証を継続

TFAを使うSSOアカウントは通常のログイン画面に戻り、発行済みのコードを検証します。再試行とキャンセルで中断したログインに対応し、セッションの作成やメールの再送信は行いません。Auth 2.2.10が短期間のHttpOnly継続を提供し、X SSO 1.0.63が明示的なログイン画面の印を利用します。

## 保留中の試行を保護

期限切れ、不可分な検証、キャンセル、置き換え、ログアウトは対応するサーバー所有の試行を無効にします。古いタブは新しい試行を取り消したりCookieを上書きしたりできません。遅れたブラウザー処理は現在のフォームに限定されます。
