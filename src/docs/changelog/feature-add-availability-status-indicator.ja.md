# 在席状況ステータス

## 在席状況をひと目で確認

ナビゲーションバー、プロフィールプレビュー、メッセージ、会議のアバターに、空き、予定あり、仮予定の状態が表示されます。

## 状態を手動で設定

カレンダー予定の開始時、または現在の時間帯に予定を作成した時点で状態が設定されます。その後、プロフィールメニューから進行中の予定による状態を上書きできます。

## プロフィールメニューで状態を操作

プロフィールメニューは、ポインターを合わせるかクリックすると開き、別の場所をクリックするまで表示されます。先頭行には、色付きの点が対応する「空き」「取り込み中」「仮予定」の枠なし状態メニューが表示され、各メニュー項目はポインターを合わせると輪郭が強調されます。

## 必要な場所で状態を確認

アバターのステータス表示にポインターを合わせると状態を確認できます。コンポーネントは ctx ケイパビリティを通じて、カレンダーを考慮したユーザーの空き状況も照会できます。

## 状態の選択肢でメニューが動かない

状態セレクターを開くと選択肢がプロフィールメニューの左側に表示され、下にあるプロフィール操作は元の位置に保たれます。

## カレンダー状態の制御

ユーザー設定の「一般」に、カレンダー予定による空き状況の変更を防ぐオプションを追加しました。
