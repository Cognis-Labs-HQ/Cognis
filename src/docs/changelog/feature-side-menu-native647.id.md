# Aksi menu samping

**Cabang Fitur:** feature-side-menu-native647

## Memilih tanpa mengirim

Pilihan menu samping bersama kini secara eksplisit menggunakan tombol yang tidak mengirim formulir untuk grup tetap maupun yang dapat dilipat. Callback pilihan, status aktif, pengguliran ke judul, penyimpanan grup, dan pembersihan masa hidup pemilik tetap tidak berubah.
