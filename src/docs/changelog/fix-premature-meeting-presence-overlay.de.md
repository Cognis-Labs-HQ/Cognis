# Meeting-Präsenz später starten

**Feature-Zweig:** N/A

## Präsenz erst nach echtem Beitritt

Die Meeting-Präsenzverfolgung und die Allein-im-Meeting-Aufforderung warten jetzt auf den echten Jitsi-Konferenzbeitritt, statt bereits auf dem Vorab- oder Warten-auf-Moderator-Bildschirm zu starten. Zustände mit ausstehender Authentifizierung starten kein Heartbeat-Tracking mehr, sodass Benutzer kein verfrühtes „Allein im Meeting“-Overlay sehen, bevor das Meeting tatsächlich läuft.
