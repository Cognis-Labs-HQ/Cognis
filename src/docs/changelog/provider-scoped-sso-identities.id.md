# Nama SSO Berlingkup Penyedia

**Cabang Fitur:** provider-scoped-sso-identities

## Nama Pengguna Eksternal Unik

Akun eksternal dan handle profil baru kini menyertakan ruang nama penyedia. Sebagai contoh, handle X menjadi `x:firehawksystems`, sehingga dapat berdampingan dengan `line:firehawksystems` dan nama pengguna lokal `firehawksystems`.
