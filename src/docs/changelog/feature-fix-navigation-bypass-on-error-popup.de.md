# Fehlerpopup-Navigation

## Abstürze nach dem Laden bleiben auf der Seite

Das Schließen des Laufzeitfehler-Popups führt nicht mehr von einer Seite weg, die bereits erfolgreich geladen wurde, bevor eine Schaltfläche oder eine andere Aktion nach dem Laden abgestürzt ist. Fehler beim Laden oder Einhängen von Routen führen Benutzer bei Bedarf weiterhin zur vorherigen Route zurück.
