# ログイン後の復帰

## 元のページを再開

セッションがタイムアウトした際、Cognis は現在のページをログイン URL に保持し、ログイン成功後にダッシュボードではなく元のページへ戻るようになりました。

## 安全な復帰先

ログイン後の復帰先を Cognis 内のローカルパスに限定し、外部サイトやログイン画面への再帰的なリダイレクトを防止します。

## 確認と二要素認証後に続行

アカウント登録では復帰先がメール確認と二要素認証の設定にも引き継がれるため、どちらのフローを完了した場合も、最初に認証を必要としたページへ移動できます。

## 復帰前にダッシュボードを初期化

認証成功後は要求されたページを開く前にダッシュボードのシェルを読み込み、ナビゲーションの追加項目とキーリングの設定が常に初期化されるようになりました。

## ルート相対の復帰パスを受け付ける

ログイン後の復帰先では先頭のスラッシュを省略できます。Cognis は安全なルート相対パスに正規化し、外部の復帰先は引き続き拒否します。
