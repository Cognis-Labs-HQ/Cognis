# より明確なナビゲーション操作

## テーマ対応の検索アイコン

グローバル検索の操作に、ライトテーマとダークテーマ専用の、より大きく鮮明な SVG アイコンを使用するようになりました。

## アクティブなアカウントメニュー操作

ユーザーのドロップダウンメニューが開いている間はアカウントのアバターボタンにアクティブ状態が表示され、メニュー内では現在のページへのリンクが常に強調表示されるようになりました。
