# PRの変更履歴 — カレンダーUIリデザイン

## 概要

サイドツールバーの幅を最小化し、カレンダーに水平スペースを確保しました。
カレンダーリストの各項目には、カレンダー名の横に表示設定アイコン（非公開は
鍵アイコン、公開は地球アイコン）が表示されるようになりました。

新しいカレンダーの作成フォームがツールバーからポップアップに移動し、
「マイカレンダー」の見出し横に配置された「+」ボタンで開くようになりました。
そのポップアップ内のカラーピッカーは名前入力欄の左側に移動し、別途の
「色」ラベルはなくなりました。

イベント作成はスタンドアロンページ要素ではなくなり、共有の再利用可能な
ポップアップシステムを通じてのみポップアップとして開くようになりました。

日表示では1日分のみ表示し、日付・曜日が見出しに表示されます。時間スロットは
固定された左列にラベル付きの行インデックスとして表示されます。各スロットの
イベントは隣接する右列に表示されます。空のイベント列またはスロット行の
「+」ボタンをクリックするとイベント作成ポップアップが開きます。スロットラベル
自体をクリックしても何も起こりません。

週表示では、日グリッドの上に月ラベルの行が表示されます。各日列のヘッダーには
曜日と日付が表示され、クリックするとその日の日表示に切り替わります。

月表示では「週表示を開く」ボタンが廃止されました。代わりに、各週行の左端の
セルにISO週番号が表示され、クリックするとその週が週表示で読み込まれます。
