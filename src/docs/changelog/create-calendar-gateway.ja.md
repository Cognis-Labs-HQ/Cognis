# カレンダー強化

**Feature Branch:** copilot/create-calendar-gateway

## 複数カレンダーの予定を常時表示

カレンダーページを再読み込みしても、デフォルト以外のカレンダーにある予定が
消えなくなりました。メインのカレンダー表示、保留中の招待、今後の予定概要は
引き続き利用可能なすべてのカレンダーの予定を集約するため、承諾した予定や
手動で作成したサブカレンダーの予定も再読み込み後に利用できます。

## 今後の概要に保留中の招待を追加

今後の概要に、承諾・仮承諾・辞退をすぐに実行できる「回答待ちの予定」
セクションを追加しました。招待を承諾する際は追加先のカレンダーを選べる
ようになり、従来の共有リンク生成UIはカレンダー編集ポップアップから
取り除かれました。

## カレンダー招待通知を復旧

カレンダーの招待通知と回答通知は、カレンダー Gateway の起動時だけでなく
各リクエスト時にも notify capability を解決するようになりました。これに
より、notify Gateway が calendar の後に読み込まれても、起動順のせいで
配信が黙って止まることがなくなります。

## 永続化された予定データ

DB executor の機能が利用できる場合、カレンダー Gateway はカレンダー、予定、
参加者の回答を DB ベースのストアに永続化するようになりました。カレンダー
ルートは予定単位の取得・更新・削除、参加者回答、内部招待ユーザー向けの
Invited カレンダー自動コピーに対応しました。

## 充実した予定操作

カレンダーのポップアップは予定の表示、編集、削除、回答に対応し、繰り返し、
空き/予定あり、重複警告も扱えます。カレンダー表示はより豊かな予定バッジを
描画し、ダッシュボードには今後の予定が表示され、翻訳も拡張されました。
さらに Gateway テストでは Invited カレンダー、予定更新、ミラーコピー削除を
確認するようになりました。

## 修正: URL から開いた予定ポップアップが閉じられない問題

`eventId` クエリパラメータ付きでカレンダーページを開いた場合に、予定詳細
ポップアップを正常に閉じられるようになりました。従来は、ポップアップ実装が
`"close"` アクション ID を `null` に変換した後 `onAction` を呼び出すにも
かかわらず、ハンドラーが文字列 `"close"` を照合していたため、閉じる操作が
静かに破棄されていました。照合を `null` に修正したことで、ポップアップを
閉じられるようになり、直リンクからのページ読み込み後にローディングインジケーターが
無限に回り続ける問題も解消されました。

## カレンダーをクリックして編集

サイドバーツールバーの各カレンダーは単一のインタラクティブ要素になりました。
クリックすると編集ポップアップが直接開きます。以前各カレンダー名の横に表示
されていた独立した鉛筆ボタンは削除されました。

## カレンダーUIの改善

カレンダーの表示コントロールが1行のツールバーに統合されました。左側にナビゲーション
ボタンと現在の期間ラベル、右側に表示切替ボタン（日 / 週 / 月 / 年）が配置されています。
週表示では月・年の後にISO週番号が表示されます。月表示では1日ごとのイベント件数表示が
廃止され、最大3件のイベントがインラインで表示され、それ以上ある場合は「…」で示します。
年表示ではイベントのある日がより鮮明なコントラストカラーでハイライトされます。
週軸のコーナーセルがタイムスロットラベルと同じ背景色になり、軸が連続して見えます。
年表示の2月のカードが他の月より高くなる問題が修正されました。

## 名前付き共有リンクと件数無制限

カレンダー共有UIでは、生成する各リンクにオプションで名前を付けられるようになりました。
複数のリンクを作成した際の識別が容易になります。リンク件数の上限もなくなり、
生成したリンクはすべてポップアップに表示され、有効期限が切れるまで利用できます。

## 時刻形式の設定

設定の「日付と時刻」に 12 時間表示 / 24 時間表示の選択を追加しました。共有の
タイムスタンプ整形がこの設定を使うため、カレンダー、メッセージの時刻表示、
時計、そのほかの時刻ラベルがすべて選択した形式で統一されます。

## すっきりしたカレンダースロット

週表示と日表示のスロットは高さを一定に保ちながら、予定を積み重ねたカードと
固定位置の追加ボタンで表示するようになりました。イベントや追加ボタン以外の
場所をクリックすると予定作成を開くため、作成できないデッドゾーンも解消されます。

## 作成直後のカレンダーイベントポップアップ

新しく作成したカレンダー予定は、保存後すぐに詳細ポップアップが開くようになりました。
ページの再読み込みは不要です。週表示の参加者チップは、Jitsi の参加者スタイルに
合わせた縦型アバターバブルで表示されるようになりました。

## Jitsi Meet – 管理画面の予定されたミーティングセクション

Jitsi Meet 管理ページに「予定されたミーティング」という2つ目のテーブルが追加されました。
このテーブルには、今後のカレンダーイベント用に作成されたが、まだ開始または終了されて
いないミーティングが一覧表示されます。カレンダーイベントからミーティングを生成する際、
イベント作成者は常に参加者として含まれます。

## カレンダーUIの改善

カレンダーを削除すると、ポップアップが自動的に閉じるようになりました。空い
ている時間枠にカーソルを合わせると、クリック可能な領域がわかりやすい色付き
の背景で強調表示されます。週表示の終日行もタイムスロットと同様にホバー時に
ポインターカーソルが表示されるようになりました。保留中のイベント招待は「マ
イカレンダー」ツールバーセクションに移動し、サイドバーから重複していた「今
後のイベント」ラベルが削除されました。すべてのビューのイベントカードが、月
表示のコンパクトカードも含め、カレンダーの色に合わせた色調背景を正しく表示
するようになりました。

## イベントポップアップが24時間設定に対応

イベント詳細ポップアップが、設定の12時間/24時間時刻表示の設定を正しく反映
するようになりました。以前は、ユーザーが選択した時刻形式に関わらず、ポップ
アップ内の開始・終了時刻が常に12時間形式で表示されていました。
