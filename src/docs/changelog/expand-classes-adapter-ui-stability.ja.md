# 教室のUI安定性とマテリアル表示の改善

## タイルアニメーションが中断されなくなりました

動的更新でワークスペースタイルの順序が実際に変更された場合のみ再配置を行うようになりました。不要なDOMの移動がなくなり、アクティブなタイルとヘッダーのアニメーションが中断されません。

## チャット作成中にフォーカスが維持されるようになりました

教室のコンテンツが動的に更新される際、メッセージ入力フィールドなど現在フォーカスされている要素が自動的に保存・復元されるようになりました。更新後も作業中の内容が失われません。

## Whiteboard モジュール未設定時は Whiteboard タブが非表示になりました

Nextcloud Whiteboard モジュールが設定されていない場合、ワークスペースタブ一覧からホワイトボードタブが完全に除外されます。タブの表示はモジュールの有効状態に基づいてサーバー側で制御されます。

## クラスマテリアルがインラインビューアで表示されるようになりました

PDF・画像マテリアルが、ファイルアイコンの代わりに埋め込みビューアで表示されるようになりました。教師がマテリアルを選択する際の競合状態を解消し、選択されたマテリアルキーが生徒に正しく配信されるようになっています。
