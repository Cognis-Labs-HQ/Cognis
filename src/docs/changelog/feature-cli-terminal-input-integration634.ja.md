# CLI 端末と入力

**機能ブランチ:** feature-cli-terminal-input-integration634

## 入力案内と結果を分離

入力待ちの間は進捗を停止し、送信後に再開します。入力案内と進捗は stderr、最終結果は stdout に出力します。EOF、Ctrl-C、SIGINT はコマンドの変更処理を行わずに失敗し、端末状態を復元します。非対話操作では明示引数を使用できます。入力案内の前にコンポーネント検出の読み取りが発生する場合があります。

## 有効な入力を収集して保持

CLI 0.4.7 はヘルプの分類と独立したコマンド所有のスキーマで、必須のパス・本文・クエリ項目を収集します。明示指定された通常項目は表示できますが、パスワード、トークン、未宣言項目は非表示です。文字列の空白、有効な空コレクション、偽、ゼロを保持します。無効な数値、真偽値、JSON 形式はコマンドのリクエスト前に拒否します。必須クエリの明示的な空値も保持し、重複する項目名は登録時に拒否します。API ポリシーと業務上の検証は変更しません。

## 検証

実際の CLI の PTY と公開登録のテストで出力衝突、キャンセル、秘密情報の非表示、空コレクション、正確なパスワード、型、クエリ、重複名を確認します。限定テストは実サービスの成功や全コマンドの動作を証明するものではありません。削除結果の修正や TFA 登録の刷新は含みません。
