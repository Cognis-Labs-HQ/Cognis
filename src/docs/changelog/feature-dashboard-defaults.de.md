# Dashboard-Standardlayout

**Feature-Zweig:** feature-dashboard-defaults

## Ausgewogene Standardkarten

Die Digitaluhr mit Datum bleibt im Dashboard aktiv. Konto, letzte Anmeldung und Begrüßung verwenden kompakte Übersichtskarten. Anstehende Kalendertermine erhalten mehr Höhe für ihre Liste; Meine Klassen nutzt eine kürzere Karte für Einführung und Aktion. Abstände und Umbruch übernimmt Page Composer statt einer eigenen Dashboard-Layoutlogik.

## Optionale Analoguhr

Die Analoguhr befindet sich zunächst unter den verfügbaren Elementen. Öffnen Sie Seitenelemente anordnen und wählen Sie Hinzufügen neben der Analoguhr. Verschieben oder vergrößern Sie sie mit den üblichen Touch- oder Tastaturbedienelementen und speichern Sie die Anordnung. Beide Uhren bleiben verfügbar.

## Eigene Anordnung behalten

Diese Vorgaben gelten für neu platzierte Karten. Gespeicherte Positionen, Größen und ausgeblendete Elemente bleiben erhalten, auch eine zuvor hinzugefügte Analoguhr. Schmale Ansichten verwenden die vorhandene inhaltsabhängige Darstellung über die volle Breite von Page Composer, ohne Desktop-Profile zu überschreiben.
