# Consistent Profile Initials

**Feature Branch:** feature-profile-initials-integrated

## Share Avatar Presentation

Navbar, hover preview and Profile hero now share Profile-owned initials, color and explicit size rules. Retained images use the latest authorized name when restoring initials after an image error. The preview avatar links to its profile without reopening the preview.

## Upgrade Matching Assets

Profile 4.0.0 requires the matching shell navbar provider contract. Ship both together; the owner supplies synchronous content and the shell retains its existing button, menu and availability. Existing custom avatar renderer options remain available. Messages and Calendar tested ceilings advance to 4.0.0; external module compatibility and native browser layout remain unverified.
