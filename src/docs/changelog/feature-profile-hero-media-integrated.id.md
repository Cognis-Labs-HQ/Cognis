# Pertahankan Gambar Profil

**Cabang Fitur:** feature-profile-hero-media-integrated

## Pertahankan Gambar Saat Pembaruan

Avatar dan banner profil tetap terpasang saat pembaruan lain dan kegagalan pembacaan sementara. Perubahan kunci, ketiadaan yang dipastikan, serta penolakan akses tetap menghapus gambar yang tepat.

## Kelola Masa Aktif Media

Profile 3.0.20 membatasi pembacaan asinkron, unggahan, penghapusan, dan pemilihan berkas pada rute, sesi, dan penyedia aktif. URL objek yang ditinggalkan dilepaskan; penyelesaian lama tidak dapat memengaruhi profil baru. Kontrak editor dan pratinjau avatar tetap dipertahankan.
