# 変更履歴要約更新

**Feature Branch:** copilot/create-changelog-ingestion-system

## 見出し解析を統一

リリース変更履歴の取り込みは、`#` 見出しをタイトルとして扱い、
`##` 見出しをリリースポップアップの要約箇条書きとして扱うように
なりました。

## 箇条書き要約を表示

リリースポップアップは、変更履歴タイトルと `##` 見出し由来の
箇条書き要約を表示します。詳細本文は変更履歴ページでのみ表示します。

## 前向き設定を追加

ユーザー設定は単純な否定チェックボックスではなく、
「変更履歴を表示」という前向きな制御に更新され、
「リリースごとに変更履歴の要約を表示します。」という
情報ツールチップを表示します。

## ルール文書を更新

貢献ガイドに変更履歴ファイルの必須構造を追記し、
保存先を `src/docs/changelog/` に統一すること、
対応言語すべてで PR ごとに新規ファイルを追加することを明記しました。
