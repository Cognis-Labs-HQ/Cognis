# 言語設定の修正

**Feature Branch:** feature-investigate-and-fix-language-preference-issue

## 言語のドラッグがより確実に

設定の言語設定テーブルは、ブラウザーが近くの子要素や周辺要素をドロップ先として報告した場合でも、ポインター位置からドロップ先を判定するようになりました。これにより、「利用可能な言語」から「優先言語」へ移動する操作が、最初のドロップでより安定して完了します。
