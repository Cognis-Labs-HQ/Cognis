# メッセージ表示のプレビュー

**機能ブランチ:** feature-settings-message-preview

## メッセージスタイルのプレビュー

外観のメッセージスタイルの下に、架空の会話であることを明示したサンプルが表示されます。受信と送信の例は Messages の表示を使用し、名前と地域に合わせた日付・時刻を示します。スタイルを切り替えると未保存の選択を確認でき、保存すると適用され、破棄すると保存済みの表示に戻ります。外観のガイドには、利用可能な場合だけプレビューの手順が含まれます。サンプルにリンク、プロフィール操作、既読通知、実際の会話データはありません。Messages が利用できなくても、選択と通常の設定保存は使用できます。セクションを再表示しても未保存の選択は維持され、設定を離れると未完了の描画は取り消されます。
