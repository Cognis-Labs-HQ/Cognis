# Abhängigkeitsprüfung

**Feature-Zweig:** N/A

## Flexible Komponentenabhängigkeiten

Cognis-Komponentenpakete verwenden jetzt geprüfte Obergrenzen für Abhängigkeiten, damit die Administration bei neueren, nicht verifizierten Komponentenkombinationen warnen kann, statt exakte Versionsgleichheit zu verlangen.

## Namespace-Erkennung für Avatare

Jitsi Meet erhält den Datei-Namespace für Profile jetzt über Komponentenfähigkeiten, bevor Avatar-Datei-URLs erstellt werden.
