# 安定したメッセージ表示

**機能ブランチ:** feature-fix-test-failures-from-last-pr

## すべての表示スタイルを復元

メッセージページへ直接アクセスした際に、クライアント側ナビゲーション用に登録されたスタイルと同じ、アダプター所有のすべてのスタイルシートを再び読み込むようにしました。

## 壊れやすいテストなしで直接読み込み時の表示を維持

プロフィールおよびクラスページと同様に、Messages には直接アクセス用の独立した HTML シェルがあります。そのため、SPA ルートのスタイルと一致する明示的なリンクは維持します。機能固有のテストは、特定の読み込み方式を要求せず、表示動作に集中するようにしました。
