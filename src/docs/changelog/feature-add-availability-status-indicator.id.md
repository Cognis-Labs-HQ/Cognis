# Status Ketersediaan

## Lihat ketersediaan sekilas

Avatar kini menampilkan status kosong, sibuk, atau sementara di bilah navigasi, pratinjau profil, pesan, dan rapat.

## Atur status secara manual

Pilih lampu status pada avatar navigasi untuk mengubah ketersediaan manual. Acara kalender yang sedang berlangsung berlaku sementara, lalu pilihan manual dipulihkan setelah acara berakhir.
