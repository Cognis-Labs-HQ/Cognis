# Kontrol Komponen Responsif

**Cabang Fitur:** feature-administration-control-layout

## Baris Administrasi sesuai isi

Administrasi mengembalikan ruang kontrol yang tidak terpakai dan membungkus nama, label status terlokalisasi, serta detail versi dalam baris komponen yang sempit. Kontrol pembuka detail tetap terpisah dari sakelar daya, termasuk pada baris terbuka dan dinonaktifkan.

## Akses papan ketik dan sentuh

Sakelar komponen tetap menjadi kontrol papan ketik asli dengan nama terlokalisasi dan fokus yang terlihat. Sakelar dan target pembuka detail memiliki tinggi minimal 44 piksel. Label kesehatan dan tutorial papan ketik tersedia dalam bahasa Jerman, Inggris, Indonesia, dan Jepang.
