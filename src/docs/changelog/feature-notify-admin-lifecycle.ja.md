# 通知の下書きを確実に管理

**機能ブランチ:** feature-notify-admin-lifecycle

## 下書きを自分の判断で保持

通知と一斉通知の下書きは、同じページ内の再描画でも保持されます。「このページに留まる」は未保存の作業を保持し、「元に戻す」は初期値に戻します。「通知を送信」または「一斉通知を作成」だけが送信や公開を行い、一般設定の「保存」では行いません。送信成功時は変更のない下書きを初期化し、新しい編集や拒否された送信の下書きは保持します。

## 公開と一覧の更新を区別

処理中の送信や状態変更は重複して実行できません。一斉通知一覧の更新失敗は成功した変更とは別に通知され、以前の一覧が表示されます。遅れて届いた確認詳細で、閉じた画面や置き換えた画面が再び開くことはありません。有効・無効のラベルと更新されたガイドは、対応する4言語すべてに翻訳されています。

独立した「更新」操作は一覧の読み込みだけを再試行し、下書きを保持します。成功した作成や状態変更は繰り返しません。
