# Dunkelmodus für das Kontrollkästchen im Änderungsprotokoll-Popup

## Verbesserte Sichtbarkeit des Kontrollkästchens im Dunkelmodus

Das Kontrollkästchen „Nicht mehr anzeigen“ im Popup für Versionsänderungen verwendet nun das aktive Farbschema und die Akzentfarbe der Anwendung. Dadurch bleibt das Steuerelement sowohl im dunklen als auch im hellen Design klar erkennbar.
