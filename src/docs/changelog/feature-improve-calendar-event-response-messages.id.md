# Balasan Kalender

**Feature Branch:** feature-improve-calendar-event-response-messages

## Balasan Undangan Lebih Ramah

Notifikasi kalender kini memakai kata-kata yang lebih ramah untuk undangan, respons, pengingat, dan pembatalan, mempertahankan tautan undangan tertunda, menampilkan pengundang atau pemberi respons sebagai pengirim, menggabungkan status respons peserta di popup acara, serta menyegarkan respons peserta setiap menit saat popup terbuka.
