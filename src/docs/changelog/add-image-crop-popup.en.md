# Profile Image Crop Popup

**Feature Branch:** copilot/add-image-crop-popup

## Crop Before Upload

Profile avatar and banner uploads now open a popup before saving so users can drag and reposition the image to match the visible in-app frame proportions.

## Expandable Guide Grid

The crop popup now includes an expandable guide grid and zoom control so framing is easier before the final upload.
