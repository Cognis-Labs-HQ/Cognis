# Complete Files Workspace

**Feature Branch:** work

## Virtual file organization

Added a responsive Files workspace with category navigation, namespace pills, provider selection, virtual folders, favorites, recents, destructive actions, and a reusable context menu without moving provider objects.

## Classroom and sharing integration

Teacher classroom folders synchronize through a `ctx` capability. Files participate in Share gateway user and link flows with viewer/editor choices and guest-compatible access.

## File opening and administration

Added the File Render Gateway's renderer-neutral open contract, including forced “Open With...” dispatch, plus provider assignment and pooled quota controls in Administration.
