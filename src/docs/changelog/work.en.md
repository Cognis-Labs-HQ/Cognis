# Reliable External Profiles

**Feature Branch:** work

## Stable External Accounts

External identities now resolve to one normalized local account before registration, persistence, token issuance, and profile creation.

## Provider Profile Experience

External accounts use resolved handles and provider icons in Administration and can request a provider profile refresh from the profile banner. Provider media is persisted in Cognis.
