# Language-scoped Study Library navigation

**Feature Branch:** work

## Keep Study languages in context

Study and Library links now retain the selected, validated BCP-47 language across direct loads, client navigation, and browser history traversal. Declarative language packages remain useful through their generated Library experience even without executable pages.

## Open reading access to learners

Authorized learners can discover and browse the Library while authoring and publishing permissions remain enforced independently by Library scopes.
