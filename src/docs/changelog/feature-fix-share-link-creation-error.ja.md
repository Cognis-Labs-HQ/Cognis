# 共有ポップアップを復元

## 一貫した共有ポップアップ

ホワイトボードはリソース識別子と機能を指定して共有ゲートウェイの共通ポップアップを開き、他のコンポーネントと同じゲートウェイ統合を使用するようになりました。共有方法とトークン要求は引き続きゲートウェイが担当します。

## プレゼンスアバターの配置を維持

ページプレゼンスのプロフィール画像は共有プレゼンススタイルシートから表示スタイルを受け取るようになり、未装飾の画像レイヤーとしてホワイトボードキャンバス上に表示されず、ツールバーのアバターとして維持されます。

## 共有ゲストの認証を維持

ホワイトボードの共有リンクを開いた際、限定されたゲストセッションが維持されるようになりました。Cognis は一時的なゲスト識別子を通常のユーザーアカウントとして検証せず、トークンを削除したり、アカウントが削除されたと表示したりしなくなりました。

## ゲストセッションに対応したダッシュボードデータ

共有ページは、プロフィールおよびダッシュボードのリクエストを選択する際に Share ゲートウェイのゲストセッション機能を使用するようになりました。これにより、ホワイトボードを開いている間に不要なアカウント専用リクエストが失敗しなくなります。
