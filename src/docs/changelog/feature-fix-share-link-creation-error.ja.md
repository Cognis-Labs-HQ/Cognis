# 共有フォームを復元

## 本番環境で共有フォームを読み込み

本番用 UI ビルドにアダプター提供の共有方法ページモジュールが含まれるようになり、リンク共有とユーザー共有のポップアップに利用不可エラーではなくフォームが表示されます。

## 一貫したホワイトボード共有

ホワイトボードでも他のページと同じゲートウェイ所有の共有ポップアップを使用し、リンク共有とユーザー共有の両方を利用できるようになりました。プレゼンスアバターはツールバー内に収まり、プロフィール画像が描画キャンバスを覆うことはありません。

ページプレゼンスのプロフィール画像要素は、共有プレゼンススタイルシート自体から表示スタイルを受け取るようになりました。これにより、未装飾の画像レイヤーとしてホワイトボードキャンバス上に表示されず、ツールバーのアバターとして維持されます。
