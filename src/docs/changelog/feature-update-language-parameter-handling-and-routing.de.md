# Sprachbezogene Navigation der Study-Bibliothek

**Feature-Zweig:** feature-update-language-parameter-handling-and-routing

## Study-Sprache im Kontext behalten

Study- und Bibliothekslinks behalten die ausgewählte, validierte BCP-47-Sprache bei Direktaufrufen, Client-Navigation und dem Browserverlauf bei. Deklarative Sprachpakete bleiben auch ohne ausführbare Seiten über ihre erzeugte Bibliothek nutzbar.

## Lesezugriff für Lernende öffnen

Berechtigte Lernende können die Bibliothek entdecken und durchsuchen, während Berechtigungen zum Erstellen und Veröffentlichen weiterhin unabhängig durch Bibliotheksbereiche erzwungen werden.
