# Composer のグリッド寸法

**機能ブランチ:** feature-composer-grid-dimensions

## 一貫した全幅表示

全幅の配列指定が、メインと入れ子の Composer で利用可能なすべての列を使用するようになりました。ログインと登録フォームにも適用されます。数値による高さの上限と高さを埋める動作は、それぞれ独立して機能します。

## グリッドの外へドラッグ

ウィジェットを現在のグリッドの下へドラッグすると、コンテンツ、グリッドの表示領域、ドロップ先の影が一緒に拡張されます。拡張された領域はドロップするまで維持されます。
