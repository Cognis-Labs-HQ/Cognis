# Current Calendar Period

**Feature Branch:** fix-calendar-period-navigation

## Highlight the Current Period

Today, This Week, This Month and This Year show an active state when the selected period contains the current date in the configured timezone. The state refreshes at midnight and when returning to the page. Calendar weeks retain their Sunday-start convention.

## Align Month Controls

Month view aligns day-add controls and removes the box around the date number. Narrow layouts place the add control below the date to keep both usable.
