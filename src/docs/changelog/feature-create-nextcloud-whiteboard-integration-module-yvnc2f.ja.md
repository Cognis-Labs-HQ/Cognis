# ダッシュボード内のホワイトボード

**機能ブランチ:** feature-create-nextcloud-whiteboard-integration-module-yvnc2f

## キャンバスがダッシュボードレイアウト内に直接埋め込まれるように

ホワイトボードキャンバスはブラウザのポップアップとして開かれなくなりました。ボードリストからボードをクリックすると、フルの描画キャンバスがダッシュボード内にインラインで読み込まれ、すべてのコラボレーションを同じタブで維持します。

## キャンバス起動前のプリフライトチェックでサーバー到達性を確認

キャンバスが接続する前に、ホワイトボードサーバーの URL が設定されており応答可能であることを確認する到達性チェックが実行されます。設定が不足しているかサーバーに到達できない場合、明確なエラーメッセージが表示されます。

## ダッシュボード内でフルの描画ツールを使用可能

埋め込みキャンバスには完全なツールバー（ペン、消しゴム、線の色、線の太さ、消去）が含まれており、以前のポップアップウィンドウで利用可能だったすべての機能を備えています。

## Socket.IO によるリアルタイムコラボレーションは変更なし

Socket.IO 接続とエレメント同期は以前と同じように機能します。変更点は、キャンバスが別のブラウザウィンドウではなくページコンポーザーのグリッドエレメント内に配置されることだけです。

## JWT セッショントークンをサーバー側で発行し、クレデンシャルなしで安全に接続

ユーザーがホワイトボードを開くと、Cognis サーバーは短命の JWT（設定済み API キーで署名）を発行してクライアントへ返します。クライアントはこのトークンで Nextcloud Whiteboard サーバーに認証するため、API キーは厳密にサーバー側に保持されます。

## 管理設定に独立したコラボレーションサーバー URL

管理者はスタンドアロンの Nextcloud Whiteboard コラボレーションサーバーエンドポイントを指す専用の**ホワイトボードサーバー URL** を設定します。これにより Nextcloud インスタンス URL と Socket.IO サーバーアドレスが分離されます。

## 新機能: `whiteboard:getEmbedUrl` と `whiteboard:fetchBoardData`

他のモジュールやアダプターがこれらの公開ケイパビリティを通じてホワイトボードの埋め込み URL やメタデータを取得でき、将来のクラスルームおよびミーティング統合が可能になります。
