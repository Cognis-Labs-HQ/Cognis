# Nextcloud Whiteboard: WSS ネイティブキャンバス

## ネイティブホワイトボードキャンバスが WebSocket で Nextcloud Whiteboard コラボレーションサーバーに直接接続

以前の実装ではユーザーを Nextcloud 独自のフロントエンドへリダイレクトしていました。ホワイトボードはポップアップウィンドウ内のネイティブキャンバスとして開き、Nextcloud Whiteboard コラボレーションサーバー（Socket.IO / WSS）に直接接続します — iframe は不要です。

## JWT セッショントークンをサーバー側で発行し、クレデンシャルなしでクライアント接続を安全に確立

ユーザーがホワイトボードを開くと、Cognis サーバーは短命の JWT（設定済み API キーで署名）を発行してクライアントへ返します。クライアントはこのトークンで Nextcloud Whiteboard サーバーに認証するため、API キーは厳密にサーバー側に保持されます。

## 管理設定に独立したコラボレーションサーバー URL を追加

管理者はスタンドアロンの Nextcloud Whiteboard コラボレーションサーバーエンドポイントを指す専用の**ホワイトボードサーバー URL** を設定するようになりました。これにより Nextcloud インスタンス URL と Socket.IO サーバーアドレスが分離され、任意のポートやホスト構成に対応します。

## ホワイトボード一覧ページに各ボードの「開く」ボタンを追加

Whiteboards ページの各ボードカードに**開く**ボタンが表示されるようになり、ネイティブキャンバスをポップアップウィンドウで起動できます。

## 新機能: `whiteboard:getEmbedUrl` と `whiteboard:fetchBoardData`

他のモジュールやアダプターがこれらの公開ケイパビリティを通じてホワイトボードの埋め込み URL やメタデータを取得できるようになり、将来のクラスルームおよびミーティング統合が可能になります。
