# Penanda Wajib Sejajar

**Cabang Fitur:** feature-required-field-labels

## Satukan penanda dengan judul

Judul kolom bersama mempertahankan tanda bintang wajib dalam wadah teksnya, termasuk Perlindungan Kata Sandi di Berbagi. Label panjang dapat membungkus tanpa menempatkan penanda dalam bagian kisi tersendiri.

## Selaraskan status wajib

Perubahan status wajib memakai judul yang sama untuk semua jenis kolom yang didukung. Kelompok radio wajib tanpa pilihan dapat divalidasi tanpa kesalahan karena kontrol tidak ditemukan. Hubungan label dan kontrol, label berformat, serta tombol keterangan terpisah tetap dipertahankan.

Perubahan pilihan radio membersihkan tampilan tidak valid di seluruh kelompok tanpa mengubah nilai atau fokusnya.
