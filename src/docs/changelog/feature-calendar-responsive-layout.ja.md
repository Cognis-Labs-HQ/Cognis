# 画面に合わせたカレンダー

**機能ブランチ:** feature-calendar-responsive-layout

## 広い予定フォーム

パソコンでは、新規作成と編集のダイアログが広く表示されます。十分な幅がある場合、開始と終了、状態と繰り返しがそれぞれ横に並びます。タイトル、説明、カレンダー、参加者、通知は全幅を使います。狭い画面では読み順に縦に並び、画面内でスクロールできます。保存、キャンセル、未保存の変更の保護は従来どおりです。終日は終了の直後に表示されます。日付の検証、書き込み可能なカレンダーの選択、会議の利用可否、オフラインの変更キューは同じ仕組みを使います。

## 読みやすい週の見出し

週の見出しは各日の列内で折り返され、デスクトップのサイドバーがある場合もカレンダー領域の幅に応じて縦に並びます。

## 予定の状態を重ねて表示

日表示の終日欄と時間枠は最小の高さを共有します。コンパクトな予定の間隔は小さいままです。未回答の招待には、予定あり・空き・仮予定の背景の上に斜線と低い不透明度、破線の枠が適用されます。マウスを重ねても両方の状態が維持されます。
