# Notification Keyboard Access

**Feature Branch:** feature-notification-keyboard-integration

## Open Notification Destinations

Inbox rows and arrival popups expose native links or buttons with accessible names and visible focus. Commands and dismiss controls remain separate. Nonlinked arrivals keep the inbox open.

## Preserve Navigation Ownership

Internal Notifications 0.5.37 preserves modified and middle-click link defaults, cancelable notification navigation, confirmed read receipts and current account/provider lifetimes. Unsupported URL schemes do not become active links. Four-language guidance and public-provider regression coverage are updated.
