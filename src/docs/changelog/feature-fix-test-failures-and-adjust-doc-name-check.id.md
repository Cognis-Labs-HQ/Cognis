# Rangkaian Pengujian Andal

## Catatan perubahan dikecualikan

Validasi panjang judul dokumentasi kini mengecualikan entri catatan perubahan karena judul ringkasan rilisnya boleh lebih panjang daripada label navigasi dokumentasi.

## Pemeriksaan gagal diperbaiki

Pengaturan ulang kata sandi, penggabungan basis data dalam memori, pemeriksaan sumber UI, batas komponen, dan harapan regresi lama kini berfungsi secara konsisten.

## Berkas besar dibagi

Pengujian dan modul waktu jalan yang terlalu besar dibagi menjadi berkas terfokus agar tetap memenuhi batas ukuran sumber repositori.
