# 投稿作成画面の公開範囲を改善

**機能ブランチ:** feature-add-theme-select-class-to-visibility-dropdown

## 投稿の公開範囲がプロフィール設定に連動

新しい投稿では、プロフィールに設定された公開範囲が初期値として使用されます。また、公開範囲の選択メニューがライトテーマとダークテーマの両方で正しく表示されるようになりました。
