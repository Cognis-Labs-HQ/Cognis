# ファイル名前空間制御の成熟化

**Feature Branch:** N/A

## 名前空間契約の強化

ファイルゲートウェイは登録時に名前空間 ID とコンポーネント ID を検証し、許可リストを正規化し、不変の名前空間定義として保持するようになりました。これにより、将来のコンポーネントが予測可能な名前空間契約を利用できます。

## より安全な ACL とクォータ動作

名前空間付きファイルの読み取りは各名前空間の上限に従って共有可能なままですが、上書きと削除は所有者または特権を持つアクターに制限されます。クォータ確認では、同じ所有者による上書きを最終的なサイズ差分だけで計算するようになりました。
