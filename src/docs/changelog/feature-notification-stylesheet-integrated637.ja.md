# 通知スタイルの復旧

**機能ブランチ:** feature-notification-stylesheet-integrated637

## 失敗後の表示を復旧

内部通知は5秒の期限付きでスタイルシートの読み込みを共有します。エラーや時間切れでも受信トレイを利用でき、翻訳済みの警告を表示します。後続のプロバイダーマウントでは新しいスタイルシートを取得できます。中止しても他の待機側と正常な外部スタイルを保持し、遅れた結果が終了済みプロバイダーを再開することはありません。

## 既存の受信トレイ動作を維持

通知操作、定期取得、到着通知の寿命、ワークスペースのチュートリアルは変更しません。内部通知アダプターのバージョンは0.5.38です。
