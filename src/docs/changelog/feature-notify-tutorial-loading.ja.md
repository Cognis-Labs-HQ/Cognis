# 通知ガイドの検証

**機能ブランチ:** feature-notify-tutorial-loading

## 通知ガイドのカタログを検証

回帰テストで、通知の設定、通知の配信、お知らせの管理の各ガイド登録を英語、ドイツ語、インドネシア語、日本語のカタログと照合します。通知チュートリアルの文書では、カタログの所有元と英語へのフォールバックを説明します。

## キャッシュを使う登録を検証

ホスト側のチュートリアル回帰テストで、サービスワーカー、翻訳処理、段階的な登録を組み合わせて実行します。登録前の古いゲートウェイカタログの更新、英語へのフォールバック、オフラインでの再登録、翻訳欠落時の明示的な失敗を検証します。
