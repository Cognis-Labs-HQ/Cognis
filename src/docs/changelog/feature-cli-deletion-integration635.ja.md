# 正確な削除結果

**機能ブランチ:** feature-cli-deletion-integration635

## アカウントの結果を区別

アカウント削除は、所有者が確認した後処理未完了の削除、正式な拒否、不明な結果を区別します。通常の HTTP 200 は変わりません。既存の拒否ステータス、コード、安全なメッセージを維持し、明示的な結果データを追加します。実際のフロー例外は元のコンポーネント復旧への帰属を維持します。

完了したフローで証明が利用不能の場合は既存の HTTP 503 エラー項目を保持し、削除済みの可能性があっても削除結果を null・不明と報告します。証明が確認できないフロー例外と不正な完了結果は HTTP 500・不明のままです。認可や有効性の確認は変更しません。

## 完了の証拠を必須に

CLI には HTTP 200 と正確な削除確認が必要です。その他の成功ステータス、不正または欠落した完了結果は不明のままです。公開された任意の通信ステータス制約は、既存の呼び出し側を既定では変更しません。

## 再試行せずに失敗を説明

部分的な完了、拒否、不明な結果には翻訳済みの stderr メッセージと非ゼロの終了コードを使います。応答が欠落しても、削除や後処理を自動で再試行しません。ドイツ語、英語、インドネシア語、日本語の文書で結果契約と安全な確認手順を説明します。
