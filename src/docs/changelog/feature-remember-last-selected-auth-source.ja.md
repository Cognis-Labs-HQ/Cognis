# ログイン元を記憶

**Feature Branch:** feature-remember-last-selected-auth-source

## 優先認証元

ログインページは最後に選択した資格情報の認証元を記憶し、次回以降も選択します。その認証元が利用できない場合は、既定でローカルを選択します。

## 登録カードの表示

登録カードはローカル認証が選択されている場合にのみ表示されます。
