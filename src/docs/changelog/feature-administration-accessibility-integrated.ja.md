# 管理画面の操作名

**機能ブランチ:** feature-administration-accessibility-integrated

## セキュリティのラベルを関連付け

セッション有効期間、検証方式、承認の操作には、表示される翻訳済みラベルを使います。「単位」の選択欄は独自のラベルを持ち、有効期間の見出しも文脈として維持します。情報ボタンはチェックボックスの切り替えから分離します。

## 標準スイッチを操作対象に維持

管理画面のスイッチ入力は、チェック状態と無効状態を持つ標準のチェックボックスとして維持します。透明な入力要素はフォーカス可能なまま、表示中のスライダーにフォーカス枠を付けます。既存のコンポーネント行の寸法、保護された操作部、お知らせのラベル、メモリ内の下書きと破棄の動作を維持します。

## 描画された操作部を検証

公開レンダラーのテストでは、4 言語、繰り返し描画、厳密な英語へのフォールバック、両方のスタイル順序を確認します。既存のチュートリアルの手順と対象は変わりません。DOM と CSS の確認は、実際のキーボード、スクリーンリーダー、端末での検証に代わるものではありません。
