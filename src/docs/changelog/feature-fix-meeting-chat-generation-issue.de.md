# Zuverlässiger Meeting-Chat

## Wiederverwendete Meetings verbinden

Wiederverwendete Meetings speichern nun den neu ermittelten Chatraum, sodass Teilnehmende keinen gelöschten Raum mehr anfordern und keine Nicht-gefunden-Antwort erhalten.

## Teilnehmende und Einladungen laden für alle Eingeladenen

In der Meeting-Teilnehmersuche erscheinen nun für die Community sichtbare Personen, ohne dass die betrachtende Person ihnen folgen muss. Meeting-Einladungen werden an das authentifizierte Konto der eingeladenen Person zugestellt, und eingeladene Personen können Details aktiver Teilnehmender laden.
