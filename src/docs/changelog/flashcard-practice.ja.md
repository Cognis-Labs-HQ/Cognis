# フラッシュカード練習

**Feature Branch:** feature-update-external-package-contract-definitions

## 練習の区分

デッキを開くとすぐに練習を開始します。合計は全カード、新規は復習記録のないカード、復習は予定時刻に達したカード、完了は次の予定が先のカードを含みます。合計内も含め新しいカードでは全内容を表示します。それ以外は読みの選択を間違えた場合や筆画が不正だった場合のみ答えを表示します。区分を選ぶと新しい練習列を開始します。

## 読む練習と書く練習

読む練習では主要な読みと、探索と同じ表示可能なライブラリの類似項目から異なる三つの読みを提示します。有効な選択肢が三つ揃う場合のみ利用できます。書く練習は共通の描画パッド全体を埋め込み、文字を固定し、筆順の評価で成功を判定します。対応しないカードは成功した復習として記録せずにスキップできます。正解と新規カードは良好、不正解は再試行として予定します。

## 探索とエクスポート

ライブラリ由来の名前、読み、定義は探索の元カードへリンクします。移動前に練習を終了する確認を表示します。共有された内容からでも、アクセス権のない元カードは開けません。エクスポートは右上のテーマ対応ダウンロードアイコンを使用し、作成者または管理者のみ利用できます。デッキのページでもフラッシュカードのメニューが選択状態になります。

## フロー契約

ブラウザー操作はbefore、execute、afterの段階を持つstudy:decksフローを実行します。サーバーの一覧と詳細はauthorize、read、auditを実行し、保存、復習、削除は検証、権限、トランザクションを維持します。Studyは共通の描画、パターン合成、類似項目、操作フローを所有します。任意の描画アダプターは浮動パッドの統合のみ提供し、不在でも埋め込み練習は動作します。移動時はページと練習を終了します。
