# Settings Email Actions

**Feature Branch:** feature-settings-email-integration

## Prevent Repeated Email Changes

Set as primary and Remove use their appropriate action styles and share a pending lock. Page departure and account or provider changes suppress stale completion feedback.

## Explain Results and Recovery

Localized toasts distinguish confirmed, queued, rejected and unconfirmed changes. Refresh checks authoritative state without repeating a mutation, while queued changes preserve their pending projection. The General tutorial explains recovery; an unresolved result remains page-local and reopening Settings does not prove it completed.
