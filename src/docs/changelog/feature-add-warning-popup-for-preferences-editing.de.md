# Sichere Einstellungsbearbeitung

## Vollständige Einstellungs-JSON bearbeiten

In den erweiterten Einstellungen können erfahrene Benutzer nach Bestätigung eines Sicherheitshinweises ihr vollständiges UI-Einstellungsdokument bearbeiten. Änderungen werden geprüft, verfolgt, gespeichert und über das bestehende Einstellungssystem angewendet.

## Übersichtliche Einstellungsdokumente

Der Bestätigungsverlauf der Versionshinweise wird nun getrennt von den relevanten UI-Einstellungen gespeichert.
