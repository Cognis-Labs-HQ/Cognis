# Schneller Sprachwechsel

## Optionaler Umschalter

Der Sprachumschalter wird standardmäßig angezeigt und mit Sprachumschalter anzeigen in einem durchgehenden Bereich über den nebeneinander angeordneten Sprachtabellen gesteuert. Das Dashboard liest die gespeicherte Sprachpriorität direkt, damit der Umschalter zuverlässig erscheint. Jeder Klick wählt die nächste bevorzugte Sprache; nach fünf Sekunden ohne weiteren Klick setzt Cognis diese Sprache an die erste Stelle und lädt die Seite neu.
