# Schneller Sprachwechsel

## Optionaler Umschalter

Der Sprachumschalter wird standardmäßig angezeigt und mit Sprachumschalter anzeigen in einem durchgehenden Bereich über den nebeneinander angeordneten Sprachtabellen gesteuert. Das Dashboard liest und normalisiert die gespeicherte Sprachpriorität; der aktivierte Umschalter bleibt auch bei nur einer bevorzugten Sprache sichtbar. Jeder Klick wählt die nächste bevorzugte Sprache; nach fünf Sekunden ohne weiteren Klick setzt Cognis diese Sprache an die erste Stelle und lädt die Seite neu.
