# Schneller Sprachwechsel

## Optionaler Umschalter

Der Sprachumschalter ist standardmäßig aktiviert und wird mit Sprachumschalter anzeigen in einem durchgehenden Bereich über den nebeneinander angeordneten Sprachtabellen gesteuert. Das Dashboard liest und normalisiert die gespeicherte Sprachpriorität und zeigt den Umschalter nur an, wenn mindestens zwei Sprachen zur Auswahl stehen. Jeder Klick wählt die nächste bevorzugte Sprache; nach fünf Sekunden ohne weiteren Klick setzt Cognis diese Sprache an die erste Stelle und lädt die Seite neu.
