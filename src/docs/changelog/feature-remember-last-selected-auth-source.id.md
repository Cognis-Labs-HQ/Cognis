# Ingat Sumber Masuk

**Feature Branch:** feature-remember-last-selected-auth-source

## Sumber autentikasi pilihan

Halaman masuk kini mengingat sumber autentikasi kredensial yang terakhir dipilih dan memilihnya pada kunjungan berikutnya. Jika sumber itu tidak lagi tersedia, Lokal dipilih secara bawaan.

## Visibilitas pendaftaran

Kartu pendaftaran hanya ditampilkan saat autentikasi Lokal dipilih.
