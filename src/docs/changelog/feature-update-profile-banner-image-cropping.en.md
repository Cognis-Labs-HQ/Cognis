# Banner Crop Defaults

**Feature Branch:** feature-update-profile-banner-image-cropping

## Profile banner crops follow height preference

GIF banner uploads now start with a crop region that matches the selected full- or half-height profile banner view, with half height selected by default.

## Banner removal is easier

The remove banner action now appears as a dedicated X button next to the banner menu, while remaining visible only on your own profile when a banner exists.
