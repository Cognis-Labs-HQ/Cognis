# Visibilitas Profil SSO

**Cabang Fitur:** honor-sso-profile-visibility

## Visibilitas dari Penyedia

Sesi autentikasi eksternal dan profil eksternal yang dihasilkan kini dapat mengembalikan `profileVisibility`. Cognis memvalidasi nilai yang didukung dan menyimpan visibilitas yang diminta setelah membuat atau menyinkronkan profil, alih-alih selalu mempertahankan nilai bawaan.
