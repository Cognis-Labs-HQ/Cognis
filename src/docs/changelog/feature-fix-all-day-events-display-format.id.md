# ICS Sehari Kalender

**Cabang Fitur:** feature-fix-all-day-events-display-format

## Ekspor sehari penuh

Feed kalender kini mengekspor acara sehari penuh dengan nilai tanggal ICS meskipun browser menyimpan rentang tengah malam lokal dengan offset UTC, sehingga klien kalender menampilkannya sebagai acara sehari penuh, bukan blok waktu 00:00-24:00.
