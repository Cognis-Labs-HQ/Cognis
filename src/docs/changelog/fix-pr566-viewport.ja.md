# レスポンシブ配置の修正

**機能ブランチ:** fix-pr566-viewport

## デスクトップの内容を表示

共通ボタンのスタイルが後から読み込まれても、デスクトップではモバイル用ツールバーボタンを非表示に保ちます。ボタンがコンテンツ列を占有してページ内容をツールバーの下に押し出す問題を修正しました。スマートフォンとタブレットでは、44 ピクセルの操作領域と中央に配置されたアイコンを維持します。
