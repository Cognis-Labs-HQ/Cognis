# ナビゲーションの維持

**機能ブランチ:** perf-persistent-navigation

## ナビゲーションの維持

ルートとドキュメントの読み込みには全画面の読み込み表示を使用します。別の移動に置き換えられた場合は読み込みトークンを直ちに解放し、未完了の処理や実行時エラーは既存の読み込み・エラー表示で示します。

移動先の読み込み中も、表示中のページのルートスタイルを保持します。移動先のスタイルは無効な状態で準備し、コンテンツの切り替え時に有効化します。中断や失敗した準備では、その準備が所有するスタイルだけを解放します。共有コントロールと開いているコンポーネントウィンドウは、破棄されるまで所有するスタイルを保持します。本番用ドキュメントはスタイルシートのソース識別情報を保持し、直接読み込みとSPAナビゲーションで所有関係を共有します。

初期ルートが所有するのは、宣言されたルートスタイル、またはソース情報を持つ本番用ドキュメントのスタイルだけです。通知などの常駐プロバイダーが挿入したスタイルは、そのプロバイダーが引き続き所有するため、ルート切り替えで通知ベルのサイズ指定が削除されません。

画面の構成ごとに最新の設定を一度取得し、テーマと言語の操作で共有します。プロバイダーの準備後にアバターを一度更新し、内容が同じ要素は維持します。アカウント、トークン、プロバイダー、更新処理が変わった後の遅延結果は破棄します。非公開応答のキャッシュは追加しません。
