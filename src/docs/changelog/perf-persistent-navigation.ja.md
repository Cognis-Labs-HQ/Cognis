# ナビゲーションの維持

**機能ブランチ:** perf-persistent-navigation

## ナビゲーションの維持

ルートの読み込み中は対象の作業領域に読み込み表示を重ね、既存のヘッダーとナビゲーションを表示し続けます。ドキュメントの直接読み込みでは全画面の読み込み表示を維持します。別の移動に置き換えられた場合は読み込みトークンを直ちに解放し、未完了の処理や実行時エラーは既存の読み込み・エラー表示で示します。

画面の構成ごとに最新の設定を一度取得し、テーマと言語の操作で共有します。プロバイダーの準備後にアバターを一度更新し、内容が同じ要素は維持します。アカウント、トークン、プロバイダー、更新処理が変わった後の遅延結果は破棄します。非公開応答のキャッシュは追加しません。
