# Waktu Toast Dapat Dijeda

**Feature Branch:** feature-add-hover-behavior-to-toast-decay

## Toast menunggu saat disorot

Menyorot toast sementara kini menjeda masa tampilnya dan menyembunyikan bilah waktunya. Ketika penunjuk meninggalkan toast, bilah waktu ditampilkan kembali dan seluruh batas waktu yang dikonfigurasi dimulai ulang.

Toast sementara juga dapat ditutup dengan menyeretnya ke kanan menggunakan tetikus atau layar sentuh lalu melepaskannya. Sebelum dilepas, toast dapat diseret kembali untuk membatalkan gestur dan melanjutkan perilaku normalnya. Toast permanen tetap tampil hingga kontrol tutupnya digunakan.
