# Kehadiran Meeting Tepat Waktu

**Feature Branch:** N/A

## Tunda kehadiran sampai benar-benar bergabung

Pelacakan kehadiran meeting dan prompt peserta sendirian kini menunggu hingga benar-benar masuk ke konferensi Jitsi, bukan dimulai saat layar pra-gabung atau menunggu moderator. Status yang masih menunggu autentikasi juga tidak lagi memulai pelacakan heartbeat, sehingga pengguna tidak melihat overlay "sendirian di meeting" terlalu cepat sebelum meeting benar-benar berjalan.
