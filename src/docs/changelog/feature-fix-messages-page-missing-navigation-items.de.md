# Zuverlässige Nachrichtenhülle

## Vollständige Dashboard-Hülle laden

Die Nachrichtenseite verwendet jetzt denselben gemeinsamen Seitenlebenszyklus wie alle anderen Dashboard-Seiten. Dieser lädt die Fähigkeitsanbieter vor dem Einbinden und die Navigationsleisten-Erweiterungen erst nach dem Aufbau der Dashboard-Hülle, sodass alle verfügbaren Navigationseinträge sichtbar sind und spätere Einzelseiten-Navigationen die benötigten Elemente behalten.
