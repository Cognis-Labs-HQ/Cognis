# Database Type Contracts

**Feature Branch:** feature-database-type-contracts

## Typed Database Boundaries

Database initialization accepts only the raw execution capability it uses. Public application executors retain structured commands, while adapter transactions preserve their raw executor type. Column declarations include the existing optional rename source. PostgreSQL reports zero for statements whose driver row count is null; rows and numeric counts are preserved. MariaDB narrows command variants before normalizing conditions. Adapter fixtures retain generic query signatures and use component-owned datasets.
