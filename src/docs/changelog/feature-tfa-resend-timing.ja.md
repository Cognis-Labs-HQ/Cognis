# TFA 再送待機時間

**機能ブランチ:** feature-tfa-resend-timing

## 再び待たずに再開

既存のログインチャレンジを再開したり、その認証方法を再選択したりしても、サーバーが発行した絶対再送時刻を保持します。時刻が過ぎている場合、元の待機時間を再び開始しません。絶対時刻がない場合や無効な場合は、引き続きプロバイダーの相対待機時間を使用します。

## 再送の保護を維持

再送時刻になるまで操作は無効のままで、操作が有効になった後もサーバーの制限が適用されます。既存のチャレンジを表示または再開しても自動再送は行いません。発行済みコードの長さ、検証、認証方法の選択、新しいログイン試行の所有権は変わりません。
