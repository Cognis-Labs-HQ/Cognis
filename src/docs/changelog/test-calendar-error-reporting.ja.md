# カレンダーのエラー報告

**機能ブランチ:** test-calendar-error-reporting

## カレンダー操作の重複を防止

カレンダー表示のリスナーを描画単位で管理します。サイズ変更や再描画で以前のリスナーを置き換え、一度のクリックで一つのフォームを開きます。画面移動時にはこれらを解除し、無関係なリスナーと異なるエラーの表示は維持します。
