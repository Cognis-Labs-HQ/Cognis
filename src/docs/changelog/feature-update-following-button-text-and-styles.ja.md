# ソーシャルフォロー通知

**機能ブランチ:** feature-update-following-button-text-and-styles

## フォロー中ボタンでフォロー解除操作をプレビュー

フォロー中状態のプロフィールボタンは、ホバー時にフォロー解除ラベルとキャンセルスタイルへ切り替わり、クリック前に破壊的操作であることが分かりやすくなりました。

## フォロー活動にSocial通知クラスを使用

フォロー操作はSocial通知カテゴリを登録して送信するようになり、受信者は設定済みの通知プロバイダーを通じてフォロー活動通知を受け取れます。

## プロフィールイニシャルはプロフィール名を優先

プロフィールアバターのフォールバック用イニシャルは、ユーザー名よりプロフィール表示名を先に使い、1語の名前では1文字のイニシャルを表示できるようになりました。
