# プロフィール画像の回復

**機能ブランチ:** feature-profile-avatar-recovery

## 読み込み済み画像を維持

ナビゲーションバーとプレビューは、無関係な更新や一時的な読み込み障害が起きても変更のない画像を維持します。回復可能な読み込みエラーや画像エラーは次の更新や表示時に再試行できます。

## アクセスと有効期間を守る

削除の確認、アクセス拒否、ユーザー情報の変更、プロバイダーの削除時に画像を除去します。アカウントごとの制限付きキャッシュと古い結果の検証で非同期更新を保護します。Profile 3.0.19 とホスト側の変更は同時に配布します。プロフィールページのメイン画像は対象外です。

## プレビューの準備状態

メッセージスタイルのプレビューには、準備が整ったバージョン2の表示プロバイダーが必要です。Profile または Messages が利用できないときはサンプルだけを隠し、選択操作と未保存の選択は維持します。プロバイダーが回復すると現在の選択を自動表示します。任意のプレビュー用チュートリアルも同じ表示領域に従います。対応する Settings、Messages 2.8.1、Profile 3.0.19 のアセットを同時に配布してください。
