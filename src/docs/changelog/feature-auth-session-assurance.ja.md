# 認証保証付きログイン

**機能ブランチ:** feature-auth-session-assurance

## セッション確定を延期

プロフィールの有効化と通常のトークン発行の前に完全な認証を要求します。状態や TFA の評価に失敗した場合は安全に拒否し、管理者による明示的な無効化を維持して、提供元の障害時にも復旧コードを利用できるようにします。

## 完了境界を検証

所有元の段階的契約、試行の不可分な消費、設定の同時完了防止、翻訳済みエラー、コンポーネント所有のオフライン回帰テストを追加します。一次認証の拡張は評価前に実行し、最終ログインの呼び出し元は `auth:login` を使用します。

## 初期化失敗を保持

Core 0.6.4 は検出済みゲートウェイの起動失敗を実行可能な登録と分離して記録します。Auth は本来の任意未導入と意図的な無効化を初期化失敗と区別します。Auth 2.2.5 と TFA 1.3.7 は全拡張方針検査後に最終機能を使用し、操作単位のトークン失効とトランザクションではない状態更新の限界を明示します。
