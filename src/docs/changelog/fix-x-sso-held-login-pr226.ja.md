# コールバックの移動

**機能ブランチ:** fix-x-sso-held-login-pr226

## 承認を維持

`navigateTo` は移動先に SPA ルートがない場合、ホストのリンクやブラウザー履歴と同様に、ガード付きの同一オリジンドキュメント移動を行います。別オリジンへの移動は拒否します。`ui:log` は送信成否を真偽値で返し、匿名要求を省略し、アクセス拒否や接続回復イベントを発生させずに HTTP・ネットワーク送信失敗を処理します。ユーザーへの通知は呼び出し側が担当し、ログエンドポイントは引き続き認証を要求します。
