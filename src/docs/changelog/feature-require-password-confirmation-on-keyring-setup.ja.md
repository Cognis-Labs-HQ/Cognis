# より安全なキーリング設定

## 新しいキーリングパスワードの確認

初回ログイン時およびキーリング再作成時の設定で、独自のキーリングパスワードを再入力するようになり、入力内容が一致しない場合は作成されません。

## 一貫したパスワードフォーム

すべてのキーリングパスワードポップアップで共通のフォームコンポーザーを使用し、必須項目を明示して、検証とレイアウトを統一しました。確認条件は、成功のチェックが表示されるときにパスワードが一致していることを示します。 「ユーザーパスワードを使用」操作では、ログイン時に検証済みの認証情報を適用するため、以降のパスワードログインで追加の入力なしにキーリングを自動解除できます。キーリングの破棄は再作成より先に完了し、再作成を取り消した場合も設定が必須のままになります。

## 削除ユーザーのキーリングを初期化

ユーザー削除後はサーバーの空のキーリング状態を優先します。同じユーザー名を再利用した場合、ブラウザーに残った古い暗号化コピーではなく初回設定が表示されます。
