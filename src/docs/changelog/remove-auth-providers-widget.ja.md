# 認証とパスワードポリシーの更新

## 管理画面から重複する認証プロバイダーウィジェットを削除

認証プロバイダーウィジェットは、コンポーネントページにすでに表示されているため、管理画面の認証セクションから削除されました。認証管理セクション全体が廃止されました。

## パスワードポリシーを管理画面 → セキュリティに移動

パスワードポリシーの設定ウィジェットは、旧認証セクションから管理画面のセキュリティセクションに移動しました。標準のダーティ状態トラッカーと統合されており、変更内容は専用の保存ボタンではなく、統一された変更バーで保存またはキャンセルできます。

## パスワードポリシーで文字クラスに数値の最小値を使用

大文字、数字、特殊文字の要件は、トグルスイッチではなく数値入力を使用するようになりました。値を 0（デフォルト）に設定するとその要件が無効になり、正の整数を設定するとパスワードに含まれる必要があるその文字クラスの最小文字数が指定されます。

## 登録ページ：ユーザー名のインラインバリデーション

登録フォームでは、印刷可能な ASCII 文字以外の文字や大文字を入力した直後に、ユーザー名フィールドの下にインライン警告が表示されるようになりました。警告はフォーム送信時ではなく、入力時に即座に表示されます。

## 登録ページ：常に表示されるパスワードポリシーの箇条書き

登録ページのパスワードフィールドの下に、適用されるすべてのポリシー要件が常に箇条書きで表示されるようになりました。各項目はユーザーが入力するたびにリアルタイムで更新され、要件を満たした場合は緑色のチェックマーク付きで、満たしていない場合は赤色で表示されます。
