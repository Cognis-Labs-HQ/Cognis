# より分かりやすい共有認証情報と履歴

## 共有パスワードをすぐに送信可能

パスワード保護されたリンク共有またはユーザー共有を作成すると、標準の表示切り替えとコピー操作を備えた非表示フィールドでパスワードを確認できるダイアログが開きます。

## 共有履歴に作成日時とフォーム編集を追加

各共有カードに作成日時が表示されます。ユーザー共有カードを選ぶと、履歴カード内で直接編集する代わりに、受信者、権限、有効期限などの値が共有フォームへ読み込まれ、明示的に更新できます。

## ユーザー数と通知操作を安定化

ユーザー共有の操作ボタンは、ユーザーを追加または削除したときに受信者数を更新します。アプリ内の共有通知を開いた際、正規の受信箱ルートを通じて通知を既読にできるようになりました。
