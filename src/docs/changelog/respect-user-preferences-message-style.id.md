# Kontras Gelembung Pesan

## Visibilitas Lebih Baik
Pesan bergaya gelembung kini memakai token permukaan yang lebih menonjol dan bayangan yang lebih kuat agar tetap jelas pada latar gelap.

## Konsisten di Dua Chat
Penyesuaian visibilitas yang sama sekarang berlaku di Social Messages dan chat Jitsi saat gaya gelembung dipilih.
