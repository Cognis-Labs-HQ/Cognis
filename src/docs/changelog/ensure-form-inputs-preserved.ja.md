# ページコンポーザーのグリッド再レンダリング時にフォーム入力を保持

## 概要

ページコンポーザーが小画面と大画面の表示バリエーションを切り替えるとき、
グリッドが再レンダリングされ、表示されているエレメントカードに入力された
テキスト・選択肢・チェックボックスがすべて失われていました。
フォームフィールドの値はグリッドをクリアする直前に保存され、
新しくレンダリングされたカードに復元されるようになったため、
画面サイズの変更中にユーザーが入力内容を失うことはなくなりました。

この修正はメイングリッドコンポーザーとサブグリッドコンポーザーの両方に適用されます。
フィールドは `name`、次に `id`、次に各エレメントカード内の序数位置で照合されます。

## 変更されたファイル/コンポーネント

- `src/ui/reuse/page-composer.js` — `captureFormState` / `restoreFormState`
  ヘルパーを追加；`renderGridComposer` と `renderSubGrid` で呼び出し
- `src/ui/tests/page-composer-refresh.test.js` — 新しい構造テスト
