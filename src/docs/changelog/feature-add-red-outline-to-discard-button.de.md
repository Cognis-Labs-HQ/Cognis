# Composer-Bearbeiten-Menü

## Link-Schaltflächen im Bearbeiten-Menü

Das Bearbeiten-Menü des Seitenkomponisten zeigt seine Aktionen jetzt als animierte Links mit gemeinsamen Schaltflächenklassen. Die Verwerfen-Aktion behält ihre Gefahr-Umrandung, während Fertig und Zurücksetzen Bestätigen- beziehungsweise Neutral-Stile verwenden, damit das gesamte Menü visuell konsistent ist.
