# モジュール表示の現地語化

## 初回から翻訳名を表示

モジュールマーケットプレイスが検出した各モジュールの翻訳文字列をキャッシュして配信するようになり、初回表示かつインストール前でも名前、概要、カテゴリー、タグが翻訳されます。

## コアをコア実行環境で維持

外部モジュールのルートローダーがコアマニフェストを無視するようになり、外部モジュールのインストール先から Cognis Core を探さなくなりました。

## マーケットプレイス構成を明確化

マーケットプレイスの読み込み処理を専用ディレクトリへ移し、カタログ検出、リポジトリアクセス、公開サービスを小さなファイルに分割して、ソースサイズ制限を十分に下回るようにしました。
