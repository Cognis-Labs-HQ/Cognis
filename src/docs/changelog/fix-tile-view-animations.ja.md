# 教室ワークスペース修正

## 教室SPAスタイルを復元

教室のSPAルートはアプリ内遷移でもワークスペース用スタイルシートを読み込むようになり、黒板ワークスペース、サイドバーの余白、チャットタイル、アジェンダ操作がハードリロードなしでも正しく表示されます。

## ワークスペース切替を安定化

タイル表示とスライドショー表示の切替は、アクティブなワークスペースを正しい見た目の順序で保ち、チャットを開いてもレイアウト切替ボタンを表示し続け、チャットとホワイトボードを一貫して初期化し、先生が退出したときはトーストを表示して生徒を教室ビューへ戻します。

## 教材アップロードを改善

教師用ライブラリアップロードは `teacher-materials/` 保存パスを使うようになり、ファイル選択ポップアップでは共通のアップロードSVGを使い、ポップアップの二重起動を防ぎ、教室教材向けの大きなドキュメント上限を利用します。

## Notepadの責務をNotepadアダプターへ移管

教室アジェンダとNotepadファイルのAPIロジックは study/notepad アダプターへ移動し、classes アダプターは共有される教室リソース機能のみを公開する構成になりました。Notepad アダプターがアジェンダのスナップショット、ノートファイル用ルート、そして最大ファイルサイズ設定を管理します。

## Nextcloud Whiteboard の管理設定を追加

Nextcloud Whiteboard モジュールに Administration 用の設定ポップアップと、`/api/v1/modules/nextcloud-whiteboard/config` の永続設定ルートを追加しました。URL、署名シークレット、トークン有効期限はデータベースへ保存され、実行時の埋め込みトークン生成に使用されます。
