# Multiple LDAP Servers

## Manage several directories

Administrators can save, edit, delete, and reorder named LDAP servers from one LDAP configuration home page.

## Choose the login presentation

LDAP sources can appear separately on the Login page or as one unified LDAP source that tries servers in the configured order.

## Enforce user group membership

When an LDAP group maps to the user role, successful authentication is accepted only for members of that group.
