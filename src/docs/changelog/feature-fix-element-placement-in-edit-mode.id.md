# Tata letak edit page composer yang stabil

## Mode edit mempertahankan posisi grid

Kartu page composer kini memakai ukuran jalur grid tetap dan celah grid yang sama di mode tampilan seperti overlay seret dan ubah ukuran di mode edit. Ini mencegah kartu bergeser secara horizontal atau menyusut secara vertikal saat pengguna masuk atau keluar dari pengeditan tata letak.
