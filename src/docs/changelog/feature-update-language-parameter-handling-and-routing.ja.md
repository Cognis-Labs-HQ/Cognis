# 言語別の Study ライブラリーナビゲーション

**機能ブランチ:** feature-update-language-parameter-handling-and-routing

## Study の言語コンテキストを維持

Study とライブラリーのリンクは、直接読み込み、クライアントナビゲーション、ブラウザー履歴の移動を通じて、選択および検証済みの BCP-47 言語を維持します。宣言型言語パッケージは、実行可能なページがなくても生成されたライブラリーを通じて利用できます。

## 学習者に閲覧アクセスを提供

許可された学習者はライブラリーを見つけて閲覧でき、作成と公開の権限はライブラリーのスコープによって個別に適用されます。
