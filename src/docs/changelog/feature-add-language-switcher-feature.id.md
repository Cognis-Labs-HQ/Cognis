# Pergantian Bahasa Cepat

## Pengalih opsional

Pengalih bahasa diaktifkan secara bawaan dan dikendalikan dengan Tampilkan Pengalih Bahasa dalam satu blok menyatu di atas tabel bahasa yang berdampingan. Dasbor membaca dan menormalkan prioritas bahasa tersimpan, lalu hanya menampilkan pengalih jika setidaknya dua bahasa dapat dipilih. Setiap klik memilih bahasa pilihan berikutnya; setelah lima detik tanpa klik lain, Cognis memindahkan bahasa tersebut ke urutan pertama dan memuat ulang halaman.
