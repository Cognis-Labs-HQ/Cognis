# Pergantian Bahasa Cepat

## Pengalih opsional

Pengaturan Pengguna kini menyediakan opsi untuk selalu menampilkan pengalih bahasa di atas kontrol tema. Setiap klik memilih bahasa pilihan berikutnya; setelah lima detik tanpa klik lain, Cognis memindahkan bahasa tersebut ke urutan pertama dan memuat ulang halaman.
