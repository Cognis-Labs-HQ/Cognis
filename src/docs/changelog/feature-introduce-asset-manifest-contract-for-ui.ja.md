# 本番アセットの改訂

**機能ブランチ:** feature-introduce-asset-manifest-contract-for-ui

## 不変のバージョン付きアセット

UI アセットにデプロイ改訂を付与し、変更可能な文書は再検証しながら、長期間の不変キャッシュを使用します。

## 効率的な検証

未バージョンのアセットは検証子に対応し、内容を読み込まずに最新のクライアントコピーへ 304 を返します。

## デプロイ固有のアセット版

本番コンテナのビルドでは Git コミットのリビジョンをアセット URL に埋め込み、不変のブラウザーおよび CDN キャッシュが古いアプリケーションを保持しないようにしました。

## 安全でオフライン対応の配信

レスポンスヘッダーを送信する前に静的ディレクトリを拒否し、ネットワークが利用できない場合もバージョンなしのアプリケーション依存関係を service worker から利用できるようにしました。
