# 高速なダッシュボード起動

**Feature Branch:** feature-refactor-dashboard-initialization-and-api-flows

## ダッシュボードカードを独立して読み込み

基本レイアウトの描画直後にマウントを完了し、アカウント情報、今後の予定、拡張機能をそれぞれ独立して読み込み続けるため、任意の連携機能がナビゲーションを妨げることはありません。

## 今後の予定を1回の制限付きリクエストで取得

Calendar Gateway のフローが、アクセス可能なカレンダーの予定と招待を、呼び出し側が指定した件数上限を使う認証済みエンドポイントからまとめて返します。

## カレンダーのリクエストをカレンダーゲートウェイ内に集約

ダッシュボードはカレンダーゲートウェイが公開する今後のイベント取得関数を使用し、エンドポイントと応答の詳細を担当コンポーネント内に保持します。

## 認証バージョン表示を統一

認証のランタイム登録がコンポーネントマニフェストと同じバージョンを報告するようになりました。
