# Module Setup Guidance

**Feature Branch:** module-activation-guidance

## Clear Post-Activation Steps

Modules can now declare localized activation guidance with one or more adapter targets. After enablement, Cognis presents the module's next steps and offers to take administrators directly to Administration without core knowing provider-specific names.
