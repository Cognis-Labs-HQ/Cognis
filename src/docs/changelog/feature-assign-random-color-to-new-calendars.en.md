# Varied colors for new calendars

**Feature Branch:** feature-assign-random-color-to-new-calendars

## New calendars start with a random color

New calendars now receive a randomly selected color from the Calendar palette instead of always starting in blue. The creation dialog displays the selected color before saving and still allows it to be changed.
