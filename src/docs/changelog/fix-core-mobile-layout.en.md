# Mobile Core Layout

**Feature Branch:** fix-core-mobile-layout

## Compact Shared Controls

Phone headers use two rows. Toolbar toggles scroll behind the header, floating tutorial controls remain compact, and highlighted targets are easier to see. Short-screen explanations can use header space; font preferences and touch targets remain usable.

## Readable Built-In Pages

Administration separates gateway names from their controls. Error codes fit their content column. Calendar month and week views scroll horizontally with readable day controls, and year views fit a narrow column. External module pages are excluded.
