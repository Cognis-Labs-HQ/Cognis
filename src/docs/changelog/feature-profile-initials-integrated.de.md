# Einheitliche Profilinitialen

**Feature-Zweig:** feature-profile-initials-integrated

## Avatardarstellung Vereinheitlichen

Navigation, Kurzvorschau und Profilkopf teilen nun Profile-eigene Regeln für Initialen, Farbe und ausdrückliche Größen. Beibehaltene Bilder zeigen nach einem Bildfehler Initialen des zuletzt autorisierten Namens. Der Vorschauavatar verlinkt sein Profil, ohne die Vorschau erneut zu öffnen.

## Passende Dateien Aktualisieren

Profile 4.0.0 benötigt den passenden Navigationsvertrag der Shell. Beide müssen gemeinsam bereitgestellt werden. Der Anbieter liefert synchronen Inhalt; die Shell erhält Knopf, Menü und Verfügbarkeit. Bestehende eigene Avataroptionen bleiben verfügbar. Die getesteten Grenzen von Messages und Calendar steigen auf 4.0.0; externe Module und natives Browserlayout bleiben ungeprüft.
