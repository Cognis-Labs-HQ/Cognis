# Hinweise zur Moduleinrichtung

**Feature-Zweig:** module-activation-guidance

## Klare Schritte nach Aktivierung

Module können jetzt lokalisierte Aktivierungshinweise mit einem oder mehreren Adapterzielen deklarieren. Nach der Aktivierung zeigt Cognis die nächsten Schritte des Moduls an und bietet den direkten Wechsel zur Administration an, ohne dass der Core anbieterspezifische Namen kennen muss.
