# Lernsprachenrahmen

Wählen Sie verfügbare Sprachen und nutzen Sie die jeweils bereitgestellten Lerninhalte.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Die beschriebenen Vorgänge können Konto- oder Verwaltungsrechte verlangen. Das Lesen eines Themas aktiviert keine optionalen Funktionen.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/study-language-framework/usage) erklärt Abläufe. [Technik](/docs/study-language-framework/technical) beschreibt Schnittstellen und Konfiguration.
