# Usage

Practical procedures for Study Language Framework.

## Prerequisites

Enroll in an installed language through Study settings.

## Examples

Browse an available collection, inspect its readings or writing units and start a supported practice activity.

## Expected Results

Content and available activities follow the language provider; fixed charts can differ from growing card collections.

## Troubleshooting

Check installed module status and enrollment. A collection's authored order and relationships are not interchangeable with arbitrary translated text.
