# Penggunaan

Prosedur praktis untuk Kerangka Bahasa Studi.

## Prasyarat

Daftar bahasa terpasang melalui pengaturan Study.

## Contoh

Jelajahi koleksi, periksa bacaan atau unit tulis, lalu mulai latihan yang didukung.

## Hasil yang Diharapkan

Konten serta aktivitas mengikuti penyedia bahasa; bagan tetap dapat berbeda dari koleksi kartu berkembang.

## Pemecahan Masalah

Periksa status modul dan pendaftaran. Urutan serta hubungan konten tidak dapat diganti sembarang terjemahan.
