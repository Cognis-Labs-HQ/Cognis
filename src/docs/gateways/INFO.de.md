# Gateway- und Adapter-Leitfaden

Funktionsdienste verbinden aktivierte Cognis-Bereiche mit verfügbaren Dienstanbietern.

## Möglichkeiten

Verstehe, wie Gateways austauschbare Anbieter koordinieren.

## Vor dem Start

Verfügbarkeit folgt installierten Abhängigkeiten.

## Erste Schritte

Suche Gateway und Adapter in Administration.
