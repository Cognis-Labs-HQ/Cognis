# Anwendung

Praktische Abläufe für Gateway- und Adapter-Leitfaden.

## Voraussetzungen

Verfügbarkeit folgt installierten Abhängigkeiten.

## Beispiele

Vergleiche gemeinsame Gateway-Aufgaben mit Adaptereinstellungen und konfiguriere den Anbieter über sein Gateway.

## Erwartete Ergebnisse

Anbieter stellen aktive erklärte Aktionen bereit; Entfernen überträgt keine Berechtigungen auf andere.

## Fehlerbehebung

Ermittle den Eigentümer einer fehlgeschlagenen Aktion vor Änderungen an fremden Komponenten.
