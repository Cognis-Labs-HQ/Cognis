# ゲートウェイとアダプターの開発

機能のゲートウェイは、有効な Cognis の機能を利用できるサービスにつなぎます。

## できること

[機能のページ](/) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

説明する操作にはアカウントや管理者の権限が必要な場合があります。トピックを読むだけで任意の機能が有効になることはありません。

## はじめに

[機能のページ](/) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/usage)、インターフェースと設定は[技術情報](/docs/gateways/technical)を参照してください。
