# Penggunaan

Prosedur praktis untuk Standar Kontributor.

## Prasyarat

Pilih komponen serta versi sesuai instalasi.

## Contoh

Pakai Info untuk memahami fitur, Penggunaan untuk prosedur, dan Teknis untuk antarmuka, konfigurasi, serta keamanan.

## Hasil yang Diharapkan

Ketiga tampilan merujuk paket versi lengkap dengan struktur terjemahan sama.

## Pemecahan Masalah

Bila petunjuk bertentangan, pilih versi instalasi dan laporkan klaim tepatnya; riwayat rilis bukan isi manual.
