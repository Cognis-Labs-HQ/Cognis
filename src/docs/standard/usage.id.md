# Penggunaan

Prosedur praktis untuk Standar Kontributor.

## Prasyarat

Tinjau [persyaratan akses](/docs/standard) sebelum menjalankan prosedur ini.

## Contoh

```sh
npm --prefix <module-checkout> test
cognisctl modules:jitsi-meet:ping
```

## Hasil yang Diharapkan

Contoh ini memakai antarmuka Standar Kontributor yang didokumentasikan. Periksa respons atau keadaan tersimpan yang dijelaskan dalam [Teknis](/docs/standard/technical) sebelum mengulangi operasi tulis.

## Pemecahan Masalah

Jika Standar Kontributor tidak tersedia, periksa status masuk dan minta administrator memeriksa komponen beserta dependensinya.
