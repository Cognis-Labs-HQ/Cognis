# Usage

Practical procedures for Contributor Standard.

## Prerequisites

Review [the access requirements](/docs/standard) before performing these procedures.

## Examples

```sh
npm --prefix <module-checkout> test
cognisctl modules:jitsi-meet:ping
```

## Expected Results

The example uses the documented interface of Contributor Standard. Confirm the response or saved state described in [Technical](/docs/standard/technical) before repeating a write operation.

## Troubleshooting

If Contributor Standard is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
