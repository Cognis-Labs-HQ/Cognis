# Anwendung

Praktische Abläufe für API.

## Voraussetzungen

Geschützte Aktionen benötigen Rolle und Inhaltszugriff.

## Beispiele

Lies Methode, Pfad und Rechte, sende eine berechtigte Anfrage und prüfe die Antwort vor erneuten Schreibversuchen.

## Erwartete Ergebnisse

Der Server prüft Anmeldung und Aktionsrechte; Lesen gewährt keinen Zugriff.

## Fehlerbehebung

Unterscheide Anmeldung, Berechtigung und Eingabefehler. Teile keine Tokens oder privaten Antworten in Diagnosen.
