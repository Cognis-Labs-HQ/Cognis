# API

Server aplikasi menghubungkan peramban Anda dengan akun, konten tersimpan, dan fitur aktif.

## Yang Dapat Anda Lakukan

Pahami operasi server di balik tindakan peramban dan terminal.

## Sebelum Memulai

Operasi terlindungi memerlukan peran dan akses sumber daya.

## Langkah Awal

Cari tampilan Teknis komponen pemilik sebelum memakai operasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/api/usage) menjelaskan prosedur. [Teknis](/docs/api/technical) mendokumentasikan antarmuka dan konfigurasi.
