# Penggunaan

Prosedur praktis untuk Versi Komponen.

## Prasyarat

Versi komponen dapat berbeda dari rilis aplikasi keseluruhan.

## Contoh

Baca daftar versi, buka komponen di Dokumen, dan pilih arsip sesuai bila tersedia.

## Hasil yang Diharapkan

Versi bertahan di Info, Penggunaan, dan Teknis. Hanya paket arsip lengkap ditawarkan.

## Pemecahan Masalah

Arsip hilang bukan bukti ketidakcocokan. Bandingkan versi terpasang dan batas dependensi teruji sebelum meningkatkan.
