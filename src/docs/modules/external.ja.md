# 外部モジュール

## 安定した識別子

各モジュールには読みやすい ID と、変更してはならない UUID があります。`requires` の依存関係はすべて UUID で指定します。

## リポジトリ契約

1 つの Git リポジトリが 1 つのモジュールを提供します。ルートには `manifest.json`、`package.json`、`routes.json` と、必要に応じて `bootstrap.js`、`api/index.js`、`ui/index.js`、`cli/index.js` を置きます。Cognis との接続は `bootstrap.js` が `ctx` を介して行い、内部ファイルは自由に構成できます。マニフェストにはメタデータ、カテゴリー、機能、ライセンス、UUID 依存関係、アバターとスクリーンショットの相対パスを記述します。

`package.json` は `"type": "module"` を使用し、マニフェストと同じバージョンにします。`routes.json` は常に配列です。インストール前に Cognis は入口、ストア画像、安全な相対パス、宣言済み SHA-256 チェックサムを検証し、失敗時には一時チェックアウトを完全に削除します。

## 分離チェックリスト

独立リポジトリへ移す際も UUID と読みやすい ID は変更しません。リポジトリ、ホームページ、サポートのリンクを更新し、マニフェストとパッケージのバージョンを同期し、チェックサムを再生成し、モノリポジトリ相対インポートを `ctx` のケイパビリティとフローへ置き換えます。

## ソースと安全性

ユーザーメニューのモジュール管理画面は GitHub 組織と GitLab グループ内のリポジトリを検出します。任意の読み取り専用 PAT は管理者のキーリングに保存し、ソース設定には識別子だけを保持します。インストール時は HTTPS でクローンし、マニフェストと UUID を検証してから安全に配置します。コードは別途有効化するまで実行されません。有効化前に第三者コードを確認してください。

## ストア画像とタグ

モジュールは広い分類の `categories` に加えて、詳しい `tags` を宣言でき、どちらも絞り込みに使われます。ストア画像はリポジトリの `assets/` に置きます。カタログ用には `assets/icon.svg` または `assets/icon.png`、詳細ページのヒーロー画像には `assets/banner.svg`、`assets/banner.png`、`assets/banner.jpg` を使用し、`manifest.json` の `assets.icon` と `assets.banner` に選んだパスを指定します。任意のギャラリー画像は `assets.screenshots` に列挙します。
