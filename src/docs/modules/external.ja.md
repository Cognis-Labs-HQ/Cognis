# 外部モジュール

## 安定した識別子

各モジュールには読みやすい ID と、変更してはならない UUID があります。`requires` の依存関係はすべて UUID で指定します。

## リポジトリ契約

1 つの Git リポジトリが 1 つのモジュールを提供します。ルートには `manifest.json`、`package.json`、`routes.json` と、必要に応じて `bootstrap.js`、`api/index.js`、`ui/index.js`、`cli/index.js` を置きます。Cognis との接続は `bootstrap.js` が `ctx` を介して行い、内部ファイルは自由に構成できます。マニフェストにはメタデータ、カテゴリー、機能、ライセンス、UUID 依存関係、アバターとスクリーンショットの相対パスを記述します。

## ソースと安全性

モジュール管理画面は GitHub 組織と GitLab グループ内のリポジトリを検出します。任意の読み取り専用 PAT は管理者のキーリングに保存し、ソース設定には識別子だけを保持します。インストール時は HTTPS でクローンし、マニフェストと UUID を検証してから安全に配置します。コードは別途有効化するまで実行されません。有効化前に第三者コードを確認してください。
