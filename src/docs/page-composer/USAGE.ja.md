# 使用例

ページコンポーザー の実践的な操作手順です。

## 前提条件

内容は各画面が提供し、共通の構成機能が配置とサイドバーを管理します。

## 使用例

配置を変更できるページで「レイアウトを編集」を開きます。ウィジェットの任意の位置をつかんでドラッグし、上下の端付近で保持すると画面外の行へスクロールできます。スマートフォンでは表示された角のハンドルでサイズを変更します。「要素」が作業領域を覆う場合は最小化し、最後に展開して「完了」または「元に戻す」を選びます。「追加」では非表示の要素をドラッグせずに配置できます。

電話の幅で一覧を開いて移動し、タブレットとデスクトップの幅でも繰り返します。

## 期待される結果

移動操作を維持し、拡大する作業領域は最小の読み取り領域を残して画面に合わせます。

## 問題の解決

高さが足りない場合はページをスクロールします。切れた操作は画面名と寸法を添えて報告してください。
