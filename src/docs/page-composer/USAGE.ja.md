# 使用例

ページコンポーザー の実践的な操作手順です。

## 前提条件

内容は各画面が提供し、共通の構成機能が配置とサイドバーを管理します。

## 使用例

黄色のプレビューは、ウィジェットを離したときの吸着先を示し、編集画面を開いたまま移動が反映されます。オレンジ色は、操作中の軸で最小値、最大値、グリッド端の制限を超えようとしていることを示します。「完了」は空き領域も含め、表示中の位置とサイズを保持します。

両方のサイズが入れ替え先に収まる場合にウィジェットを交換できます。収まらない場合は無効なプレビューを表示し、配置は変更されません。

サイズ変更カーソルは、拡大、縮小、または両方向の変更が可能かを示します。隣の要素が拡大を妨げても、縮小できるハンドルは残ります。可能な変更がなくなるとハンドルは非表示になります。

配置を変更できるページで「レイアウトを編集」を開きます。ウィジェットの内側をドラッグして移動し、画面の上下の端付近で保持すると画面外の行へスクロールできます。強調表示された辺や角をドラッグすると、左辺や上辺からもサイズを変更できます。反対側の辺の位置は変わりません。「要素」が作業領域を覆う場合は最小化し、最後に展開して「完了」または「元に戻す」を選びます。「追加」では非表示の要素をドラッグせずに配置できます。

「完了」、レイアウトのショートカット、リセット操作では、保存の成否を通知します。保存に失敗すると編集画面は開いたままになり、変更内容を保持して再試行できます。

電話の幅で一覧を開いて移動し、タブレットとデスクトップの幅でも繰り返します。

## 期待される結果

移動操作を維持し、拡大する作業領域は最小の読み取り領域を残して画面に合わせます。

## 問題の解決

高さが足りない場合はページをスクロールします。切れた操作は画面名と寸法を添えて報告してください。
