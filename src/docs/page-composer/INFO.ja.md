# ページコンポーザー

Cognis の画面は表示領域に合わせて内容を配置し、サイズを変えても移動や操作ができるようにします。

## できること

スマートフォン、タブレット、デスクトップで共通の配置を利用できます。

配置を変更できるページでは、ウィジェットを移動し、利用可能な辺や角からサイズを変更できます。保存の成否は通知で確認できます。

## 始める前に

内容は各画面が提供し、共通の構成機能が配置とサイドバーを管理します。

## はじめに

カレンダーやメッセージなどを開きます。

## 詳しい情報

手順は[使用例](/docs/page-composer/usage)、インターフェースと設定は[技術情報](/docs/page-composer/technical)を参照してください。
