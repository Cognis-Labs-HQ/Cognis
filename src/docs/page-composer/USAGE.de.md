# Anwendung

Praktische Abläufe für Page Composer.

## Voraussetzungen

Seiten liefern Inhalte; der gemeinsame Composer steuert Layout und Seitenleisten.

## Beispiele

Der Größenänderungszeiger zeigt, ob eine Kante vergrößert, verkleinert oder in beide Richtungen bewegt werden kann. Blockiert ein anderes Element das Vergrößern, bleibt Verkleinern möglich. Ohne zulässige Größenänderung verschwindet der Regler.

Öffne Layout bearbeiten auf einer anpassbaren Seite. Ziehe ein Widget an einer beliebigen Stelle; halte es zum Scrollen nahe am oberen oder unteren Rand. Auf dem Telefon änderst du die Größe am sichtbaren Eckgriff. Minimiere Elemente, wenn das Fenster im Weg ist, und öffne es wieder für Fertig oder Verwerfen. Hinzufügen platziert ausgeblendete Elemente ohne Ziehen.

Verkleinere auf Telefonbreite, öffne die Seitenleiste und wähle ein Ziel; wiederhole bei Tablet- und Desktopbreite.

## Erwartete Ergebnisse

Navigation bleibt erreichbar; wachsende Bereiche passen zur Ansicht und behalten eine Mindestlesefläche.

## Fehlerbehebung

Kurze Bildschirme benötigen gegebenenfalls Seitenscrollen. Melde abgeschnittene Aktionen mit Seite und Abmessungen.
