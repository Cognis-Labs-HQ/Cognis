# Anwendung

Praktische Abläufe für Page Composer.

## Voraussetzungen

Seiten liefern Inhalte; der gemeinsame Composer steuert Layout und Seitenleisten.

## Beispiele

Eine gelbe Vorschau zeigt das Einrastziel beim Ablegen eines Widgets; die Bewegung wird im geöffneten Editor übernommen. Orange kennzeichnet einen versuchten Mindest-, Höchst- oder Rasterrandwert auf den aktiven Größenachsen. Fertig erhält die angezeigten Positionen und Größen einschließlich freier Flächen.

Tausche Widgets nur, wenn beide Größen an den getauschten Positionen Platz haben. Ein blockierter Tausch zeigt eine ungültige Vorschau und lässt die Anordnung unverändert.

Der Größenänderungszeiger zeigt, ob eine Kante vergrößert, verkleinert oder in beide Richtungen bewegt werden kann. Blockiert ein anderes Element das Vergrößern, bleibt Verkleinern möglich. Ohne zulässige Größenänderung verschwindet der Regler.

Öffne Layout bearbeiten auf einer anpassbaren Seite. Ziehe im Inneren eines Widgets, um es zu verschieben; halte es zum Scrollen nahe am oberen oder unteren Bildschirmrand. Ziehe eine hervorgehobene Kante oder Ecke zum Skalieren, auch links und oben. Die gegenüberliegende Kante bleibt an ihrem Platz. Minimiere Elemente, wenn das Fenster im Weg ist, und öffne es wieder für Fertig oder Verwerfen. Hinzufügen platziert ausgeblendete Elemente ohne Ziehen.

Fertig, das Layout-Kürzel und Zurücksetzen melden Erfolg oder Fehler. Schlägt das Speichern fehl, bleibt der Editor mit deinen ausstehenden Änderungen für einen erneuten Versuch geöffnet.

Verkleinere auf Telefonbreite, öffne die Seitenleiste und wähle ein Ziel; wiederhole bei Tablet- und Desktopbreite.

## Erwartete Ergebnisse

Navigation bleibt erreichbar; wachsende Bereiche passen zur Ansicht und behalten eine Mindestlesefläche.

## Fehlerbehebung

Kurze Bildschirme benötigen gegebenenfalls Seitenscrollen. Melde abgeschnittene Aktionen mit Seite und Abmessungen.
