# Penggunaan

Prosedur praktis untuk Page Composer.

## Prasyarat

Halaman menyediakan konten; composer bersama mengatur tata letak dan bilah samping.

## Contoh

Perkecil ke lebar ponsel, buka bilah samping, pilih tujuan, dan kembali; ulangi pada tablet serta desktop.

## Hasil yang Diharapkan

Navigasi tetap terjangkau; area berkembang menyesuaikan viewport sambil mempertahankan area baca minimum.

## Pemecahan Masalah

Layar pendek mungkin perlu menggulir halaman. Laporkan kontrol terpotong dengan halaman dan ukuran viewport.
