# Page Composer

Cognis-Seiten ordnen Inhalte passend zum Bildschirm und halten Navigation und Bedienelemente bei Größenänderungen nutzbar.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Die beschriebenen Vorgänge können Konto- oder Verwaltungsrechte verlangen. Das Lesen eines Themas aktiviert keine optionalen Funktionen.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/page-composer/usage) erklärt Abläufe. [Technik](/docs/page-composer/technical) beschreibt Schnittstellen und Konfiguration.
