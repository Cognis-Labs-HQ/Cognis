# Komponentenwiederherstellung

Verwalten Sie installierte Funktionen und stellen Sie sie nach fehlgeschlagenen Aktualisierungen oder Abhängigkeiten sicher wieder her.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Die beschriebenen Vorgänge können Konto- oder Verwaltungsrechte verlangen. Das Lesen eines Themas aktiviert keine optionalen Funktionen.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/component-recovery/usage) erklärt Abläufe. [Technik](/docs/component-recovery/technical) beschreibt Schnittstellen und Konfiguration.
