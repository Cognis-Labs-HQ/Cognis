# Pemulihan Komponen

Kelola fitur terpasang dan pulihkan dengan aman saat pembaruan atau dependensi gagal.

## Yang Dapat Anda Lakukan

Periksa komponen gagal dan pulihkan pengaktifan atau peningkatan secara terkendali.

## Sebelum Memulai

Gunakan administrator berwenang dan cadangan sebelum mengubah kode terpasang.

## Langkah Awal

Periksa status dan dependensi komponen gagal.

[Penggunaan](/docs/component-recovery/usage) menjelaskan prosedur. [Teknis](/docs/component-recovery/technical) mendokumentasikan antarmuka dan konfigurasi.
