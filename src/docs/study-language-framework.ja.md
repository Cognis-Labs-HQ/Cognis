# Study言語パッケージ

## 目的

Study言語パッケージは、外部で公開される不変のデータです。マニフェスト、バージョン付きLibraryスキーマ、レコード、任意のアセット、ライセンス、翻訳済み文書を含みます。Cognisコアに言語レコードを置かず、実行可能なレンダラー、ルート、CSS、プロバイダー固有の保存処理も含みません。

## 構成とマニフェスト

パッケージは`manifest.json`、参照先のスキーマファイルとコンテンツディレクトリ、任意のアセットディレクトリを提供します。パスはスラッシュ区切りの相対パスとし、空または絶対の要素、親参照（`..`）、バックスラッシュ、シンボリックリンクによる逸脱を禁止します。コンテンツ片はレイヤー名とファイル名の辞書順で読み取られます。

マニフェストは`id`、`publisher`、`namespace`、セマンティック`version`、`contentRevision`、`schema`、`content`、任意の`assets`、`license`を宣言します。ライセンスには機械可読IDが必須で、HTTPS URLと帰属表示を追加できます。パッケージはマニフェストとスキーマが示す名前空間だけを所有し、全レコードIDは`<namespace>:`で始まります。バイト内容を変更した場合は新しいパッケージ版が必要です。

## 中立なスキーマ契約

スキーマは不変の正整数版、BCP 47言語タグ、名前空間、翻訳済みのラベルと説明、および利用側が自由に命名するレイヤーを持ちます。CognisはレイヤーIDに意味を割り当てません。代わりに`atomicWritingUnit`、`compoundWritingUnit`、`lexicalUnit`、`orderedLexicalSequence`、`passage`、`definition`、`practicePrompt`の意味役割を宣言できます。

フィールドは翻訳済みメタデータと`string`、`number`、`integer`、`boolean`、`localizedText`、`stringList`、`asset`の型を持ちます。必須指定に加え、レンダラー、順序、グループ、表示可否の詳細表示ヒントを設定できます。レイヤーヒントはタイトルフィールドとフィールド順も指定できます。

関係には翻訳済みメタデータ、対象レイヤー、最小・最大カーディナリティ、任意の順序、必須対象制約、必須の削除動作（`restrict`、`detach`、`cascade`）があります。リゾルバー役割（`grapheme`、`token`、`longestMatch`、`explicit`）はアルゴリズムを埋め込まず意図を示します。順序付き参照には重複しない非負整数位置が必要です。

レイヤーは名前空間付きcamel case役割としてアクティビティ互換性と興味系統を公開できます。これは検出タグであり実行フックではありません。SVGまたはJSONの筆順アセットフィールドと座標系も任意で宣言できます。アセット値はマニフェストのアセットディレクトリ内を参照します。アトミック取込時に、Cognisは検証済みバイトを不変のパッケージ識別情報と共に保存し、レコード値を認証付きLibraryアセットURLへ置換します。

## レコードと参照

コンテンツ直下の各ディレクトリ名は、宣言済みレイヤーIDと完全に一致します。JSON片は配列または`{ "records": [...] }`を含みます。レコードは名前空間付きの安定した`id`、表示用`label`、型付き`fields`、参照を持ちます。すべての対象は同じパッケージとスキーマ版に存在し、宣言されたレイヤーを指し、カーディナリティ、順序、必須対象制約を満たす必要があります。言語の事実はすべて外部レコードファイルに残します。

## 決定的なアトミック取込

`inspectContentPack`は書込みを伴わない事前検査として、マニフェスト、セマンティック版、ライセンス、安全なパス、名前空間所有権、スキーマ参照、型付きフィールド、完全な関係グラフ、全アセット参照を検証します。正規化したマニフェスト、スキーマ、レコードデータと参照アセットのバイトを決定的な順序でハッシュ化します。失敗時の書込みはありません。

`ingestContentPack`は検証済みスキーマ、レコード、関係、受領情報を単一データベーストランザクションで保存します。スキーマIDと版は不変です。同一の公開者・パッケージ・版のダイジェストを再導入しても冪等で、同じ識別情報に異なるバイトを使うと拒否されます。画面は意味役割と表示ヒントを利用し、リゾルバーとアクティビティのアダプターは`ctx`フローで参加します。

## 作成者チェックリスト

- すべてのレコードとアセットをCognisコアの外に置く。
- 安定した名前空間とレコードID、セマンティックパッケージ版、不変のスキーマ版を使う。
- スキーマ、レイヤー、フィールド、関係、文書のメタデータを翻訳する。
- ライセンス、帰属表示、関係の削除動作、正確な制約を宣言する。
- 公開前に検査を実行し、コンテンツ片の列挙順序に依存しない。
