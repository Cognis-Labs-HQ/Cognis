# DevOps

Richten Sie Cognis einschließlich Speicherung, Diensten und Bereitstellung ein und warten Sie die Installation.

## Möglichkeiten

Betreibe Cognis mit dauerhafter Datenbank, Medien- und Konfigurationsablage.

## Vor dem Start

Bereite Docker Compose, Datenbankzugang und Verschlüsselungsschlüssel vor.

## Erste Schritte

Prüfe Compose-Datei und erforderliche Umgebungswerte.

## Weitere Informationen

[Anwendung](/docs/devops/usage) erklärt Abläufe. [Technik](/docs/devops/technical) beschreibt Schnittstellen und Konfiguration.
