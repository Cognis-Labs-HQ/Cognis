# Leistungsbudgets

Erkennen Sie langsame Seiten und Anfragen, messen Sie ihr Verhalten und vergleichen Sie Verbesserungen unter gleichen Bedingungen.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Die beschriebenen Vorgänge können Konto- oder Verwaltungsrechte verlangen. Das Lesen eines Themas aktiviert keine optionalen Funktionen.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

[Anwendung](/docs/performance/usage) erklärt Abläufe. [Technik](/docs/performance/technical) beschreibt Schnittstellen und Konfiguration.
