# パフォーマンス予算

遅い画面やリクエストを特定し、同じ条件で測定して改善を比較できます。

## できること

[機能のページ](/) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

説明する操作にはアカウントや管理者の権限が必要な場合があります。トピックを読むだけで任意の機能が有効になることはありません。

## はじめに

[機能のページ](/) を開き、必要な操作を選びます。

手順は[使用例](/docs/performance/usage)、インターフェースと設定は[技術情報](/docs/performance/technical)を参照してください。
