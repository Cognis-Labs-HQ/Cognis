# Cognis – Überblick

Cognis verbindet Sprachenlernen, Gespräche und Kalender. Aktive Komponenten und Sprachpakete der Installation bestimmen verfügbare Werkzeuge und Inhalte.

## Möglichkeiten

Erkenne das Zusammenspiel von Lernen, sozialen Funktionen und Terminplanung.

## Vor dem Start

Ein Administrator wählt Komponenten und Sprachmodule der Installation.

## Erste Schritte

Prüfe Dashboard und verfügbare Hauptnavigation.
