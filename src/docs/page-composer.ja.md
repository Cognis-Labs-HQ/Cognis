# ページコンポーザー

## 概要

`createPageComposer` はすべてのCognisページで使用されるレイアウトオーケストレーションユーティリティです。個々のページモジュールは*何を*レンダリングするかを宣言し（要素と呼ばれる名前付きコンテンツブロックのリスト）、コンポーザーはそれらのブロックをどのように配置、永続化、ナビゲート、再レンダリングするかを処理します。

## 責務

- 名前付き要素のセットを親DOMノードにレンダリングする。
- `allowCustomization: true` の場合、90pxの自由グリッドを管理する。
- 設定APIを通じて要素の配置と表示を永続化・復元する。
- `subPageNavigation: true` の場合、サブページナビゲーションを駆動する。

## アーキテクチャ

### 要素

要素は名前付きコンテンツブロックです:

```js
{
  id: 'my-widget',
  label: 'マイウィジェット',
  render: () => '<h2>コンテンツ</h2>',
  gridSize: { default: [4, 3], min: [2, 2] },
  pinned: false,
}
```

| フィールド | 必須   | 説明                                                  |
| ---------- | ------ | ----------------------------------------------------- |
| `id`       | はい   | 一意の文字列識別子                                    |
| `label`    | はい   | 人間が読めるラベル                                    |
| `render`   | はい   | HTML文字列を返す関数                                  |
| `gridSize` | いいえ | 90pxグリッド単位での `{ default: [w,h], min: [w,h] }` |
| `pinned`   | いいえ | `true` の場合、ユーザーが要素を削除できない           |

### グリッドレイアウト

グリッド単位は90px幅・高さです。`gridSize.max: 'full'` は要素をすべての利用可能な列にまたがらせます。

### サブページナビゲーション

`subPageNavigation: true` の場合、一度に1つの要素のみが表示されます。`[data-composer-scroll]` を持つツールバーボタンがセクションセレクターとして機能します。

### DOM パーキング

DOM パーキングは既定では無効です。メディア DOM を composer の再レンダリング後も維持する必要がある場合に限り、page composer に `enableDomParking: true` を指定してください。有効にすると、iframe などのメディアを含むカードは DOM をそのまま退避して復元します。これは Jitsi Meet のような状態を持つ埋め込み向けです。通常のページでは、新しいレンダリングと一時的なフォーム状態の復元を利用し、古い退避 DOM がユーザーの更新内容を隠さないようにしてください。

### 永続化

レイアウトは引き続き `preferenceKey` を使って設定APIに保存されます。これに加えて、フォーム下書きはユーザー・ページパス・コンポーザーキー単位で `localStorage` に保存されるため、ページ再読み込みやレスポンシブ再レンダリング後も入力内容が復元されます。永続的な下書き保存はオプトイン方式です。最も近い祖先要素に `data-composer-include-form-memory="true"` が指定されているフィールドのみが localStorage に書き込まれます。オプトインされていないフィールドは、同一セッション内のレスポンシブ再レンダリングを乗り越えられるようにメモリ内の一時スナップショットには引き続きキャプチャされますが、永続ストレージには書き込まれません。`password` / `file` / `hidden` フィールド、および識別子に `password` / `secret` / `token` を含む項目は、オプトイン状態に関わらず常に永続的な下書き保存の対象外です。

大きなフォーム（永続化対象フィールドが6個以上）を含むカードには **下書きをリセット** ボタンが表示されます。このボタンはそのカードの保存済み下書きを削除し、現在のフィールドを既定値に戻します。
