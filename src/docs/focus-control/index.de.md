# Fokussteuerung

Öffnen Sie unterstützte Funktionen in eigenen Fenstern und ordnen Sie sie passend zur Aufgabe an.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Die beschriebenen Vorgänge können Konto- oder Verwaltungsrechte verlangen. Das Lesen eines Themas aktiviert keine optionalen Funktionen.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

[Anwendung](/docs/focus-control/usage) erklärt Abläufe. [Technik](/docs/focus-control/technical) beschreibt Schnittstellen und Konfiguration.
