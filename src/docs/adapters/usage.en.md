# Usage

Practical procedures for Adapters.

## Prerequisites

Configuration requires administrator access and the provider's connection details.

## Examples

Inspect an adapter's settings, configure the service and use its test action where available before enabling normal use.

## Expected Results

The gateway uses registered active providers; provider-specific settings remain owned by the adapter.

## Troubleshooting

Check dependency status and test diagnostics. Installing an adapter does not guarantee its external service is reachable.
