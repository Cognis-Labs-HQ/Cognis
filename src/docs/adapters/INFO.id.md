# Adapter

Pilih penyedia layanan instalasi untuk masuk, penyimpanan, notifikasi, dan fitur belajar.

## Yang Dapat Anda Lakukan

Pilih penyedia autentikasi, penyimpanan, notifikasi, dan belajar.

## Sebelum Memulai

Konfigurasi memerlukan administrator dan detail koneksi penyedia.

## Langkah Awal

Buka gateway terkait di Administrasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/usage) menjelaskan prosedur. [Teknis](/docs/adapters/technical) mendokumentasikan antarmuka dan konfigurasi.
