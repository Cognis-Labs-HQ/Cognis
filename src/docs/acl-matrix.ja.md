# ACLマトリクス

## 概要

ACLマトリクスは、Cognisの各ロールが実行できるアクションを定義します。ロールはアカウント作成時または管理者が後から割り当てます。自己登録は常に `user` ロールを生成します。

Cognisには4つのロールがあります。`user` は通常の学習者活動のデフォルトです。`teacher` は教師固有のAPIアクセスを付与します。`moderator` はコミュニティモデレーション権限（任意の投稿の削除）を追加します。`admin` は完全なプラットフォームアクセスを持ちます。

## ロールマトリクス

| 機能                                | user | teacher | moderator | admin |
| ----------------------------------- | ---: | ------: | --------: | ----: |
| 自己登録                            |   ✅ |      ✅ |        ✅ |    ✅ |
| 自分のプロフィールの表示/編集       |   ✅ |      ✅ |        ✅ |    ✅ |
| 投稿の作成                          |   ✅ |      ✅ |        ✅ |    ✅ |
| ユーザーのフォロー/アンフォロー     |   ✅ |      ✅ |        ✅ |    ✅ |
| ファイルのアップロード/ダウンロード |   ✅ |      ✅ |        ✅ |    ✅ |
| 教師固有のAPIへのアクセス           |   ❌ |      ✅ |        ❌ |    ✅ |
| 任意のユーザーの投稿を削除          |   ❌ |      ❌ |        ✅ |    ✅ |
| 任意のファイルを削除                |   ❌ |      ❌ |        ❌ |    ✅ |
| ファイルサイズ制限を設定            |   ❌ |      ❌ |        ❌ |    ✅ |
| モジュールのインストール/管理       |   ❌ |      ❌ |        ❌ |    ✅ |
| 認証プロバイダー設定の管理          |   ❌ |      ❌ |        ❌ |    ✅ |
| システム診断エンドポイント          |   ❌ |      ❌ |        ❌ |    ✅ |

## ロールの注意点

- **user** — 自己登録で付与されるデフォルトロール。
- **teacher** — 教師機能のための昇格APIアクセス; 管理者が割り当て。
- **moderator** — コミュニティモデレーション権限; システムや管理設定へのアクセスなし。
- **admin** — 完全なプラットフォームアクセス; `cognisctl user:create` で帯域外に作成。
