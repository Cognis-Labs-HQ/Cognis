# プロフィール

## 概要

プロフィール機能は、各アカウントに公開されたアイデンティティ、ソーシャルグラフ、マイクロブログスタイルの投稿ストリーム、ファイルアップロード機能を提供します。プロフィールゲートウェイとして実装されています。

公開設定は最重要事項です。各アカウントはプロフィール、ソーシャルカウント、投稿を誰が見られるかを制御する公開設定レベルを選択します。ブロックされたアカウントはブロッカーを対象とするすべてのエンドポイントで404レスポンスを受け取ります。

## 責務

- `account_profiles`、`account_follows`、`account_blocks`、`posts`、`file_size_limits` データベーステーブルを所有する。
- すべてのプロフィールとコンテンツエンドポイントでアカウントレベルと投稿レベルの公開設定を強制する。
- ファイルゲートウェイを通じてアバターとバナーのアップロードを管理する。
- ソーシャルグラフを維持する。

## アーキテクチャ

### 公開設定モデル

| 段階                   | プロフィール閲覧可能な対象 | 投稿・カウントの閲覧可能な対象  |
| ---------------------- | -------------------------- | ------------------------------- |
| `hidden`（デフォルト） | 自分と管理者のみ           | — （投稿はブロック; 403を返す） |
| `private`              | 既存のフォロワーのみ       | フォロワーのみ                  |
| `friends`              | 認証済みユーザー全員       | フォロワーのみ                  |
| `community`            | 認証済みユーザー全員       | 認証済みユーザー全員            |

### フロントエンドページ構造

| 要素           | デフォルト表示 | グリッドサイズ |
| -------------- | -------------- | -------------- |
| `hero`         | はい           | full           |
| `followers`    | はい           | `[2, 3]`       |
| `following`    | はい           | `[2, 3]`       |
| `posts`        | はい           | full           |
| `social-links` | いいえ         | `[2, 3]`       |
