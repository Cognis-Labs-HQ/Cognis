# Utilitas Frasa Sandi

Runtime API menyediakan `reuse:generatePassphrase` melalui `ctx` agar modul seperti Jitsi Meet dapat menghasilkan rahasia yang mudah dibaca tanpa mengimpor internal API.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/) sesuai izin akun Anda.

## Sebelum Memulai

Operasi yang dibahas dapat memerlukan izin akun atau administrator. Membaca topik tidak mengaktifkan fitur opsionalnya.

## Langkah Awal

Buka [fitur ini](/) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/passphrase-utility/usage) menjelaskan prosedur. [Teknis](/docs/passphrase-utility/technical) mendokumentasikan antarmuka dan konfigurasi.
