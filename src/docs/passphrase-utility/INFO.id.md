# Utilitas Frasa Sandi

Fitur pendukung dapat membuat frasa sandi acak terbaca tanpa meminta Anda menciptakan kata sandi sendiri.

## Yang Dapat Anda Lakukan

Buat frasa sandi acak terbaca untuk fitur yang memerlukan rahasia.

## Sebelum Memulai

Fitur harus menyediakan tindakan pembuatan; utilitas tidak memiliki halaman pengguna sendiri.

## Langkah Awal

Gunakan kontrol pembuatan kata sandi pada fitur pendukung.
