# Penggunaan

Prosedur praktis untuk Matriks ACL.

## Prasyarat

Peran saja belum cukup; kepemilikan, keanggotaan, dan visibilitas juga berlaku.

## Contoh

Bandingkan aturan akses, uji dengan pengguna tujuan, dan pastikan akun tak berizin ditolak.

## Hasil yang Diharapkan

Otorisasi mengikuti hubungan sumber daya saat ini, bukan sekadar tautan navigasi.

## Pemecahan Masalah

Periksa pemblokiran, keanggotaan kelas, dan cakupan berbagi. Akses administrator harus dibuktikan per operasi.
