# Anwendung

Praktische Abläufe für ACL-Matrix.

## Voraussetzungen

Rollen reichen oft nicht; Eigentum, Mitgliedschaft und Sichtbarkeit zählen mit.

## Beispiele

Vergleiche die Zugriffsregel, teste mit dem vorgesehenen Benutzer und prüfe die Ablehnung eines unberechtigten Kontos.

## Erwartete Ergebnisse

Berechtigung folgt der aktuellen Beziehung zum Inhalt statt bloßer Navigation.

## Fehlerbehebung

Prüfe Blockierungen, Klassenmitgliedschaft und Freigabebereich. Administratorzugriff muss pro Operation belegt sein.
