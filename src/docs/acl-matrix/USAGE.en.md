# Usage

Practical procedures for ACL Matrix.

## Prerequisites

Roles alone may be insufficient: ownership, membership and visibility also matter.

## Examples

Compare the operation's access rule, test with the intended user and verify that a different unauthorized account is refused.

## Expected Results

Authorization follows the current resource relationship, not merely a visible navigation link.

## Troubleshooting

Check blocks, classroom membership and share scope. Administrator access must be established by the operation, not assumed universally.
