# Anwendung

Praktische Abläufe für UI.

## Voraussetzungen

Melde dich zum Speichern von Kontoeinstellungen an.

## Beispiele

Ändere und speichere eine Einstellung, besuche eine andere Seite und öffne nach Größenänderung die Seitenleiste per Doppelpfeil.

## Erwartete Ergebnisse

Gemeinsame Seiten nutzen die Auswahl und passen Navigation an die Breite an.

## Fehlerbehebung

Prüfe die Speicherbestätigung vor Neuladen; geladene Schriften können Umbrüche ändern, ohne die gewählte Größe zu ändern.
