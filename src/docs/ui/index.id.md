# UI

Gunakan antarmuka Cognis untuk berpindah fitur serta memilih tampilan dan bahasa yang sesuai.

## Yang Dapat Anda Lakukan

Jelajahi Cognis dan pilih tema, bahasa, serta font.

## Sebelum Memulai

Masuk untuk menyimpan preferensi akun.

## Langkah Awal

Buka tampilan dan bahasa di Pengaturan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/ui/usage) menjelaskan prosedur. [Teknis](/docs/ui/technical) mendokumentasikan antarmuka dan konfigurasi.
