# プラットフォーム機能

## 概要

Cognisは、構造化された学習コンテンツ、ソーシャル機能、プラグイン可能な認証、柔軟な永続化、リアルタイムコラボレーション対応レイヤーを組み合わせたセルフホスト型言語学習プラットフォームです。

## コア機能

- **認証とアイデンティティ** — プラグイン可能な認証アダプターがローカル認証情報、LDAPディレクトリサービス、SAML 2.0、OAuth2/OIDCプロバイダーをサポート。
- **モジュラー言語コンテンツ配信** — モジュールシステムでカリキュラムユニットをモジュールとしてパッケージ化し、実行時にインストール可能。
- **設定可能なUIページ** — すべてのページが `createPageComposer` でユーザーごとのレイアウトスロットと設定永続化を提供。
- **軽量ソーシャルネットワーク** — 公開プロフィール、マイクロブログスタイルの投稿、フォロワー/フォローグラフ、ブロック管理。
- **APIファーストアーキテクチャ** — 安定した `{ data }` / `{ error }` レスポンスエンベロープを持つバージョン管理されたHTTP APIで全機能にアクセス可能。

## 学習モード

- **独立した学習者** は自分のペースでモジュラー言語コンテンツを学習。
- **教師とチューター** は `teacher` ロールでセッションを指導。
- **コミュニティ** はソーシャル機能で共同学習リズムを組織。
