# UI

## 概要

`src/ui/` はCognisのブラウザフロントエンドをホストします。学習ワークフロー、ソーシャルインタラクション面、管理パネル、組み込みドキュメントブラウザを提供します。UIはサーバーレンダリングのマルチページアプリケーションです。

UIレイヤーは、どのゲートウェイやアダプターがインストールされているかを知りません。代わりに、ゲートウェイは `UIRegistry` とページエクステンションAPIを通じてランタイムでUI要素を提供します。

すべてのユーザー向けテキストは `src/ui/reuse/i18n.js` のi18nシステムを通じて処理されます。JavaScriptやHTMLテンプレートにテキストは直接ハードコードされていません。

## 責務

- すべてのページエントリポイントと関連するHTMLテンプレートをホストする。
- すべての非ログインページがレンダリングするレイアウトシェルを提供する。
- i18n、ページコンポーザー、未保存変更ガードのreaseユーティリティを維持する。
- テーマの一貫性を保つ: すべての要素がCSS変数から色を解決する。
- 4つの必須言語（en、de、ja、id）のi18n文字列パックを提供する。

## アーキテクチャ

### ディレクトリ構造

| パス | 目的 |
| ---- | ---- |
| `src/ui/layouts/` | 共有HTMLシェル |
| `src/ui/app/` | ページエントリポイントJavaScriptモジュール |
| `src/ui/reuse/` | ページ横断ユーティリティモジュール |
| `src/ui/styles/` | CSS: ベーストークン、レイアウト、ページ固有ルール |
| `src/ui/languages/` | i18n文字列パック（en、de、ja、id） |

### i18nキー規約

| プレフィックス | 用途 |
| ------------ | ---- |
| `ui.reuse.*` | 複数ページで共有されるラベル |
| `ui.reuse.generic.*` | コンテキストのない独立したアクションワード（保存、破棄、リセット） |
| `ui.app.<page>.*` | ページ固有のテキスト |
| `ui.layout.*` | レイアウトシェルテキストとARIAラベル |
