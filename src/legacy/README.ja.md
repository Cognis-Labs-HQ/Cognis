# レガシー移行

このディレクトリは、廃止された永続形式を現行の Cognis 契約へ変換する、コンポーネント横断アップグレード処理の唯一の配置先です。実行時の互換処理は、ここにもアプリケーションの他の場所にも置きません。

各移行は一方向かつ冪等で、起動時の移行ランナーからだけ呼び出される必要があります。また、その移行を必要とする最後の移行元バージョンと削除条件を文書化します。リクエストハンドラー、ゲートウェイ、アダプター、モジュール、ブラウザーコードは現行形式だけを使用し、このディレクトリをインポートしてはなりません。

コンポーネント所有のデータベース移行は、各コンポーネントの `sql/migrate/` に残します。スキーマの所有権をこのディレクトリへ移さないでください。
