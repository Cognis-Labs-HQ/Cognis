# 範囲を限定したルート認証

アカウント認証ではセッション用認証情報のみを受け入れます。混合リソースルートは `share:getGuestClaims(request)` を明示的に取得し、リソースと操作の権限を検証します。ゲスト認証が無効または利用できない場合、通常のアカウント認証だけを試み、ゲストのクレームでアカウント権限を付与しません。ハンドラー内で完全な認証を行うモジュールルートは外側のアカウントロールメタデータを省略し、管理ルートは維持します。描画に必要なプロバイダーとアプリルートの取得だけが、有効なゲスト認証と既存のロール表示条件を利用します。キャッシュしない識別エンドポイントは、検証済みの主体、ロール、プロバイダー、目的、設定状態だけを返します。

## 使用方法

`await ctx.getCapability("share:getGuestClaims")(request)`

## 契約

`Promise<{ sub: string; role: "user"; providerId: string; purpose: "share"; setupPending: false } | null>`
