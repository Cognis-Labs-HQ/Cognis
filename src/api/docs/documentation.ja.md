# ドキュメントのグループ

ドキュメントを開き、表示名でモジュールのグループを展開してページを選びます。同じ表示名のモジュールも別のグループとして扱われます。検索結果の説明と検索対象のテキストには同じ翻訳済みの名前を使います。

## 使用例

GET /api/v1/docs は既存の group、slug、title、path、versions に加えて、任意の groupPresentation メタデータを返します。グループの識別子は不変のモジュール UUID のままです。表示名によって識別子やルートは変わりません。

## 技術仕様

ドキュメントは対応するソースディレクトリの公開マニフェストを読みます。マニフェストの UUID がグループと一致し、正規化されたパスが所有元の範囲内にある必要があります。返されるのは id、name、ui.stringsBaseUrl、検証済みバージョンと並べ替えた公開言語ファイルの SHA-256 情報から生成する ui.stringsRevision だけです。設定、認証情報、実行状態、管理用カタログの情報は含みません。追加認証や管理用エンドポイントは不要です。

/static/reuse/presentation.js の共通エクスポート localizeModulePresentation をモジュール画面とドキュメントで使います。既存の名前キーとカタログ URL を使用し、キーを推測しません。優先言語の値が空または存在しない場合は英語を使います。英語の値も空または存在しない場合、キーや代替ラベルを表示せず missing_translation で描画に失敗します。

アーカイブだけに残る文書にも、所有元のマニフェストがある間は現在の表示メタデータを使います。メタデータがなければ従来の識別子を表示し、文書、バージョン、グループは引き続き利用できます。モジュールを削除しても古い翻訳名を作ったり保持したりしません。

ドキュメントのガイドは引き続きナビゲーション、現在の文書、バージョンリンクを強調します。ナビゲーションの手順では表示名によるグループを説明します。展開状態は安定したグループ ID で保持されます。翻訳の読み込み中にページ表示を中止した場合、メニューは公開されません。

言語カタログの URL は /static/modules/{id}/ 配下の正規パスで、空でない公開パス要素だけを使用します。ディレクトリ移動、クエリ、フラグメント、外部オリジンは許可しません。文字列以外の URL や不正な記述子は翻訳前に拒否します。URL を宣言していないインストール済みマニフェストは既存の /static/modules/{id}/languages を使用し、ホストはモジュール初期化前でも UUID が所有する UI ディレクトリに解決します。

任意のマニフェスト JSON、データ形状、言語記述子が使用できない場合は省略し、グループ識別子と安全な理由を構造化ログに記録します。他の有効な文書は元の識別子で利用できます。予期しないファイルシステムのエラーは引き続き伝播します。このメタデータ処理は宣言済み翻訳キーの欠落を抑制しません。

バージョン情報は明示的なカタログにも標準のカタログにも適用され、モジュール更新後の次回表示時に翻訳名が更新されます。ページと全体検索は保存済みの言語優先順位と異なる場合でも現在の表示言語を使います。バックグラウンド検索は設定を書き換えません。

同じソフトウェアバージョンでも公開言語ファイルのハッシュが変わればコンテンツのリビジョンも変わります。インストール状態を公開せず、別のタブなどで行った更新後に名前を更新できます。宣言されていない言語ファイルの変更には通常のモジュールライフサイクルによるキャッシュ無効化が必要です。

公開されたプレリリースのバージョン識別子は、アーカイブのみの文書を含め、表示リビジョンとして有効です。空白や非ラテン文字を名前に含む無関係な公開アセットは、言語の検証やダイジェストに影響しません。
