# 使用例

アプリケーションサーバー の実践的な操作手順です。

## 前提条件

運用者がサーバーを配置します。公開資料の閲覧に管理者権限は不要です。

## 使用例

情報・使い方・技術とバージョンを選び、表示を切り替えても版が維持されることを確認します。

`docs:versionStore` 機能で作成したストアから `store.diff(fromVersion, toVersion)` を呼び出します。ランタイムモジュールは独自の認証済みルートから構造化された結果を返し、ブラウザ ctx から `ui:documentDiff` を取得して、その結果を `renderDocumentDiff(diff)` に渡せます。

認証済みのシステムセキュリティまたはTFA強制設定エンドポイントで必須の登録を変更します。ポリシーの適用に失敗した場合、保存成功ではなくエラーを返します。

GET /api/v1/docs は既存の group、slug、title、path、versions に加えて、任意の groupPresentation メタデータを返します。グループの識別子は不変のモジュール UUID のままです。表示名によって識別子やルートは変わりません。

## 期待される結果

公開版には全種類の翻訳済み資料が含まれ、別の版から不足を補いません。

## 問題の解決

項目、版、サーバー接続を確認してください。アーカイブの保存先には書き込み権限が必要です。
