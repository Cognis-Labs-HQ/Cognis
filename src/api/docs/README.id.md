# Server Aplikasi

Server aplikasi menghubungkan peramban Anda dengan akun, konten tersimpan, dan fitur aktif.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Server Aplikasi aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/components/api/usage) menjelaskan prosedur. [Teknis](/docs/components/api/technical) mendokumentasikan antarmuka dan konfigurasi.
