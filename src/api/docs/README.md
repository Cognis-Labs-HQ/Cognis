# Application Server

The application server connects your browser to accounts, saved content and enabled features.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that Application Server is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/components/api/usage) explains procedures. [Technical](/docs/components/api/technical) documents interfaces and configuration.
