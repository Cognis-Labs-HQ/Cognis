# トークンのライフサイクル保護

## 使用例

認証済みのシステムセキュリティまたはTFA強制設定エンドポイントで必須の登録を変更します。ポリシーの適用に失敗した場合、保存成功ではなくエラーを返します。

## 技術仕様

すべてのTFA強制設定の変更は担当コンポーネントのポリシーフローを使用します。強制設定の無効化では、操作した管理者の古い認証情報を含む、設定待ちのすべての認証情報を失効させます。通常のセッションは維持します。失効処理はポリシーの保存前に行い、再試行できます。必要なプロバイダーがない場合や保存に失敗した場合はエラーになります。トークンファイルとデータベースは単一トランザクションではありません。ポリシーの保存に失敗すると、厳格なポリシーを維持したまま設定待ちの認証情報が失効している場合があります。ローカルのアトミックなファイル置換は、ハードウェア障害への耐性や複数サーバープロセス間の同期を保証しません。

無関係な設定の保存ではTFAポリシーを適用しません。TFA読み取りケイパビリティがある場合、システムの読み取りとTFA項目を省略した保存では、その現在のポリシーを使用します。読み取り失敗時は強制設定が無効と表示せず、エラーを返します。この任意のケイパビリティがない場合、保存された設定は古い可能性のあるコピーにすぎません。明示的なポリシー変更には引き続き担当コンポーネントのケイパビリティが必要です。
