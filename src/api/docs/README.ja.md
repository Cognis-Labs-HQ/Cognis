# アプリケーションサーバー

アプリケーションサーバーはブラウザーをアカウント、保存した内容、有効な機能につなぎます。

## できること

[機能のページ](/administration) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

アプリケーションサーバー が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/administration) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/components/api/usage)、インターフェースと設定は[技術情報](/docs/components/api/technical)を参照してください。
