# アプリケーションサーバー

アプリケーションサーバーはブラウザーをアカウント、保存した内容、有効な機能につなぎます。

## できること

コンポーネントの資料を読み、サーバーに接続する機能を使えます。

ドキュメントを開き、表示名でモジュールのグループを展開してページを選びます。同じ表示名のモジュールも別のグループとして扱われます。検索結果の説明と検索対象のテキストには同じ翻訳済みの名前を使います。

## 始める前に

運用者がサーバーを配置します。公開資料の閲覧に管理者権限は不要です。

## はじめに

ドキュメントでコンポーネントやコアの項目を選びます。
