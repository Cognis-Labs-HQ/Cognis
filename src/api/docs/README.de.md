# Anwendungsserver

Der Anwendungsserver verbindet Ihren Browser mit Konten, gespeicherten Inhalten und aktivierten Funktionen.

## Möglichkeiten

Lies Komponentendokumente und nutze servergestützte Funktionen.

## Vor dem Start

Betreiber stellen den Server bereit; veröffentlichte Dokumente benötigen keine Administratorrechte.

## Erste Schritte

Öffne Dokumente und wähle Komponente oder Kernthema.

[Anwendung](/docs/components/api/usage) erklärt Abläufe. [Technik](/docs/components/api/technical) beschreibt Schnittstellen und Konfiguration.
