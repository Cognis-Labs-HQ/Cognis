# Anwendungsserver

Der Anwendungsserver verbindet Ihren Browser mit Konten, gespeicherten Inhalten und aktivierten Funktionen.

## Möglichkeiten

Lies Komponentendokumente und nutze servergestützte Funktionen.

Öffne die Dokumentation, klappe eine Modulgruppe anhand ihres Anzeigenamens auf und wähle eine Seite. Module mit gleichem Anzeigenamen bleiben getrennte Gruppen. Suchbeschreibungen und Suchtext verwenden dieselben übersetzten Namen.

Das Löschen eines Kontos und der Abschluss der abhängigen Bereinigung sind getrennte Ergebnisse. Eine fehlgeschlagene Antwort beweist allein nicht, dass das Konto noch vorhanden ist.

## Vor dem Start

Betreiber stellen den Server bereit; veröffentlichte Dokumente benötigen keine Administratorrechte.

## Erste Schritte

Öffne Dokumente und wähle Komponente oder Kernthema.
