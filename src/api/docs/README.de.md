# Anwendungsserver

Der Anwendungsserver verbindet Ihren Browser mit Konten, gespeicherten Inhalten und aktivierten Funktionen.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Anwendungsserver aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/components/api/usage) erklärt Abläufe. [Technik](/docs/components/api/technical) beschreibt Schnittstellen und Konfiguration.
