# ローカルファイル保存

アップロードしたファイルを Cognis サーバーの保存領域に保管します。

## できること

アップロードしたメディアを Cognis サーバーのローカル保存領域に置きます。

## 始める前に

コンテナー交換後も残る、書き込み可能なメディア領域が必要です。

## はじめに

アップロード前にメディアの保存先を設定します。

## 詳しい情報

手順は[使用例](/docs/adapters/file/local/usage)、インターフェースと設定は[技術情報](/docs/adapters/file/local/technical)を参照してください。
