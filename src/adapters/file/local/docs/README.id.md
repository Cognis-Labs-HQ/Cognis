# Penyimpanan Berkas Lokal

Simpan berkas unggahan pada penyimpanan server Cognis.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/settings) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Penyimpanan Berkas Lokal aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/settings) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/file/local/usage) menjelaskan prosedur. [Teknis](/docs/adapters/file/local/technical) mendokumentasikan antarmuka dan konfigurasi.
