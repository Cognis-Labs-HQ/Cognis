# Local File Storage

Save uploaded files on the storage provided by the Cognis server.

## What You Can Do

Available actions are shown on [the feature page](/settings) according to your account permissions.

## Before You Start

Check that Local File Storage is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/settings) and choose the action you need.

## Learn More

[Usage](/docs/adapters/file/local/usage) explains procedures. [Technical](/docs/adapters/file/local/technical) documents interfaces and configuration.
