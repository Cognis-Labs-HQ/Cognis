# Lokaler Dateispeicher

Speichern Sie hochgeladene Dateien auf dem Speicher des Cognis-Servers.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/settings) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Lokaler Dateispeicher aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/settings) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/file/local/usage) erklärt Abläufe. [Technik](/docs/adapters/file/local/technical) beschreibt Schnittstellen und Konfiguration.
