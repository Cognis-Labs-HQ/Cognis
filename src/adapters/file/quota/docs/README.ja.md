# 保存容量の制限

アップロードが上限を超えないように、アカウントの保存容量を確認して制限します。

## できること

[機能のページ](/settings) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

保存容量の制限 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/file/quota/usage)、インターフェースと設定は[技術情報](/docs/adapters/file/quota/technical)を参照してください。
