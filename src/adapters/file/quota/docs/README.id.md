# Batas Penyimpanan

Lihat dan terapkan batas penyimpanan akun agar unggahan tidak melebihi jatah.

## Yang Dapat Anda Lakukan

Atur jatah penyimpanan global dan per fitur untuk akun.

## Sebelum Memulai

Hanya administrator mengelola nilai baku kuota dan penggantian per akun.

## Langkah Awal

Buka kontrol kuota penyimpanan di Administrasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/file/quota/usage) menjelaskan prosedur. [Teknis](/docs/adapters/file/quota/technical) mendokumentasikan antarmuka dan konfigurasi.
