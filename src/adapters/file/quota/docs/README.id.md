# Batas Penyimpanan

Lihat dan terapkan batas penyimpanan akun agar unggahan tidak melebihi jatah.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/settings) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Batas Penyimpanan aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/settings) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/file/quota/usage) menjelaskan prosedur. [Teknis](/docs/adapters/file/quota/technical) mendokumentasikan antarmuka dan konfigurasi.
