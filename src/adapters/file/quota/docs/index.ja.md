# ファイルクォータアダプター

## 概要

ファイルクォータアダプターは、すべての書き込みの前にファイルゲートウェイが内部的に参照するデータベースベースのポリシーストアです。2つのことを管理します: 管理者が調整可能なデフォルトクォータ（名前空間ごと、およびすべての名前空間にわたる単一のグローバルデフォルト）と、アカウント作成時にそれらのデフォルトから取得されるユーザーごとのクォータスナップショットです。ユーザーが実際にどれだけのストレージを使用したかは追跡**しません** — 使用状況の会計は、オブジェクトごとのサイズデータと自然に同じ場所にあるため、ファイルゲートウェイ自身のファイルオブジェクトメタデータテーブルで行われます。

## 責務

- 登録された名前空間ごとにデフォルトクォータを保存し、管理者が名前空間デフォルト一覧を初めて表示したときに遅延生成する（`ensureNamespaceDefault`）。
- すべての名前空間にわたる単一のグローバルデフォルトクォータを保存する。
- アカウント作成時（`provisionUser`）に現在のデフォルトをユーザーごとのオーバーライド行にスナップショットし、ユーザーのクォータが後の管理者による変更に伴って変動するのではなく、登録時に適用されていたものを反映するようにする。
- 管理者がプロビジョニング後にユーザーの名前空間ごとまたはグローバルクォータを編集できるようにする。

責任範囲外: 使用状況の会計（ファイルゲートウェイの `DbFileObjectStore` が行う）またはクォータの実施（ファイルゲートウェイの `NamespaceFileService` が、すべての書き込みの前に使用状況をこれらの値と比較する）。

## アーキテクチャ

`src/adapters/file/quota/index.ts` の `DbFileQuotaStore` は、4つのテーブルに対して `FileQuotaStore` 契約（`src/gateways/files/reuse/quota-store-contract.ts`）を実装します:

| テーブル                        | 目的                                                 |
| ------------------------------- | ---------------------------------------------------- |
| `file_namespace_quota_defaults` | 管理者が調整可能な名前空間IDごとのデフォルトクォータ |
| `file_global_quota_default`     | 単一行のグローバルデフォルト（ID `"global"`）        |
| `file_user_namespace_quotas`    | ユーザーごと・名前空間ごとのクォータオーバーライド   |
| `file_user_global_quotas`       | ユーザーごとのグローバルクォータオーバーライド       |

デフォルトが一度も設定されていない場合、組み込みのフォールバック定数が適用されます: 名前空間ごとに `1 GiB`、グローバルに `5 GiB`。これは個人ドキュメントや小さなメディア添付(プロフィールのアバター/バナー)を想定した控えめな初期値であり、教室教材のような大きなコンテンツを扱う名前空間が構築された際は、下記の管理ルートから引き上げるべきです。

### 遅延スキーマ初期化

ファイルゲートウェイ自体と同様に、このアダプターはデータベースゲートウェイの準備が保証される前にブートストラップします（`GatewayService.bootstrap()` の固定順序を参照）。そのため、スキーマ作成（`ensureSchema()`）は、即座に実行されるのではなく、最初の実際の呼び出しまで延期されメモ化されます。

### プロビジョニングは冪等

`provisionUser(username)` は、登録された名前空間ごとに1行、さらにグローバル行を1行挿入し、`conflict: { action: "ignore" }` を使用するため、繰り返し呼び出しても（最初の登録時だけでなく、ログインのたびになど）既存のオーバーライドを上書きすることはありません。

## 設定

このアダプターには環境変数による設定はありません。デフォルトクォータは、環境変数ではなくファイルゲートウェイの管理ルート（`/api/v1/files/admin/namespace-defaults`、`/api/v1/files/admin/global-default`）を通じて設定されるため、再起動なしで実行時に変更できます。
