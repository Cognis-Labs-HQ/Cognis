# Speichergrenzen

Prüfen und begrenzen Sie den Kontospeicher, damit Uploads das erlaubte Volumen nicht überschreiten.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/settings) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Speichergrenzen aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/settings) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/file/quota/usage) erklärt Abläufe. [Technik](/docs/adapters/file/quota/technical) beschreibt Schnittstellen und Konfiguration.
