# 使用例

通話 の実践的な操作手順です。

## 前提条件

通話とメッセージが有効で、音声や映像にはブラウザーの権限が必要です。

## 使用例

参加者に発信し、別のアカウントで応答してマイクを許可し、最後に終了します。

Call アダプターは、Messages と `voip:startCall` ブラウザプロバイダーが利用可能な場合に自動的に有効になります。

## 期待される結果

シグナリングが通話を調整し、実際のメディアは認証済みの提供機能とブラウザーに依存します。

## 問題の解決

ルーム参加資格、メディア権限、提供機能を確認してください。シグナリングだけではメディア通信を提供しません。
