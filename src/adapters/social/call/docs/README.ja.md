# 通話

会話の参加者を通話に招待し、届いた招待に応答できます。

## できること

[機能のページ](/messages) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

通話 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/messages) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/social/call/usage)、インターフェースと設定は[技術情報](/docs/adapters/social/call/technical)を参照してください。
