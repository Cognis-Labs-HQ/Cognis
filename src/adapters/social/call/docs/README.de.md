# Anrufe

Laden Sie Gesprächsteilnehmer zu einem Anruf ein und nehmen Sie eingehende Einladungen an.

## Möglichkeiten

Starte oder beantworte einen Anruf aus einem geeigneten Gespräch.

## Vor dem Start

Anrufe und Nachrichten müssen aktiv sein; Audio und Video benötigen Browserberechtigungen.

## Erste Schritte

Öffne ein Gespräch und nutze dessen Anrufsteuerung.

## Weitere Informationen

[Anwendung](/docs/adapters/social/call/usage) erklärt Abläufe. [Technik](/docs/adapters/social/call/technical) beschreibt Schnittstellen und Konfiguration.
