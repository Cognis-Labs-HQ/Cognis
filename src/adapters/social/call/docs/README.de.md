# Anrufe

Laden Sie Gesprächsteilnehmer zu einem Anruf ein und nehmen Sie eingehende Einladungen an.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/messages) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Anrufe aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/messages) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/social/call/usage) erklärt Abläufe. [Technik](/docs/adapters/social/call/technical) beschreibt Schnittstellen und Konfiguration.
