# Calls

Invite conversation participants to a call and answer incoming invitations.

## What You Can Do

Available actions are shown on [the feature page](/messages) according to your account permissions.

## Before You Start

Check that Calls is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/messages) and choose the action you need.

[Usage](/docs/adapters/social/call/usage) explains procedures. [Technical](/docs/adapters/social/call/technical) documents interfaces and configuration.
