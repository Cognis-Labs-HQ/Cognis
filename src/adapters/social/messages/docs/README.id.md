# Pesan

Mulai percakapan pribadi, baca pesan, dan simpan templat pesan yang dapat digunakan ulang.

## Yang Dapat Anda Lakukan

Buat percakapan, kelola anggota ruang, dan tulis pesan dengan pratinjau serta templat.

## Sebelum Memulai

Masuk; ruang terenkripsi juga memerlukan akses keyring akun.

## Langkah Awal

Buka Pesan dan pilih ruang; di layar sempit tombol chevron ganda membuka daftar ruang.

[Penggunaan](/docs/adapters/social/messages/usage) menjelaskan prosedur. [Teknis](/docs/adapters/social/messages/technical) mendokumentasikan antarmuka dan konfigurasi.
