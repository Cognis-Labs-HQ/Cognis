# Nachrichten

Beginnen Sie private Gespräche, lesen Sie Nachrichten und speichern Sie Nachrichtenvorlagen.

## Möglichkeiten

Erstelle Gespräche, verwalte Mitglieder und verfasse Nachrichten mit Vorschau und Vorlagen.

## Vor dem Start

Melde dich an; verschlüsselte Räume benötigen auch Zugriff auf deinen Schlüsselbund.

## Erste Schritte

Öffne Nachrichten und wähle einen Raum; auf schmalen Bildschirmen öffnet der Doppelpfeil die Liste.
