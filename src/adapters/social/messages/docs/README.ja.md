# メッセージ

非公開の会話を始め、メッセージを読んだり、繰り返し使うテンプレートを保存したりできます。

## できること

- サイドバーでルームを選ぶか会話を始めます。スマートフォンとタブレットでは左上の二重山括弧ボタンで開きます。
- 会話を読み、参加者と未処理のリクエストを確認します。
- 送信前に下書きとプレビューを確認します。添付と通話はそれぞれの操作から利用します。

## 始める前に

メッセージ が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/messages) を開き、必要な操作を選びます。

手順は[使用例](/docs/adapters/social/messages/usage)、インターフェースと設定は[技術情報](/docs/adapters/social/messages/technical)を参照してください。
