# Messages

Start private conversations, read messages and keep reusable message templates.

## What You Can Do

Create conversations, manage room membership and compose messages with previews and reusable templates.

## Before You Start

Sign in; encrypted rooms also require access to your account keyring.

## Get Started

Open Messages and select a room; on compact screens the double-chevron opens the room list.
