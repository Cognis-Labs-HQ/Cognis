# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

## 技術仕様

| ページ・画面         | ガイド             | アクセス           |
| -------------------- | ------------------ | ------------------ |
| `^/messages(?:/\|$)` | メッセージの使い方 | ログイン済み利用者 |

公開機能 `ui:tutorials` を通じて、コンポーネント所有の定義、カタログ、対象、ライフサイクルのシグナルを登録します。ページ、表示中の領域、アクセス権により利用可否が決まります。コンポーネントを解除するとガイドも解除します。共通の表示と完了動作は[ホストのチュートリアル契約](/docs/tutorials)を参照してください。

ルーターのシグナルでガイド登録とページコンポーザーの寿命を限定します。スクロール中も操作を残し、一時的に失われた表示対象を黙って進めずに復旧します。
