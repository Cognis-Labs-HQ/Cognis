# 使用例

メッセージ の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/adapters/social/messages)を確認してください。

## 使用例

- サイドバーでルームを選ぶか会話を始めます。スマートフォンとタブレットでは左上の二重山括弧ボタンで開きます。
- 会話を読み、参加者と未処理のリクエストを確認します。
- 送信前に下書きとプレビューを確認します。添付と通話はそれぞれの操作から利用します。
- 個別の会話やルームを作り、宛先と参加者を確認してから最初のメッセージを送ります。
- ここにメッセージを入力します。書式や添付ファイルを使い、送信前にプレビューを確認します。
- プレビューで書式、リンク、添付内容を確認し、修正するときは編集に戻ります。
- 会話の見出しでルームと参加者を確認します。メンバー変更や退出には、表示される操作を使います。

## 期待される結果

この例は メッセージ の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/adapters/social/messages/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

メッセージ を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
