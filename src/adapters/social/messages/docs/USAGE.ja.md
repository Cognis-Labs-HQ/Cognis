# 使用例

メッセージ の実践的な操作手順です。

## 前提条件

ログインが必要で、暗号化ルームにはキーリングへのアクセスも必要です。

## 使用例

ルームと宛先を選び、下書きを書いてプレビューで確認し送信します。繰り返し使う文は定型文として保存できます。

`uiCtx` をインポートして `social:messagesUiClient` を要求し、ブラウザーコードから `listRoomMessages(roomId, options)`、`openPrivateRoom(payload, options)`、`sendRoomMessage(roomId, payload)` を呼び出します。

## 期待される結果

確認済みのメッセージが履歴に表示されます。画面サイズの変更で下書きは失われず、暗号化された下書きは確認または永続キュー登録後に消去されます。

## 問題の解決

参加資格とキーリングを確認してください。オフライン表示には準備済みの素材と保存済みのルームが必要です。
