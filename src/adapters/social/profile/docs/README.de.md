# Profile und Beiträge

Stellen Sie sich vor, veröffentlichen Sie Beiträge und bestimmen Sie, wem Sie folgen oder wen Sie blockieren.

## Möglichkeiten

- Prüfen Sie Identität und Verfügbarkeit; Ihr eigenes Profil bietet Bearbeitungsfunktionen.
- Lesen Sie sichtbare Beiträge und nutzen Sie die für Ihr Konto erlaubten Aktionen.
- Folgen, Nachrichten und Beziehungen steuern Sie am Profil; prüfen Sie zuvor die ausgewählte Person.

## Vor dem Start

Prüfen Sie, ob Profile und Beiträge aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/profile) und wählen Sie die gewünschte Aktion.
