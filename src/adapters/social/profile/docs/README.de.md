# Profile und Beiträge

Stellen Sie sich vor, veröffentlichen Sie Beiträge und bestimmen Sie, wem Sie folgen oder wen Sie blockieren.

## Möglichkeiten

Bearbeite dein Profil, veröffentliche Beiträge und verwalte Sichtbarkeit und Kontakte.

## Vor dem Start

Melde dich für eigene Änderungen an; fremde Profile beachten Datenschutz und Blockierungen.

## Erste Schritte

Öffne dein Profil über den Avatar und wähle Bearbeiten oder einen Beitrag.
