# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

## 技術仕様

| ページ・画面        | ガイド             | アクセス           |
| ------------------- | ------------------ | ------------------ |
| `^/profile(?:/\|$)` | プロフィールと投稿 | ログイン済み利用者 |

公開機能 `ui:tutorials` を通じて、コンポーネント所有の定義、カタログ、対象、ライフサイクルのシグナルを登録します。ページ、表示中の領域、アクセス権により利用可否が決まります。コンポーネントを解除するとガイドも解除します。共通の表示と完了動作は[ホストのチュートリアル契約](/docs/tutorials)を参照してください。

識別情報、投稿、アカウント操作は空の投稿欄も含め実際の表示領域を対象とします。ページのシグナルがガイドの寿命を管理します。

投稿一覧は作成欄と別の対象を使います。交流操作の強調はボタン幅に合わせ、他人のプロフィールでは作成欄のプレビューを除外します。

本人情報と交流操作の後に、投稿一覧とプレビューを続けて案内します。

自分のプロフィールでは、プロフィール編集から詳細を開けます。保存に失敗しても変更内容が残り、修正して再試行できます。

件数や詳細が更新されてもプロフィール写真は表示されたままです。画像の更新に失敗した場合はプロフィールを開き直してください。確認済みの削除は選んだ画像だけを消去します。本人情報のステップは既存の対象、進行方法、完了識別子を維持します。

ナビゲーション、プレビュー、プロフィールのイニシャルは同じ名前と色の規則に従います。プレビューのアバターから対象プロフィールを開けます。名前の変更は画像エラー後の代替表示にも反映されます。既存の識別情報とアバター操作のチュートリアル対象、手順、完了 ID は変わりません。

操作可能なプレビューは名前付きの非モーダルダイアログです。マウスを重ねてもキーボードのフォーカスは移動せず、カード内にフォーカスがある間はマウスを離しても開いたままです。Escape で閉じると、カード内にフォーカスがあった場合だけ表示元のリンクに戻します。
