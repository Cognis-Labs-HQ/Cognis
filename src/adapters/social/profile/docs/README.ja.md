# プロフィールと投稿

自己紹介や投稿を公開し、フォローする人やブロックする人を選べます。

## できること

- 本人情報と連絡可能な状態を確認します。自分のプロフィールには編集操作があります。
- 表示できる投稿を読み、自分のアカウントで許可された操作を使います。
- プロフィールの操作からフォロー、メッセージ、関係の管理を行えます。相手を確認してから操作します。

## 始める前に

プロフィールと投稿 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/profile) を開き、必要な操作を選びます。

手順は[使用例](/docs/adapters/social/profile/usage)、インターフェースと設定は[技術情報](/docs/adapters/social/profile/technical)を参照してください。
