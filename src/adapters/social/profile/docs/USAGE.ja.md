# 使用例

プロフィールと投稿 の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/adapters/social/profile)を確認してください。

## 使用例

- 本人情報と連絡可能な状態を確認します。自分のプロフィールには編集操作があります。
- 表示できる投稿を読み、自分のアカウントで許可された操作を使います。
- プロフィールの操作からフォロー、メッセージ、関係の管理を行えます。相手を確認してから操作します。
- プレビューで公開前の最新のタイトルと本文を確認できます。作成画面に戻ったり端末の向きを変えたりしても下書きは保持されます。

## 期待される結果

この例は プロフィールと投稿 の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/adapters/social/profile/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

プロフィールと投稿 を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
