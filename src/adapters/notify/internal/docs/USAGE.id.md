# Penggunaan

Prosedur praktis untuk Notifikasi Dalam Aplikasi.

## Prasyarat

Tinjau [persyaratan akses](/docs/adapters/notify/internal) sebelum menjalankan prosedur ini.

## Contoh

Komponen ini tidak menyatakan titik masuk baris perintah mandiri. Gunakan fitur pemiliknya atau [prosedur penerapan](/docs/devops/usage) untuk mengonfigurasi instalasi; [referensi teknis](/docs/adapters/notify/internal/technical) mencantumkan antarmuka dan batasnya.

## Hasil yang Diharapkan

Contoh ini memakai antarmuka Notifikasi Dalam Aplikasi yang didokumentasikan. Periksa respons atau keadaan tersimpan yang dijelaskan dalam [Teknis](/docs/adapters/notify/internal/technical) sebelum mengulangi operasi tulis.

## Pemecahan Masalah

Jika Notifikasi Dalam Aplikasi tidak tersedia, periksa status masuk dan minta administrator memeriksa komponen beserta dependensinya.
