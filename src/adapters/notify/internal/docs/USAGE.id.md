# Penggunaan

Prosedur praktis untuk Notifikasi Dalam Aplikasi.

## Prasyarat

Masuk untuk menerima notifikasi akun sendiri.

## Contoh

Buka notifikasi belum dibaca, ikuti tujuannya, dan tandai dibaca; periksa kategori di Pengaturan.

## Hasil yang Diharapkan

Status baca dan jumlah belum dibaca diperbarui untuk akun Anda.

## Pemecahan Masalah

Periksa preferensi kategori dan konfigurasi pengiriman bila notifikasi tidak muncul.
