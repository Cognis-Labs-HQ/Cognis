# In-App Notifications

Use the notification bell to read activity updates without leaving Cognis.

## What You Can Do

Available actions are shown on [the feature page](/) according to your account permissions.

## Before You Start

Check that In-App Notifications is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/) and choose the action you need.

[Usage](/docs/adapters/notify/internal/usage) explains procedures. [Technical](/docs/adapters/notify/internal/technical) documents interfaces and configuration.
