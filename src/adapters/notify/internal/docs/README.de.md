# Hinweise in der App

Lesen Sie über die Benachrichtigungsglocke Aktivitätsmeldungen direkt in Cognis.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Hinweise in der App aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/notify/internal/usage) erklärt Abläufe. [Technik](/docs/adapters/notify/internal/technical) beschreibt Schnittstellen und Konfiguration.
