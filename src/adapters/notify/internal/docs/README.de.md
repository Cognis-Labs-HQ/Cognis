# Hinweise in der App

Lesen Sie über die Benachrichtigungsglocke Aktivitätsmeldungen direkt in Cognis.

## Möglichkeiten

Lies interne Benachrichtigungen und markiere sie als gelesen.

## Vor dem Start

Melde dich für die Benachrichtigungen deines Kontos an.

## Erste Schritte

Öffne die Glocke im Kopfbereich.
