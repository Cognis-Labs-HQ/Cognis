# アプリ内通知

Cognis を離れることなく、通知ベルから活動の更新を確認できます。

## できること

[機能のページ](/) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

アプリ内通知 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/notify/internal/usage)、インターフェースと設定は[技術情報](/docs/adapters/notify/internal/technical)を参照してください。
