# Notifikasi Dalam Aplikasi

Gunakan ikon lonceng untuk membaca pembaruan aktivitas tanpa meninggalkan Cognis.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Notifikasi Dalam Aplikasi aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/notify/internal/usage) menjelaskan prosedur. [Teknis](/docs/adapters/notify/internal/technical) mendokumentasikan antarmuka dan konfigurasi.
