# SMTP通知アダプター

## 概要

SMTPアダプターは、任意のSMTPサーバーを通じてメールとして通知を配信します。これは唯一の組み込み通知アダプターで、`COGNIS_SMTP_HOST` 環境変数が設定されると自動的に起動します。典型的なユースケースには、2要素認証コード、メール検証リンク、その他の通知カテゴリの配信が含まれます。

アダプターはグレイリスト耐性のある配信を実装します。最初の送信試行が一時的なエラーで拒否された場合、各試行の間に5分の遅延を設けて最大2回再試行します。

## 責務

- Nodemailerを使用して設定されたSMTPサーバーを通じてメールを送信する。
- 一時的な配信失敗を再試行で処理する（最大2回、5分の遅延）。
- 管理者APIを通じたランタイム再設定のために `getConfig()` と `setConfig()` を公開する。
- 配信検証のために `sendTestEmail(to)` を公開する。

## 設定

| 変数 | デフォルト | 説明 |
| ---- | ---------- | ---- |
| `COGNIS_SMTP_HOST` | — | SMTPサーバーのホスト名; 設定されていない場合アダプターは非アクティブ |
| `COGNIS_SMTP_PORT` | `587` | SMTPサーバーのポート |
| `COGNIS_SMTP_SECURE` | `false` | 接続時のTLS（ポート465）の場合は `true` |
| `COGNIS_SMTP_USER` | — | SMTP認証ユーザー名 |
| `COGNIS_SMTP_PASS` | — | SMTP認証パスワード |
| `COGNIS_SMTP_FROM` | — | `From` ヘッダーに表示される送信者アドレス |
