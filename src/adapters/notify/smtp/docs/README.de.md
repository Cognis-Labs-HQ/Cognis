# E-Mail-Zustellung

Empfangen Sie Cognis-Benachrichtigungen über den eingerichteten E-Mail-Dienst.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/settings) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob E-Mail-Zustellung aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/settings) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/notify/smtp/usage) erklärt Abläufe. [Technik](/docs/adapters/notify/smtp/technical) beschreibt Schnittstellen und Konfiguration.
