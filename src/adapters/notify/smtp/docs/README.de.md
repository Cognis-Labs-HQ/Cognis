# E-Mail-Zustellung

Empfangen Sie Cognis-Benachrichtigungen über den eingerichteten E-Mail-Dienst.

## Möglichkeiten

Versende Benachrichtigungen und Bestätigungen über deinen Mailserver.

## Vor dem Start

Administratoren benötigen SMTP-Zugang und eine erlaubte Absenderadresse.

## Erste Schritte

Öffne Benachrichtigungen in Administration und konfiguriere den E-Mail-Absender.

## Weitere Informationen

[Anwendung](/docs/adapters/notify/smtp/usage) erklärt Abläufe. [Technik](/docs/adapters/notify/smtp/technical) beschreibt Schnittstellen und Konfiguration.
