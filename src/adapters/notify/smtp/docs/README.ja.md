# メール配信

この環境で設定されたメールサービスから Cognis の通知を受け取れます。

## できること

[機能のページ](/settings) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

メール配信 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/notify/smtp/usage)、インターフェースと設定は[技術情報](/docs/adapters/notify/smtp/technical)を参照してください。
