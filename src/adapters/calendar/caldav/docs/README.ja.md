# CalDAV

対応するカレンダーアプリで、共有された Cognis カレンダーを閲覧できます。

## できること

[機能のページ](/calendar) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

CalDAV が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/calendar) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/calendar/caldav/usage)、インターフェースと設定は[技術情報](/docs/adapters/calendar/caldav/technical)を参照してください。
