# Usage

Practical procedures for CalDAV.

## Prerequisites

A feed needs a public calendar or a valid private access token.

## Examples

Add the returned address to a compatible client; test public and private access with the intended permissions.

## Expected Results

The client reads the permitted calendar feed; private access remains token-scoped.

## Troubleshooting

Check client compatibility, calendar visibility and token validity. This adapter does not provision separate calendar-client accounts.
