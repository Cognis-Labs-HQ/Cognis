# CalDAV

Baca kalender Cognis bersama melalui aplikasi kalender yang kompatibel.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/calendar) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan CalDAV aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/calendar) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/calendar/caldav/usage) menjelaskan prosedur. [Teknis](/docs/adapters/calendar/caldav/technical) mendokumentasikan antarmuka dan konfigurasi.
