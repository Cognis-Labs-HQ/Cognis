# CalDAV

Lesen Sie freigegebene Cognis-Kalender in einer kompatiblen Kalenderanwendung.

## Möglichkeiten

Abonniere unterstützte Kalender mit kompatibler Kalendersoftware.

## Vor dem Start

Ein Feed benötigt einen öffentlichen Kalender oder gültigen privaten Zugriffstoken.

## Erste Schritte

Hole die Abo-Adresse über den CalDAV-Export des Kalenders.
