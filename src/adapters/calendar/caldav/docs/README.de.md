# CalDAV

Lesen Sie freigegebene Cognis-Kalender in einer kompatiblen Kalenderanwendung.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/calendar) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob CalDAV aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/calendar) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/calendar/caldav/usage) erklärt Abläufe. [Technik](/docs/adapters/calendar/caldav/technical) beschreibt Schnittstellen und Konfiguration.
