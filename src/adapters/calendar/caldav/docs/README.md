# CalDAV

Read shared Cognis calendars from a compatible calendar application.

## What You Can Do

Available actions are shown on [the feature page](/calendar) according to your account permissions.

## Before You Start

Check that CalDAV is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/calendar) and choose the action you need.

## Learn More

[Usage](/docs/adapters/calendar/caldav/usage) explains procedures. [Technical](/docs/adapters/calendar/caldav/technical) documents interfaces and configuration.
