# Calendar Import and Export

Transfer events between Cognis and other calendar applications using calendar files.

## What You Can Do

Available actions are shown on [the feature page](/calendar) according to your account permissions.

## Before You Start

Check that Calendar Import and Export is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/calendar) and choose the action you need.

## Learn More

[Usage](/docs/adapters/calendar/ics/usage) explains procedures. [Technical](/docs/adapters/calendar/ics/technical) documents interfaces and configuration.
