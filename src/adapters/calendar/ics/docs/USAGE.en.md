# Usage

Practical procedures for Calendar Import and Export.

## Prerequisites

Use an owned calendar and an enabled ICS adapter.

## Examples

Export an ICS file, inspect its dates, then import valid ICS text into the intended owned calendar.

## Expected Results

Export produces a calendar attachment; import delegates event creation to Calendar.

## Troubleshooting

Check calendar ownership and nonempty ICS content. Review timezone and recurrence data before importing unfamiliar files.
