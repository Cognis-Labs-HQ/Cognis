# カレンダーの読み込みと書き出し

カレンダーファイルを使って、Cognis と他のアプリの間で予定を移せます。

## できること

[機能のページ](/calendar) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

カレンダーの読み込みと書き出し が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/calendar) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/calendar/ics/usage)、インターフェースと設定は[技術情報](/docs/adapters/calendar/ics/technical)を参照してください。
