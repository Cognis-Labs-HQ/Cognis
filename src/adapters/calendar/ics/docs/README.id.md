# Impor dan Ekspor Kalender

Pindahkan acara antara Cognis dan aplikasi kalender lain menggunakan berkas kalender.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/calendar) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Impor dan Ekspor Kalender aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/calendar) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/calendar/ics/usage) menjelaskan prosedur. [Teknis](/docs/adapters/calendar/ics/technical) mendokumentasikan antarmuka dan konfigurasi.
