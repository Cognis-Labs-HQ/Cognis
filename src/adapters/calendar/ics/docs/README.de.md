# Kalenderimport und -export

Übertragen Sie Termine zwischen Cognis und anderen Kalenderanwendungen mithilfe von Kalenderdateien.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/calendar) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Kalenderimport und -export aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/calendar) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/calendar/ics/usage) erklärt Abläufe. [Technik](/docs/adapters/calendar/ics/technical) beschreibt Schnittstellen und Konfiguration.
