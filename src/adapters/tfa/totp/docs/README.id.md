# Verifikasi Autentikator

Verifikasi proses masuk menggunakan kode terkini dari aplikasi autentikator Anda.

## Yang Dapat Anda Lakukan

Verifikasi masuk dengan kode enam digit dari aplikasi autentikator.

## Sebelum Memulai

Pasang autentikator dan pastikan waktu perangkat akurat.

## Langkah Awal

Tambahkan metode autentikator di pengaturan keamanan akun.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/tfa/totp/usage) menjelaskan prosedur. [Teknis](/docs/adapters/tfa/totp/technical) mendokumentasikan antarmuka dan konfigurasi.
