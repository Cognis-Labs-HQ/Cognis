# Authentifikator-Bestätigung

Bestätigen Sie eine Anmeldung mit dem aktuellen Code Ihrer Authentifikator-App.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/settings) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Authentifikator-Bestätigung aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/settings) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/tfa/totp/usage) erklärt Abläufe. [Technik](/docs/adapters/tfa/totp/technical) beschreibt Schnittstellen und Konfiguration.
