# 認証アプリによる確認

認証アプリに表示されている現在のコードでログインを確認できます。

## できること

[機能のページ](/settings) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

認証アプリによる確認 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/tfa/totp/usage)、インターフェースと設定は[技術情報](/docs/adapters/tfa/totp/technical)を参照してください。
