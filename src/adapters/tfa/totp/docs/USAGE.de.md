# Anwendung

Praktische Abläufe für Authentifikator-Bestätigung.

## Voraussetzungen

Installiere eine Authenticator-App und halte die Gerätezeit korrekt.

## Beispiele

Scanne den Einrichtungscode oder gib das Geheimnis ein und bestätige mit dem aktuellen sechsstelligen Code.

## Erwartete Ergebnisse

Bestätigung aktiviert die Methode; Codes gelten in Dreißigsekundenperioden mit je einer benachbarten Periode Toleranz.

## Fehlerbehebung

Prüfe Gerätezeit und Algorithmus. Schütze das Einrichtungsgeheimnis, denn sein Besitzer kann Codes erzeugen.
