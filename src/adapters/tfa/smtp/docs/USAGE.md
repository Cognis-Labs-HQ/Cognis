# Usage

Practical procedures for Email Verification.

## Prerequisites

Review [the access requirements](/docs/adapters/tfa/smtp) before performing these procedures.

## Examples

This component does not declare a standalone command-line entry point. Use its owning feature or the [deployment procedures](/docs/devops/usage) to configure the installation; the [technical reference](/docs/adapters/tfa/smtp/technical) lists its interfaces and constraints.

## Expected Results

The example uses the documented interface of Email Verification. Confirm the response or saved state described in [Technical](/docs/adapters/tfa/smtp/technical) before repeating a write operation.

## Troubleshooting

If Email Verification is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
