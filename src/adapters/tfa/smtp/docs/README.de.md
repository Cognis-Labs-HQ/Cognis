# E-Mail-Bestätigung

Bestätigen Sie eine Anmeldung mit einem einmaligen Code an Ihre E-Mail-Adresse.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/settings) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob E-Mail-Bestätigung aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/settings) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/tfa/smtp/usage) erklärt Abläufe. [Technik](/docs/adapters/tfa/smtp/technical) beschreibt Schnittstellen und Konfiguration.
