# SMTP TFAアダプター

## 概要

このアダプターはブートストラップ中に`notify:registerSmtpPurpose`でコード通知アクションを登録し、`notify:sendEmail`で送信します。登録、コード通知内容、送信アダプターとの同期をこのアダプターが所有します。TFAゲートウェイは共通のライフサイクル用フックだけを提供します。ゲートウェイの無効化で所有するSMTPキューを中止し、再有効化で登録を復元します。

## 前提条件

- Notificationゲートウェイで検証メール送信が利用可能であること。
- Notificationゲートウェイ管理画面でSMTP送信者が設定・有効化されていること。
- ユーザーアカウントに検証済みのプライマリメールが設定されていること。

## 設定

- `codeLength`（数値、任意）: 生成する数値コードの桁数。値は4〜10桁に制限されます。

## 実行時の挙動

- チャレンジコードはプロセスメモリに保存されます。アプリを再起動すると、保留中のセットアップ/ログインコードは無効になります。
- 複数インスタンス構成では、チャレンジ有効期間中のリクエストが同じインスタンスに固定される場合にのみ、このアダプターを利用してください。
