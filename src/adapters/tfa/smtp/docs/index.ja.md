# SMTP TFAアダプター

## 概要

SMTP TFAアダプターは、メールコードを使う第2要素認証をTFAゲートウェイに追加します。セットアップ時とログイン時に、Notificationゲートウェイの検証メール送信フローを利用して、ユーザーのプライマリメールへワンタイムコードを送信します。

## 前提条件

- Notificationゲートウェイで検証メール送信が利用可能であること。
- Notificationゲートウェイ管理画面でSMTP送信者が設定・有効化されていること。
- ユーザーアカウントに検証済みのプライマリメールが設定されていること。

## 設定

- `codeLength`（数値、任意）: 生成する数値コードの桁数。値は4〜10桁に制限されます。
