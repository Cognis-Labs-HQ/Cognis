# 画像ビューアーアダプター

## 概要

画像ビューアーアダプターは、一般的なラスターおよびベクター画像形式用のファイルリーダーアダプターです。授業教材やファイル添付ビューアー内で画像をインラインでレンダリングし、別ページの読み込みを必要としません。大きな画像のプログレッシブローディングをサポートし、ブラウザーのネイティブ画像レンダリングパイプラインを活用します。

## 責務

- JPEG、PNG、GIF、WebP、SVG、AVIF の MIME タイプのサポートをファイルリーダーゲートウェイに登録する。
- ブラウザー側が適切なビュースクリプトとスタイルシートをロードできるよう `file-reader:image:ui` ケイパビリティを提供する。
- アダプターの静的アセットディレクトリを登録して、ビュースクリプトと CSS を `/static/adapters/file-reader/image/` で提供する。

責任外: ファイルバイトの取得（これはファイルストレージゲートウェイの責務）、ファイルサイズ制限の適用、または画像変換。

## サポートされる形式

| 拡張子        | MIME タイプ     |
| ------------- | --------------- |
| `jpg`、`jpeg` | `image/jpeg`    |
| `png`         | `image/png`     |
| `gif`         | `image/gif`     |
| `webp`        | `image/webp`    |
| `svg`         | `image/svg+xml` |
| `avif`        | `image/avif`    |
