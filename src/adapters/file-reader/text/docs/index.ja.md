# テキスト / Markdown アダプター

## 概要

テキストアダプターは、プレーンテキストおよび Markdown ファイル用のファイルリーダーアダプターです。教室内では、教師と生徒がノートを書き、書式設定し、授業教材に直接保存するために使用するリッチテキストエディター（ノートパッド）としても機能します。同じアダプターが読み取り専用のファイル表示とインタラクティブなノート編集の両方を処理します。

## 責務

- `text/plain` および `text/markdown` MIME タイプのサポートをファイルリーダーゲートウェイに登録する。
- 認証済みユーザー向けの教室ノートパッド読み取り/書き込みルートを公開する。
- ビュースクリプト、スタイルシート、文字列バンドルのベース URL を含む `file-reader:text:ui` ケイパビリティを提供する。
- `TEXT_FILE_READER_MAX_BYTES` 環境変数を正規化し、安全な範囲内に制限する。

責任外: ファイルバイトの保存（これはファイルストレージゲートウェイの責務）、アップロードサイズ制限の適用、またはテキストと Markdown 以外の形式のレンダリング。

## 設定

| 変数                         | デフォルト         | 説明                                                                                       |
| ---------------------------- | ------------------ | ------------------------------------------------------------------------------------------ |
| `TEXT_FILE_READER_MAX_BYTES` | `262144`（256 KB） | アダプターが開く/受け入れるテキストファイルの最大バイトサイズ。`[16384, 4194304]` に制限。 |

## API ルート

| メソッド | パス                                | 説明                               | 認証 |
| -------- | ----------------------------------- | ---------------------------------- | ---- |
| `GET`    | `/api/v1/study/classes/:id/notepad` | 現在の教室ノートパッドの内容を取得 | 必須 |
| `PUT`    | `/api/v1/study/classes/:id/notepad` | ノートパッドの内容を授業教材に保存 | 必須 |
