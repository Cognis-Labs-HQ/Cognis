# Lernbibliothek

Durchsuchen Sie Sprachinhalte und Definitionen und verwalten Sie verfügbare Lerninhalte.

## Möglichkeiten

Durchsuche Sprachsammlungen, prüfe Karten und ergänze strukturierte Lerninhalte.

## Vor dem Start

Wähle eine eingeschriebene Sprache; Erstellen, Bearbeiten und Veröffentlichen hängen von Eigentum und Prüfberechtigung ab.

## Erste Schritte

Öffne Erkunden, wähle eine Sammlung und eine Karte.
