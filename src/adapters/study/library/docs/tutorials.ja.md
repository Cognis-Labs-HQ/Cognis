# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

## 技術仕様

| ページ・画面                                   | ガイド               | アクセス           |
| ---------------------------------------------- | -------------------- | ------------------ |
| `^/study/explore(?:/\|$)`                      | ライブラリーを探索   | ログイン済み利用者 |
| `^/study/library/search(?:/\|$)`               | 辞書の検索           | ログイン済み利用者 |
| `^/study/(?:library/)?requests(?:/\|$)`        | ライブラリーへの申請 | ログイン済み利用者 |
| `^/study/library(?:/\|$)` · `.library-browser` | ライブラリーの管理   | 管理者             |

公開機能 `ui:tutorials` を通じて、コンポーネント所有の定義、カタログ、対象、ライフサイクルのシグナルを登録します。ページ、表示中の領域、アクセス権により利用可否が決まります。コンポーネントを解除するとガイドも解除します。共通の表示と完了動作は[ホストのチュートリアル契約](/docs/tutorials)を参照してください。

`scope` は対象と検出範囲を制限します。任意の `visibleWhen` は一意の表示要素を要求しますが、その子孫だけに対象を制限せず、コンポーネント内の対象を使えます。ライブラリー管理ではブラウザーの表示を確認し、サイドバーの検索を強調します。無効なセレクターは登録時に失敗し、所有者を解除します。

Explore は階層サイドバー、フィルター、固定したお気に入りの例から始めます。選んだカードをクリックすると条件付き詳細分岐を開き、次へで省略できます。詳細と省略可能な筆記操作は所有ダイアログ内の異なる対象を強調し、分岐終了時に閉じます。

お気に入りと詳細のステップは、アルファベットの画面や並べ替え後も同じカードのコンテナーを使います。

## 言語別ガイドと分岐

プロバイダーはスコープ付き操作として `study:libraryTutorials` バージョン 1 を公開します。モジュールは固定の識別子、言語、翻訳済みステップ文言で `register({ owner, id, language, titleKey, text, stringsBaseUrls, signal })` を呼びます。戻り値は `{ id, dispose }` です。セレクター、カード操作、移動先、ダイアログ寿命は Library が所有し、モジュールは実装をインポートしません。同じ言語の重複登録は失敗し、削除すると汎用 Explore ガイドが復元されます。

明示的に学習登録した言語だけがモジュールガイドの対象です。`/study` では手動選択、対応する Explore では言語版が汎用版を置き換えます。登録や検出だけでは移動しません。概要から明示的に開始するとコンテンツを開き、既存の Explore レイヤーは維持します。作成分岐では文字専用レイヤーからカードを作れるレイヤーへ移動できます。

ガイドはレイヤー、フィルター、同じお気に入りとカード、詳細、利用可能な発音音声、書き取り、描画ツールを説明します。カードや描画をクリックすると分岐に入り、「次へ」は未選択の分岐を飛ばします。描画は詳細を閉じるため、キャンバスから「戻る」とカードを開くステップへ戻ります。

作成では実際の種類選択、編集画面、タブ、保存操作を案内します。自動送信はしません。ダイアログと描画パッドは分岐の有効期間に従い、戻る、再開始、完了、削除時には未保存変更の破棄確認を維持して閉じます。

検索結果、リクエスト、Library 管理では、表示中のレコードがない場合にレコード固有のステップを省略します。存在しない対象を待たず、概要の操作は利用できます。
