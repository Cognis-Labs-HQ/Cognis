# 使用例

学習ライブラリ の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/adapters/study/library)を確認してください。

## 使用例

- 階層サイドバーで学習言語に利用できるコンテンツの種類を切り替え、選んだ階層のカードを閲覧します。
- このカードをクリックして詳細画面を開くか、ガイドを進めて詳細の説明を省略します。
- このカードのお気に入り操作で後から使うために保存します。お気に入りフィルターで保存したカードに戻れます。
- 辞書の検索結果と、その言語、読み方、意味を確認します。
- 結果を開いて読み方と意味を比較し、コレクションに取り込む内容を確認します。
- 申請を絞り込み、次の変更を送る前に審査の状態を確認します。
- リクエストを開いて、提案された内容とレコードの保存先を確認します。
- 検索とレイヤー選択で、管理する項目を探します。

## 期待される結果

この例は 学習ライブラリ の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/adapters/study/library/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

学習ライブラリ を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
