# 学習ライブラリ

言語の教材や定義を検索し、利用できる学習項目を管理できます。

## できること

- 階層サイドバーで学習言語に利用できるコンテンツの種類を切り替え、選んだ階層のカードを閲覧します。
- このカードをクリックして詳細画面を開くか、ガイドを進めて詳細の説明を省略します。
- このカードのお気に入り操作で後から使うために保存します。お気に入りフィルターで保存したカードに戻れます。

## 始める前に

学習ライブラリ が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/study) を開き、必要な操作を選びます。

手順は[使用例](/docs/adapters/study/library/usage)、インターフェースと設定は[技術情報](/docs/adapters/study/library/technical)を参照してください。
