# ライブラリアダプター

## 目的

ライブラリアダプターは、再利用可能で追跡できる学習・活動教材をデータベースに保存します。各項目は固定階層と、グローバル、クラス、ユーザーのいずれかの範囲に属します。空の階層は画面に表示されません。

## 標準階層

順序は `alphabet`、`alt_characters`、`definitions`、`words`、`sentences`、`exercises`、`workouts`、`routines`、`collections` です。参照は許可された下位要素への有向関係です。コレクションは、別のコレクション以外の階層をまとめられます。

## 利用側向けテンプレート

利用側は `ctx` の `study:library` ケイパビリティから、必要な階層だけを指定して `cloneTemplate` を呼び出します。そのため言語モジュールは、活動用の階層を含めずに `alphabet`、`alt_characters`、`definitions`、`words`、`sentences` だけを要求できます。複製されたテンプレートは標準順序を保ち、要求されなかった階層へのリンクを除き、必須リンクを示します。単語や文の作成時には、正規化された文字や空白で区切られた単語からリンクを自動推定できます。

## アクセスと交換

全ユーザーがグローバルデータを閲覧できますが、変更と JSON インポートは管理者と所有者だけが行えます。クラスは教師と有効なメンバーが閲覧でき、教師と管理者だけが書き込めます。ユーザー範囲は本人専用です。`study:library` は `ctx` を通じて読み書き、追跡、プッシュ申請、JSON・Anki エクスポートを公開します。
