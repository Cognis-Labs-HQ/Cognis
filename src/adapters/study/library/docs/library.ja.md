# ライブラリアダプター

## 利用側定義のスキーマ

ライブラリアダプターは関係付けられた汎用学習データを保存します。利用側は ctx capability `study:library` を通じて、不変かつバージョン付きのスキーマを登録します。スキーマが言語、レイヤー、型付きフィールド、方向付き関係を定義し、アルファベット、単語、文などの名称をアダプターに固定しません。

関係は対象レイヤー、多重度、順序、任意のリゾルバーを宣言します。すべての書き込みでフィールド、スキーマバージョン、対象、可視性、多重度を検証します。別定義も利用側が宣言する通常のレイヤーと関係で表現します。

レイヤーは関係の対象として同じレイヤーを指定でき、ある項目から同一レイヤー内の別の項目を明示的に展開できます。同一レイヤーの関係は既定で構成として表示され、バリアントとして指定された関係、または `alternateSpelling` を明示した関係だけが別表記として表示されます。

## 解決、API、UI

`grapheme` リゾルバーは Unicode 書記素を、`longest-match` は明示的に区切られたブロックを使用します。どちらも項目を暗黙に作成せず、候補と未解決単位を返します。lookup プロバイダーは `registerLookupProvider` で追加し、出典付きの順位候補を返し、登録時の callback で解除できます。作成、解決、lookup は名前付き ctx flow に参加します。

Study ゲートウェイはスキーマ検出、一覧、作成、詳細、双方向追跡、解決プレビュー、lookup 候補を提供します。スキーマ駆動 UI は、内部用の定義レイヤーと助詞レイヤーを直接閲覧の対象から除外します。閲覧可能なレイヤーでは、タブ、メタデータ絞り込み、項目カード、メタデータのピル、範囲アイコンを使用します。再利用可能なポップアップ詳細は、大きくした項目見出しの下に定義と意味を表示します。文の助詞を含む認識済みの構成要素は、独立したコンポーネント区画ではなく、その見出し内の移動可能なサブボックスとして表示し、助詞の詳細は読み取り専用のままです。リゾルバーに基づく参照は、移動可能な強調ボックスだけで表示し、重複する関係見出しや構成演算子は表示しません。メタデータ絞り込みは即時反映するピルとして表示し、モジュールが提供する場合はスキーマの詳細グループを使用します。グローバル、利用者、クラスの権限はサービス境界で引き続き強制します。 メタデータ絞り込みは、シリアル化された絞り込み値を持つ基本カードだけを評価するようになり、浮動バリエーションカードが未定義値を JSON 解析へ渡すことを防ぎます。 バリエーションを持つ文字カードでは、ホバー時にローカライズ済みの長押し案内を表示し、長押ししきい値に達した後にだけ子カードを展開します。親または子にフォーカスがある間は開いた状態を保ち、フォーカスが外れると閉じます。バリアント関係を専用の詳細節へ重複表示しません。 展開した子カードには緑色の方向矢印と枠線を付け、親との間隔を通常カード同士の間隔と同じにします。

コンテンツ所有者、管理者、所有者は、表示中の複数項目を選択し、関係とともに完全に削除できます。削除したモジュール内容は、存在しない場合にモジュールの有効化ライフサイクルで復元されます。削除確認で選択したコンテンツハッシュをブロックリストに登録すると、同一レコードの再インポートを防止できます。 右クリック後の複数選択操作にはページコンポーザーの浮動アクションバーを使用し、通常のカードクリックまたは閉じる操作で選択モードを終了します。関係リンクは参照先項目の閲覧可能なレイヤーへ切り替え、共通の対象強調表示を使用します。定義参照は表示中の定義テキスト自体に適用し、スキーマで宣言したリゾルバー関係だけが構成要素ボックスを生成するため、重複または無関係な書記体系リンクを防ぎます。ダークテーマの音声操作部ではネイティブパネルの彩度を明示的に除去します。

最小グリッドは `grid.rowSize` から制限付きのチャート幅と比例カード尺度を導出します。明示的な空白項目は寸法付きグリッドセルとして保持され、列が詰まることを防ぎます。

## 宣言的コンテンツパック

導入済み言語パックは、検証に `inspectContentPack(root)`、データ専用ライブラリの導入に `ingestContentPack(root)` を呼びます。ルートには `manifest.json`、参照スキーマ、レイヤー ID のサブディレクトリを持つコンテンツディレクトリを置きます。ファイルは安定 ID と明示的関係を持つレコード配列です。Cognis はグラフ全体を検証し、名前空間 ID、digest、receipt を記録して、スキーマ、項目、edge を原子的に保存します。項目 ID はパック版が変わっても安定し、導入時に以前のインポートにある同一コンテンツハッシュを関係を保持したまま 1 つの正規項目へ統合します。 空間的な階層には関係で `child: true` を指定する必要があります。`variant: true` は代替形も示せますが、それだけではカードを展開しません。ブラウザーは明示された各子に境界内のグリッドスロットを割り当て、子チェーンを最大 4 階層まで再帰的に展開します。構成要素の参照先としてのみ必要なレコードには `hidden: true` を設定します。このレコードは詳細で解決および深層リンクできますが、表のカードとしては表示されません。子レコードは実際の概念上の親を参照し、独立したライブラリ項目のまま保持されます。ポインターを浮遊バリエーションへ移動して詳細を開けます。レイヤーは `rowSize` と、コンテンツレコード ID、数値の `displayId`、または明示的な空欄 `{ "blank": true }`（`null` も引き続き対応）を並べた `items` を持つ `grid` を定義できます。ブラウザーは表内の位置を保持し、指定された行幅に合わせて各カードを拡縮します。権限を持つコンテンツ所有者と管理者の選択チェックボックスは、カードを右クリックするまで非表示で、右クリック後はダークテーマに対応した状態でライブラリ全体に表示されます。完全な作成契約は `study-language-framework.ja.md` にあります。 メタデータフィルターグループでは、常に 1 つのタグを選択状態に保つ `required: true` と、モジュール指定の初期タグを選ぶ `defaultTag` を宣言できます。表示タグが 1 つだけのグループでは、そのタグが自動選択されます。 レイヤーに `minimal: true` を設定すると、通常のクリック、長押しによるバリアント表示、選択操作を維持したまま、各エントリの主要ラベルだけをコンパクトなカードに表示できます。 コンテンツパックの文レコードは、順序付きの語彙単位および助詞への参照によって全文を表す必要があり、リンクされていないテキストを含むラベルはインポート時に拒否されます。 レコードに `hidden: true` を設定すると、参照や詳細ポップアップでは利用可能なまま、そのレコードとすべての子孫を直接の一覧表示から除外できます。

## ローカライズされた定義

意味役割が `definition` の各レイヤーは、モジュール所有の文字列キープレフィックスと、文字列キーおよびローカライズ済みテキストのフィールドを宣言します。定義は、それを必要とする項目の編集時にのみ管理し、独立したライブラリ区画として直接閲覧または編集できません。英語は引き続き必須の原文であり、生成キーは定義レコードに保持され、未入力言語は任意の `localization:translateString` ケイパビリティで補完できます。

## 書記単位の発音と音声

`atomicWritingUnit` または `compoundWritingUnit` ロールのレイヤーは、必須の標準フィールド `pronunciation`（`stringList`）と `audio`（`audio`）を宣言します。コンテンツパックは MP3、Ogg、WAV、WebM、M4A ファイル、または HTTPS URL を提供できます。ローカルファイルは認証済みパックアセットとして扱います。リモート音声は項目の認可を行うライブラリルート経由で取得し、公開 HTTPS ホストと対応音声メディアタイプのみに制限します。ライブラリはファイルゲートウェイへコンポーネント管理の `study-library-audio` 名前空間を登録し、アダプター側のサイズ上限を設けず、URL ごとに決定的なキーで一度だけ保存します。永続化、容量制限、物理ファイル管理はファイルゲートウェイが担い、各再生リクエストでは引き続き項目の範囲を検証します。 文字と代替文字の発音はカードと詳細タイトルで書記単位の横に表示し、単語と文の発音はテキストの下に表示します。モジュールは `lexicalUnit` レコードに 1 つの文字参照を設定することで、単独で意味を持つ 1 文字の単語をモデル化できます。文字の詳細には、その入力側の単語関係が表示されますが、ライブラリが内容を自動生成することはありません。 ポップアップタイトル横の書記単位の発音には、エスケープ済みの副タイトル契約を使用し、より小さい標準ウェイトの文字で表示します。音声領域は強制的な色置換を無効化し、ダークモードでネイティブ操作部の彩度を除去します。

## メタデータフィルターグループ

バッジフィールドは `detail.group` で関連フィルターをまとめ、`detail.exclusive` で選択方法を指定できます。グループ内の全フィールドが `exclusive: true` を宣言すると、ピルを選ぶ際に以前のグループ選択が解除されます。既定値の `false` では複数のピルを選択できます。同じ名前のグループに属する全フィールドは同一の排他設定を使用する必要があります。

## 認証済み音声再生

Study ゲートウェイクライアントは認証済み API クライアントを通じて項目の音声を取得し、一時オブジェクト URL をプレイヤーへ渡します。詳細ポップアップを閉じると URL は破棄されます。ネイティブのプレイヤー操作部はライトとダークの配色に対応し、現在のアプリケーションテーマに従います。

## 構造化表示

各レイヤーのローカライズ済みメタデータが表示名になります。文字以外のレイヤーは `displayDefinition: true` を指定でき、その場合は必須の定義リレーションと、各インポート項目からその定義への参照が必要です。言語モジュールは `study:library:composeEntryDetail` を通じて、言語固有の助詞効果を含む文の統合定義を提供できます。Cognis 自体は言語コンテンツを生成しません。宣言済みで空ではなく、非表示でないフィールドだけを汎用表示します。グリッドではレコード ID、数値の `displayId`、空白を表す `{ "blank": true }` を利用できます。

定義項目は直接開いたりリンクしたりせず、他の項目へローカライズ済みテキストを提供するためだけに使用します。表示する翻訳は、現在の UI 言語のものに限定します。リゾルバー関係は `presentationRole` の `composition`、`alternateSpelling`、`pronunciation` を区別し、単語全体の読みを曖昧な文字列として表示しません。

構成が現在の項目と同じラベルを持つ 1 項目だけの場合は、重複する構成ブロックを表示せず、そのディープリンクをポップアップ見出しとして表示します。

ページコンポーザーのウィジェットはライブラリスキーマに合わせて縮み、利用可能な幅を上限とするため、余分なウィジェット幅による横方向のはみ出しを防ぎます。
