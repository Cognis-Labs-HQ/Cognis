# Study リーダーボード

## プロバイダー連携

アダプターは `study:leaderboard` を `ctx` で公開します。言語パックなどの Study プロバイダーは Bootstrap 時にこの Capability を取得し、クラスルームまたは参加選択式イベントの定義を登録できます。定義では辞書順または加重順位、最低証拠数、ローリングまたはシーズン期間、同順位規則、コホート方針、任意の昇格・降格を指定します。

プロバイダーは完了した集合を公開 Capability `engagement:recordActivity` に送ります。得た XP をリーダーボードへ反映するには、認可済みアクター、定義 ID、基準 ID、同じ証拠付きアクティビティ集合を指定して `study:leaderboard` の `scoreActivity` を呼び出します。リーダーボードは記録前にすべてのイベントを `study:progress` で検証します。

## プライバシーとクラス

プロフィール可視性判定が閲覧者への本人表示を許可しない限り、順位表には別名を表示します。ブロックと非公開アカウントの規則はクラスルームでも有効です。コホート割り当てと参加設定は定義単位なので、クラス、個人、イベントの競争を対象者を混在させず併存できます。

## ライフサイクル

`rollover` で終了シーズンを保存し、次のシーズンを開始します。訂正時は置換前に以前の証拠を無効化します。アクセシブルでローカライズ済みの表には `requestTableModel`、中立な順位モデルには `queryStandings` を使用します。
