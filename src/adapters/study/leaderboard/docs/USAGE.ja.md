# 使用例

ランキング の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/adapters/study/leaderboard)を確認してください。

## 使用例

- ランキングを選び、参加者と集計期間を確認します。
- 得点と順位の変化を比較します。自分の位置がある場合は行が強調されます。
- 選択したランキングで自分の行とスコアを確認します。ランキングを切り替えると、集計対象の活動も変わります。

## 期待される結果

この例は ランキング の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/adapters/study/leaderboard/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

ランキング を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
