# ランキング

各アカウントの公開設定を守りながら、対象となる学習成果を比較できます。

## できること

許可されたグループで、確認済みの学習活動に基づく順位を見られます。

## 始める前に

ログインが必要です。クラスには現在の参加資格が、一部のイベントには参加同意が必要です。

## はじめに

学習のランキングで利用可能な表を開きます。

## 詳しい情報

手順は[使用例](/docs/adapters/study/leaderboard/usage)、インターフェースと設定は[技術情報](/docs/adapters/study/leaderboard/technical)を参照してください。
