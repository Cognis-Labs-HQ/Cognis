# ランキング

各アカウントの公開設定を守りながら、対象となる学習成果を比較できます。

## できること

- ランキングを選び、参加者と集計期間を確認します。
- 得点と順位の変化を比較します。自分の位置がある場合は行が強調されます。
- 選択したランキングで自分の行とスコアを確認します。ランキングを切り替えると、集計対象の活動も変わります。

## 始める前に

ランキング が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/study/leaderboard) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/study/leaderboard/usage)、インターフェースと設定は[技術情報](/docs/adapters/study/leaderboard/technical)を参照してください。
