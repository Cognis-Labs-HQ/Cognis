# Rangliste

Vergleichen Sie zulässige Lernerfolge unter Berücksichtigung der Kontosichtbarkeit.

## Möglichkeiten

Sieh Ranglisten aus bestätigten Lernaktivitäten in erlaubten Gruppen.

## Vor dem Start

Melde dich an; Klassenlisten verlangen aktuelle Mitgliedschaft, manche Ereignisse eine Teilnahmefreigabe.

## Erste Schritte

Öffne Rangliste unter Lernen und wähle eine verfügbare Liste.
