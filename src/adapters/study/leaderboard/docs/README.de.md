# Rangliste

Vergleichen Sie zulässige Lernerfolge unter Berücksichtigung der Kontosichtbarkeit.

## Möglichkeiten

- Wählen Sie eine Rangliste für Teilnehmer und Wertungszeitraum.
- Vergleichen Sie Punkte und Rangänderungen; markierte Zeilen zeigen gegebenenfalls Ihre Position.
- Finden Sie Ihre Zeile und vergleichen Sie Punkte innerhalb der gewählten Rangliste. Andere Ranglisten messen andere Aktivitäten.

## Vor dem Start

Prüfen Sie, ob Rangliste aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/study/leaderboard) und wählen Sie die gewünschte Aktion.
