# クラス

言語のクラスに参加したり、教師として授業や参加者を管理したりできます。

## できること

- 言語で絞り込み、利用できるクラスを探します。
- メンバーと申請状況を確認します。チャットと会議にはクラスのアクセス条件が適用されます。
- 教師は担当クラスと招待を管理します。教師になる申請には管理者の承認が必要な場合があります。

## 始める前に

クラス が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/my-classes) を開き、必要な操作を選びます。

手順は[使用例](/docs/adapters/study/classes/usage)、インターフェースと設定は[技術情報](/docs/adapters/study/classes/technical)を参照してください。
