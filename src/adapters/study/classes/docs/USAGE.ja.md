# 使用例

クラス の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/adapters/study/classes)を確認してください。

## 使用例

- 言語で絞り込み、利用できるクラスを探します。
- メンバーと申請状況を確認します。チャットと会議にはクラスのアクセス条件が適用されます。
- 教師は担当クラスと招待を管理します。教師になる申請には管理者の承認が必要な場合があります。
- 所属するクラスと言語を確認してから、クラスを開きます。
- 利用できるクラスと申請状況を確認し、同じ申請を重ねて送らないようにします。
- 学習言語に合うクラスの詳細を確認して参加を申請します。承認後に所属が更新されます。

## 期待される結果

この例は クラス の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/adapters/study/classes/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

クラス を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
