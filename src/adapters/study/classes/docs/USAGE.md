# Usage

Practical procedures for Classes.

## Prerequisites

Review [the access requirements](/docs/adapters/study/classes) before performing these procedures.

## Examples

- Filter classes by language to find the classes available to you.
- Review class members and request status; class chat and meetings follow the class access rules.
- Teachers manage assigned classes and invitations; teacher requests may require administrator approval.
- Review the classes you belong to and check the language before opening a class.
- Browse available classes and check whether a join request is pending before applying again.
- Choose a class matching your language and review its details before requesting to join. Your membership updates when the request is approved.

## Expected Results

The example uses the documented interface of Classes. Confirm the response or saved state described in [Technical](/docs/adapters/study/classes/technical) before repeating a write operation.

## Troubleshooting

If Classes is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
