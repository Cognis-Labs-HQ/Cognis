# Kurse

Treten Sie einem Sprachkurs bei oder verwalten Sie als Lehrkraft Unterricht und Mitgliedschaften.

## Möglichkeiten

- Filtern Sie Kurse nach Sprache, um verfügbare Kurse zu finden.
- Prüfen Sie Mitglieder und Anfragestatus; Chat und Besprechungen folgen den Kursberechtigungen.
- Lehrkräfte verwalten zugewiesene Kurse und Einladungen; Lehranfragen können eine Freigabe erfordern.

## Vor dem Start

Prüfen Sie, ob Kurse aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/my-classes) und wählen Sie die gewünschte Aktion.
