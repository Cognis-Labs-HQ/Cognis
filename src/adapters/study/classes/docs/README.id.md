# Kelas

Bergabunglah dengan kelas bahasa atau kelola pelajaran dan keanggotaan sebagai guru.

## Yang Dapat Anda Lakukan

Jelajahi kelas, minta keanggotaan, dan kelola kelompok ajar.

## Sebelum Memulai

Masuk; pengajaran dan keanggotaan mengikuti kebijakan Study.

## Langkah Awal

Buka Kelas untuk menjelajah atau Kelas Saya untuk keanggotaan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/study/classes/usage) menjelaskan prosedur. [Teknis](/docs/adapters/study/classes/technical) mendokumentasikan antarmuka dan konfigurasi.
