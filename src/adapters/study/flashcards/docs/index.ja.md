# フラッシュカードアダプター

## 使用方法

Study のフラッシュカードアダプターを有効にすると、閲覧可能な任意の層から名前付きデッキを作成し、Anki 対応 TSV ノートを取り込めます。ルート、保存、描画、学習予定、画面、翻訳はすべてアダプターが所有します。カードを裏返すと読みと定義を表示します。「もう一度」は 1 分後、「良い」は 1 日から倍増、「簡単」は 4 日から 3 倍の間隔で復習します。

## 技術仕様

デッキのリソース種別は `studyDeck`、閲覧権限は `study:flashcards:read` です。標準の Cognis 共有はユーザー宛て共有、公開リンク、有効期限、パスワード、取り消しに対応します。編集と削除は所有者だけが行えます。受信者は学習とエクスポートが可能で、復習予定はアカウントごとに保存します。リンクのゲストは一時セッションで学習し、アカウントの予定を変更しません。各操作で期限と共有状態を確認します。

共有は選択したカードと定義を含むデッキのスナップショットを明示的に共有し、元のライブラリへの権限付与や範囲変更は行いません。所有者の編集でスナップショットを更新します。所有者の学習では閲覧できなくなった元カードを省きます。共有済みの内容は所有者がデッキを編集または削除するまで保持します。デッキ削除は共有を取り消し、復習記録も削除します。

入出力は UTF-8 の引用符付きタブ区切りテキストで、列は Front、Back、任意の Pronunciation です。出力には Anki 用の区切り文字、デッキ、プレーンテキスト指定と、省略可能な Cognis コンテキスト列を含めます。Anki では追加列を無視できます。引用符、タブ、改行を保持します。これは TSV 交換であり `.apkg` ではありません。個人の復習履歴は出力しません。
