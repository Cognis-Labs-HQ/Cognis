# フラッシュカードアダプター

## 上限付きデッキ文書

デッキの所属項目、インポートしたノート、学習予定は、最大60,000 UTF-8バイトのUnicode境界を守る断片で保存します。単一の結合クエリで確定済みの文書を復元し、置換と削除はデッキのトランザクション内で実行します。学習者行へのupsertで、Repeatable Readを含めスナップショット読み取り前に復習とデッキ編集を直列化します。試行の受領記録は予定と同時に確定し、Progressへの配信はトランザクション外で実行します。応答とエクスポートのカードやスキーマは最新のLibrary項目IDを参照し、保存時にLibraryカードの内容を重複保存しません。

評価要求のJSONは最大16 KiB、デッキの書き込みは最大5 MiBです。超過した要求はデッキや予定を変更せずHTTP 413になります。読み、書き、再試行のキュー、インポートしたノート、ライブラリに基づくカードの動作は維持します。

練習では問題と単一の答えの確認画面を使い、表裏の切り替えは行いません。不正解、回答済みカード、「答えを表示」では、ライブラリに基づく完全な確認と従来の「もう一度」の評価を維持します。文だけのデッキは読み練習になり、書けるデッキの保存済み設定を変えずにフローティングモード選択を非表示にします。混在デッキでは選択したモードを維持します。文や長い回答は、ページ幅の範囲内で最大72remまで広がります。不正な言語タグはHTTP 400とinvalid_languageを返します。

読み練習では、カードの表記と異なる場合に主な発音を横に表示します。正規化後に同じ文字列は重複表示しません。丸い「？」のヒントは、選択肢の並び順にかかわらず現在の正解を強調し、フォーカスを移します。ヒントを使うと既存の復習フローで「もう一度」が記録され、その後に正解しても支援ありの回答として扱われます。支援なしの正解は従来どおり「良い」と評価されます。書き練習のガイド機能は独立して維持されます。

「もう一度」は、選択した対象の最新の待ち列にカードがある場合のみ表示されます。対象が空の場合は、お祝いのメッセージと「ホーム」を表示し、空の練習を再開する操作は表示しません。

デッキを完了すると、中央に緑のチェックとお祝いのメッセージが表示されます。「ホーム」は「すべて」に戻ります。「もう一度」は、送信済みの復習でカードの状態が変わっても、合計・完了・期限・新規の選択を維持し、最新の復習状態から対象カードを再選択して先頭から再開します。セッションの回答と試行IDのみがリセットされ、保存済みの復習記録は維持されます。共有リンクでの練習にも同じ完了画面と一時セッションの再開が適用されます。

## 使用方法

表示可能なデッキを開くとすぐに練習を開始します。合計・完了・復習・新規から対象カードを選びます。

## 技術仕様

デッキのリソース種別は `studyDeck`、閲覧権限は `study:flashcards:read` です。標準の Cognis 共有はユーザー宛て共有、公開リンク、有効期限、パスワード、取り消しに対応します。編集と削除は所有者だけが行えます。受信者は学習でき、復習予定はアカウントごとに保存します。エクスポートは作成者または管理者だけが行えます。リンクのゲストは一時セッションで学習し、アカウントの予定を変更しません。各操作で期限と共有状態を確認します。

共有は、カードの範囲や一般的なライブラリ権限を変更せず、デッキ内の現在のカードと定義へのアクセスを許可します。共有権限を確認してから、所有者の権限で各IDを取得します。利用できないカードや無効な提供元の内容は省略します。ギャラリー情報と評価応答では保存済みカードのコピーを公開しません。デッキ削除時は共有を取り消し、学習予定と回答の受領記録も削除します。

入出力は UTF-8 の引用符付きタブ区切りテキストで、列は Front、Back、任意の Pronunciation です。出力には Anki 用の区切り文字、デッキ、プレーンテキスト指定と、省略可能な Cognis コンテキスト列を含めます。Anki では追加列を無視できます。引用符、タブ、改行を保持します。これは TSV 交換であり `.apkg` ではありません。個人の復習履歴は出力しません。

## Study の閲覧とお気に入り

Flashcards は所有するデッキ、アカウントに共有されたデッキ、有効な言語プロバイダーの完全なスターターデッキを一覧表示します。共有リンクのアクセス規則は維持され、公開ディレクトリーにはなりません。ウィジェット右上の + メニューでデッキの作成とインポートを選択します。Explore、Library、Flashcards はアカウントに保存される Study のお気に入りと並べ替え（提供順、A–Z、Z–A、新しい順、古い順）を再利用します。星はお気に入りだけを表示すると金色になります。Library 項目、デッキ、個々の学習カードのお気に入りは独立しています。お気に入りはアクセス権を追加しません。描画パッドは画面遷移時にセッションを終了し、composer や shell のクラスを上書きしません。

## プロバイダーのスターターデッキ

言語記述子は `starterDecks` に `{ key, name, schemaId, sourceRecordIds }` の配列を宣言できます。`key` はパック内で安定し、`name` は言語別の名前、`sourceRecordIds` は学習順の最大500件の重複しない既存レコードキーです。Cognis がグローバル Library のキーを正規 Library ID に解決します。デッキIDはコンテンツ改訂後も維持され、不完全なデッキと無効なプロバイダーは除外されます。スターターデッキは読み取り専用で、進捗とお気に入りは個人ごとに保持します。閲覧時は所属だけを解決し、開いた時にカード詳細を読み込みます。

FlashcardsはExploreとRequestsと同じpage-builderおよびpage-sectionsの共有スタイルを読み込みます。各マウントは中断可能なイベントスコープを持ち、移動後に以前の一覧・学習ハンドラーが残らないようにします。アダプターはコンポーザー、シェル、共有ボタンのクラスを上書きせず、回帰テストでこの境界と必須スタイルを確認します。

デッキ作成・インポート成功時は保護された編集画面を閉じてから更新済み一覧へ移動するため、保存後に破棄確認が表示されません。お気に入りのみのLibrary一覧では子カードを独立して表示し、プロバイダー順に戻すと元の入れ子配置を復元します。

## 保存される学習設定

読み書きモードは Composer のフローティングメニューで保存するアカウント設定です。既定は読み方です。練習中の変更は共通の警告ポップアップで確認してからキューを再開します。キャンセルすると位置と回答を維持し、送信済みの復習記録も保持します。サイドバーには「すべて」を追加し、現在のデッキを示します。共有の描画見出しは、明示的に表示するまで文字をマスクします。再度操作すると Explore 以外では移動を確認し、Explore 内ではカードを直接開きます。キーボードでも同じ操作ができます。

新しい語彙カードは入力確定時と保存前に辞書で品詞と対応する活用タグを自動検出します。手動のタグを維持し、曖昧な品詞は利用者が選択します。遅れて届いた結果で別の下書きを変更しません。選択中の動詞・形容詞の副詞形・複数形はその変形に対応する音声を要求します。見出しの出典表示から基本カードへ移動できます。アップロード欄と再生用音声要素のセレクターを分離し、文字エディター初期化時のエラーを修正しました。

デッキのサイドメニューはページ全体と一緒にスクロールします。メインナビゲーションを表示しても、独立したサイドバーのスクロール領域が伸縮したりカードがずれたりしません。

## 学習モードの表示とテーマ対応

フラッシュカードの永続的な読み・書き選択をフローティング領域に表示します。変更時の設定保存とセッション再開の確認を維持します。エクスポートと Study 設定のアイコンは操作要素の文字色を使用し、OS のテーマに関係なくアプリの明暗テーマとホバー状態に追従します。

回答には`id`とISO形式の`occurredAt`を持つ`attempt`オブジェクトを指定できます。再送では同じオブジェクトと評価を使い、新しい回答には新しいIDを割り当てます。受領記録と学習予定を同時に保存し、安定したイベントIDで進捗の重複を防ぎます。保留中の試行はURLに含めずブラウザー履歴で保持します。フラッシュカードはライブラリと進捗への依存を宣言します。共有カードとスキーマは、共有権限確認後に現在のライブラリ情報を取得します。

## 練習報酬の永続化

フラッシュカードの予定と試行記録は、アダプター間の報酬配信より先に確定します。別フローの`study:decks:recordResult`は、配信失敗後も予定を再度進めずに同じ結果を再送します。これにより、Progressによるイベント保存でデータベースのトランザクションが入れ子になることを防ぎます。

フラッシュカードの選択肢は回答専用のボタンです。カードの見出しと表示された回答は、ホバー時にカードの URL を表示せず、移動時の確認とデッキの順序を維持するアプリ内操作を使用します。Explore 内では、表示された描画見出しをもう一度クリックすると、URL を持たない操作でカードを直接開きます。

書き取り練習では描画パッド内のマスクされた見出しだけを使用します。前後のカードに移動する SVG 矢印は、お気に入り操作とともにパッドの上に配置し、次への移動には回答が必要です。Flashcards は共有パッドに `suppressRetry: true` を渡して再試行を非表示かつ無効にし、単独の描画練習では既定で再試行を許可します。

埋め込み側は、共有の見出しの確認後に呼ばれる `onNavigate(card)` を指定できます。Flashcards はこの処理で移動用フローを通じて現在の試行を記録し、Explore を開く前にデッキの移動情報を維持します。

ブラウザーの主なエントリーポイントは `ui/app/index.js` で、操作、表示、言語、練習の各モジュールを同じ場所に配置します。共有デッキは `ui/app/shared-deck.js` を使用します。サーバー側のデッキ処理は `service/index.ts` を入口に、同じサービスディレクトリ内のルート、フロー、ストレージ、結果モジュールを使用します。

## 練習の選択を均等化

描画ガイドとフラッシュカードの解答シャッフルは`randomIndex`ヘルパーを共有します。Web Cryptoとマスク付き棄却サンプリングにより、1から2^32までの整数範囲で剰余による偏りを防ぎます。選択肢が1つの場合は乱数を消費しません。決定的なテストのために乱数源を注入できますが、通常の練習では常にWeb Cryptoを使用します。

読む練習では、選択肢、ヒント、採点に共通の回答正規化を使用します。文末の句読点、大文字・小文字、互換 Unicode 表記、連続する空白では回答を区別しません。文中の句読点、数字、アクセント、異なる単語は意味のある違いとして保持します。同等の意味を競合する選択肢にはせず、異なる回答が2〜4個あれば出題できます。同等の正しい回答は、進捗送信前に通常の成功評価を受けます。

デッキのサイドメニューは表示中のページの高さに収まり、独立してスクロールします。デッキが増えてもページ全体を引き伸ばしたり、練習画面を下へ押し出したりしません。

別のデッキを開くと内容をすぐに表示します。Explore から戻る場合は保存済みの練習位置を維持します。

## オフライン学習の空画面

準備済みの Study ページは、検証済みで必要な同意を満たすオフラインセッションなら非公開コンテンツの保存がなくても開けます。未保存の言語や設定は空のナビゲーションになります。Explore は通常の空の一覧を表示し、ルート利用不可やエラー通知の代わりに「オフライン用に保存されたコンテンツはありません」と案内します。Flashcards もデッキや必要な表示リソースがなければ空画面を維持します。通知は現在のページに限定し、重複表示しません。キャッシュ不足を理由にアクセス拒否や同意拒否を隠しません。Library と Flashcards は公開の翻訳や軽量テンプレートをオンラインで準備し、非公開データは容量制限付きのタブ内キャッシュに留めます。

## 保存済みキューの結果

キュー内のカード評価は、任意の活動記録に失敗しても成功結果を維持します。活動記録は評価結果の返却を待たせません。既存のアカウント、同意、キューの制限は引き続き適用されます。

## オフライン作業環境

Flashcards は登録済みの学習・指導言語で表示対象となる全デッキを、2 ワーカーで準備します。80 件の打ち切りはありません。専用キャッシュは 64 MB、10,001 件の読み取りに制限し、ギャラリーと通常のデッキ集合を一緒に保持します。大きな集合には引き続きこの上限が適用されます。未登録言語は対象外です。共通スキーマ一覧は言語未登録でも準備し、任意の Library コレクションが未取得でも準備済みデッキで練習できます。

## オフラインの Study 練習

登録言語の準備では、言語別カタログに加えて共通のスキーマカタログもキャッシュします。描画と Flashcards はオンラインで事前にページを開かなくても通常のスキーマ読み取りを利用できます。Flashcards は Study と Share の翻訳およびギャラリーテンプレートを準備し、登録時の準備と同じスキーマ指定の要求で選択言語のコレクションを読み取ります。準備済みデッキはギャラリーと練習画面をオフラインで開けます。音声、辞書取得、コンテンツ編集、アクセス・同意確認の制限は引き続き適用します。
