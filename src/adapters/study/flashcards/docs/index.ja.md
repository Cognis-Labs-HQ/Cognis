# フラッシュカードアダプター

## 使用方法

表示可能なデッキを開くとすぐに練習を開始します。合計・完了・復習・新規から対象カードを選びます。

## 技術仕様

デッキのリソース種別は `studyDeck`、閲覧権限は `study:flashcards:read` です。標準の Cognis 共有はユーザー宛て共有、公開リンク、有効期限、パスワード、取り消しに対応します。編集と削除は所有者だけが行えます。受信者は学習でき、復習予定はアカウントごとに保存します。エクスポートは作成者または管理者だけが行えます。リンクのゲストは一時セッションで学習し、アカウントの予定を変更しません。各操作で期限と共有状態を確認します。

共有は、カードの範囲や一般的なライブラリ権限を変更せず、デッキ内の現在のカードと定義へのアクセスを許可します。共有権限を確認してから、所有者の権限で各IDを取得します。利用できないカードや無効な提供元の内容は省略します。ギャラリー情報と評価応答では保存済みカードのコピーを公開しません。デッキ削除時は共有を取り消し、学習予定と回答の受領記録も削除します。

入出力は UTF-8 の引用符付きタブ区切りテキストで、列は Front、Back、任意の Pronunciation です。出力には Anki 用の区切り文字、デッキ、プレーンテキスト指定と、省略可能な Cognis コンテキスト列を含めます。Anki では追加列を無視できます。引用符、タブ、改行を保持します。これは TSV 交換であり `.apkg` ではありません。個人の復習履歴は出力しません。

## Study の閲覧とお気に入り

Flashcards は所有するデッキ、アカウントに共有されたデッキ、有効な言語プロバイダーの完全なスターターデッキを一覧表示します。共有リンクのアクセス規則は維持され、公開ディレクトリーにはなりません。ウィジェット右上の + メニューでデッキの作成とインポートを選択します。Explore、Library、Flashcards はアカウントに保存される Study のお気に入りと並べ替え（提供順、A–Z、Z–A、新しい順、古い順）を再利用します。星はお気に入りだけを表示すると金色になります。Library 項目、デッキ、個々の学習カードのお気に入りは独立しています。お気に入りはアクセス権を追加しません。描画パッドは画面遷移時にセッションを終了し、composer や shell のクラスを上書きしません。

## プロバイダーのスターターデッキ

言語記述子は `starterDecks` に `{ key, name, schemaId, sourceRecordIds }` の配列を宣言できます。`key` はパック内で安定し、`name` は言語別の名前、`sourceRecordIds` は学習順の最大500件の重複しない既存レコードキーです。Cognis がグローバル Library のキーを正規 Library ID に解決します。デッキIDはコンテンツ改訂後も維持され、不完全なデッキと無効なプロバイダーは除外されます。スターターデッキは読み取り専用で、進捗とお気に入りは個人ごとに保持します。閲覧時は所属だけを解決し、開いた時にカード詳細を読み込みます。

FlashcardsはExploreとRequestsと同じpage-builderおよびpage-sectionsの共有スタイルを読み込みます。各マウントは中断可能なイベントスコープを持ち、移動後に以前の一覧・学習ハンドラーが残らないようにします。アダプターはコンポーザー、シェル、共有ボタンのクラスを上書きせず、回帰テストでこの境界と必須スタイルを確認します。

デッキ作成・インポート成功時は保護された編集画面を閉じてから更新済み一覧へ移動するため、保存後に破棄確認が表示されません。お気に入りのみのLibrary一覧では子カードを独立して表示し、プロバイダー順に戻すと元の入れ子配置を復元します。

## 保存される学習設定

読み書きモードは Composer のフローティングメニューで保存するアカウント設定です。既定は読み方です。練習中の変更は共通の警告ポップアップで確認してからキューを再開します。キャンセルすると位置と回答を維持し、送信済みの復習記録も保持します。サイドバーには「すべて」を追加し、現在のデッキを示します。書字の見出しは同じ大きさの代替文字をぼかします。最初のクリックで文字を表示して Explore リンクを有効にし、次のクリックで移動を確認します。キーボードでも同じ操作ができます。

新しい語彙カードは入力確定時と保存前に辞書で品詞と対応する活用タグを自動検出します。手動のタグを維持し、曖昧な品詞は利用者が選択します。遅れて届いた結果で別の下書きを変更しません。選択中の動詞・形容詞の副詞形・複数形はその変形に対応する音声を要求します。見出しの出典表示から基本カードへ移動できます。アップロード欄と再生用音声要素のセレクターを分離し、文字エディター初期化時のエラーを修正しました。

デッキのサイドメニューはページ全体と一緒にスクロールします。メインナビゲーションを表示しても、独立したサイドバーのスクロール領域が伸縮したりカードがずれたりしません。

## 学習モードの表示とテーマ対応

フラッシュカードの永続的な読み・書き選択をフローティング領域に表示します。変更時の設定保存とセッション再開の確認を維持します。エクスポートと Study 設定のアイコンは操作要素の文字色を使用し、OS のテーマに関係なくアプリの明暗テーマとホバー状態に追従します。

回答には`id`とISO形式の`occurredAt`を持つ`attempt`オブジェクトを指定できます。再送では同じオブジェクトと評価を使い、新しい回答には新しいIDを割り当てます。受領記録と学習予定を同時に保存し、安定したイベントIDで進捗の重複を防ぎます。保留中の試行はURLに含めずブラウザー履歴で保持します。フラッシュカードはライブラリと進捗への依存を宣言します。共有カードとスキーマは、共有権限確認後に現在のライブラリ情報を取得します。

## 練習報酬の永続化

フラッシュカードの予定と試行記録は、アダプター間の報酬配信より先に確定します。別フローの`study:decks:recordResult`は、配信失敗後も予定を再度進めずに同じ結果を再送します。これにより、Progressによるイベント保存でデータベースのトランザクションが入れ子になることを防ぎます。
