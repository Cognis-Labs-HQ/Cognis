# Usage

Practical procedures for Flashcards.

## Prerequisites

Review [the access requirements](/docs/adapters/study/flashcards) before performing these procedures.

## Examples

- Choose a deck from the sidebar and check which language and cards it contains.
- Review the available study modes and filters before beginning practice.
- Use the practice controls to answer and review cards; progress belongs to your account.
- Create a deck, give it a useful name, and select library cards for it. Check the selected cards before saving.
- Read the prompt and enter or choose an answer. In writing practice, use the drawing controls and stroke hints to work through the character.
- After answering, compare the feedback and revealed answer. Continue through the cards and use previous/next controls when available.
- Edit a deck you own to change its name or selected cards. Review the selection before saving and keep useful cards for your next practice.
- Use the sharing control to choose recipients and access. Review the sharing dialog before confirming who can use the deck.

## Expected Results

The example uses the documented interface of Flashcards. Confirm the response or saved state described in [Technical](/docs/adapters/study/flashcards/technical) before repeating a write operation.

## Troubleshooting

If Flashcards is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
