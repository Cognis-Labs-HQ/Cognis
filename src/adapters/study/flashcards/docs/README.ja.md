# フラッシュカード

保存したデッキで読み書きを練習し、自分のコレクションを管理できます。

## できること

デッキの作成、入門デッキの検索、読み書きの練習ができます。

## 始める前に

ログインして登録済みの言語を選びます。編集や出力には対応するデッキ権限が必要です。

## はじめに

学習のフラッシュカードからデッキを開きます。
