# フラッシュカード

保存したデッキで読み書きを練習し、自分のコレクションを管理できます。

## できること

- サイドバーからデッキを選び、言語と含まれるカードを確認します。
- 練習を始める前に、利用できる学習モードと絞り込みを確認します。
- 練習の操作で回答と復習を進めます。進捗は自分のアカウントに記録されます。

## 始める前に

フラッシュカード が有効であり、アカウントに操作の権限があることを確認してください。
