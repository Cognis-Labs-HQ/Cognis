# 書く練習

選んだ言語のガイドを使い、描画パッドで文字を書く練習ができます。

## できること

[機能のページ](/study) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

書く練習 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/study) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/study/drawing/usage)、インターフェースと設定は[技術情報](/docs/adapters/study/drawing/technical)を参照してください。
