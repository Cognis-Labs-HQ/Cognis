# Schreibübungen

Üben Sie Schriftzeichen auf der Zeichenfläche mit den Hinweisen Ihrer gewählten Sprache.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/study) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Schreibübungen aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/study) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/study/drawing/usage) erklärt Abläufe. [Technik](/docs/adapters/study/drawing/technical) beschreibt Schnittstellen und Konfiguration.
