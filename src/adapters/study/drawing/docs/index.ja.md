# 描画練習

Study は `src/gateways/study/ui/reuse/drawing.js` の描画パッド全体を所有します。キャンバス、操作、ガイド、評価、完了表示を含みます。任意の描画アダプターはブラウザー `uiCtx` に `study:drawing:open` と `study:drawing:load` を公開します。呼び出し側は操作を待機し、完全なライブラリカードと検証済み `strokePattern` を渡します。

## 使用例

同じ `openDrawingPad` は `container`、中断 `signal`、`onResult` を受け取ります。コンテナがない場合は移動・サイズ変更可能なページ内ウィンドウを開き、文字の切り替えでも位置を保持します。指定時はパッド全体を埋め込み、元の文字に固定し、全筆画が筆順通り受理された場合のみ成功を返します。埋め込み練習に任意の描画アダプターは不要です。

## 技術仕様

ペン・タッチ・マウスの入力を筆順・方向・近さで評価し、受理された線を標準線に置き換えます。現在のアカウントで未完了のパターンは、最初の入力前に番号付きの全画を表示します。入力開始後と完了済みのパターンでは、文字の境界を越えて次の一画だけを案内します。全ガイドが表示中はヘルプを無効にします。連続十回の誤りで試行を終了し、結果には誤り数と再試行を表示します。完了状態と非表示のストローク数をアカウントとカードごとに保存します。間違いが一回以下の完了で非表示数を増やし、現在の画数を上限とします。各試行、リセット、再試行で非表示の位置を新たにランダム選択します。

複合パターンは提供データを変更せず、比率・順序・時間・筆圧・ポインターの位置を保持します。注記は筆画を避け、描画は各フレーム一回です。浮動ウィンドウは標準の閉じる SVG を使い、埋め込みパッドはコンテナ内に留まります。コンポーネントのスタイルは composer、ページシェル、サイドメニューを変更しません。

開く・読み込み・筆画・リセット・ガイド・再試行・閉じるは before、execute、after 段階を持つ `study:drawing` フローを実行します。ページ移動や中断でイベント、サイズ監視、描画を解放します。Library と Flashcards は公開 Study reuse 契約を使用します。

共通の描画パッドはブラウザーモジュールごとに専用 HTML テンプレートを一度だけ読み込みます。失敗時は開く操作を拒否し、読み込み中の移動はマウントを中断します。複数字パターンの提供者による文字グループは維持します。

## 書き取りの答えを隠す

パッドの見出しは最初に文字を隠し、共通ボタンをクリックすると表示します。別の文字を読み込むと再び隠します。フローティングセッションは解除可能な `study:drawing:observe` 機能で現在のカードを通知します。一致するLibraryプレビューは開いたままぼかして操作不能にし、パッドの文字変更または終了時に解除します。読みと意味はパッドに残します。埋め込みの書き取りにも同じ処理を適用し、文字の表示を補助付き試行として通知します。
