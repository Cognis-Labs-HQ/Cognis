# 書き取り練習

## 目的

Drawing アダプターはブラウザーの `uiCtx` に `study:drawing:open` を提供します。呼び出し側は完全な Library カードと検証済みの `strokePattern` を渡し、アダプターは移動・サイズ変更可能な PiP 書き取りパッドを開きます。

## 練習モデル

パッドはペン、タッチ、マウス入力に対応し、提供元の筆順を検証して方向と経路の近さを採点し、許容された入力を提供元の正規ストロークに置き換えます。各試行の開始時にはすべてのストロークを表示します。最初のストロークを完了した後は、完了済みの正規ストロークを残しながら、次に必要な一画だけを表示します。

誤ったストロークでは、パッドの開始アニメーションを再実行せず、控えめな赤いフィードバックを表示します。文字を完成すると短い成功音を再生し、チェックマーク、試行中の間違い数、閉じるともう一度の操作を備えた安定した完了オーバーレイを表示します。もう一度を選ぶと、すべてのガイドを表示した新しい試行を開始します。キャンバスを安定させるため、ポインター入力の描画はアニメーションフレームごとに最大 1 回です。

見出しは描画後のキャンバス幅に合わせ、その真上に中央配置します。カード本文とローカライズ済み定義の配置を保ち、内容幅の閉じるボタンには専用の終了アニメーションを使用します。

最初のガイド表示では、すべての画に番号と方向を示します。10回連続で失敗すると、その試行は失敗結果で終了します。ミスが1回以下で完了すると、そのカードのメモリ内難易度が次回以降に向けて上がります。また、パッドを開いたまま別のライブラリカードへ直接切り替えられます。

**?** ガイド操作は、受理済みのストロークと試行結果を保持したまま、未完了のストロークだけに注釈を表示します。「もう一度」では段階的ガイドを維持します。複合パターンには各要素の境界が含まれ、新しく到達した各文字について注釈付きの全体プレビューを一度表示します。注釈の方向は描画後のキャンバス座標で計算されるため、複数文字の長いパターンでも矢印が正確に保たれます。

複合カードでは、主表記を構成するすべての筆記単位を一定の大きさと最小限の間隔で横に並べます。文字の大きさを保つよう描画パッドが広がり、見出しには利用可能な発音とローカライズされた定義も表示されます。

描画パッドは表示領域内に保たれ、内容に応じたコンパクトな高さと表示幅の40パーセント上限を使用するため、長い単語ではウィンドウを過大にせず内容を縮小します。サイズ変更時に最小寸法が入れ替わることもなくなり、1画ずつのガイドにも順序と方向の注記が表示されます。

注釈ラベルは各ストロークの開始点周辺で近い配置候補を評価し、ほかのラベルと描画済みの全ストローク経路を避ける最初の位置を選択します。これにより、完了したユーザーストロークを覆わず、番号付きマーカーを対象ストロークの近くで読みやすく保ちます。

ミスが1回以下の成功した試行では、ランダムに選んだストロークガイドを追加で1本隠し、カードごとの記憶難易度を上げます。隠したストロークはキャンバス隅の疑問符で示され、通常どおり検証されます。右上のガイド操作は、受理済み入力を消去したりカードの学習済み難易度を下げたりせず、現在の試行だけ隠したストロークを表示します。注釈配置は空き距離を最大化するのではなく、近くで最初に見つかった衝突しない位置を優先し、ラベルをストローク開始点の近くに保ちます。

非表示ガイドの疑問符は、学習者が実際にガイドを隠された画に到達したときだけ表示されます。後続の非表示画を事前に知らせることはありません。

開いている描画練習ウィンドウで列数の異なるカードへ切り替えると、ステージの縦横比を再適用し、レイアウト後にキャンバスのビットマップを同期するようになりました。複数文字のパターンがフローティングウィンドウの再描画時に縦へ引き伸ばされません。

Escapeキーを押すと、閉じる操作と同じアニメーションおよび完全な後処理を通して、アクティブな描画練習ウィンドウを閉じます。

描画面は、実際にレンダリングされた幅と高さから、中央配置されたアスペクト比維持の表示領域を算出します。フローティングパッドを拡大縮小しても文字形状を引き伸ばさず、必要に応じて論理ストローク領域の周囲に余白を設けます。ポインター座標・ガイド・注釈・完了ストローク・描画中の線は、すべて同じ表示領域を使用します。

複数文字の書き取りパッドは、各文字の筆画の範囲に合わせて余分な横方向の空白を取り除き、小さく均等な文字間隔を保ちます。ウィンドウの幅をコンパクトなパターンに合わせて縮め、サイズ変更やカード切り替え時も文字の縦横比、筆順、時間情報、筆圧、ポインターの位置合わせを維持します。
