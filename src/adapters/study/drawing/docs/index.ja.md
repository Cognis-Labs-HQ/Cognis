# 書き取り練習

## 目的

Drawing アダプターはブラウザーの `uiCtx` に `study:drawing:open` を提供します。呼び出し側は完全な Library カードと検証済みの `strokePattern` を渡し、アダプターは移動・サイズ変更可能な PiP 書き取りパッドを開きます。

## 練習モデル

パッドはペン、タッチ、マウス入力に対応し、提供元の筆順を検証して方向と経路の近さを採点し、完了した筆画を追跡します。リセットしても学習済みのガイド量は元に戻りません。

ガイドするのは現在の一画だけです。最初はその全経路を示し、成功するほど後続のガイドを段階的に短くします。誤りが続くと、現在のガイドを始点から終点まで伸ばします。リセットは書いた筆画を消しますが、以前のガイド量には戻しません。誤った筆画では赤く揺れ、文字を完成すると緑の揺れと短い生成成功音で知らせます。見出しではカード本文とローカライズ済み定義を横並びにし、内容幅の閉じるボタンを開閉アニメーションに含めます。

見出しは描画後のキャンバス幅に合わせ、その真上に中央配置します。フィードバックの移動量と回転量を抑え、許容された入力筆画はプロバイダーの正規筆画経路に置き換えるため、完成した文字を正確な形で表示できます。
