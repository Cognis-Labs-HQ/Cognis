# 書き取り練習

## 目的

Drawing アダプターはブラウザーの `uiCtx` に `study:drawing:open` を提供します。呼び出し側は完全な Library カードと検証済みの `strokePattern` を渡し、アダプターは移動・サイズ変更可能な PiP 書き取りパッドを開きます。

## 練習モデル

パッドはペン、タッチ、マウス入力に対応し、提供元の筆順を検証し、方向と経路の近さを採点します。完了した画数の進捗、元に戻す・リセット、自由記憶から完全なパターンまでの4段階のガイドを備えます。

筆画採点は両方の経路を均等に再サンプリングし、点ごとの RMS 偏差、終点位置、方向、長さ比を組み合わせるため、密で複雑な文字でも安定します。最初の試行では、ガイド操作やカウンターを表示せずに完全な見本を示します。連続する最初の誤りでは予定の一画を、さらに誤ると次の一画を、最後には完全な見本を表示します。誤った筆画では赤く揺れ、文字を完成すると緑に揺れて短い成功音を生成します。PiP は正方形キャンバスと操作部が収まる寸法を要求し、描画バッファを縦横独立に拡縮し、現在のライト・ダークテーマに追従します。
