# 学習進捗

進捗のイベント、利用者、投影、ケイパビリティの共通型はgateways/study/reuse/progress.tsにあります。ゲートウェイはこの契約のために任意のアダプターの入り口をインポートしません。アダプターは同じケイパビリティと公開エクスポートを維持します。イベントと訂正のJSONは60,000バイトを上限とし、超過した要求は記録前に413になります。既存のプライバシー、クラスの検査、訂正、報酬、再構築のフローは維持します。

進捗アダプターは、不変かつ冪等な学習イベントを記録し、再構築可能な学習者プロジェクションを生成します。各イベントには、実行者、正規コンテンツ識別子と改訂、活動、範囲、試行結果、ヒント、所要時間、完了状態、安全なメタデータが含まれます。

## 使用方法

```ts
const progress = ctx.capabilities.require("study:progress");
const events = await progress.listEvents(actor, {});
```

## 技術仕様

### プライバシーと認可

サービスは読み書きの前に実行者の所有権を検査します。管理者と所有者は別の実行者を参照でき、教室操作にはクラスアダプターのアクセス権も必要です。現在のアクセス権が取り消された教室イベントは広範なクエリから除外されます。

### ケイパビリティとフロー

`study:progress` は記録、補償訂正、検索、集計、再構築を提供します。`study:progress:recordEvent` は `authorize`、`validate`、`observe`、`persist`、`project` の各段階を公開します。

### HTTP API

認証済みクライアントは `/api/v1/study/progress/events`、`/projections`、`/aggregate` を使用し、管理者は `/rebuild` を実行できます。実行者、スキーマ、層、言語、活動、関心領域、教室、イベント、期間で絞り込めます。訂正は履歴を書き換えず追加されます。

認証済みクライアントは訂正を `/api/v1/study/progress/events/corrections` に送信します。訂正は履歴を書き換えず追加されます。補償は、ディメンションまたは期間のフィルターを適用する前に、認可済みの全履歴に対して解決されます。イベントとプロジェクションは DB ゲートウェイを通じて永続化され、再起動後も保持されます。

通常のイベントエンドポイントは `compensatesEventId` を拒否します。対象の認可とスコープ検証を必ず実行するため、クライアントは修正エンドポイントを使用します。永続ストアは、修正要求が同時に到着した場合も、対象ごとに修正を1件だけアトミックに保証します。

### 復習スケジュールの安全性

復習間隔は14日を上限とします。イベントの日時は、その間隔全体を表現できる場合にのみ受け入れます。そのため、受け入れ済みイベントの復習日が対応日時範囲を超え、後のプロジェクション再構築を失敗させることはありません。

安定したイベントIDはデータベースへの保存と読み込み後も維持されます。同一イベントを再送すると、履歴を追加せずに中断した投影を修復します。正規化イベントは内容、対象範囲、時刻、ヒント、正誤、完了状態、補正参照を保持します。

所属する学習者はクラスの閲覧権限で自身の結果を記録でき、編集権限は不要です。他の学習者の結果を記録する場合は引き続き特権が必要です。クラスの対象範囲は現在の所属に従い、デッキ共有だけではクラスへの所属を付与しません。

## 練習報酬の永続化

進捗投影のIDは、PostgreSQLのテキスト列が拒否するNULバイトを含まない、一意なJSON形式の識別子組を使用します。信頼された描画とフラッシュカードの結果は、`study:progress:recordPractice`の認可、検証、イベント記録、報酬の各段階を通ります。未加工のイベント取り込みではXPを付与しません。認証済みの`GET /api/v1/study/progress/engagement`は本人の報酬集計を返します。助けを使わない正解で、翻訳済みの練習バッジを獲得できます。訂正は関連する報酬とランキングの証拠を無効化します。再送では正規のイベントと報酬の識別子を保持します。
