# Lernfortschritt

Prüfen Sie gespeicherte Übungsergebnisse und den Fortschritt Ihrer Lernaktivitäten.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/study) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Lernfortschritt aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/study) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/study/progress/usage) erklärt Abläufe. [Technik](/docs/adapters/study/progress/technical) beschreibt Schnittstellen und Konfiguration.
