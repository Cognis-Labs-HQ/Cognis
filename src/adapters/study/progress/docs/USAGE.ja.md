# 使用例

学習の進み具合 の実践的な操作手順です。

## 前提条件

有効な学習機能で練習します。クラスの記録には現在のアクセス権が必要です。

## 使用例

試行を終えて結果を確認し、後で記録した進捗から続けます。

```ts
const progress = ctx.capabilities.require("study:progress");
const events = await progress.listEvents(actor, {});
```

## 期待される結果

記録は再起動後も残り、信頼された練習は XP の対象になります。修正は履歴を追記します。

## 問題の解決

アカウントとクラスを確認してください。同じ記録の再送で進捗や報酬が増えることはありません。
