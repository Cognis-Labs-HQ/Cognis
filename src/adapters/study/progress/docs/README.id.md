# Kemajuan Belajar

Tinjau hasil latihan tersimpan dan kemajuan dari aktivitas belajar Anda.

## Yang Dapat Anda Lakukan

Simpan percobaan belajar, jadwal tinjauan, dan hadiah latihan antarsesi.

## Sebelum Memulai

Berlatih melalui aktivitas Study aktif; rekaman kelas memerlukan akses saat ini.

## Langkah Awal

Selesaikan aktivitas Kartu Belajar atau Menggambar yang didukung.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/study/progress/usage) menjelaskan prosedur. [Teknis](/docs/adapters/study/progress/technical) mendokumentasikan antarmuka dan konfigurasi.
