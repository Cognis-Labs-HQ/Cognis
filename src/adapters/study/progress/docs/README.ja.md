# 学習の進み具合

記録された練習結果と、学習活動に基づく進み具合を確認できます。

## できること

[機能のページ](/study) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

学習の進み具合 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/study) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/study/progress/usage)、インターフェースと設定は[技術情報](/docs/adapters/study/progress/technical)を参照してください。
