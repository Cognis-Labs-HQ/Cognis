# 登録トークン

必須の登録トークンアダプターは、招待トークンとアカウント作成認可トークンを管理します。有効なメール通知プロバイダーを通じて使い捨てリンクを送信し、ユーザーページで管理者と創設者が招待するときのトークン元になります。

## 使用例

管理者と創設者はユーザーページから招待を発行します。外部認証プロバイダーはアダプターを直接インポートせず、検証済みメールアドレスと登録トークンをアカウント作成ゲートフローへ渡します。

## 技術仕様

公開登録が無効な場合、外部認証が Cognis アカウントを作成するには、セッションに有効なトークンがあり、プロバイダーのメールアドレスが招待先と一致する必要があります。プロバイダーがメールアドレスを返さない場合、アカウントゲートはメール入力が必要であることを報告します。この要求をキャンセルするか認可を省略すると、アカウントを作成せずにログインを中止します。

トークンは外部アカウントの保存後にのみ使用され、一致した招待先アドレスをアカウントの検証済みプライマリメールとして記録します。アカウントまたはメールの保存に失敗した場合、招待は引き続き利用できます。再招待は、新しいメールの送信に成功した後でのみ以前の保留中リンクを置き換えます。

## SSO 承認と招待ポリシー

公開登録が無効な場合、Cognis は認証済みプロバイダー状態を不透明で期限付きの試行 ID の背後に保持し、このアダプター所有のトークンフォームを標準登録シェル内に表示します。「メール」タブは SMTP で招待を送信し、「トークン」タブはメールを送信せず、メールアドレスに関連付けられた登録リンクを作成します。公開登録ではトークン段階を省略します。創設ユーザーが成功させられる登録は最大 10 件です。管理者はこの枠をリセットでき、所有者だけが「管理 → 登録」で創設ユーザーまたは管理者による招待を無効にできます。
