# Undangan Pendaftaran

Undang seseorang membuat akun menggunakan token pendaftaran berbatas waktu.

## Yang Dapat Anda Lakukan

Undang orang memakai tautan pendaftaran sekali pakai yang terikat email.

## Sebelum Memulai

Kebijakan undangan mengatur penerbitan; token mandiri memerlukan administrator atau pemilik.

## Langkah Awal

Gunakan Undang atau kontrol undangan pada Pengguna.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/registration/token/usage) menjelaskan prosedur. [Teknis](/docs/adapters/registration/token/technical) mendokumentasikan antarmuka dan konfigurasi.
