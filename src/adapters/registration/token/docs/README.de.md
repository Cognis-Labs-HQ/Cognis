# Registrierungseinladungen

Laden Sie jemanden mit einem zeitlich begrenzten Registrierungstoken zur Kontoerstellung ein.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/register) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Registrierungseinladungen aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/register) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/registration/token/usage) erklärt Abläufe. [Technik](/docs/adapters/registration/token/technical) beschreibt Schnittstellen und Konfiguration.
