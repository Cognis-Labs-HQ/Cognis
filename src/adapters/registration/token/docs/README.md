# Registration Invitations

Invite someone to create an account using a time-limited registration token.

## What You Can Do

Available actions are shown on [the feature page](/register) according to your account permissions.

## Before You Start

Check that Registration Invitations is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/register) and choose the action you need.

## Learn More

[Usage](/docs/adapters/registration/token/usage) explains procedures. [Technical](/docs/adapters/registration/token/technical) documents interfaces and configuration.
