# 登録の招待

有効期限のある登録トークンを使って、アカウントの作成に招待できます。

## できること

メールに結び付いた一回限りの登録リンクで招待できます。

## 始める前に

発行には招待ポリシーが適用され、単独トークンは管理者または所有者が発行します。

## はじめに

招待画面またはユーザー管理の招待操作を使います。

## 詳しい情報

手順は[使用例](/docs/adapters/registration/token/usage)、インターフェースと設定は[技術情報](/docs/adapters/registration/token/technical)を参照してください。
