# 使用例

登録の招待 の実践的な操作手順です。

## 前提条件

発行には招待ポリシーが適用され、単独トークンは管理者または所有者が発行します。

## 使用例

`cognisctl invite:email:send person@example.com` で送信し、許可された単独リンクには `cognisctl invite:token:generate` を使います。

管理者と創設者はユーザーページから招待を発行します。外部認証プロバイダーはアダプターを直接インポートせず、検証済みメールアドレスと登録トークンをアカウント作成ゲートフローへ渡します。

## 期待される結果

登録成功で招待が使用済みになります。メール配信成功後に以前の未処理招待を置き換えます。

## 問題の解決

期限、招待先メール、ポリシー、配信を確認してください。創設者の未処理招待は最大十件です。
