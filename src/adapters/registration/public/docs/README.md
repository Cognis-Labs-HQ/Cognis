# Public Registration

Create an account without an invitation when public registration is enabled.

## What You Can Do

Available actions are shown on [the feature page](/register) according to your account permissions.

## Before You Start

Check that Public Registration is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/register) and choose the action you need.

[Usage](/docs/adapters/registration/public/usage) explains procedures. [Technical](/docs/adapters/registration/public/technical) documents interfaces and configuration.
