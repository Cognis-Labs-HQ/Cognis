# Pendaftaran Publik

Buat akun tanpa undangan saat pendaftaran publik diaktifkan.

## Yang Dapat Anda Lakukan

Izinkan pengguna baru membuat akun lokal biasa tanpa token undangan.

Registrasi publik membuat akun melalui penyedia registrasi yang aktif dan dapat membuat profilnya melalui kapabilitas yang diinjeksi.

## Sebelum Memulai

Administrator harus mengaktifkan pendaftaran publik secara eksplisit.

## Langkah Awal

Buka formulir pendaftaran instalasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/registration/public/usage) menjelaskan prosedur. [Teknis](/docs/adapters/registration/public/technical) mendokumentasikan antarmuka dan konfigurasi.
