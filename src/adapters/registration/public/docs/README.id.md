# Pendaftaran Publik

Buat akun tanpa undangan saat pendaftaran publik diaktifkan.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/register) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Pendaftaran Publik aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/register) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/registration/public/usage) menjelaskan prosedur. [Teknis](/docs/adapters/registration/public/technical) mendokumentasikan antarmuka dan konfigurasi.
