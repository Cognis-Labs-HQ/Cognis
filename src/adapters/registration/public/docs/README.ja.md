# 公開登録

公開登録が有効な場合は、招待なしでアカウントを作成できます。

## できること

[機能のページ](/register) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

公開登録 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/register) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/registration/public/usage)、インターフェースと設定は[技術情報](/docs/adapters/registration/public/technical)を参照してください。
