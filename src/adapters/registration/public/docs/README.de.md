# Öffentliche Registrierung

Erstellen Sie bei aktivierter öffentlicher Registrierung ein Konto ohne Einladung.

## Möglichkeiten

Erlaube neue lokale Benutzerkonten ohne Einladungstoken.

Die öffentliche Registrierung erstellt ein Konto über den aktivierten Registrierungsprovider und kann dessen Profil über eine injizierte Fähigkeit anlegen.

## Vor dem Start

Ein Administrator muss öffentliche Registrierung ausdrücklich aktivieren.

## Erste Schritte

Öffne das Registrierungsformular der Installation.
