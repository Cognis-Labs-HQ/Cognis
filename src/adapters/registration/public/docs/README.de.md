# Öffentliche Registrierung

Erstellen Sie bei aktivierter öffentlicher Registrierung ein Konto ohne Einladung.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/register) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Öffentliche Registrierung aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/register) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/registration/public/usage) erklärt Abläufe. [Technik](/docs/adapters/registration/public/technical) beschreibt Schnittstellen und Konfiguration.
