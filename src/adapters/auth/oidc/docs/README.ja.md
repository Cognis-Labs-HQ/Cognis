# OpenID Connect

OpenID Connect は、対応する接続機能を構成した環境で外部の認証元によるログインを提供します。

## できること

OpenID Connect のアクセストークンでログインできます。外部の認証情報は引き続き認証元が管理します。

## 始める前に

この認証方式を使うには追加の接続機能が必要です。設定フォームへの入力だけでは認証サービスに接続しません。

## はじめに

この方式を案内する前に、接続機能が用意されているか運用担当に確認してください。ローカル認証を残します。
