# 使用例

OpenID Connect の実践的な操作手順です。

## 前提条件

同梱の OIDC アダプターには動作するプロトコルクライアントが接続されていません。createAdapter() はクライアントが null の状態を返し、setClient() による明示的な連携が必要です。設定だけではログインできません。

## 使用例

クライアントで有効なトークンを取得し、設定済みの Cognis 認証元に送ります。最初は管理者ではない識別情報で試します。

## 期待される結果

クライアントがなければ設定済みでも認証は null を返します。成功の試験にはクライアントを提供する連携環境が必要です。

## 問題の解決

まず接続機能の有無を確認してください。ディスカバリー、署名、通信は注入したクライアントが担当し、ロール設定では代替できません。
