# Lokale Konten

Melden Sie sich ohne externen Kontodienst mit Cognis-Benutzernamen und Passwort an.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/login) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Lokale Konten aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/login) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/auth/local/usage) erklärt Abläufe. [Technik](/docs/adapters/auth/local/technical) beschreibt Schnittstellen und Konfiguration.
