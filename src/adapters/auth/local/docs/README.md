# Local Accounts

Sign in with a Cognis username and password without an external account provider.

## What You Can Do

Available actions are shown on [the feature page](/login) according to your account permissions.

## Before You Start

Check that Local Accounts is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/login) and choose the action you need.

## Learn More

[Usage](/docs/adapters/auth/local/usage) explains procedures. [Technical](/docs/adapters/auth/local/technical) documents interfaces and configuration.
