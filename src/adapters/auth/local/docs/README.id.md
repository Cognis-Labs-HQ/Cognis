# Akun Lokal

Masuk dengan nama pengguna dan kata sandi Cognis tanpa penyedia akun eksternal.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/login) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Akun Lokal aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/login) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/auth/local/usage) menjelaskan prosedur. [Teknis](/docs/adapters/auth/local/technical) mendokumentasikan antarmuka dan konfigurasi.
