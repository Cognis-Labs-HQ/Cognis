# ローカルアカウント

外部の認証サービスを使わず、Cognis のユーザー名とパスワードでログインできます。

## できること

外部の認証サービスを使わず、Cognis のユーザー名とパスワードでログインできます。管理者の復旧用アカウントとしても使えます。

## 始める前に

アカウント作成は登録ポリシーに従います。ローカル認証は必須で、無効にできません。

## はじめに

ログイン画面でローカル認証を選び、Cognis の認証情報を入力します。

## 詳しい情報

手順は[使用例](/docs/adapters/auth/local/usage)、インターフェースと設定は[技術情報](/docs/adapters/auth/local/technical)を参照してください。
