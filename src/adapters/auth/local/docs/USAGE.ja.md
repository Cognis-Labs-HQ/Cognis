# 使用例

ローカルアカウント の実践的な操作手順です。

## 前提条件

他のユーザーの認証情報を管理するには、管理権限のある認証済み CLI セッションが必要です。

## 使用例

`cognisctl user:create` の質問に答えて作成します。ローカルパスワードの変更は `cognisctl user:set-password`、アカウントの停止は `cognisctl user:disable` を使います。

## 期待される結果

作成した認証情報でログインでき、無効なアカウントでは認証できません。登録画面は管理者ではなく一般ユーザーを作成します。

## 問題の解決

ユーザー名、アカウント状態、認証元を確認してください。外部サービスのパスワードはそのサービスで管理します。
