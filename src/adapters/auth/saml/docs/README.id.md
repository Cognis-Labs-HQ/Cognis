# Masuk SAML

SAML menyediakan opsi masuk melalui identitas eksternal bagi penerapan dengan integrasi protokol yang dikonfigurasi.

## Yang Dapat Anda Lakukan

Gunakan layanan identitas SAML organisasi tanpa kata sandi Cognis terpisah untuk identitas tersebut.

## Sebelum Memulai

Metode masuk ini memerlukan integrasi penerapan tambahan. Mengisi formulir pengaturan saja tidak menghubungkan layanan identitas.

## Langkah Awal

Tanyakan kepada integrator apakah klien protokol disediakan sebelum menawarkan metode ini. Pertahankan masuk lokal.

[Penggunaan](/docs/adapters/auth/saml/usage) menjelaskan prosedur. [Teknis](/docs/adapters/auth/saml/technical) mendokumentasikan antarmuka dan konfigurasi.
