# 使用例

SAML ログイン の実践的な操作手順です。

## 前提条件

同梱の SAML アダプターには動作するプロトコルクライアントが接続されていません。createAdapter() はクライアントが null の状態を返し、setClient() による明示的な連携が必要です。設定だけではログインできません。

## 使用例

設定を保存し、一般の組織アカウントからの署名済みアサーションで試します。メールと管理者グループの対応を確認します。

## 期待される結果

クライアントがなければ設定済みでも認証は null を返します。成功の試験にはクライアントを提供する連携環境が必要です。

## 問題の解決

まず接続機能の有無を確認してください。ディスカバリー、署名、通信は注入したクライアントが担当し、ロール設定では代替できません。
