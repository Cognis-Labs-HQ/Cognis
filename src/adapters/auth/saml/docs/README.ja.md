# SAML ログイン

組織が連携している SAML 認証サービスでログインできます。

## できること

[機能のページ](/login) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

SAML ログイン が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/login) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/auth/saml/usage)、インターフェースと設定は[技術情報](/docs/adapters/auth/saml/technical)を参照してください。
