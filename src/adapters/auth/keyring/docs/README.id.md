# Penyimpan Kunci

Simpan rahasia akun di penyimpan kunci terlindungi dan buka saat fitur memerlukannya.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/settings) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Penyimpan Kunci aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/settings) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/auth/keyring/usage) menjelaskan prosedur. [Teknis](/docs/adapters/auth/keyring/technical) mendokumentasikan antarmuka dan konfigurasi.
