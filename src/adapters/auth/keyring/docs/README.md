# Keyring

Keep account secrets in your protected keyring and unlock them when a feature needs them.

## What You Can Do

Available actions are shown on [the feature page](/settings) according to your account permissions.

## Before You Start

Check that Keyring is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/settings) and choose the action you need.

## Learn More

[Usage](/docs/adapters/auth/keyring/usage) explains procedures. [Technical](/docs/adapters/auth/keyring/technical) documents interfaces and configuration.
