# ユーザーキーリングアダプター

## 概要

ユーザーキーリングアダプターは、ブラウザーで暗号化された不透明な保管庫を認証済みアカウント向けに永続化します。ログインプロバイダーにかかわらず、パスワード、暗号鍵、その他のユーザー固有の秘密情報を単一の安定したケイパビリティで扱うための必須認証アダプターです。

ブラウザー側の標準インターフェースは `src/adapters/auth/keyring/ui/keyring.js` のままです。暗号化と復号はブラウザー内で行われ、アダプターが平文の秘密情報を受け取ることはありません。

## 責務

- `db:executor` ケイパビリティを通じて保管庫ストアを初期化する。
- `ctx` を通じてルートファクトリーと保管庫ストアのケイパビリティを提供する。
- 検証済みの不透明な保管庫エンベロープを保存し返却する。

責務外: ユーザー認証、暗号鍵の導出、保存された秘密情報の解釈。

## アーキテクチャ

`src/adapters/auth/keyring/index.ts` は認証ゲートウェイによって自動検出され、`auth:keyringVaultStore` と `auth:keyringRouteFactory` を提供します。ゲートウェイがルートコンテキストをファクトリーへ渡すため、認証検査は注入されたままです。`src/adapters/auth/keyring/store.ts` はデータベース実行ケイパビリティのみを通じて永続化へアクセスします。

## 設定

この必須アダプターに設定項目はなく、有効な `db:executor` プロバイダーを使用します。

## API ルート

| メソッド | パス                   | 説明                             | 認証     |
| -------- | ---------------------- | -------------------------------- | -------- |
| GET      | `/api/v1/auth/keyring` | アカウントの暗号化保管庫を読む。 | ユーザー |
| PUT      | `/api/v1/auth/keyring` | 暗号化保管庫を置き換える。       | ユーザー |
| DELETE   | `/api/v1/auth/keyring` | 暗号化保管庫を削除する。         | ユーザー |

## ブラウザー Capability API

コンポーネントはアダプター内部を直接インポートせず、`uiCtx.capabilities` からキーリング操作を取得します。`keyring:forComponent` で帰属先付きスコープを作成し、Capability が所有する安定した識別子で秘密情報を解決します。解決処理は既存値を検証し、欠落または無効な場合は利用者への入力要求や信頼できる情報源への照会を行えます。ロック状態、項目管理、パスワード変更、操作履歴のページング、一時ゲストキーリングのライフサイクルも Capability として公開されます。

## ログイン時のロック解除動作

ログイン時、アダプターは既存の保管庫をアカウントパスワードで復号できるかだけを試します。失敗した場合は保管庫をロックしたままにし、ロック解除ダイアログを開かず、ダッシュボードへの移動も妨げません。コンテキスト付きのロック解除ダイアログは、コンポーネントがキーリング保護されたコンテンツを解決するときにのみ要求されます。

## ブラウザーセッション内のロック解除復元

ロック解除に成功すると、アダプターは抽出不可能な Web Crypto キーを専用の IndexedDB セッションキーストアに保存し、`sessionStorage` には秘密ではないマーカーだけを書き込みます。同じタブセッションでページを再読み込みした場合、パスワードや抽出可能なキーを保持せずに保管庫のロック解除状態を復元できます。明示的なロック、自動再ロック、アカウントインスタンスの不一致、セッション終了時には復元を無効にします。コンポーネントは引き続き帰属情報付きキーリングスコープからアクセスを要求し、まず復元を試み、利用できない場合だけコンテキスト付きダイアログを開きます。
