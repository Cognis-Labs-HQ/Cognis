# Schlüsselbund

Bewahren Sie Kontogeheimnisse im geschützten Schlüsselbund auf und entsperren Sie sie bei Bedarf.

## Möglichkeiten

Bewahre Passwörter und Schlüssel in einem im Browser verschlüsselten Tresor auf und sperre ihn nach der Nutzung.

## Vor dem Start

Melde dich mit deinem Konto an. Merke dir das Tresorpasswort: Der Server kann Geheimnisse weder lesen noch wiederherstellen.

## Erste Schritte

Öffne Einstellungen und Schlüsselbund. Erstelle bei Bedarf einen Tresor; ein vorhandener kann bis zur nächsten Zugriffsanfrage gesperrt bleiben.
