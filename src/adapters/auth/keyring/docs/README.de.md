# Schlüsselbund

Bewahren Sie Kontogeheimnisse im geschützten Schlüsselbund auf und entsperren Sie sie bei Bedarf.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/settings) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Schlüsselbund aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/settings) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/auth/keyring/usage) erklärt Abläufe. [Technik](/docs/adapters/auth/keyring/technical) beschreibt Schnittstellen und Konfiguration.
