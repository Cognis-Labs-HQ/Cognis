# キーリング

アカウントの秘密情報を保護されたキーリングに保存し、必要なときに解除できます。

## できること

パスワードや暗号鍵をブラウザーで暗号化した保管庫に保存し、使い終わったらロックできます。

## 始める前に

自分のアカウントでログインしてください。保管庫のパスワードはサーバーで読み取ることも復元することもできません。

## はじめに

設定のキーリングを開き、未作成なら保管庫を作成します。既存の保管庫は機能から要求されるまでロックしたままにできます。
