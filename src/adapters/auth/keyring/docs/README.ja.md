# キーリング

アカウントの秘密情報を保護されたキーリングに保存し、必要なときに解除できます。

## できること

[機能のページ](/settings) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

キーリング が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/auth/keyring/usage)、インターフェースと設定は[技術情報](/docs/adapters/auth/keyring/technical)を参照してください。
