# LDAP Sign In

Use your organisation's directory account to sign in when LDAP is configured.

## What You Can Do

Available actions are shown on [the feature page](/login) according to your account permissions.

## Before You Start

Check that LDAP Sign In is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/login) and choose the action you need.

## Learn More

[Usage](/docs/adapters/auth/ldap/usage) explains procedures. [Technical](/docs/adapters/auth/ldap/technical) documents interfaces and configuration.
