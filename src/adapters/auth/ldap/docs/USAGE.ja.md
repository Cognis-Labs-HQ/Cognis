# 使用例

LDAP ログイン の実践的な操作手順です。

## 前提条件

認証管理で LDAP の接続先、バインド情報、ユーザー検索の起点とフィルターを用意します。

## 使用例

設定を保存して接続テストを実行します。接続や検索の問題を解消し、管理者グループを使う前に実際のユーザーでログインを確認します。

## 期待される結果

テストは接続と検索の状態を示します。認証成功時にディレクトリの識別情報が Cognis アカウントに結び付きます。

## 問題の解決

TLS の信頼、バインド権限、検索範囲、フィルターを確認してください。接続成功だけでは個別のパスワードやグループ設定は確認できません。
