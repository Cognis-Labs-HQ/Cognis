# Masuk LDAP

Gunakan akun direktori organisasi untuk masuk saat LDAP telah dikonfigurasi.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/login) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Masuk LDAP aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/login) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/auth/ldap/usage) menjelaskan prosedur. [Teknis](/docs/adapters/auth/ldap/technical) mendokumentasikan antarmuka dan konfigurasi.
