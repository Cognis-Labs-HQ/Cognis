# LDAP-Anmeldung

Melden Sie sich bei eingerichtetem LDAP mit Ihrem Organisationskonto an.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/login) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob LDAP-Anmeldung aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/login) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/auth/ldap/usage) erklärt Abläufe. [Technik](/docs/adapters/auth/ldap/technical) beschreibt Schnittstellen und Konfiguration.
