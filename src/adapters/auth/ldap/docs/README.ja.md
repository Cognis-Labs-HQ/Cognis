# LDAP ログイン

LDAP が設定されていれば、組織のディレクトリアカウントでログインできます。

## できること

組織のディレクトリの認証情報でログインできます。管理者が LDAP 接続と管理者グループの対応を設定します。

## 始める前に

管理者による接続設定が必要です。テスト中は利用可能なローカル管理者アカウントを残してください。

## はじめに

ログイン画面で設定済みのディレクトリを選び、そのユーザー名とパスワードを入力します。

手順は[使用例](/docs/adapters/auth/ldap/usage)、インターフェースと設定は[技術情報](/docs/adapters/auth/ldap/technical)を参照してください。
