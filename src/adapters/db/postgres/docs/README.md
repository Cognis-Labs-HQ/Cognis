# PostgreSQL

Store Cognis accounts and content in a PostgreSQL database managed by your administrator.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that PostgreSQL is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/adapters/db/postgres/usage) explains procedures. [Technical](/docs/adapters/db/postgres/technical) documents interfaces and configuration.
