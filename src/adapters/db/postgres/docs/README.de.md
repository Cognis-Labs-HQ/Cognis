# PostgreSQL

Speichern Sie Cognis-Konten und Inhalte in einer administrierten PostgreSQL-Datenbank.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob PostgreSQL aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/db/postgres/usage) erklärt Abläufe. [Technik](/docs/adapters/db/postgres/technical) beschreibt Schnittstellen und Konfiguration.
