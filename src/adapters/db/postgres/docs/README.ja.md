# PostgreSQL

管理者が用意した PostgreSQL データベースに Cognis のアカウントと内容を保存します。

## できること

Cognis のデータを PostgreSQL に永続保存します。

## 始める前に

アプリから接続できる PostgreSQL を用意します。

## はじめに

配置環境の保存先に PostgreSQL を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/db/postgres/usage)、インターフェースと設定は[技術情報](/docs/adapters/db/postgres/technical)を参照してください。
