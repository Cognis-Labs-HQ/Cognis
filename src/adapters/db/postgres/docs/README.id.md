# PostgreSQL

Simpan akun dan konten Cognis di basis data PostgreSQL yang dikelola administrator.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan PostgreSQL aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/db/postgres/usage) menjelaskan prosedur. [Teknis](/docs/adapters/db/postgres/technical) mendokumentasikan antarmuka dan konfigurasi.
