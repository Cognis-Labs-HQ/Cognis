# PostgreSQL

Simpan akun dan konten Cognis di basis data PostgreSQL yang dikelola administrator.

## Yang Dapat Anda Lakukan

Simpan data Cognis secara persisten di PostgreSQL.

## Sebelum Memulai

Siapkan basis data PostgreSQL yang dapat dijangkau aplikasi.

## Langkah Awal

Pilih PostgreSQL sebagai backend basis data instalasi.

[Penggunaan](/docs/adapters/db/postgres/usage) menjelaskan prosedur. [Teknis](/docs/adapters/db/postgres/technical) mendokumentasikan antarmuka dan konfigurasi.
