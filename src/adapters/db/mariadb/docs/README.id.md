# MariaDB

Simpan akun dan konten Cognis di basis data MariaDB yang dikelola administrator.

## Yang Dapat Anda Lakukan

Simpan akun dan konten Cognis dalam MariaDB.

## Sebelum Memulai

Operator memerlukan basis data MariaDB dan kredensial.

## Langkah Awal

Pilih MariaDB dalam konfigurasi basis data instalasi.
