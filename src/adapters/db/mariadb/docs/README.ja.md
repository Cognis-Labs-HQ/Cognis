# MariaDB

管理者が用意した MariaDB データベースに Cognis のアカウントと内容を保存します。

## できること

Cognis のアカウントや内容を MariaDB に保存します。

## 始める前に

運用者は MariaDB と接続情報を用意します。

## はじめに

配置環境のデータベース設定で MariaDB を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/db/mariadb/usage)、インターフェースと設定は[技術情報](/docs/adapters/db/mariadb/technical)を参照してください。
