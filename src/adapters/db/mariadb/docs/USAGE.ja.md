# 使用例

MariaDB の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/adapters/db/mariadb)を確認してください。

## 使用例

```sh
DB_TYPE=mariadb
```

## 期待される結果

この例は MariaDB の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/adapters/db/mariadb/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

MariaDB を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
