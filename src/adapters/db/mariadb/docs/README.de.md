# MariaDB

Speichern Sie Cognis-Konten und Inhalte in einer administrierten MariaDB-Datenbank.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob MariaDB aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/db/mariadb/usage) erklärt Abläufe. [Technik](/docs/adapters/db/mariadb/technical) beschreibt Schnittstellen und Konfiguration.
