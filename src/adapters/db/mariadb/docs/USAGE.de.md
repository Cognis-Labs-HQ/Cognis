# Anwendung

Praktische Abläufe für MariaDB.

## Voraussetzungen

Beachten Sie vor dem Ausführen [die Zugriffsanforderungen](/docs/adapters/db/mariadb).

## Beispiele

```sh
DB_TYPE=mariadb
```

## Erwartete Ergebnisse

Das Beispiel verwendet die dokumentierte Schnittstelle von MariaDB. Prüfen Sie vor erneuten Schreibvorgängen die unter [Technik](/docs/adapters/db/mariadb/technical) beschriebene Antwort oder den gespeicherten Zustand.

## Fehlerbehebung

Falls MariaDB nicht verfügbar ist, prüfen Sie Ihre Anmeldung und lassen Sie den Administrator die Komponente und ihre Abhängigkeiten kontrollieren.
