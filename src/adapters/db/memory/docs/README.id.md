# Basis Data Dalam Memori

Jalankan demonstrasi dan pengujian sementara tanpa menyimpan data setelah proses berakhir.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Basis Data Dalam Memori aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/db/memory/usage) menjelaskan prosedur. [Teknis](/docs/adapters/db/memory/technical) mendokumentasikan antarmuka dan konfigurasi.
