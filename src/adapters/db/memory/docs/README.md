# In-Memory Database

Run temporary demonstrations and tests without keeping data after the process ends.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that In-Memory Database is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/adapters/db/memory/usage) explains procedures. [Technical](/docs/adapters/db/memory/technical) documents interfaces and configuration.
