# Arbeitsspeicher-Datenbank

Führen Sie vorübergehende Vorführungen und Tests ohne dauerhafte Datenspeicherung durch.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Arbeitsspeicher-Datenbank aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/db/memory/usage) erklärt Abläufe. [Technik](/docs/adapters/db/memory/technical) beschreibt Schnittstellen und Konfiguration.
