# メモリ内データベース

プロセス終了後にデータを残さず、一時的なデモやテストを実行できます。

## できること

[機能のページ](/administration) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

メモリ内データベース が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/administration) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/db/memory/usage)、インターフェースと設定は[技術情報](/docs/adapters/db/memory/technical)を参照してください。
