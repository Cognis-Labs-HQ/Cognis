# SQLiteデータベースアダプター

## 概要

SQLiteアダプターは、単一サーバーのCognisデプロイメントに依存関係のないリレーショナルデータベースを提供します。`better-sqlite3`互換クライアントを使用して、ローカルファイルシステム上の単一ファイルにすべてのプラットフォームデータを保存します。小規模デプロイメント、ローカル開発、テストに推奨される出発点です。

## 責務

- `DatabaseGateway` インターフェースを実装する: `query`、`execute`、`transaction`。
- 起動時にSQLiteデータベースファイルを開く（必要に応じて作成）。
- すべての接続でWALモードと外部キー強制を有効にする。

## アーキテクチャ

`src/adapters/db/sqlite/adapter.ts` の `SqliteDbGateway` が `better-sqlite3` データベースハンドルをラップします。

### プレースホルダー構文

`?` 位置プレースホルダーを使用:

```sql
SELECT * FROM users WHERE id = ?
```

## 設定

| 変数          | デフォルト             | 説明                                                   |
| ------------- | ---------------------- | ------------------------------------------------------ |
| `DB_TYPE`     | —                      | このアダプターを起動するには `sqlite` である必要がある |
| `SQLITE_PATH` | `./data/cognis.sqlite` | SQLiteデータベースファイルへのパス; 不在時に自動作成   |
