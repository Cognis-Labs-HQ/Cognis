# SQLiteデータベースアダプター

## 概要

SQLiteアダプターは、SQLiteベースのデプロイメント、ローカル開発、組み込みリレーショナルストアを必要とするテスト向けに、軽量なデータベースゲートウェイを提供します。

## 責務

- `SqliteDbGateway` を通じて `DatabaseGateway` インターフェースを実装する。
- 提供されたSQLiteクライアントに対してクエリ、コマンド、トランザクションを実行する。
- SQLiteのプレースホルダー構文と競合解決構文を使う構造化データベースコマンドをサポートする。
- SQLite固有の認証スキーマヘルパーと、SQL初期化・マイグレーションスクリプトを提供する。

## 設定

デプロイメントがこのアダプターを使用するように構成されている場合は、`DB_TYPE=sqlite` でSQLiteバックエンドを選択します。データベースファイルのパスは、実行環境で使われるSQLite設定（サポートされている場合は `SQLITE_PATH` など）で設定してください。

ゲートウェイ全般の設定については、[データベースゲートウェイドキュメント](/docs/gateways/db)を参照してください。
