# SQLite Database Adapter (Removed)

SQLite is no longer supported. The SQLite adapter has been removed from Cognis.

The platform now supports **PostgreSQL** (default) and **MariaDB** as database backends. Set `DB_TYPE` to `postgresql` or `mariadb` and provide a `DATABASE_URL` connection string.

See the [Database Gateway documentation](../../../../gateways/db/docs/index.en.md) for configuration details.
