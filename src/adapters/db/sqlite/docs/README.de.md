# SQLite

Bewahren Sie Cognis-Daten in einer eingebetteten Datenbankdatei für lokale Installationen auf.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob SQLite aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/db/sqlite/usage) erklärt Abläufe. [Technik](/docs/adapters/db/sqlite/technical) beschreibt Schnittstellen und Konfiguration.
