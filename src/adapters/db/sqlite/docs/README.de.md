# SQLite

Bewahren Sie Cognis-Daten in einer eingebetteten Datenbankdatei für lokale Installationen auf.

## Möglichkeiten

Nutze eine eingebettete relationale Datenbank in Laufzeitumgebungen mit SQLite-Client.

## Vor dem Start

Eine einbettende Laufzeit muss den SQLite-Client bereitstellen; die Standardinstallation bindet diese Klasse nicht als auswählbaren Anbieter ein.

## Erste Schritte

Prüfe vor der Auswahl, dass deine Laufzeit den SQLite-Adapter ausdrücklich einbindet.
