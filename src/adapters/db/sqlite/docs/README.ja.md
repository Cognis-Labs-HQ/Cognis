# SQLite

ローカル環境向けの組み込みデータベースファイルに Cognis のデータを保存します。

## できること

SQLite クライアントを提供する実行環境で組み込みデータベースを利用できます。

## 始める前に

組み込む実行環境が SQLite クライアントを渡します。標準の配置ではこのクラスを保存先として接続しません。

## はじめに

保存先に選ぶ前に、実行環境が SQLite を明示的に接続しているか確認します。
