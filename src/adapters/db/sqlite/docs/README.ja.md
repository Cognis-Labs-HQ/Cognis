# SQLite

ローカル環境向けの組み込みデータベースファイルに Cognis のデータを保存します。

## できること

[機能のページ](/administration) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

SQLite が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/administration) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/db/sqlite/usage)、インターフェースと設定は[技術情報](/docs/adapters/db/sqlite/technical)を参照してください。
