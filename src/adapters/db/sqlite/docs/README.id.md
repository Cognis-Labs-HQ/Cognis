# SQLite

Simpan data Cognis dalam berkas basis data tertanam untuk instalasi lokal.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan SQLite aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/db/sqlite/usage) menjelaskan prosedur. [Teknis](/docs/adapters/db/sqlite/technical) mendokumentasikan antarmuka dan konfigurasi.
