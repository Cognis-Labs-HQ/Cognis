# SQLite

Keep Cognis data in an embedded database file suitable for local installations.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that SQLite is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

[Usage](/docs/adapters/db/sqlite/usage) explains procedures. [Technical](/docs/adapters/db/sqlite/technical) documents interfaces and configuration.
