# Usage

Practical procedures for Public Share Links.

## Prerequisites

You must own the resource or have permission to share it.

## Examples

Choose the permitted access, expiry and protection, create the link and open it in a separate browser session.

Creates public, expiring links through the Share gateway. The adapter owns link-specific input preparation and the Link page shown inside the gateway popup.

## Expected Results

The link opens only the shared resource; expiry or revocation removes access.

## Troubleshooting

Check the link's current status and password. Read-only resources cannot gain write access through a share option.
