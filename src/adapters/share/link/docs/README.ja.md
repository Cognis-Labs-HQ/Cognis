# 公開共有リンク

指定した権限の公開リンクで、対応する内容を他の人に開いてもらえます。

## できること

[機能のページ](/) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

公開共有リンク が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/share/link/usage)、インターフェースと設定は[技術情報](/docs/adapters/share/link/technical)を参照してください。
