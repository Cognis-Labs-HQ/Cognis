# Öffentliche Freigabelinks

Ermöglichen Sie den Zugriff auf unterstützte Inhalte über einen öffentlichen Link mit gewählten Rechten.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Öffentliche Freigabelinks aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/share/link/usage) erklärt Abläufe. [Technik](/docs/adapters/share/link/technical) beschreibt Schnittstellen und Konfiguration.
