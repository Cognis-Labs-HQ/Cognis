# Tautan Berbagi Publik

Izinkan orang membuka konten yang didukung melalui tautan publik dengan izin pilihan Anda.

## Yang Dapat Anda Lakukan

Buat tautan dengan kedaluwarsa dan kontrol akses untuk sumber daya yang didukung.

## Sebelum Memulai

Anda harus memiliki sumber daya atau izin membagikannya.

## Langkah Awal

Buka Bagikan pada sumber daya lalu pilih Tautan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/share/link/usage) menjelaskan prosedur. [Teknis](/docs/adapters/share/link/technical) mendokumentasikan antarmuka dan konfigurasi.
