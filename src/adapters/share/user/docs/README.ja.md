# 利用者との共有

公開リンクを作らずに、特定の Cognis 利用者へ内容のアクセス権を付与できます。

## できること

[機能のページ](/) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

利用者との共有 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/adapters/share/user/usage)、インターフェースと設定は[技術情報](/docs/adapters/share/user/technical)を参照してください。
