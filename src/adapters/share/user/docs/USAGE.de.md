# Anwendung

Praktische Abläufe für Mit Personen teilen.

## Voraussetzungen

Empfänger benötigen Cognis-Konten; Absender brauchen eine Freigabeberechtigung.

## Beispiele

Wähle Empfänger und erlaubte Rechte, speichere und lasse das Konto seine persönliche Freigabeseite öffnen.

## Erwartete Ergebnisse

Der Zugriff ist an dieses Konto gebunden statt an einen öffentlichen Link.

## Fehlerbehebung

Prüfe Empfänger, vorhandene Freigaben und Inhaltsrechte. Doppelte Freigaben für denselben Empfänger werden abgelehnt.
