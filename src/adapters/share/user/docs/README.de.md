# Mit Personen teilen

Geben Sie ausgewählten Cognis-Nutzern Zugriff auf Inhalte, ohne einen öffentlichen Link zu erstellen.

## Möglichkeiten

Erteile benannten Cognis-Benutzern Zugriff auf unterstützte Inhalte.

## Vor dem Start

Empfänger benötigen Cognis-Konten; Absender brauchen eine Freigabeberechtigung.

## Erste Schritte

Wähle Benutzer im Teilen-Dialog des Inhalts.

[Anwendung](/docs/adapters/share/user/usage) erklärt Abläufe. [Technik](/docs/adapters/share/user/technical) beschreibt Schnittstellen und Konfiguration.
