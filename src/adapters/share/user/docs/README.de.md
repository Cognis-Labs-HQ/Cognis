# Mit Personen teilen

Geben Sie ausgewählten Cognis-Nutzern Zugriff auf Inhalte, ohne einen öffentlichen Link zu erstellen.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Mit Personen teilen aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/share/user/usage) erklärt Abläufe. [Technik](/docs/adapters/share/user/technical) beschreibt Schnittstellen und Konfiguration.
