# Berbagi dengan Orang

Berikan akses konten kepada pengguna Cognis tertentu tanpa menerbitkan tautan publik.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Berbagi dengan Orang aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/share/user/usage) menjelaskan prosedur. [Teknis](/docs/adapters/share/user/technical) mendokumentasikan antarmuka dan konfigurasi.
