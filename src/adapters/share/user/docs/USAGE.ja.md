# 使用例

利用者との共有 の実践的な操作手順です。

## 前提条件

受信者の Cognis アカウントと、送信者の共有権限が必要です。

## 使用例

相手と許可された権限を選び保存し、そのアカウントで共有ページを確認します。

Share ゲートウェイを通じて Cognis ユーザーへリソースを直接共有します。ユーザー受信者を検証し、ゲートウェイポップアップ内のユーザーページを管理します。

## 期待される結果

公開リンクの所持者ではなく、指定したアカウントにアクセスが結び付きます。

## 問題の解決

相手、既存の共有、内容の権限を確認してください。同じ相手への重複した共有は拒否されます。
