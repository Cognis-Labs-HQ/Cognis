# ユーザー共有アダプター

## 使用例

Share ゲートウェイを通じて Cognis ユーザーへリソースを直接共有します。ユーザー受信者を検証し、ゲートウェイポップアップ内のユーザーページを管理します。

## 技術仕様

アダプターは方式固有の受信者またはトークン入力を検証し、共有リソースのオーケストレーションを Share ゲートウェイへ委譲し、所有ゲートウェイとアダプターのライフサイクルが有効な間だけ動作します。

共有画面に `allowedPermissions: ["read"]` を指定すると、リソースが実装している権限だけを提示できます。ユーザー向けの選択肢と変更処理はこの一覧に従います。リソース側の認可フローでも同じ権限を検証する必要があります。
