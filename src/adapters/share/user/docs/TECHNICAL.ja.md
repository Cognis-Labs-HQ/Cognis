# 技術リファレンス

利用者との共有 の公開インターフェースと運用規則を説明します。

## インターフェース

createShareAdapter がアカウント宛ての user 方式を返します。prepare で宛先を要求し、validateUnique で重複を拒否します。表示にはログインが必要です。

## 設定

共有画面で宛先と許可する権限を指定します。外部のメッセージ接続ではなく Cognis の識別情報を使います。

## 動作

アカウント宛ての共有はログインしてから対象を解決します。方式は宛先フォームと表示画面を提供し、トークン保存・期限・取り消しは Share が管理します。

## セキュリティ

受信者は明示したアカウント参照である必要があります。空や重複を拒否し、Share が送信者の権限と対象の上限を確認します。

## リファレンス

### 技術仕様

アダプターは方式固有の受信者またはトークン入力を検証し、共有リソースのオーケストレーションを Share ゲートウェイへ委譲し、所有ゲートウェイとアダプターのライフサイクルが有効な間だけ動作します。

共有画面に `allowedPermissions: ["read"]` を指定すると、リソースが実装している権限だけを提示できます。ユーザー向けの選択肢と変更処理はこの一覧に従います。リソース側の認可フローでも同じ権限を検証する必要があります。
