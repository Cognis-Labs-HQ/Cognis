# File Logs

Keep application logs in files with configurable rotation and compression.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that File Logs is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/adapters/logging/file/usage) explains procedures. [Technical](/docs/adapters/logging/file/technical) documents interfaces and configuration.
