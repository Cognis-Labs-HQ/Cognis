# Dateiprotokolle

Bewahren Sie Anwendungsprotokolle in Dateien mit einstellbarer Rotation und Komprimierung auf.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Dateiprotokolle aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/logging/file/usage) erklärt Abläufe. [Technik](/docs/adapters/logging/file/technical) beschreibt Schnittstellen und Konfiguration.
