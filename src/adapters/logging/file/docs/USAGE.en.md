# Usage

Practical procedures for File Logs.

## Prerequisites

The log location must be writable and persist as required by your retention policy.

## Examples

Set the output level, rotation size, retained archive count and compression; inspect new output and rotated files.

## Expected Results

The Logging gateway owns writing and rotation; a zero archive count retains no rotated archives.

## Troubleshooting

Check file permissions, free space and retention settings before assuming older records are available.
