# Log Berkas

Simpan log aplikasi dalam berkas dengan rotasi dan kompresi yang dapat diatur.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Log Berkas aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/logging/file/usage) menjelaskan prosedur. [Teknis](/docs/adapters/logging/file/technical) mendokumentasikan antarmuka dan konfigurasi.
