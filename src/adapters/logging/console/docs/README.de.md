# Konsolenprotokolle

Lesen Sie Anwendungsprotokolle in der Serverkonsole oder Containerausgabe.

## Möglichkeiten

Gib Anwendungsprotokolle auf der Prozesskonsole aus.

## Vor dem Start

Administratoren konfigurieren die Ausgabe; Betreiber erfassen sie im Hostsystem.

## Erste Schritte

Öffne Protokolleinstellungen und wähle Konsolenausgabe.

## Weitere Informationen

[Anwendung](/docs/adapters/logging/console/usage) erklärt Abläufe. [Technik](/docs/adapters/logging/console/technical) beschreibt Schnittstellen und Konfiguration.
