# Konsolenprotokolle

Lesen Sie Anwendungsprotokolle in der Serverkonsole oder Containerausgabe.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Konsolenprotokolle aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/adapters/logging/console/usage) erklärt Abläufe. [Technik](/docs/adapters/logging/console/technical) beschreibt Schnittstellen und Konfiguration.
