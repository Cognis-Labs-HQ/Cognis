# Console Logs

Read application log messages in the server console or container output.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that Console Logs is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/adapters/logging/console/usage) explains procedures. [Technical](/docs/adapters/logging/console/technical) documents interfaces and configuration.
