# Log Konsol

Baca pesan log aplikasi di konsol server atau keluaran kontainer.

## Yang Dapat Anda Lakukan

Kirim log aplikasi ke konsol proses.

## Sebelum Memulai

Administrator mengatur keluaran; operator menangkap log pada sistem hosting.

## Langkah Awal

Buka pengaturan Logging dan pilih konsol.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/logging/console/usage) menjelaskan prosedur. [Teknis](/docs/adapters/logging/console/technical) mendokumentasikan antarmuka dan konfigurasi.
