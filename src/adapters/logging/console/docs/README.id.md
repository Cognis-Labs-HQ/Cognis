# Log Konsol

Baca pesan log aplikasi di konsol server atau keluaran kontainer.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Log Konsol aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/adapters/logging/console/usage) menjelaskan prosedur. [Teknis](/docs/adapters/logging/console/technical) mendokumentasikan antarmuka dan konfigurasi.
