# 使用例

コマンドラインツール の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/components/tooling/cli)を確認してください。

## 使用例

ヘルプコマンドで、インストール済みの操作と引数を一覧表示できます。

```sh
cognisctl --help
```

1. [機能のページ](/administration) を開きます。
2. コマンドラインツール で利用できる操作を選びます。
3. 必要な値を確認し、結果を確かめます。

## 期待される結果

この例は コマンドラインツール の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/components/tooling/cli/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

コマンドラインツール を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
