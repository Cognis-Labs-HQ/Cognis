# Befehlszeilenwerkzeuge

Mit den Befehlszeilenwerkzeugen verwalten Administratoren Cognis ohne Browser.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Befehlszeilenwerkzeuge aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/components/tooling/cli/usage) erklärt Abläufe. [Technik](/docs/components/tooling/cli/technical) beschreibt Schnittstellen und Konfiguration.
