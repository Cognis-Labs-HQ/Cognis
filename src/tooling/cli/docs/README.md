# Command-Line Tools

Command-line tools let administrators manage Cognis without opening the browser.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that Command-Line Tools is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/components/tooling/cli/usage) explains procedures. [Technical](/docs/components/tooling/cli/technical) documents interfaces and configuration.
