# Usage

Practical procedures for Command-Line Tools.

## Prerequisites

Review [the access requirements](/docs/components/tooling/cli) before performing these procedures.

## Examples

Run the help command to list installed operations and their arguments.

```sh
cognisctl --help
```

1. Open [the feature](/administration).
2. Select an available action for Command-Line Tools.
3. Review the requested values and confirm the result.

## Expected Results

The example uses the documented interface of Command-Line Tools. Confirm the response or saved state described in [Technical](/docs/components/tooling/cli/technical) before repeating a write operation.

## Troubleshooting

If Command-Line Tools is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
