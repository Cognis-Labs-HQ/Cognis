# Alat Baris Perintah

Alat baris perintah memungkinkan administrator mengelola Cognis tanpa membuka peramban.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Alat Baris Perintah aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/components/tooling/cli/usage) menjelaskan prosedur. [Teknis](/docs/components/tooling/cli/technical) mendokumentasikan antarmuka dan konfigurasi.
