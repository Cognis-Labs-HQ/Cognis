# Dashboard Defaults

## Balanced Default Cards

The dashboard keeps the digital clock and date active. Account, Last Login and the greeting use compact summary cards. Upcoming Calendar Events has more vertical room for its list; My Classes uses a shorter card for its introduction and action. The cards use Page Composer spacing and reflow rather than a separate dashboard layout engine.

## Optional Analogue Clock

The analogue clock starts in available elements. Open Arrange Page Widgets, then use Add beside the analogue clock. Move or resize it with the usual touch or keyboard controls and save the arrangement. Both clocks remain available.

## Keep Your Arrangement

These defaults apply to newly placed cards. Saved positions, sizes and hidden choices remain intact, including a previously added analogue clock. Narrow views use the existing full-width, content-sized Page Composer presentation without overwriting desktop profiles.

## Workspace Guide

On /dashboard, the workspace guide explains the default digital clock, optional analogue clock and upcoming-event links. Arrange Page Widgets explains Add, touch controls, keyboard movement and resizing, and Save or Discard. Use the question-mark control beside the page title to replay the guide. Its existing targets and interaction sequence are unchanged.
