# ダッシュボードの初期配置

## 内容に合った初期カード

ダッシュボードではデジタル時計と日付が引き続き有効です。アカウント、最終ログイン、挨拶はコンパクトな概要カードを使用します。今後のカレンダー予定には一覧用の高さを確保し、マイクラスには説明と操作に合った短いカードを使用します。独自の配置処理を追加せず、Page Composer の間隔と折り返しを利用します。

## 任意のアナログ時計

アナログ時計は最初に利用可能な項目へ入ります。ページのウィジェットを配置する操作を開き、アナログ時計の横にある追加を選択してください。通常のタッチ操作やキーボード操作で移動とサイズ変更を行い、配置を保存できます。どちらの時計も利用できます。

## 保存した配置を維持

この初期設定は新しく配置するカードに適用されます。保存済みの位置、サイズ、非表示の選択は、以前追加したアナログ時計も含めて維持されます。狭い画面では既存の Page Composer による全幅かつ内容に応じた高さの表示を利用し、デスクトップのプロファイルを上書きしません。

## 時計の更新

表示中の時計は、現在のタイムゾーンと時刻形式の設定を使って毎秒更新されます。カードの並べ替えや画面サイズの変更後も、各表示では一つの時計だけが動作します。時計を非表示にしたりダッシュボードを離れたりすると更新が停止し、再表示すると新しく動作を開始します。

## ワークスペースガイド

/dashboard のワークスペースガイドでは、初期表示のデジタル時計、任意のアナログ時計、今後の予定へのリンクを説明します。配置の説明では、追加、タッチ操作、キーボードでの移動とサイズ変更、保存と破棄を案内します。ページタイトル横の疑問符からガイドを再生できます。既存の対象と操作順序は変わりません。
