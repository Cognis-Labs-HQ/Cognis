# ホワイトボード

## 概要

Nextcloud Whiteboard モジュールは、設定済みの Nextcloud Whiteboard インスタンスを使って、Cognis ユーザーに共同ホワイトボードセッションを提供します。

## 管理

管理者はモジュールの管理セクションで Nextcloud のベース URL と API キーを設定します。API キーはサーバー側に保存され、設定 API から返されません。

## アクセス制御

Cognis は作成された各ホワイトボードの許可リストを保存します。ユーザーは所有者または招待された参加者である場合のみ、ホワイトボードを一覧表示して開けます。
