# Whiteboards

## Überblick

Das Nextcloud-Whiteboard-Modul öffnet kollaborative Whiteboard-Sitzungen für Cognis-Benutzer über eine konfigurierte Nextcloud-Whiteboard-Instanz.

## Administration

Administratoren konfigurieren die Nextcloud-Basis-URL und den API-Schlüssel im Administrationsbereich des Moduls. Der API-Schlüssel bleibt serverseitig gespeichert und wird nicht über die Konfigurations-API zurückgegeben.

## Zugriffskontrolle

Cognis speichert für jedes gestartete Whiteboard eine Zulassungsliste. Benutzer können Whiteboards nur auflisten und öffnen, wenn sie Besitzer oder eingeladene Teilnehmer sind.
