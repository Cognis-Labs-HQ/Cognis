# Jitsi Meetモジュール

## 概要

Jitsi Meetモジュールは、`src/modules/jitsi-meet` にある自己完結型モジュールで、ユーザーペアおよび教室/手動エンティティ向けに Cognis 管理の会議オーケストレーションを提供します。

主な提供機能:

- グローバルナビゲーションの **ミーティング** エントリ
- ページコンポーザーで編集可能な分離ペイン（会議ウィンドウ、参加者コントロール、チャットウィンドウ）
- Administration での Jitsi インスタンス設定
- DB 永続化された再利用可能会議エンティティと参加者制御

## セキュリティモデル

- 会議 URL は決定的なルームスラッグからサーバー側で生成し、コピー可能な UI メタデータとしては表示しません。
- Jitsi ネイティブチャットは無効化し、Cognis ネイティブチャット連携を使用します。
- 参加者メンバーシップはモジュール DB チェックで Cognis が強制します。
- 参加者更新は会議オーナーのみ可能です。
