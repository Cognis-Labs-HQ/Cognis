# Core

The core keeps enabled Cognis features working together and manages their access to shared services.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that Core is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/components/core/usage) explains procedures. [Technical](/docs/components/core/technical) documents interfaces and configuration.
