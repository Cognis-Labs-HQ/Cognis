# Kernsystem

Das Kernsystem verbindet aktivierte Cognis-Funktionen und verwaltet ihren Zugriff auf gemeinsame Dienste.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Kernsystem aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/components/core/usage) erklärt Abläufe. [Technik](/docs/components/core/technical) beschreibt Schnittstellen und Konfiguration.
