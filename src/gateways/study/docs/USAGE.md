# Usage

Practical procedures for Study.

## Prerequisites

Review [the access requirements](/docs/gateways/study) before performing these procedures.

## Examples

- Explore browses enrolled languages. Flashcards and other installed tools appear here when available to your account.
- Switch between the languages you have enrolled in. Names shorten to a code or flag when space is tight. Use Study settings to change your enrollment.
- These cards open the installed learning tools. Each language’s guide walks through its own collections and card actions.
- Choose the languages you want to learn from the installed language modules.
- Your language selection determines the learning activities and navigation available to you.
- Use the dictionary search to look up a word or expression with an available provider. Results can help you find or build cards. On small screens, the search button opens a dialog with the query and provider controls.
- Open Study settings to choose the languages you learn or teach. Language walkthroughs are offered for languages you have enrolled in.

## Expected Results

The example uses the documented interface of Study. Confirm the response or saved state described in [Technical](/docs/gateways/study/technical) before repeating a write operation.

## Troubleshooting

If Study is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
