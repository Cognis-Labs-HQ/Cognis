# ガイド付きチュートリアル

## ガイドを使う

Explore のページタイトル横にある ? から Study の概要を選びます。この手動ガイドは、ナビゲーション、選択言語、利用可能な辞書検索、学習設定を説明します。現在のレイヤーを維持し、利用できない操作は省きます。言語ごとのガイドはコンテンツを説明し、その言語だけを対象とします。

## 技術仕様

| ページ / 画面                       | ガイド       | アクセス           |
| ----------------------------------- | ------------ | ------------------ |
| `/study/explore/*`                  | Study の概要 | ログイン済み利用者 |
| `/study/settings`, `/study/welcome` | Study の設定 | ログイン済み利用者 |

## 概要と言語ガイド

概要の完了識別子 `study:getting-started` は維持します。次へ、戻る、再開を使ってページを移動せずにナビゲーションを確認できます。完了したガイドは同じ ? メニューから再実行できます。言語ガイドは学習登録した自身の言語のコンテンツで自動開始でき、選択言語を変えると対応するガイドが表示されます。

`study:tutorialTargets` は Study 所有のナビゲーションと描画の対象、およびスコープ付きの `route` と `attachDrawing` 操作を公開します。`matchesPage` は指定言語の Explore パスだけに一致します。`isEnrolled(language)` は `study:navigation` を通じて確認済みのアカウント別設定を読みます。ガイドの検出では移動も学習登録も行いません。対話型のカード操作と汎用の代替ガイドは Library が所有します。

旧言語一覧専用のチュートリアル対象 `modules` は削除します。外部のガイドは廃止した一覧ではなく、現在のナビゲーションまたは自身のコンテンツを対象にしてください。
