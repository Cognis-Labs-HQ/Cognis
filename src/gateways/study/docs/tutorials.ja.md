# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

## 技術仕様

| ページ・画面                     | ガイド       | アクセス           |
| -------------------------------- | ------------ | ------------------ |
| `/study`                         | Study の概要 | ログイン利用者     |
| `^/study/(?:settings\|welcome)$` | 学習の設定   | ログイン済み利用者 |

## 概要と言語ガイド

`/study` のガイドは操作サブナビ、登録済み学習言語、利用可能モジュール、辞書検索、学習設定を説明します。利用できない操作は省略し、カード操作は重複させません。

`study:tutorialTargets` は Study 所有のナビゲーションと描画対象、およびスコープ付きの `route`、`attachDrawing` 操作を公開します。`isEnrolled(language)` は `study:navigation` から検証済み設定を読み、現在のアカウントに限定し、登録変更時に無効化します。言語ページを訪問しても学習登録にはなりません。

概要の ? メニューから言語モジュールのガイドを選択できます。この明示的な選択でその言語の Explore を開きます。自動開始は専用コンテンツページのみで、すでに開いているレイヤーは維持します。対話的なカード操作と汎用の代替ガイドは Library が所有します。詳細はコンポーネント文書を参照してください。
