# 技術リファレンス

学習 の公開インターフェースと運用規則を説明します。

## インターフェース

### 音声プロバイダー契約

`study:audio:provider.registerProvider({ id, revision, languages, fetchAudio })` → disposer.

`fetchAudio({ language, label, semanticRole, readings }, signal)` → `{ mediaType, data: Uint8Array }`.

両方の Study モジュールが同じ解除可能な音声プロバイダー契約を使い、制限付きのローカル読み込みで同梱録音を取得します。認可、キャッシュ方針、合成再生はホストが所有します。

初期録音は多言語ニューラルモデル Kokoro をオフラインで使用し、英語に `bf_emma`、日本語に `jf_alpha` を使用します。クリップは 128 kbps、開始前の無音 200 ms、終了後の無音 180 ms、上限付きピーク正規化、遅めの発話速度で生成します。モデルの帰属表示と Apache ライセンスは `data/audio/VOICE-LICENSE.txt`、声と処理設定は録音一覧に記録します。

音声の取得は学習者が再生を要求したときに始まり、カードを開くだけでは音声を要求しません。再生エラーはホストのローカライズ済みトーストと構造化ログで示します。文の構成要素は選択した変形記述を保持し、認証済み音声エンドポイントは任意の表示テキストを受け取らず、スキーマから発話形を導出します。英語の文字組み合わせの初期音声は記載された IPA 音素から合成し、アルファベットの音声は文字名を発音します。

### 拡張可能なブラウザー操作

Libraryのブラウザークライアントはctxから`study:library:client`を取得します。プロバイダーは読み取り、辞書操作、リクエスト、インポート、メディアに対し、`study:library:<clientFunction>`の`before`、`execute`、`after`を登録します。ルートで要求した機能により、ページをマウントする前にプロバイダーを読み込みます。拡張の引数、拒否、解除時の動作はLibraryアダプターのドキュメントを参照してください。

### Studyの認証契約を適用

Studyはルート登録前にAuthenticationゲートウェイと`auth:routeContext`機能を必要とします。アダプター管理、言語の検出、描画の各ルートは、独自のアクセス制御も含めて注入されたコンテキストを使用します。認証契約がない場合は既定の制御を選ばず、起動を失敗させます。

## 設定

登録言語で内容と移動先を選びます。モジュールやアダプターが活動・辞書・画面を登録し、不在時は自身の選択だけを除きます。

## 動作

### 発音音声

Bootstrap は `study:audio:provider` を必須とし、辞書と筆順のプロバイダーとともに解除可能な音声プロバイダーを登録します。発話ラベルと優先する読みに基づいて同梱録音を解決し、容量制限付きでファイルを読み、不足する音声は明示的なエラーにします。解除時には処理中の取得を中断します。Cognis はカードへのアクセスを認可し、スキーマから選択した変形の発話形を導出し、作成済みフィールドを変更せず Files に非公開キャッシュを保存します。`study:library:audio` フローは認可、検証、解決を実行し、`study:audio:fetch` はプロバイダーのバイト列を検証して取得します。文の音声は構成要素を順番に再生します。

### 辞書音声とホストのキャッシュ

要求された発音が同梱されていない場合、English Study は English Dictionary API で単語を検索し、その発音メディアエンドポイントから一致する MP3 を取得します。優先 IPA の読みが指定されている場合は一致が必須で、異なる発音で代用しません。`api.dictionaryapi.dev` の HTTPS メディアだけを許可し、リダイレクトを拒否します。検索とダウンロードは一つの制限時間を共有し、両方の応答をストリーミング時のバイト数で制限します。録音がない場合は明示的なエラーを返します。Google の音声サービスは使用しません。

録音キャッシュはモジュールではなく Cognis が管理します。認可後、非公開の Files キャッシュで取得済み録音をカード間および再起動後も再利用します。同時再生要求は取得と保存を共有します。キーには提供元の識別子、リビジョン、言語、役割、ラベル、読みを含め、読みや提供元リビジョンが変われば別途解決します。要求や保存の失敗は再試行できます。モジュールが辞書に接続するのは、再生要求時にキャッシュがない場合だけです。

### 間を付けた合成と手動置換

文カードには任意の音声フィールドがあります。初回再生時に Cognis は全構成要素へのアクセスを認可し、最初の発音グループだけを選び、指定の変形を適用して、開始前の無音と単語・読点・文末の間を持つ一つの連続 WAV を生成します。録音は非公開でキャッシュし、構成音声のバイト列、読み、変形、間の変更で識別子が変わります。新規カードと既存カードの両方で必要時に生成します。通常の作成画面で音声をアップロードすると生成音声を即座に置き換え、明示ファイルを削除すると自動合成に戻ります。提供元は語の録音を提供し、Cognis が合成とキャッシュ方針を管理します。

### 文の活用形音声を維持

文の結合では、複数段階の経路を含む選択済み活用形の表記と第一発音を要求します。派生形の録音がない場合、基本形の発音リンクをたどらず明示的に失敗します。派生形の直接再生と入れ子の構成要素にも同じ規則を適用します。

### 使用方法

削除の確認はサーバーが保存済みのスキーマバージョンを使って計画し、現在のページに表示されていない依存カードも含めます。Study ゲートウェイクライアントはデータを変更しない削除事前確認を提供します。

`POST /api/v1/study/library/entries/deletion-plan`

### コンパクトなナビゲーション

スマートフォンとタブレットでは、Studyのページリンクを横スクロール可能な1行にまとめ、画面サイズやフォントの変更後も選択中のページを表示します。言語、辞書検索、設定は次の行に配置します。検索アイコンで開くダイアログは元のフォーム、選択したプロバイダー、入力内容を保持します。閉じるとフォーカスを戻し、ページ移動やデスクトップサイズへの変更時にも閉じます。概要は文書スクロールを使用します。スクロール中はメインナビゲーションを利用可能に保ち、ブランド行を折りたたみます。

表示領域が狭くなると、言語名を言語コード、次に旗へと短縮します。完全な言語名はアクセシブルなラベルとツールチップに残ります。旗がない言語ではコードを表示します。領域が広がると言語名に戻ります。

### 描画枠のサイズを統一

フローティング描画パッドは単語やパターンの縦横比に依存しない大きな枠で開きます。カードを切り替えても位置と手動で変更したサイズを維持し、描画の縦横比はキャンバス内で保たれます。

### 描画の進捗を保存

完了状態と非表示にするストローク数を、設定ストアでアカウントとカードごとに保存します。各試行、リセット、再試行では、その数に従って重複しない位置を新たにランダム選択します。間違いが一回以下で完了すると非表示数を一つ増やし、現在のストローク数を上限とします。完了済みのパターンでは次の一画の案内を維持し、未完了のパターンでは入力前に全体を表示します。`/api/v1/study/drawing/:cardId` への認証済み GET と POST は、`study:drawing:readProgress` と `study:drawing:complete` フローを実行し、ブラウザーはアカウント識別子を送信しません。

最後のストロークが受理されると、完了と次の難易度を直ちに保存します。描画パッドを閉じたり Explore から移動したりしても保存は中断しません。同じカードを再び開く場合や再試行する場合は、保存の完了を待って非表示ストロークを選びます。

### 書き取りの答えを隠す

パッドの見出しは最初に文字を隠し、共通ボタンをクリックすると表示します。別の文字を読み込むと再び隠します。フローティングセッションは解除可能な `study:drawing:observe` 機能で現在のカードを通知します。一致するLibraryプレビューは開いたままぼかして操作不能にし、パッドの文字変更または終了時に解除します。読みと意味はパッドに残します。埋め込みの書き取りにも同じ処理を適用し、文字の表示を補助付き試行として通知します。

### 書字パッドのナビゲーション

カード詳細から書字パッドを正常に開くと、詳細ポップアップを閉じます。隠された見出しは最初のクリックで表示します。Explore 上では表示済みの見出しをクリックするとカードを直接開き、ほかの Study ページでは Explore へ移動する前の確認を維持します。

フラッシュカードの選択肢は回答専用のボタンです。カードの見出しと表示された回答は、ホバー時にカードの URL を表示せず、移動時の確認とデッキの順序を維持するアプリ内操作を使用します。Explore 内では、表示された描画見出しをもう一度クリックすると、URL を持たない操作でカードを直接開きます。

書き取り練習では描画パッド内のマスクされた見出しだけを使用します。前後のカードに移動する SVG 矢印は、お気に入り操作とともにパッドの上に配置し、次への移動には回答が必要です。Flashcards は共有パッドに `suppressRetry: true` を渡して再試行を非表示かつ無効にし、単独の描画練習では既定で再試行を許可します。

埋め込み側は、共有の見出しの確認後に呼ばれる `onNavigate(card)` を指定できます。Flashcards はこの処理で移動用フローを通じて現在の試行を記録し、Explore を開く前にデッキの移動情報を維持します。

### 練習の選択を均等化

描画ガイドとフラッシュカードの解答シャッフルは`randomIndex`ヘルパーを共有します。Web Cryptoとマスク付き棄却サンプリングにより、1から2^32までの整数範囲で剰余による偏りを防ぎます。選択肢が1つの場合は乱数を消費しません。決定的なテストのために乱数源を注入できますが、通常の練習では常にWeb Cryptoを使用します。

### コンポーネントの分離と稼働状態

APIは有効なゲートウェイが所有するポリシーを通じて拡張機能の名前空間を委譲し、言語の規則はStudyが所有します。LibraryアダプターまたはStudy内の依存先を無効にすると、公開機能を登録解除し、保持された関数参照も拒否します。有効化すると再登録します。Studyアダプターは稼働状態に連動する登録に `onAvailabilityChange(listener)` を使用し、起動に失敗した場合は登録を取り消します。

### オフライン学習

設定のオフラインモードは既定で有効です。無効にすると従来の接続警告とエラー通知に戻り、ワーカーの代替表示を停止します。有効な場合は接続が切れるとエラー通知なしでオフラインモードに切り替わり、利用できない移動はエラーポップアップを出さずに制限します。

Study は現在のタブ内に容量制限付きの軽量 JSON スナップショットを保持します。対象はスキーマ、許可された文字・カードデータ、保存先、閲覧済み ID、お気に入り、以前開いたデッキです。言語スキーマは `metadata.offline: { cache: "lightweight" }` で対応を宣言します。Library キャッシュは最大 16 MB・100 件、その他の読み取りキャッシュは最大 4 MB・100 件です。音声バイト、辞書応答、認証情報、認証済み文書は永続保存しません。

Explore のプレビューは認可済みのキャッシュデータを使います。描画とフラッシュカード練習はローカルで動作します。完了、評価、閲覧済み ID、お気に入りの最終状態を送信待ちとして保存し、進捗・XP・報酬はサーバー確認後に確定します。音声・辞書・ElevenLabs の要求は停止します。編集・削除・共有には接続が必要です。容量制限内で以前読み込んだ内容のみ利用できます。

非公開の Study では、同じタブ内で以前検証済みの、有効期限内の同じアカウントセッションが必要です。非公開ページのオフライン再読み込みには接続が必要ですが、検証済みタブではバックグラウンド準備後にStudy へ初めてアクセスできます。アカウント・セッション、設定、モジュールの状態が変わるか、プロバイダーが破棄されると非公開スナップショットを無効化します。切断中はサーバーでのアクセス取り消しを検知できません。復旧時には未保存変更を確認してから再読み込みし、サーバーの認可を更新します。

### 送信待ちと同意

ホストは ctx 経由で `offline:outbox`、`offline:state`、`offline:accessPolicy` を提供します。各コンポーネントはプロバイダーの有効期間中に送信処理を登録し、安定した操作 ID を `offline:enqueue` に渡します。`offline:flush` が認可と送信を行います。永続キューはアカウント別で最大 1,000 件・1 MB・7 日間、トークンは保存しません。元の ID と時刻を維持し、一時的な失敗を再試行し、確認済みまたは恒久的に拒否された項目を削除します。拒否は翻訳済みの警告で通知します。ログアウトで当該アカウントのキューを消去し、他のアカウントのデータは送信しません。オフラインモードを無効にすると新規保存を停止します。既存の項目はオンラインで送信できます。

復旧ではプロバイダーを更新し、`authenticate-session` の最終段階 `afterSession` で送信します。必須プロバイダーはサーバーカタログに `offlineAccessGuard` を宣言します。要件が不明または未同意の場合はオフライン利用を拒否します。Terms of Service は最後に取得した文書の版とサーバー確認済みの同意をアカウント別に保存します。新しい未同意の版を取得すると、オフラインの読み取り・移動・書き込みを直ちに禁止し、オンラインで同意するまで送信も停止します。オフラインでは同意できません。非公開コンテンツはタブ内のみで、再読み込み後も残るのは容量制限付きのキューと法的文書です。 各認証の前に、最初の `beforeSession` 段階で以前の送信検証を消去します。

### Dashboard と Study の利用

Dashboard はセッション内限定の非公開オフラインアクセスを宣言し、アカウント概要とキャッシュ済みの予定を引き続き利用できます。オフラインで開き直す際はサーバーから取得する任意の拡張機能を省きます。Study のプロバイダーは既定の入口ルートを登録し、`study:navigation` フローを通じて言語一覧、学習設定、モジュールリンクのアカウントとセッションに紐付いたスナップショットを使用します。ナビゲーションバーの読み込み時に軽量なナビゲーション情報を先行取得します。Explore とフラッシュカードは引き続き各プロバイダーがルートを宣言し、未対応ページには静かな復帰処理を適用します。学習言語の変更には接続が必要です。

### オフライン学習アセット

Studyはオンライン時に、遅延読み込みするポップアップのアイコン、描画テンプレート、描画スタイル、閉じるアイコンを準備します。描画パッドを開いたり、ログインを妨げたりしません。接続回復後に再試行し、提供元の終了時に停止します。キャッシュ済みの文字は、オフラインで初めて描画パッドを開けます。オフラインではコンテンツを編集できず、開いている詳細画面も接続喪失時に編集を無効化します。装飾アイコンが取得できない場合は、リソースエラーのダイアログを表示せず、翻訳済みの操作ラベルを表示します。

### オフライン作業環境

認証済みログイン後、Study は登録済みの学習言語と指導言語について、スキーマ、読み取り可能な保存先、フォーム、閲覧済みマーカー、明示的に許可された軽量コレクションを準備します。Flashcards は既存のキャッシュ上限内で一覧と表示されるすべての該当デッキおよびカード詳細を準備します。登録言語の変更時も再準備します。同時読み取りは 2 ワーカーで制限し、プロバイダーの停止、アカウント変更、アクセス拒否、保存済みの法的同意を引き続き適用します。ページへの事前訪問は不要です。非公開スナップショットは認証済みタブとセッションに紐付きます。

### オフラインの Study 練習

Library の管理画面と編集・検索・申請ページには接続が必要です。Study のサブメニューは、切断直後も含めオフラインではこれらのリンクを残したまま無効にします。Explore ではキャッシュ済みコンテンツの閲覧と描画を引き続き利用できます。Library プロバイダーは Explore だけをオフラインセッションのルートとして登録します。

この動作については[共通の契約](/docs/api/technical)を参照してください。

### 滑らかな復旧と画面遷移

Study のナビゲーションは確認済みセッションのスナップショットをすぐに利用し、再検証を集約して最大三十秒に一度行います。初回のメタデータ取得は五秒、任意の辞書検出は三秒で打ち切ります。明確なアクセス拒否でスナップショットを無効化し、登録言語やモジュールの変更でナビゲーションデータを破棄します。失敗した子ページ検出は再試行できます。

### オフライン時の移動先表示

利用できない移動先も、メインナビゲーション、ユーザーメニュー、Study サブメニューに共通の無効表示で残します。Library と管理・申請へのリンクはオフライン中も一覧に残り、無効になって再接続後に有効に戻ります。表示する項目は引き続き Study の権限に従います。無効なリンクからはルートの読み込みや復旧通知を開始しません。Study の状態を引き継ぐ言語・設定リンクも同様です。キャッシュ済みの Explore と Flashcards は利用できます。

### 確認済みのお気に入り

オンラインで成功したお気に入り変更と再送の確認時に、Studyの容量制限付きオフラインスナップショットをサーバー応答で置き換えます。進行中の古い読み込みでは上書きできません。オフラインで画面を開き直しても確認済みの追加と削除を保持し、未送信の変更は引き続きスナップショットに重ねて表示します。

### セッションの識別

個人の活動と保存済み状態には、名前が `share:` で始まるアカウントも含め、検証済みのアカウントセッションを使用します。ゲスト制限は名前やブラウザーのマーカーではなく、検証済み認証情報の目的に基づきます。オフライン配信では、検証済みセッション、アカウント、インスタンスの確認を維持します。

### ダッシュボードのクラス概要

生徒用と教師用のダッシュボード項目は、説明文と生徒用のマイクラス操作に合わせて幅5列、高さ2行から始まります。Page Composer で拡大や配置変更を引き続き行えます。保存済みの配置と最小サイズは変わりません。既存のワークスペースガイドが配置編集を説明し、クラスガイドは引き続き各ページでクラス管理を案内します。

### 選択言語から学習を開始

`/study` を開くと、選択した利用可能な言語の Explore が直接表示されます。Study のナビゲーションと同じ選択規則を使い、意図的に選択した登録済み言語は学習登録がなくても維持します。それ以外は、学習登録した利用可能な言語の先頭を選びます。有効な選択も学習登録もない場合は、オンラインで言語設定に進みます。カタログや Explore の提供元が利用できない場合は既存の利用不可ページを表示します。オフラインのメタデータがない場合は Page Composer の空の Study ページを表示します。

`study:navigation:enter` フローは `resolve` と `navigate` の段階で構成されます。共通の Study ナビゲーションモデルと提供元のスキーマを使い、解決した言語と履歴置換を指定して `ui:navigate` を呼び出します。コンテンツ、デッキ、Library、その他の Study ページへの直接リンクは維持します。ページの置換、中止、提供元の破棄によって待機中の解決を無効にし、学習登録や提供元の変更時は再解決します。アクセス拒否を隠さず、ルーターによる中止を尊重し、待機中に言語一覧を表示しません。

### ガイドを使う

Explore のページタイトル横にある ? から Study の概要を選びます。この手動ガイドは、ナビゲーション、選択言語、利用可能な辞書検索、学習設定を説明します。現在のレイヤーを維持し、利用できない操作は省きます。言語ごとのガイドはコンテンツを説明し、その言語だけを対象とします。

概要の完了識別子 `study:getting-started` は維持します。次へ、戻る、再開を使ってページを移動せずにナビゲーションを確認できます。完了したガイドは同じ ? メニューから再実行できます。言語ガイドは学習登録した自身の言語のコンテンツで自動開始でき、選択言語を変えると対応するガイドが表示されます。

`study:tutorialTargets` は Study 所有のナビゲーションと描画の対象、およびスコープ付きの `route` と `attachDrawing` 操作を公開します。`matchesPage` は指定言語の Explore パスだけに一致します。`isEnrolled(language)` は `study:navigation` を通じて確認済みのアカウント別設定を読みます。ガイドの検出では移動も学習登録も行いません。対話型のカード操作と汎用の代替ガイドは Library が所有します。

## セキュリティ

学習には現在のアカウントと言語登録を使います。クラス参加や教材の公開範囲は担当元が検証し、オフラインの保存状態で権限や同意を回避しません。

## リファレンス

### 参照データの収録範囲

日本語の参照カタログは同梱する公式 KANJIDIC2 データの全 13,108 字、英語のカタログは Open English WordNet の全 135,969 語彙項目（正規化キー 127,311 件）を収録します。別の遅延読込辞書プロバイダーであり、149,077 件のカードを起動時に一括取り込みするものではありません。Study 検索で参照辞書を選び、対応項目を通常のグラフ検証経由で取り込みます。意味や使用可能な読みがない項目は不明のままとし、発音・翻訳・筆順を捏造しません。全 Unicode 漢字や存在し得る全英単語の網羅を意味しません。

漢字の読みは JMdict の一般的な用例と利用可能な頻度情報に基づき、送り仮名形も含めて並べます。グループ参照と初期音声は同じ順序に従い、漢字再生は常に最初の読みを使います。既存英単語カードには一つの IPA を収録し、参照項目は優先する英国発音内の原資料の順序を他の方言より先に維持します。発音頻度は文脈に依存し、原資料は全ての読みの普遍的順位を提供しません。

`python3 scripts/import-reference.py --source <source-file>` で参照シャードを再生成します。日本語は `--priorities <reading-priorities.json>` に対応します。`data/reference/manifest.json` に原資料のチェックサム、帰属、件数、シャードのハッシュを記録します。要求されたキーのシャードだけを読み込み、実行時の検索結果は Cognis がキャッシュします。

### 参照項目の完全な読みの録音

日本語はさらに `data/audio/reference/` の容量制限付きバンクに、完全な読みのニューラル音声 2,913 件を同梱します。初期録音と合わせて、原資料で読みが分かる全 12,356 字の優先読みに対応します。残る 752 字には読みが記録されておらず、音声を捏造しません。索引は最初の読みを選び、ファイル範囲と中断を確認します。`python3 scripts/reference-audio.py plan --work <directory>` で計画を作り、合成スクリプトで一覧を処理し、`pack` で容量制限付きバンクを生成します。

日本語の並べ替えツールは `--dictionary <JMdict.gz> --kanji-dictionary <KANJIDIC2.xml.gz> --output <priorities.json>` と任意の `--content-root data/library/content` に対応します。一般的な独立語の読みを優先し、他の読みは実在語の対応付けを頻度で重み付けして並べ、`data/audio/primary-readings.json` の確認済み単字カード用の指定を維持します。連濁と促音化は原資料の標準読みに戻して集計します。訓・音・名乗りの読みを保持し、選択された最初の読みだけが再生とキャッシュ識別を決めます。頻度情報は順序付けの手掛かりであり、全発音に通用する普遍的な頻度測定ではありません。

自動合成には発話対象の構成要素の録音が必要です。不足する録音は明示的なエラーとし、通常の音声アップロード欄から補えます。同梱アルファベットに結び付けられない参照項目の綴りは、原文と定義を保持し、架空の綴りリンクを作りません。

### 技術仕様

`{ "entryIds": ["entry-id"] }` → `{ "data": { "entryIds": ["entry-id"], "entries": [{ "id": "entry-id", "label": "..." }] } }`

不足している翻訳を取得する操作は `{ translations, languages }` を `POST /api/v1/study/library/definitions/localize` に送信します。`localization:translateString` で不足する UI 言語を取得し、既存の翻訳を保持します。プロバイダーがない場合や失敗した場合は `missingLanguages` を返します。不足する訳文は編集でき、英語を別の言語の欄にコピーしません。定義を手動で追加する場合にも利用できます。

### 技術仕様

ギャラリーはパスから言語を解決し、Study の公開契約で表示可能なデッキを絞り込みます。詳細 URL は言語とデッキ UUID を示し、言語変更時は対応するギャラリーへ戻ります。一時的なクエリデータを URL に持ち込みません。

Study はリクエストなどのアダプター所有リンクに、アクティブなアダプタールートの `navigationLabels` を使用します。これらのラベルキーをゲートウェイの言語バンドルで解決しません。表示ラベルは UI の完全なロケール、基本言語、英語の順で選択し、Study 所有のリンクには引き続きゲートウェイの XML リソースを使用します。

### 筆順ガイドを統一

未完了のパターンでは最初の入力前に全ストロークを表示します。入力開始後は文字の境界を越えて次の一画だけを案内します。完了済みのパターンは最初から次の一画の案内となり、知識確認用の非表示ストロークと表示操作を維持します。
