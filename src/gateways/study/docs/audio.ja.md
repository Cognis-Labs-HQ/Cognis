# 発音音声

Bootstrap は `study:audio:provider` を必須とし、辞書と筆順のプロバイダーとともに解除可能な音声プロバイダーを登録します。発話ラベルと優先する読みに基づいて同梱録音を解決し、容量制限付きでファイルを読み、不足する音声は明示的なエラーにします。解除時には処理中の取得を中断します。Cognis はカードへのアクセスを認可し、スキーマから選択した変形の発話形を導出し、作成済みフィールドを変更せず Files に非公開キャッシュを保存します。`study:library:audio` フローは認可、検証、解決を実行し、`study:audio:fetch` はプロバイダーのバイト列を検証して取得します。文の音声は構成要素を順番に再生します。

## 音声プロバイダー契約

`study:audio:provider.registerProvider({ id, revision, languages, fetchAudio })` → disposer.

`fetchAudio({ language, label, semanticRole, readings }, signal)` → `{ mediaType, data: Uint8Array }`.

両方の Study モジュールが同じ解除可能な音声プロバイダー契約を使い、制限付きのローカル読み込みで同梱録音を取得します。認可、キャッシュ方針、合成再生はホストが所有します。

発音対象の初期カードは `data/library/assets/audio/` に生成済み MP3 を含み、同じ発話テキストは一つのファイルを共有します。英語はパブリックドメインの LJ Speech データセットに基づく音声を使い、Piper でオフライン生成します。日本語は Open JTalk と HTS Voice Mei でオフライン生成し、CC BY に基づいて MMDAgent プロジェクトチームと名古屋工業大学を帰属表示します。音声の権利表示と録音一覧は `data/audio/` に置きます。句読点は発音せず、文の合成音声ファイルは作成しません。Cognis が構成要素の音声を順番に再生します。

音声の取得は学習者が再生を要求したときに始まり、カードを開くだけでは音声を要求しません。再生エラーはホストのローカライズ済みトーストと構造化ログで示します。文の構成要素は選択した変形記述を保持し、認証済み音声エンドポイントは任意の表示テキストを受け取らず、スキーマから発話形を導出します。英語の文字組み合わせの初期音声は記載された IPA 音素から合成し、アルファベットの音声は文字名を発音します。
