# Study のナビゲーション

Flashcards は `/study/<iso>/flashcards` と `/study/<iso>/flashcards/<deck-id>` を使用します。言語の切り替えは該当する一覧を開き、別言語のデッキを引き継ぎません。`/study/flashcards` は現在の言語を解決します。ライブラリーとリクエストは共通ページのままです。

## 使用例

`/study/ja/flashcards` で日本語のデッキを開き、英語を選ぶと `/study/en/flashcards` を開きます。

## 技術仕様

ギャラリーはパスから言語を解決し、Study の公開契約で表示可能なデッキを絞り込みます。詳細 URL は言語とデッキ UUID を示し、言語変更時は対応するギャラリーへ戻ります。一時的なクエリデータを URL に持ち込みません。

Study はリクエストなどのアダプター所有リンクに、アクティブなアダプタールートの `navigationLabels` を使用します。これらのラベルキーをゲートウェイの言語バンドルで解決しません。表示ラベルは UI の完全なロケール、基本言語、英語の順で選択し、Study 所有のリンクには引き続きゲートウェイの XML リソースを使用します。

## 描画枠のサイズを統一

フローティング描画パッドは単語やパターンの縦横比に依存しない大きな枠で開きます。カードを切り替えても位置と手動で変更したサイズを維持し、描画の縦横比はキャンバス内で保たれます。

## 筆順ガイドを統一

未完了のパターンでは最初の入力前に全ストロークを表示します。入力開始後は文字の境界を越えて次の一画だけを案内します。完了済みのパターンは最初から次の一画の案内となり、知識確認用の非表示ストロークと表示操作を維持します。

## 描画の進捗を保存

完了状態と非表示にするストローク数を、設定ストアでアカウントとカードごとに保存します。各試行、リセット、再試行では、その数に従って重複しない位置を新たにランダム選択します。間違いが一回以下で完了すると非表示数を一つ増やし、現在のストローク数を上限とします。完了済みのパターンでは次の一画の案内を維持し、未完了のパターンでは入力前に全体を表示します。`/api/v1/study/drawing/:cardId` への認証済み GET と POST は、`study:drawing:readProgress` と `study:drawing:complete` フローを実行し、ブラウザーはアカウント識別子を送信しません。

最後のストロークが受理されると、完了と次の難易度を直ちに保存します。描画パッドを閉じたり Explore から移動したりしても保存は中断しません。同じカードを再び開く場合や再試行する場合は、保存の完了を待って非表示ストロークを選びます。

## 書き取りの答えを隠す

パッドの見出しは最初に文字を隠し、共通ボタンをクリックすると表示します。別の文字を読み込むと再び隠します。フローティングセッションは解除可能な `study:drawing:observe` 機能で現在のカードを通知します。一致するLibraryプレビューは開いたままぼかして操作不能にし、パッドの文字変更または終了時に解除します。読みと意味はパッドに残します。埋め込みの書き取りにも同じ処理を適用し、文字の表示を補助付き試行として通知します。

## 保存される学習設定

辞書選択に theme-select を適用し、候補が一つなら非表示にします。設定アイコンを辞書検索の右側へ移します。KANJIDIC2 は漢字情報の補完用とし、Jisho と並ぶ検索候補にはしません。参照資料には実際の資料名を表示します。

読み書きモードは Composer のフローティングメニューで保存するアカウント設定です。既定は読み方です。練習中の変更は共通の警告ポップアップで確認してからキューを再開します。キャンセルすると位置と回答を維持し、送信済みの復習記録も保持します。サイドバーには「すべて」を追加し、現在のデッキを示します。書字の見出しは同じ大きさの代替文字をぼかします。最初のクリックで文字を表示して Explore リンクを有効にし、次のクリックで移動を確認します。キーボードでも同じ操作ができます。
