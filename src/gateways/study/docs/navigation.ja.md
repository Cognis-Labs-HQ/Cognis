# Study のナビゲーション

## 拡張可能なブラウザー操作

Libraryのブラウザークライアントはctxから`study:library:client`を取得します。プロバイダーは読み取り、辞書操作、リクエスト、インポート、メディアに対し、`study:library:<clientFunction>`の`before`、`execute`、`after`を登録します。ルートで要求した機能により、ページをマウントする前にプロバイダーを読み込みます。拡張の引数、拒否、解除時の動作はLibraryアダプターのドキュメントを参照してください。

## 使用例

`/study/ja/flashcards` で日本語のデッキを開き、英語を選ぶと `/study/en/flashcards` を開きます。

## 技術仕様

ギャラリーはパスから言語を解決し、Study の公開契約で表示可能なデッキを絞り込みます。詳細 URL は言語とデッキ UUID を示し、言語変更時は対応するギャラリーへ戻ります。一時的なクエリデータを URL に持ち込みません。

Study はリクエストなどのアダプター所有リンクに、アクティブなアダプタールートの `navigationLabels` を使用します。これらのラベルキーをゲートウェイの言語バンドルで解決しません。表示ラベルは UI の完全なロケール、基本言語、英語の順で選択し、Study 所有のリンクには引き続きゲートウェイの XML リソースを使用します。

## 描画枠のサイズを統一

フローティング描画パッドは単語やパターンの縦横比に依存しない大きな枠で開きます。カードを切り替えても位置と手動で変更したサイズを維持し、描画の縦横比はキャンバス内で保たれます。

## 筆順ガイドを統一

未完了のパターンでは最初の入力前に全ストロークを表示します。入力開始後は文字の境界を越えて次の一画だけを案内します。完了済みのパターンは最初から次の一画の案内となり、知識確認用の非表示ストロークと表示操作を維持します。

## 描画の進捗を保存

完了状態と非表示にするストローク数を、設定ストアでアカウントとカードごとに保存します。各試行、リセット、再試行では、その数に従って重複しない位置を新たにランダム選択します。間違いが一回以下で完了すると非表示数を一つ増やし、現在のストローク数を上限とします。完了済みのパターンでは次の一画の案内を維持し、未完了のパターンでは入力前に全体を表示します。`/api/v1/study/drawing/:cardId` への認証済み GET と POST は、`study:drawing:readProgress` と `study:drawing:complete` フローを実行し、ブラウザーはアカウント識別子を送信しません。

最後のストロークが受理されると、完了と次の難易度を直ちに保存します。描画パッドを閉じたり Explore から移動したりしても保存は中断しません。同じカードを再び開く場合や再試行する場合は、保存の完了を待って非表示ストロークを選びます。

## 書き取りの答えを隠す

パッドの見出しは最初に文字を隠し、共通ボタンをクリックすると表示します。別の文字を読み込むと再び隠します。フローティングセッションは解除可能な `study:drawing:observe` 機能で現在のカードを通知します。一致するLibraryプレビューは開いたままぼかして操作不能にし、パッドの文字変更または終了時に解除します。読みと意味はパッドに残します。埋め込みの書き取りにも同じ処理を適用し、文字の表示を補助付き試行として通知します。

## 保存される学習設定

辞書選択に theme-select を適用し、候補が一つなら非表示にします。設定アイコンを辞書検索の右側へ移します。KANJIDIC2 は漢字情報の補完用とし、Jisho と並ぶ検索候補にはしません。参照資料には実際の資料名を表示します。

読み書きモードは Composer のフローティングメニューで保存するアカウント設定です。既定は読み方です。練習中の変更は共通の警告ポップアップで確認してからキューを再開します。キャンセルすると位置と回答を維持し、送信済みの復習記録も保持します。サイドバーには「すべて」を追加し、現在のデッキを示します。書字の見出しは同じ大きさの代替文字をぼかします。最初のクリックで文字を表示して Explore リンクを有効にし、次のクリックで移動を確認します。キーボードでも同じ操作ができます。

## 書字パッドのナビゲーション

カード詳細から書字パッドを正常に開くと、詳細ポップアップを閉じます。隠された見出しは最初のクリックで表示します。Explore 上では表示済みの見出しをクリックするとカードを直接開き、ほかの Study ページでは Explore へ移動する前の確認を維持します。

フラッシュカードの選択肢は回答専用のボタンです。カードの見出しと表示された回答は、ホバー時にカードの URL を表示せず、移動時の確認とデッキの順序を維持するアプリ内操作を使用します。Explore 内では、表示された描画見出しをもう一度クリックすると、URL を持たない操作でカードを直接開きます。

書き取り練習では描画パッド内のマスクされた見出しだけを使用します。前後のカードに移動する SVG 矢印は、お気に入り操作とともにパッドの上に配置し、次への移動には回答が必要です。Flashcards は共有パッドに `suppressRetry: true` を渡して再試行を非表示かつ無効にし、単独の描画練習では既定で再試行を許可します。

埋め込み側は、共有の見出しの確認後に呼ばれる `onNavigate(card)` を指定できます。Flashcards はこの処理で移動用フローを通じて現在の試行を記録し、Explore を開く前にデッキの移動情報を維持します。

## Studyの認証契約を適用

Studyはルート登録前にAuthenticationゲートウェイと`auth:routeContext`機能を必要とします。アダプター管理、言語の検出、描画の各ルートは、独自のアクセス制御も含めて注入されたコンテキストを使用します。認証契約がない場合は既定の制御を選ばず、起動を失敗させます。

## 練習の選択を均等化

描画ガイドとフラッシュカードの解答シャッフルは`randomIndex`ヘルパーを共有します。Web Cryptoとマスク付き棄却サンプリングにより、1から2^32までの整数範囲で剰余による偏りを防ぎます。選択肢が1つの場合は乱数を消費しません。決定的なテストのために乱数源を注入できますが、通常の練習では常にWeb Cryptoを使用します。

## コンポーネントの分離と稼働状態

APIは有効なゲートウェイが所有するポリシーを通じて拡張機能の名前空間を委譲し、言語の規則はStudyが所有します。LibraryアダプターまたはStudy内の依存先を無効にすると、公開機能を登録解除し、保持された関数参照も拒否します。有効化すると再登録します。Studyアダプターは稼働状態に連動する登録に `onAvailabilityChange(listener)` を使用し、起動に失敗した場合は登録を取り消します。

## オフライン学習

設定のオフラインモードは既定で有効です。無効にすると従来の接続警告とエラー通知に戻り、ワーカーの代替表示を停止します。有効な場合は接続が切れるとエラー通知なしでオフラインモードに切り替わり、利用できない移動はエラーポップアップを出さずに制限します。

Study は現在のタブ内に容量制限付きの軽量 JSON スナップショットを保持します。対象はスキーマ、許可された文字・カードデータ、保存先、閲覧済み ID、お気に入り、以前開いたデッキです。言語スキーマは `metadata.offline: { cache: "lightweight" }` で対応を宣言します。Library キャッシュは最大 16 MB・100 件、その他の読み取りキャッシュは最大 4 MB・100 件です。音声バイト、辞書応答、認証情報、認証済み文書は永続保存しません。

Explore のプレビューは認可済みのキャッシュデータを使います。描画とフラッシュカード練習はローカルで動作します。完了、評価、閲覧済み ID、お気に入りの最終状態を送信待ちとして保存し、進捗・XP・報酬はサーバー確認後に確定します。音声・辞書・ElevenLabs の要求は停止します。編集・削除・共有には接続が必要です。容量制限内で以前読み込んだ内容のみ利用できます。

非公開の Study では、同じタブ内で以前検証済みの、有効期限内の同じアカウントセッションが必要です。非公開ページのオフライン再読み込みには接続が必要ですが、検証済みタブではバックグラウンド準備後にハブへ初めてアクセスできます。アカウント・セッション、設定、モジュールの状態が変わるか、プロバイダーが破棄されると非公開スナップショットを無効化します。切断中はサーバーでのアクセス取り消しを検知できません。復旧時には未保存変更を確認してから再読み込みし、サーバーの認可を更新します。

## 送信待ちと同意

ホストは ctx 経由で `offline:outbox`、`offline:state`、`offline:accessPolicy` を提供します。各コンポーネントはプロバイダーの有効期間中に送信処理を登録し、安定した操作 ID を `offline:enqueue` に渡します。`offline:flush` が認可と送信を行います。永続キューはアカウント別で最大 1,000 件・1 MB・7 日間、トークンは保存しません。元の ID と時刻を維持し、一時的な失敗を再試行し、確認済みまたは恒久的に拒否された項目を削除します。拒否は翻訳済みの警告で通知します。ログアウトで当該アカウントのキューを消去し、他のアカウントのデータは送信しません。オフラインモードを無効にすると新規保存を停止します。既存の項目はオンラインで送信できます。

復旧ではプロバイダーを更新し、`authenticate-session` の最終段階 `afterSession` で送信します。必須プロバイダーはサーバーカタログに `offlineAccessGuard` を宣言します。要件が不明または未同意の場合はオフライン利用を拒否します。Terms of Service は最後に取得した文書の版とサーバー確認済みの同意をアカウント別に保存します。新しい未同意の版を取得すると、オフラインの読み取り・移動・書き込みを直ちに禁止し、オンラインで同意するまで送信も停止します。オフラインでは同意できません。非公開コンテンツはタブ内のみで、再読み込み後も残るのは容量制限付きのキューと法的文書です。 各認証の前に、最初の `beforeSession` 段階で以前の送信検証を消去します。

## Dashboard と Study の利用

Dashboard はセッション内限定の非公開オフラインアクセスを宣言し、アカウント概要とキャッシュ済みの予定を引き続き利用できます。オフラインで開き直す際はサーバーから取得する任意の拡張機能を省きます。Study のプロバイダーはハブルートを登録し、`study:navigation` フローを通じて言語一覧、学習設定、モジュールリンクのアカウントとセッションに紐付いたスナップショットを使用します。ナビゲーションバーの読み込み時に軽量なハブ情報を先行取得します。Explore とフラッシュカードは引き続き各プロバイダーがルートを宣言し、未対応ページには静かな復帰処理を適用します。学習言語の変更には接続が必要です。

## オフライン学習の空画面

準備済みの Study ページは、検証済みで必要な同意を満たすオフラインセッションなら非公開コンテンツの保存がなくても開けます。未保存の言語や設定は空のナビゲーションになります。Explore は通常の空の一覧を表示し、ルート利用不可やエラー通知の代わりに「オフライン用に保存されたコンテンツはありません」と案内します。Flashcards もデッキや必要な表示リソースがなければ空画面を維持します。通知は現在のページに限定し、重複表示しません。キャッシュ不足を理由にアクセス拒否や同意拒否を隠しません。Library と Flashcards は公開の翻訳や軽量テンプレートをオンラインで準備し、非公開データは容量制限付きのタブ内キャッシュに留めます。

## オフライン学習アセット

Studyはオンライン時に、遅延読み込みするポップアップのアイコン、描画テンプレート、描画スタイル、閉じるアイコンを準備します。描画パッドを開いたり、ログインを妨げたりしません。接続回復後に再試行し、提供元の終了時に停止します。キャッシュ済みの文字は、オフラインで初めて描画パッドを開けます。オフラインではコンテンツを編集できず、開いている詳細画面も接続喪失時に編集を無効化します。装飾アイコンが取得できない場合は、リソースエラーのダイアログを表示せず、翻訳済みの操作ラベルを表示します。

## オフライン利用の維持

オフラインのルート登録は、バンドル版と直接配信版の繰り返し読み込みでも保持されます。スクリプト、スタイル、機能提供元が同じルート記述を再構築しても準備状態を維持し、アセットが変わった場合は再準備が必要です。メッセージは認証済みログイン後にチャット一覧、翻訳、絵文字カタログを準備します。初めてオンラインで訪問する前でもオフラインでページを開けます。自動で開くのはチャット情報と履歴がキャッシュ済みの場合だけで、未保存の履歴を選ぶと専用の情報トーストを表示します。Exploreは別のコレクションや閲覧済み情報が欠けていても、利用可能なキャッシュ済み項目を維持します。権限や同意の拒否は引き続き伝播します。バナーのボタンは共通の操作行に直接配置し、継承した上下のずれを解消します。

## 学習お気に入りの共有

Study提供元は、ライフサイクルに従う `load`、`toggle`、`has` 操作を持つ `study:favourites` を公開します。表示用の関数はローダーごとのキャッシュを作らず、このctx機能を参照します。認証確認後にお気に入りを準備し、保留中の変更を反映して、Explore、フラッシュカード、繰り返し読み込んだモジュール間でアカウントとセッションに紐付く状態を共有します。任意のお気に入りスナップショットがない場合は空の選択にキュー内の変更を適用し、キャッシュ済みコンテンツを隠したり更新失敗のトーストを出したりしません。アカウント変更時は表示上の選択を消し、権限拒否をキャッシュ欠落とは扱いません。
