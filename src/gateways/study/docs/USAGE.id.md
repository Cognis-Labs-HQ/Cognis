# Penggunaan

Prosedur praktis untuk Belajar.

## Prasyarat

Masuk dan daftar pada bahasa yang terpasang.

## Contoh

Pilih bahasa terdaftar, buka alat belajar, dan cari kata memakai penyedia kamus tersedia.

Server merencanakan konfirmasi penghapusan menggunakan versi skema tersimpan dan menyertakan kartu dependan yang tidak ada di halaman saat ini. Klien gateway Study menyediakan pemeriksaan penghapusan tanpa perubahan data.

`POST /api/v1/study/library/entries/deletion-plan`

Buka `/study/ja/flashcards` untuk deck Jepang; memilih Inggris membuka `/study/en/flashcards`.

## Hasil yang Diharapkan

Navigasi menampilkan alat dan konten tersedia; nama yang memendek tidak mengubah bahasa terpilih.

## Pemecahan Masalah

Periksa pendaftaran bahasa, penyedia, dan persiapan luring. Adapter opsional yang hilang menghapus alatnya, bukan seluruh Study.
