# Kalender

Rencanakan acara, beralih kalender, dan bagikan jadwal dengan orang lain.

## Yang Dapat Anda Lakukan

Buat kalender dan acara, tinjau jadwal, dan bagikan konten yang diizinkan.

## Sebelum Memulai

Masuk; perubahan acara memerlukan kepemilikan atau izin edit.

## Langkah Awal

Buka Kalender dan pilih kalender di bilah samping.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/calendar/usage) menjelaskan prosedur. [Teknis](/docs/gateways/calendar/technical) mendokumentasikan antarmuka dan konfigurasi.
