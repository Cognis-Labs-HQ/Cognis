# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

## 技術仕様

| ページ・画面 | ガイド             | アクセス           |
| ------------ | ------------------ | ------------------ |
| `/calendar`  | カレンダーの使い方 | ログイン済み利用者 |

公開機能 `ui:tutorials` を通じて、コンポーネント所有の定義、カタログ、対象、ライフサイクルのシグナルを登録します。ページ、表示中の領域、アクセス権により利用可否が決まります。コンポーネントを解除するとガイドも解除します。共通の表示と完了動作は[ホストのチュートリアル契約](/docs/tutorials)を参照してください。

予定がなくても日付操作を強調します。予定作成ではカレンダー全体を繰り返さず、実際の作成対象を一つ強調します。

予定作成の案内は作成枠を対象に保ち、広いフォーム、狭い画面の読み順、スクロールを説明します。予定の手順では斜線付きの未回答の招待を説明します。案内ID、6つの手順、highlightNextの値、ページの有効期間は変更されません。空のカレンダーでも日付移動と作成の対象を利用できます。
