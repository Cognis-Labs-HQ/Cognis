# 使用例

カレンダー の実践的な操作手順です。

## 前提条件

アカウントまたは有効な共有リンクでカレンダーを開きます。予定の変更には所有権または編集権限が必要です。

## 使用例

日時を指定して予定を保存し、表示期間を変えて位置を確認します。

グリッド表示では、年表示の月名からその月を、週番号からその週を、日付の表示からその日を開けます。読み取り専用の共有カレンダーでも、これらの操作で移動できます。

「今日」「今週」「今月」「今年」で、選択中の表示を変えずに現在の期間へ戻れます。矢印は選択した表示の期間単位で移動します。共有カレンダーでも同じ操作を使えます。

## 期待される結果

保存した予定が表示され、狭い画面では一覧、広い画面ではグリッドも利用できます。

## 問題の解決

対象、期間、タイムゾーンを確認してください。共有とオフラインキューにはそれぞれの権限と配信規則が適用されます。
