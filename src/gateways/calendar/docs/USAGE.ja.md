# 使用例

カレンダー の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/calendar)を確認してください。

## 使用例

- 予定を追加する前に、カレンダーと公開範囲を確認します。
- 日、週、月、年を選択します。スマートフォンの日、週、月の表示では、すべての予定と各日付の予定追加操作を見やすい一覧で表示します。
- 予定を開き、詳細、参加者、招待への回答を確認してから変更します。
- 日付の操作で期間を移動し、予定に合うカレンダー表示を選びます。
- 日時を選んで予定を作ります。保存前にカレンダー、時刻、繰り返し、公開範囲、通知を設定します。
- 今後の予定から詳細や招待を確認します。繰り返し予定の編集では、今回だけかシリーズ全体かを確認します。

## 期待される結果

この例は カレンダー の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/calendar/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

カレンダー を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
