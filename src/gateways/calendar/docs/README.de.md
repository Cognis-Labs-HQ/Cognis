# Kalender

Planen Sie Termine, wechseln Sie zwischen Kalendern und teilen Sie Zeitpläne mit anderen.

## Möglichkeiten

- Wählen Sie einen Kalender und prüfen Sie seine Sichtbarkeit vor dem Anlegen eines Termins.
- Wähle Tag, Woche, Monat oder Jahr. Auf Telefonen zeigen Tag, Woche und Monat eine lesbare Terminliste mit allen Ereignissen und einer Aktion zum Hinzufügen für jedes Datum.
- Öffnen Sie Termine und prüfen Sie Details, Teilnehmer und Einladungsstatus vor Änderungen.

## Vor dem Start

Prüfen Sie, ob Kalender aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/calendar) und wählen Sie die gewünschte Aktion.
