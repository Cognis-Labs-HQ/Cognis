# Kalender

Planen Sie Termine, wechseln Sie zwischen Kalendern und teilen Sie Zeitpläne mit anderen.

## Möglichkeiten

Erstelle Kalender und Termine, prüfe Zeitpläne und teile erlaubte Inhalte.

## Vor dem Start

Melde dich an; Änderungen benötigen Eigentum oder Bearbeitungsrechte.

## Erste Schritte

Öffne Kalender und wähle einen Kalender in der Seitenleiste.
