# カレンダー

予定を作成し、カレンダーを切り替えて、他の人と日程を共有できます。

## できること

- 予定を追加する前に、カレンダーと公開範囲を確認します。
- 日、週、月、年を選択します。スマートフォンの日、週、月の表示では、すべての予定と各日付の予定追加操作を見やすい一覧で表示します。
- 予定を開き、詳細、参加者、招待への回答を確認してから変更します。

## 始める前に

カレンダー が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/calendar) を開き、必要な操作を選びます。

手順は[使用例](/docs/gateways/calendar/usage)、インターフェースと設定は[技術情報](/docs/gateways/calendar/technical)を参照してください。
