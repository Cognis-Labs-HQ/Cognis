# Usage

Practical procedures for Calendar.

## Prerequisites

Review [the access requirements](/docs/gateways/calendar) before performing these procedures.

## Examples

- Choose a calendar and check its visibility before adding an event.
- Choose a day, week, month or year. On phones, day, week and month show a readable agenda with every event and an Add Event action for each date.
- Open an event to review details, participants and invitation status before making changes.
- Use the date navigation to move between periods, then choose the calendar view that best fits your schedule.
- Select a date or time to create an event. Set its calendar, time, recurrence, visibility and reminders before saving.
- Open an upcoming event to review details and invitations. For repeating events, check whether an edit applies to one occurrence or the series.

## Expected Results

The example uses the documented interface of Calendar. Confirm the response or saved state described in [Technical](/docs/gateways/calendar/technical) before repeating a write operation.

## Troubleshooting

If Calendar is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
