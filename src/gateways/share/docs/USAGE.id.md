# Penggunaan

Prosedur praktis untuk Berbagi.

## Prasyarat

Tinjau [persyaratan akses](/docs/gateways/share) sebelum menjalankan prosedur ini.

## Contoh

Periksa argumen perintah yang terpasang sebelum menjalankan operasi.

```sh
cognisctl share:tokens --help
cognisctl share:resolve --help
cognisctl share:recipients:users --help
cognisctl share:approvals:pending --help
```

## Hasil yang Diharapkan

Contoh ini memakai antarmuka Berbagi yang didokumentasikan. Periksa respons atau keadaan tersimpan yang dijelaskan dalam [Teknis](/docs/gateways/share/technical) sebelum mengulangi operasi tulis.

## Pemecahan Masalah

Jika Berbagi tidak tersedia, periksa status masuk dan minta administrator memeriksa komponen beserta dependensinya.
