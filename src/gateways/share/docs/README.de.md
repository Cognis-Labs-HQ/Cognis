# Freigaben

Teilen Sie unterstützte Inhalte mit ausgewählten Personen oder über einen öffentlichen Link mit festgelegten Rechten.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Freigaben aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/gateways/share/usage) erklärt Abläufe. [Technik](/docs/gateways/share/technical) beschreibt Schnittstellen und Konfiguration.
