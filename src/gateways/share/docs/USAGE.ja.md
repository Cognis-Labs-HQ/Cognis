# 使用例

共有 の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/share)を確認してください。

## 使用例

操作する前に、インストール済みコマンドの引数をヘルプで確認してください。

```sh
cognisctl share:tokens --help
cognisctl share:resolve --help
cognisctl share:recipients:users --help
cognisctl share:approvals:pending --help
```

## 期待される結果

この例は 共有 の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/share/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

共有 を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
