# Share ブラウザークライアント

アダプターは自身のナビゲーションプロバイダーを宣言し、有効状態に連動させます。送信者の取得には具体的な通知ゲートウェイではなく `notify:listSenders` を使います。Share の定期保守はゲートウェイの停止と再開に従います。

Share ブラウザークライアントは、Share ゲートウェイの公開ブラウザー契約を通じて、現在認証されている共有ゲストプロフィールをモジュールが取得できるようにします。

## 使用例

`uiCtx` をインポートして `share:uiClient` を要求し、`getGuestProfile()` を呼び出します。返された `Response` を確認してから `{ data }` JSON ペイロードを読み取ります。

## 技術仕様

クライアントは `/api/v1/share/guest-profile` を所有し、元の `Response` を返し、認証と接続処理をホスト API クライアントへ委ねます。プロバイダーは Share ゲートウェイが有効な場合だけ動作するため、マウント時に必要とするルートは `share:uiClient` を宣言する必要があります。

共有アクションを描画するブラウザーコンポーネントは `share:uiGateway` を要求し、`mountTrigger(container, options)` を呼び出します。ローカライズ済みのアイコンとラベル、操作結果に応じたスタイル、ゲストセッションでの非表示、破棄ハンドルはゲートウェイが所有し、利用側はコンテナと起動コールバックだけを渡します。
