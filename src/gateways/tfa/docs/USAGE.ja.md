# 使用例

二要素認証 の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/tfa)を確認してください。

## 使用例

- 利用できる方式を選び、ログインに使う前に設定を完了します。
- 有効な方式を並べ替え、最初に使う方式を決めます。
- 通常の第2認証要素が使えない場合は、リカバリーコードでログインできます。ログインせずに取り出せる場所に控えを保管してください。
- 全アカウントへの影響を確認してから、二要素認証を必須にします。
- 必須設定と利用者に必要な準備を見直してから保存します。

## 期待される結果

この例は 二要素認証 の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/tfa/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

二要素認証 を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
