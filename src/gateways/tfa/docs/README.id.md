# Autentikasi Dua Faktor

Lindungi akun Anda dengan langkah verifikasi kedua saat masuk.

## Yang Dapat Anda Lakukan

Tambahkan langkah verifikasi kedua saat masuk.

## Sebelum Memulai

Selesaikan penyiapan metode tersedia sebelum mengandalkannya.

## Langkah Awal

Buka keamanan akun di Pengaturan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/tfa/usage) menjelaskan prosedur. [Teknis](/docs/gateways/tfa/technical) mendokumentasikan antarmuka dan konfigurasi.
