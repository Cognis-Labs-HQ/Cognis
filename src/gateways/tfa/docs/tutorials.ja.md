# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

## 技術仕様

| ページ・画面                           | ガイド               | アクセス           |
| -------------------------------------- | -------------------- | ------------------ |
| `/settings` · `#tfa-settings-panel`    | 二要素認証           | ログイン済み利用者 |
| `/administration` · `#tfa-enforcement` | 二要素認証の必須設定 | 管理者             |

公開機能 `ui:tutorials` を通じて、コンポーネント所有の定義、カタログ、対象、ライフサイクルのシグナルを登録します。ページ、表示中の領域、アクセス権により利用可否が決まります。コンポーネントを解除するとガイドも解除します。共通の表示と完了動作は[ホストのチュートリアル契約](/docs/tutorials)を参照してください。

第2認証要素が使えない場合のログイン方法としてリカバリーコードを説明し、強制設定ではパネル全体ではなくスイッチを示します。

## 有効期限付きチャレンジ配送

Email Codeの「送信待ち」はまだ配送が完了していない状態です。最新のコードを待ってください。再送が受け付けられた場合だけ前のコードを置換し、拒否時は維持します。配送失敗後は試行の期限内に明示的に再送するか、新しくログインしてください。ログイン試行は5分、設定は10分です。設定の中止はその設定だけに影響します。ログイン再開で追加メールを送ったり期限を延長したりしません。

## 再送信の結果表示

選択中の認証方法の再送信リクエストが完了すると、ログイン画面に結果が表示されます。送信待ちや送信済みの通知は、報告された配信状態を示します。配信確認のない有効な応答は、認証方法から応答があったことだけを示します。拒否、不正な応答、通信の中断だけでは、配信されたかどうかは分かりません。再試行する前にコードが届いているか確認してください。ログイン試行が期限切れの場合は、キャンセルしてもう一度ログインしてください。待機時間は引き続きサーバーが決定し、処理中は操作が無効になります。再試行やメール送信が自動で行われることはありません。

再送信が未完了の間、操作には「コードをリクエスト中…」と処理中の状態を表示します。新しい期限を作ったり自動再試行したりせず、操作を無効のまま維持します。キャンセル処理中に再送信が完了し、その後キャンセルに失敗した場合、同じ画面が結果、処理中ロック、発行済み期限を反映します。サーバーの相対待機時間は応答の受信時点から数えるため、キャンセルを待つ時間によって最初からやり直されません。
