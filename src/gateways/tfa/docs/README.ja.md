# 二要素認証

ログイン時に二つ目の確認手順を求めることでアカウントを保護できます。

## できること

- 利用できる方式を選び、ログインに使う前に設定を完了します。
- 有効な方式を並べ替え、最初に使う方式を決めます。
- 通常の第2認証要素が使えない場合は、リカバリーコードでログインできます。ログインせずに取り出せる場所に控えを保管してください。

## 始める前に

二要素認証 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/tfa/usage)、インターフェースと設定は[技術情報](/docs/gateways/tfa/technical)を参照してください。
