# アプリケーションログ

アプリケーションログは、管理者がエラーの原因や重要なアカウント操作を調べるのに役立ちます。

## できること

- 重要度、キーワード、期間で、調査に必要なログを絞り込みます。
- 時刻と構造化された詳細を確認し、新しい状態が必要なら更新します。

## 始める前に

アプリケーションログ が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/administration) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/logging/usage)、インターフェースと設定は[技術情報](/docs/gateways/logging/technical)を参照してください。
