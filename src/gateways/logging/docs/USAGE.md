# Usage

Practical procedures for Application Logs.

## Prerequisites

Review [the access requirements](/docs/gateways/logging) before performing these procedures.

## Examples

- Use severity, keyword and time-range filters to narrow the logs for an investigation.
- Inspect timestamps and structured details; refresh when you need a new snapshot.

## Expected Results

The example uses the documented interface of Application Logs. Confirm the response or saved state described in [Technical](/docs/gateways/logging/technical) before repeating a write operation.

## Troubleshooting

If Application Logs is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
