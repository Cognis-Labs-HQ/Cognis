# Log Aplikasi

Log aplikasi membantu administrator menyelidiki kesalahan dan memahami aktivitas akun penting.

Diagnostik halaman dan pemuatan latar belakang ditangani oleh gateway logging yang sama dengan aktivitas server.

## Yang Dapat Anda Lakukan

Periksa log aplikasi dan atur keluaran konsol serta berkas.

## Sebelum Memulai

Administrasi log memerlukan akses administrator.

## Langkah Awal

Buka Log di Administrasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/logging/usage) menjelaskan prosedur. [Teknis](/docs/gateways/logging/technical) mendokumentasikan antarmuka dan konfigurasi.
