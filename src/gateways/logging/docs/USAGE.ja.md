# 使用例

アプリケーションログ の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/logging)を確認してください。

## 使用例

- 重要度、キーワード、期間で、調査に必要なログを絞り込みます。
- 時刻と構造化された詳細を確認し、新しい状態が必要なら更新します。

## 期待される結果

この例は アプリケーションログ の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/logging/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

アプリケーションログ を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
