# Application Logs

Application logs help administrators investigate errors and understand important account activity.

## What You Can Do

- Use severity, keyword and time-range filters to narrow the logs for an investigation.
- Inspect timestamps and structured details; refresh when you need a new snapshot.

## Before You Start

Check that Application Logs is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.
