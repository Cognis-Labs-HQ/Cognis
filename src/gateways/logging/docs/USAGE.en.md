# Usage

Practical procedures for Application Logs.

## Prerequisites

Log administration requires administrator access.

## Examples

Filter logs by the available controls, inspect a relevant failure and adjust output levels or rotation through logging settings.

## Expected Results

Selected entries show recorded activity; file output rotates according to its configured size and retention policy.

## Troubleshooting

Check output level and file permissions. Increasing verbosity cannot recreate events that were never recorded.
