# Anwendungsprotokolle

Anwendungsprotokolle helfen Administratoren bei der Fehlersuche und beim Nachvollziehen wichtiger Kontoaktivitäten.

## Möglichkeiten

Prüfe Anwendungsprotokolle und konfiguriere Konsolen- und Dateiausgabe.

## Vor dem Start

Protokollverwaltung benötigt Administratorrechte.

## Erste Schritte

Öffne Protokolle in Administration.

## Weitere Informationen

[Anwendung](/docs/gateways/logging/usage) erklärt Abläufe. [Technik](/docs/gateways/logging/technical) beschreibt Schnittstellen und Konfiguration.
