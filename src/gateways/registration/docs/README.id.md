# Pendaftaran

Buat akun menggunakan undangan atau opsi pendaftaran yang diaktifkan pada instalasi ini.

## Yang Dapat Anda Lakukan

Atur pembuatan akun dan undangan sesuai kebijakan instalasi.

Gateway registrasi mengelola pendaftaran publik dan penukaran undangan serta menyediakan operasi penyedia melalui kapabilitas dan rute gateway.

## Sebelum Memulai

Pemilik mengatur kebijakan; penerbitan bergantung pada peran dan penyedia.

## Langkah Awal

Buka Undang atau Pendaftaran di Administrasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/registration/usage) menjelaskan prosedur. [Teknis](/docs/gateways/registration/technical) mendokumentasikan antarmuka dan konfigurasi.
