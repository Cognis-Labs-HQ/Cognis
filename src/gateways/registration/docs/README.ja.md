# 登録

招待またはこの環境で有効な登録方法を使ってアカウントを作成できます。

## できること

- 自分の役割で利用できる方法を選びます。メール招待と登録トークンでは渡し方が異なります。
- 状態と有効期限を確認します。トークンは招待する相手にだけ渡し、不要な招待は取り消せます。
- アカウントを作成できる人を変更する前に、公開登録と招待の許可を確認します。

## 始める前に

登録 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/register) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/registration/usage)、インターフェースと設定は[技術情報](/docs/gateways/registration/technical)を参照してください。
