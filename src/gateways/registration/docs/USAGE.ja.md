# 使用例

登録 の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/registration)を確認してください。

## 使用例

- 自分の役割で利用できる方法を選びます。メール招待と登録トークンでは渡し方が異なります。
- 状態と有効期限を確認します。トークンは招待する相手にだけ渡し、不要な招待は取り消せます。
- アカウントを作成できる人を変更する前に、公開登録と招待の許可を確認します。
- 方針を見直して保存し、招待ページに表示される操作を確認します。
- 招待をコピー・共有する前に宛先と状態を確認し、不要な招待は無効にします。

## 期待される結果

この例は 登録 の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/registration/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

登録 を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
