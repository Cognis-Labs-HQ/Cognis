# Anwendung

Praktische Abläufe für Registrierung.

## Voraussetzungen

Beachten Sie vor dem Ausführen [die Zugriffsanforderungen](/docs/gateways/registration).

## Beispiele

- Wählen Sie eine erlaubte Methode; E-Mail-Einladungen und Registrierungstoken werden unterschiedlich zugestellt.
- Prüfen Sie Status und Ablauf; kopieren Sie Token nur für vorgesehene Empfänger und widerrufen Sie unbenutzte Einladungen bei Bedarf.
- Prüfen Sie öffentliche Registrierung und Einladungsrechte, bevor Sie die Kontoerstellung ändern.
- Speichern Sie geprüfte Regeln und prüfen Sie Einladungsoptionen auf der Einladungsseite.
- Prüfen Sie Empfänger und Status, bevor Sie eine Einladung kopieren oder weitergeben. Widerrufen Sie nicht mehr benötigte Einladungen.

## Erwartete Ergebnisse

Das Beispiel verwendet die dokumentierte Schnittstelle von Registrierung. Prüfen Sie vor erneuten Schreibvorgängen die unter [Technik](/docs/gateways/registration/technical) beschriebene Antwort oder den gespeicherten Zustand.

## Fehlerbehebung

Falls Registrierung nicht verfügbar ist, prüfen Sie Ihre Anmeldung und lassen Sie den Administrator die Komponente und ihre Abhängigkeiten kontrollieren.
