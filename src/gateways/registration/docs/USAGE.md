# Usage

Practical procedures for Registration.

## Prerequisites

Review [the access requirements](/docs/gateways/registration) before performing these procedures.

## Examples

- Choose an invitation method available to your role; email invitations and registration tokens have different delivery steps.
- Review invitation status and expiry; copy tokens only for the intended recipient and revoke unused invitations when needed.
- Review public registration and invitation permissions before changing who can create accounts.
- Save reviewed policy changes and check the invitation page for the resulting options.
- Review each invitation’s recipient and status before copying or sharing it. Revoke invitations that should no longer be used.

## Expected Results

The example uses the documented interface of Registration. Confirm the response or saved state described in [Technical](/docs/gateways/registration/technical) before repeating a write operation.

## Troubleshooting

If Registration is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
