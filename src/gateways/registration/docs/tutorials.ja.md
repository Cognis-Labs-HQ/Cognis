# ガイド付きチュートリアル

このコンポーネントで利用できる操作を案内します。

## ガイドの使い方

以下のページを開くと未完了のガイドを開始します。完了したガイドはページ見出しの ? から再実行し、スキップで再実行を終了します。

招待方法のガイドでは、招待先の修正について説明します。招待メールの送信ではメールアドレスが必須で、翻訳されたフィードバックを表示し、修正が必要な欄にフォーカスを戻します。「招待を作成」と Enter キーは同じ検証を行います。ダイアログを閉じると未完了の入力は破棄され、再度開くと空欄になります。登録トークンと招待履歴の操作は従来どおりです。

## 技術仕様

| ページ・画面                        | ガイド       | アクセス           |
| ----------------------------------- | ------------ | ------------------ |
| `/invite`                           | 招待の使い方 | ログイン済み利用者 |
| `/administration` · `#registration` | 登録の方針   | 管理者             |

公開機能 `ui:tutorials` を通じて、コンポーネント所有の定義、カタログ、対象、ライフサイクルのシグナルを登録します。ページ、表示中の領域、アクセス権により利用可否が決まります。コンポーネントを解除するとガイドも解除します。共通の表示と完了動作は[ホストのチュートリアル契約](/docs/tutorials)を参照してください。
