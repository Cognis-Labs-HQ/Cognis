# Database

The database stores accounts and application content so they remain available after a restart.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that Database is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/gateways/db/usage) explains procedures. [Technical](/docs/gateways/db/technical) documents interfaces and configuration.
