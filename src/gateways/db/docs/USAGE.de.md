# Anwendung

Praktische Abläufe für Datenbank.

## Voraussetzungen

Beachten Sie vor dem Ausführen [die Zugriffsanforderungen](/docs/gateways/db).

## Beispiele

Prüfen Sie vor der Ausführung die Argumente des installierten Befehls.

```sh
cognisctl search:query --help
cognisctl docs:list --help
cognisctl docs:get --help
cognisctl ui:routes --help
cognisctl ui:settings-sections --help
cognisctl ui:navbar-plugins --help
```

## Erwartete Ergebnisse

Das Beispiel verwendet die dokumentierte Schnittstelle von Datenbank. Prüfen Sie vor erneuten Schreibvorgängen die unter [Technik](/docs/gateways/db/technical) beschriebene Antwort oder den gespeicherten Zustand.

## Fehlerbehebung

Falls Datenbank nicht verfügbar ist, prüfen Sie Ihre Anmeldung und lassen Sie den Administrator die Komponente und ihre Abhängigkeiten kontrollieren.
