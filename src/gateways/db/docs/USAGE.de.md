# Anwendung

Praktische Abläufe für Datenbank.

## Voraussetzungen

Betreiber müssen vor regulärer Nutzung einen unterstützten Anbieter einrichten.

## Beispiele

Starte Cognis und prüfe Schemainitialisierung sowie den Fortbestand gespeicherter Konten oder Termine nach Neustart.

## Erwartete Ergebnisse

Deklarierte Schemas werden initialisiert; Persistenz hängt vom Anbieter ab.

## Fehlerbehebung

Prüfe Anbieter, Zugangsdaten und Schemarechte. Speicher protokolliert Aufrufe, speichert aber keine Anwendungsdaten.
