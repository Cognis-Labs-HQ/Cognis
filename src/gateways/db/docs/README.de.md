# Datenbank

Die Datenbank speichert Konten und Anwendungsinhalte über Neustarts hinweg.

## Möglichkeiten

Stelle dauerhaften Speicher für Konten und aktive Funktionen bereit.

## Vor dem Start

Betreiber müssen vor regulärer Nutzung einen unterstützten Anbieter einrichten.

## Erste Schritte

Konfiguriere die Datenbankverbindung bei der Bereitstellung.

[Anwendung](/docs/gateways/db/usage) erklärt Abläufe. [Technik](/docs/gateways/db/technical) beschreibt Schnittstellen und Konfiguration.
