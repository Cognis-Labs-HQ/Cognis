# Basis Data

Basis data menyimpan akun dan konten aplikasi agar tetap tersedia setelah dimulai ulang.

## Yang Dapat Anda Lakukan

Tindakan yang tersedia ditampilkan pada [halaman fitur](/administration) sesuai izin akun Anda.

## Sebelum Memulai

Pastikan Basis Data aktif dan akun Anda diizinkan melakukan operasi tersebut.

## Langkah Awal

Buka [fitur ini](/administration) dan pilih tindakan yang diperlukan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/db/usage) menjelaskan prosedur. [Teknis](/docs/gateways/db/technical) mendokumentasikan antarmuka dan konfigurasi.
