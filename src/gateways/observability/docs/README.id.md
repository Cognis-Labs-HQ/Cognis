# Pemantauan Kinerja

Pemantauan kinerja membantu administrator mengenali permintaan dan interaksi peramban yang lambat.

## Yang Dapat Anda Lakukan

Kumpulkan pengukuran kinerja terbatas untuk mendiagnosis permintaan dan halaman lambat.

## Sebelum Memulai

Operator perlu akses ke tujuan metrik; tujuan bawaan menulis log debug.

## Langkah Awal

Tinjau metrik bersama log aplikasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/observability/usage) menjelaskan prosedur. [Teknis](/docs/gateways/observability/technical) mendokumentasikan antarmuka dan konfigurasi.
