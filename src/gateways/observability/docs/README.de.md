# Leistungsüberwachung

Die Leistungsüberwachung hilft Administratoren, langsame Anfragen und Browseraktionen zu erkennen.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Leistungsüberwachung aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/gateways/observability/usage) erklärt Abläufe. [Technik](/docs/gateways/observability/technical) beschreibt Schnittstellen und Konfiguration.
