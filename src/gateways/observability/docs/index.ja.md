# オブザーバビリティゲートウェイ

このゲートウェイは、ベンダー中立な ctx ケイパビリティ `observability:metrics` と、サイズ制限付きのサンプリング済みブラウザテレメトリエンドポイントを提供します。メトリクス名とラベルを許可リストで制限し、カーディナリティを抑えます。ルートやゲートウェイを特定ベンダーに結合せず、送信先を交換できます。

## 使用例

サーバーメトリクスには `ctx.capabilities` から `observability:metrics` を解決し、許可されたブラウザーテレメトリはゲートウェイエンドポイントへ送信します。

## 技術仕様

メトリクス名とラベルは許可リストで制限され、ブラウザーペイロードはサンプリングとサイズ制限を受けます。出力先は機能契約を通じてベンダー中立かつ交換可能です。
