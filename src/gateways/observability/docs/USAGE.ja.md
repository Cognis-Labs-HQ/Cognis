# 使用例

パフォーマンスの監視 の実践的な操作手順です。

## 前提条件

運用者は測定出力を確認できる必要があります。既定ではデバッグログに出力します。

## 使用例

デバッグ出力を設定し、遅い処理を再現して、同条件で HTTP やデータベースの時間を比較します。

サーバーメトリクスには `ctx.capabilities` から `observability:metrics` を解決し、許可されたブラウザーテレメトリはゲートウェイエンドポイントへ送信します。

## 期待される結果

許可された値のみを記録し、ブラウザーの標本はすべての訪問を表しません。

## 問題の解決

ログレベルとサンプリングを確認してください。専用の測定ダッシュボードはありません。
