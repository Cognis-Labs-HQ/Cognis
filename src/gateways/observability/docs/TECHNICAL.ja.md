# 技術リファレンス

パフォーマンスの監視 の公開インターフェースと運用規則を説明します。

## インターフェース

observability:metrics.record(name, value, labels) で許可した有限値を記録します。POST /api/v1/observability/client は metrics と navigation を受け、最大十六件、蓄積した本文は 16,384 文字までです。

## 設定

既定はデバッグログです。名前とラベルは許可一覧に限定し、交換先は独自ルートではなく observability:metrics.record を実装します。

## 動作

### オブザーバビリティゲートウェイ

このゲートウェイは、ベンダー中立な ctx ケイパビリティ `observability:metrics` と、サイズ制限付きのサンプリング済みブラウザテレメトリエンドポイントを提供します。メトリクス名とラベルを許可リストで制限し、カーディナリティを抑えます。ルートやゲートウェイを特定ベンダーに結合せず、送信先を交換できます。

## セキュリティ

POST /api/v1/observability/client はユーザー認証が必要です。名前とラベルキーを許可一覧で制限し、値は八十文字まで、送信は毎分六回までです。

## リファレンス

### 技術仕様

メトリクス名とラベルは許可リストで制限され、ブラウザーペイロードはサンプリングとサイズ制限を受けます。出力先は機能契約を通じてベンダー中立かつ交換可能です。
