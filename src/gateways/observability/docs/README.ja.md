# パフォーマンスの監視

パフォーマンスの監視により、管理者は遅いリクエストやブラウザー操作を特定できます。

## できること

遅いリクエストや画面を調べるため、範囲を限定した性能測定を行います。

## 始める前に

運用者は測定出力を確認できる必要があります。既定ではデバッグログに出力します。

## はじめに

アプリのログと併せて測定値を確認します。

## 詳しい情報

手順は[使用例](/docs/gateways/observability/usage)、インターフェースと設定は[技術情報](/docs/gateways/observability/technical)を参照してください。
