# ファイルリーダーゲートウェイ

## 概要

ファイルリーダーゲートウェイは、Cognis 内でファイルをレンダリングするための統一されたアダプター駆動のメカニズムを提供します。授業教材、アップロードされた添付ファイル、アプリ内でユーザーが開くあらゆるリソースに対応します。起動時にレンダリングアダプターを検出し、MIME タイプに基づいて適切なアダプターにファイルオープンリクエストをルーティングすることで、プラットフォームを特定のファイル形式から分離します。

新しいファイル形式のサポートを追加するには、`src/adapters/file-reader/<id>/` に新しいアダプターを作成するだけです。ゲートウェイやコアのコードを変更する必要はありません。

## 責務

- 起動時に `src/adapters/file-reader/` をスキャンしてすべてのアダプターを検出する。
- MIME タイプと拡張子をそれを処理するアダプターにマッピングするレジストリを管理する。
- 他のゲートウェイやアダプターが特定の MIME タイプに対して適切なレンダラーを検索できるようにケイパビリティを公開する。
- アダプターのブートストラップ時に提供された静的アセットと API ルートを登録する。

責任外: 実際のファイルバイトの保存や取得（これはファイルストレージゲートウェイの責務）、アップロードサイズ制限の適用、またはファイルアクセス制御の管理。

## アーキテクチャ

ゲートウェイのエントリーポイントは `src/gateways/file-reader/bootstrap.ts` です。起動時に `src/adapters/file-reader/` をスキャンし、各アダプターの `index.ts` をインポートし、`bootstrapFileReaderAdapter(ctx)` を呼び出して、サポートされる MIME タイプをレジストリに収集します。

## 拡張ポイント

新しいファイルレンダラーを追加するには:

1. `createFileReaderAdapter()` と `bootstrapFileReaderAdapter(ctx)` をエクスポートする `src/adapters/file-reader/<id>/index.ts` を作成する。
2. `getSupportedTypes()` からサポートされる MIME タイプを返す。
3. ブラウザー側が適切なビュースクリプトをロードできるよう `scriptUrl` と `stylesheetUrl` を含む `file-reader:<id>:ui` ケイパビリティを提供する。

ゲートウェイは次回の起動時に新しいアダプターを自動的に検出します。
