# Fitur Sosial

Terhubung dengan pengguna Cognis melalui profil, kiriman, dan percakapan pribadi.

## Yang Dapat Anda Lakukan

Gunakan profil, percakapan, dan panggilan aktif dengan aturan akun bersama.

## Sebelum Memulai

Masuk; adapter sosial menyediakan fiturnya masing-masing.

## Langkah Awal

Buka Profil atau Pesan melalui navigasi aplikasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/social/usage) menjelaskan prosedur. [Teknis](/docs/gateways/social/technical) mendokumentasikan antarmuka dan konfigurasi.
