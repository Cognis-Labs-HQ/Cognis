# 使用例

交流機能 の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/social)を確認してください。

## 使用例

- 有効な交流機能のアダプターと設定を確認します。
- 提供元の有効化、無効化、設定変更の前に、利用者への影響を確認します。

## 期待される結果

この例は 交流機能 の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/social/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

交流機能 を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
