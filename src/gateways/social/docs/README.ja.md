# 交流機能

プロフィール、投稿、非公開の会話を通じて他の Cognis 利用者と交流できます。

## できること

- 有効な交流機能のアダプターと設定を確認します。
- 提供元の有効化、無効化、設定変更の前に、利用者への影響を確認します。

## 始める前に

交流機能 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/messages) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/social/usage)、インターフェースと設定は[技術情報](/docs/gateways/social/technical)を参照してください。
