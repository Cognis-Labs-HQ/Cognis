# Usage

Practical procedures for Social Features.

## Prerequisites

Review [the access requirements](/docs/gateways/social) before performing these procedures.

## Examples

- Inspect the active social adapters and their available settings.
- Review the affected user features before enabling, disabling or reconfiguring a provider.

## Expected Results

The example uses the documented interface of Social Features. Confirm the response or saved state described in [Technical](/docs/gateways/social/technical) before repeating a write operation.

## Troubleshooting

If Social Features is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
