# 使用例

ファイル の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/files)を確認してください。

## 使用例

- 全体の既定容量と、それを使用するコンポーネントの名前空間を確認します。
- 名前空間の所有者と公開範囲を確認してから、容量の上限を変更して保存します。

## 期待される結果

この例は ファイル の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/files/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

ファイル を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
