# ファイルストレージゲートウェイ

## 概要

ファイルストレージゲートウェイは、ファイルの読み取り、書き込み、追記のための統一インターフェースをプラットフォームに提供します。ローカルファイルアダプターをブートストラップし、4つのケイパビリティをケイパビリティストアに提供します。これにより他のゲートウェイ（アバターアップロード用のプロフィールゲートウェイ、ログ書き込み用のロギングゲートウェイ）が、ローカルファイルシステム、S3バケットなどに書き込んでいるかを知らずにファイル操作を利用できます。

## 責務

- `MEDIA_LOCATION` から導出されたストレージルートで `LocalFileGateway` をインスタンス化する。
- `file:gateway`、`file:write`、`file:read`、`file:append` をケイパビリティストアに提供する。
- ゲートウェイレジストリに `files` ゲートウェイを登録する。

## アーキテクチャ

### 提供されるケイパビリティ

| ケイパビリティ | 型 | 説明 |
| ------------ | -- | ---- |
| `file:gateway` | `FileStorageGateway` | 完全なゲートウェイインスタンス |
| `file:write` | `(filePath, content) => Promise<void>` | ファイルを上書き |
| `file:read` | `(filePath) => Promise<Buffer \| null>` | ファイルを読み取り |
| `file:append` | `(filePath, content) => Promise<void>` | ファイルにテキストを追記（ロギングゲートウェイが使用） |

## 設定

| 変数 | デフォルト | 説明 |
| ---- | ---------- | ---- |
| `MEDIA_LOCATION` | `/app/media` | メディアストレージのルートディレクトリ; アップロードは `$MEDIA_LOCATION/uploads` に保存 |
