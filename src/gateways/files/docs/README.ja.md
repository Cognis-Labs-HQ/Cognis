# ファイル

アカウントの保存容量と共有権限の範囲で、ファイルをアップロードして取得できます。

## できること

- 全体の既定容量と、それを使用するコンポーネントの名前空間を確認します。
- 名前空間の所有者と公開範囲を確認してから、容量の上限を変更して保存します。

## 始める前に

ファイル が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/files/usage)、インターフェースと設定は[技術情報](/docs/gateways/files/technical)を参照してください。
