# Usage

Practical procedures for Files.

## Prerequisites

Review [the access requirements](/docs/gateways/files) before performing these procedures.

## Examples

- Review the global storage default and the component namespaces using it.
- Check a namespace’s owner and visibility before changing its byte quota and saving.

## Expected Results

The example uses the documented interface of Files. Confirm the response or saved state described in [Technical](/docs/gateways/files/technical) before repeating a write operation.

## Troubleshooting

If Files is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
