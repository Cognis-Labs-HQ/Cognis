# Berkas

Unggah dan ambil berkas sesuai batas penyimpanan dan izin berbagi akun Anda.

## Yang Dapat Anda Lakukan

Unggah berkas milik fitur dengan aturan akses dan batas penyimpanan.

## Sebelum Memulai

Unggahan memerlukan penyedia penyimpanan aktif dan kuota cukup.

## Langkah Awal

Gunakan kontrol unggah pada fitur pemilik berkas.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/files/usage) menjelaskan prosedur. [Teknis](/docs/gateways/files/technical) mendokumentasikan antarmuka dan konfigurasi.
