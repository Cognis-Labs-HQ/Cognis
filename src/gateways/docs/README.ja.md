# 機能のゲートウェイ

機能のゲートウェイは、有効な Cognis の機能を利用できるサービスにつなぎます。

## できること

[機能のページ](/administration) には、アカウントの権限に応じた操作が表示されます。

## 始める前に

機能のゲートウェイ が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/administration) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/components/gateways/usage)、インターフェースと設定は[技術情報](/docs/components/gateways/technical)を参照してください。
