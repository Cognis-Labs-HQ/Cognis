# 機能のゲートウェイ

機能のゲートウェイは、有効な Cognis の機能を利用できるサービスにつなぎます。

## できること

サービスを担当するゲートウェイと提供機能を確認できます。

## 始める前に

このパッケージは共通基盤をまとめ、個別の利用機能は各ゲートウェイが提供します。

## はじめに

管理画面で対象サービスのゲートウェイを探します。

## 詳しい情報

手順は[使用例](/docs/components/gateways/usage)、インターフェースと設定は[技術情報](/docs/components/gateways/technical)を参照してください。
