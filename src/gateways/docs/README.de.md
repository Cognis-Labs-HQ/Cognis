# Funktionsdienste

Funktionsdienste verbinden aktivierte Cognis-Bereiche mit verfügbaren Dienstanbietern.

## Möglichkeiten

Erkenne zuständiges Gateway und Anbieter eines Dienstes.

## Vor dem Start

Dieses Paket bündelt Infrastruktur; Benutzerfunktionen gehören zu einzelnen Gateways.

## Erste Schritte

Suche das zuständige Gateway in Administration.

[Anwendung](/docs/components/gateways/usage) erklärt Abläufe. [Technik](/docs/components/gateways/technical) beschreibt Schnittstellen und Konfiguration.
