# Funktionsdienste

Funktionsdienste verbinden aktivierte Cognis-Bereiche mit verfügbaren Dienstanbietern.

## Möglichkeiten

Verfügbare Aktionen erscheinen auf [der Funktionsseite](/administration) entsprechend Ihren Kontorechten.

## Vor dem Start

Prüfen Sie, ob Funktionsdienste aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/administration) und wählen Sie die gewünschte Aktion.

## Weitere Informationen

[Anwendung](/docs/components/gateways/usage) erklärt Abläufe. [Technik](/docs/components/gateways/technical) beschreibt Schnittstellen und Konfiguration.
