# Feature Gateways

Feature gateways connect the enabled parts of Cognis to their available service providers.

## What You Can Do

Available actions are shown on [the feature page](/administration) according to your account permissions.

## Before You Start

Check that Feature Gateways is enabled and that your account has permission for the operation.

## Get Started

Open [the feature](/administration) and choose the action you need.

## Learn More

[Usage](/docs/components/gateways/usage) explains procedures. [Technical](/docs/components/gateways/technical) documents interfaces and configuration.
