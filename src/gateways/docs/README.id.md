# Gerbang Fitur

Gerbang fitur menghubungkan bagian Cognis yang aktif dengan penyedia layanan yang tersedia.

## Yang Dapat Anda Lakukan

Kenali gateway dan penyedia pemilik layanan.

## Sebelum Memulai

Paket ini mengelompokkan infrastruktur; fitur pengguna dimiliki gateway individual.

## Langkah Awal

Temukan gateway layanan di Administrasi.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/components/gateways/usage) menjelaskan prosedur. [Teknis](/docs/components/gateways/technical) mendokumentasikan antarmuka dan konfigurasi.
