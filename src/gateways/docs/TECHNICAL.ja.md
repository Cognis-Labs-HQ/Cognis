# 技術リファレンス

機能のゲートウェイ の公開インターフェースと運用規則を説明します。

## インターフェース

このワークスペースは共通のプラットフォームコードを提供します。公開する機能の契約は、説明されたケイパビリティ、コマンド、ゲートウェイが管理し、このパッケージは独立した HTTP サービスを提供しません。

## 設定

ホストの設定と登録されたケイパビリティにより、動作する環境を決定します。このパッケージに独立した設定サービスはありません。

## 動作

このパッケージは Cognis と共に配備します。個別の機能のライフサイクルが、有効化、依存先の確認、終了時の解放を管理します。

## セキュリティ

公開されたケイパビリティとコマンドには、操作ごとの認可が適用されます。パッケージを追加するだけで、非公開のリソースにアクセスできるようにはなりません。

## リファレンス

ソースとパッケージの情報: `src/gateways/`。
