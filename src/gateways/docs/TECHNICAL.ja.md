# 技術リファレンス

機能のゲートウェイ の公開インターフェースと運用規則を説明します。

## インターフェース

GatewayBootstrapContext が機能・ルート・画面・動作期間の登録を提供します。共通の起動処理は所有元の範囲で defineContracts とアダプター起動を実行します。

## 設定

ホストがゲートウェイとアダプターの起点を渡します。宣言は識別・版・依存先・資料を定義し、固有の設定は各アダプターのスキーマが管理します。

## 動作

有効な所有元と提供機能を登録します。契約・ルート・コールバックはアダプターに属し、初期化失敗で登録を戻します。機能別サービスは各ディレクトリに置きます。

## セキュリティ

登録範囲は所有元を示すものでユーザー権限ではありません。実行時の認証と対象権限を確認し、他の内部サービスは公開しません。
