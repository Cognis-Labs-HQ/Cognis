# ログイン

ローカルアカウント、または管理者が有効にした認証サービスで Cognis にログインできます。

## できること

- 認証方式に対応する操作でパスワードを変更します。本人確認が必要な場合があります。
- 許可されたセッション期間を選ぶか全体の既定値に戻し、変更を保存します。

## 始める前に

ログイン が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/login) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/auth/usage)、インターフェースと設定は[技術情報](/docs/gateways/auth/technical)を参照してください。
