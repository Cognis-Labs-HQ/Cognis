# Anmelden

Melden Sie sich mit einem lokalen Konto oder einem aktivierten Anmeldedienst bei Cognis an.

## Möglichkeiten

- Verwenden Sie die Passwortfunktion Ihres Anbieters; eine Änderung kann eine Identitätsbestätigung erfordern.
- Wählen Sie eine erlaubte Sitzungsdauer oder den globalen Standard und speichern Sie Änderungen.

## Vor dem Start

Prüfen Sie, ob Anmelden aktiviert ist und Ihr Konto den Vorgang ausführen darf.

## Erste Schritte

Öffnen Sie [die Funktion](/login) und wählen Sie die gewünschte Aktion.
