# 使用例

ログイン の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/auth)を確認してください。

## 使用例

- 認証方式に対応する操作でパスワードを変更します。本人確認が必要な場合があります。
- 許可されたセッション期間を選ぶか全体の既定値に戻し、変更を保存します。

## 期待される結果

この例は ログイン の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/auth/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

ログイン を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
