# Usage

Practical procedures for Sign In.

## Prerequisites

Review [the access requirements](/docs/gateways/auth) before performing these procedures.

## Examples

- Use the password control available for your authentication provider; changing a password may require confirming your identity.
- Choose a permitted session duration or restore the global default, then save your changes.

## Expected Results

The example uses the documented interface of Sign In. Confirm the response or saved state described in [Technical](/docs/gateways/auth/technical) before repeating a write operation.

## Troubleshooting

If Sign In is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
