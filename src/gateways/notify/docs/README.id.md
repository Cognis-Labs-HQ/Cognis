# Notifikasi

Terima pemberitahuan aktivitas terkait melalui metode pengiriman yang aktif untuk akun Anda.

## Yang Dapat Anda Lakukan

Pilih pengiriman notifikasi per kategori dan kelola alamat terverifikasi.

## Sebelum Memulai

Masuk untuk preferensi pribadi; administrator mengatur penyedia dan siaran.

## Langkah Awal

Buka preferensi notifikasi di Pengaturan.

## Pelajari Lebih Lanjut

[Penggunaan](/docs/gateways/notify/usage) menjelaskan prosedur. [Teknis](/docs/gateways/notify/technical) mendokumentasikan antarmuka dan konfigurasi.
