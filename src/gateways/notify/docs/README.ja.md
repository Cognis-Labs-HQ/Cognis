# 通知

アカウントで有効な配信方法を通じて、関連する操作の通知を受け取れます。

## できること

- 通知の種類ごとに、受け取る通知先を選びます。
- 選択を確認して保存します。利用できない通知先はここで有効にできません。
- 宛先とカテゴリーを選び、テスト通知の件名と本文を入力します。

## 始める前に

通知 が有効であり、アカウントに操作の権限があることを確認してください。

## はじめに

[機能のページ](/settings) を開き、必要な操作を選びます。

## 詳しい情報

手順は[使用例](/docs/gateways/notify/usage)、インターフェースと設定は[技術情報](/docs/gateways/notify/technical)を参照してください。
