# 使用例

通知 の実践的な操作手順です。

## 前提条件

操作の前に、[アクセスの要件](/docs/gateways/notify)を確認してください。

## 使用例

- 通知の種類ごとに、受け取る通知先を選びます。
- 選択を確認して保存します。利用できない通知先はここで有効にできません。
- 宛先とカテゴリーを選び、テスト通知の件名と本文を入力します。
- テスト通知を送信し、選択した配信方法で相手がメッセージを受け取れるか確認します。
- 掲載前に、お知らせの内容、対象者、表示期間を確認します。
- 編集や削除の前に既存のお知らせを確認します。公開すると他の利用者の画面に反映されます。

## 期待される結果

この例は 通知 の公開されたインターフェースを使います。書き込みを繰り返す前に、[技術情報](/docs/gateways/notify/technical)で説明する応答または保存された状態を確認してください。

## 問題の解決

通知 を利用できない場合は、ログイン状態を確認し、コンポーネントと依存先の有効状態を管理者に確認してもらってください。
