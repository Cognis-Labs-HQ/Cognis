# Usage

Practical procedures for Notifications.

## Prerequisites

Review [the access requirements](/docs/gateways/notify) before performing these procedures.

## Examples

- Choose which available channels receive each category of notification.
- Review the selected combinations and save the settings; unavailable channels cannot be enabled here.
- Choose the recipient and category, then write a subject and message for the test notification.
- Send a test notification to check that a recipient can receive messages through the selected channel.
- Review the announcement content, audience and display period before publishing.
- Inspect existing broadcasts before editing or removing them; publishing changes what other users see.

## Expected Results

The example uses the documented interface of Notifications. Confirm the response or saved state described in [Technical](/docs/gateways/notify/technical) before repeating a write operation.

## Troubleshooting

If Notifications is unavailable, verify your sign-in and ask an administrator to check whether the component and its dependencies are enabled.
