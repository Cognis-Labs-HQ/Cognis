# Usage

Practical procedures for Notifications.

## Prerequisites

Sign in for personal preferences; administrators configure delivery providers and broadcasts.

## Examples

Select available senders for a category, save and trigger a relevant action; administrators can test a sender without enabling routine delivery.

## Expected Results

Delivery follows category choices and always-on senders. Email-dependent actions require an available email provider.

## Troubleshooting

Check verified email, sender availability and category preferences; an outage does not waive required verification.
