# Anwendung

Praktische Abläufe für Benachrichtigungen.

## Voraussetzungen

Persönliche Einstellungen benötigen Anmeldung; Administratoren konfigurieren Zustellung und Rundmeldungen.

## Beispiele

Wähle verfügbare Sender für eine Kategorie, speichere und löse eine passende Aktion aus; Administratoren können Sender separat testen.

## Erwartete Ergebnisse

Zustellung folgt Kategorien und dauerhaft aktiven Sendern. E-Mail-Aktionen brauchen einen verfügbaren Mailanbieter.

## Fehlerbehebung

Prüfe bestätigte Adresse, Sender und Kategorie; ein Ausfall hebt Bestätigungspflichten nicht auf.
