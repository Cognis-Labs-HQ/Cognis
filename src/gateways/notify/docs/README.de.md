# Benachrichtigungen

Erhalten Sie Hinweise zu wichtigen Aktivitäten über die für Ihr Konto aktivierten Zustellwege.

## Möglichkeiten

Wähle Benachrichtigungskanäle pro Kategorie und verwalte bestätigte Kontaktadressen.

## Vor dem Start

Persönliche Einstellungen benötigen Anmeldung; Administratoren konfigurieren Zustellung und Rundmeldungen.

## Erste Schritte

Öffne Benachrichtigungen in Einstellungen.

## Weitere Informationen

[Anwendung](/docs/gateways/notify/usage) erklärt Abläufe. [Technik](/docs/gateways/notify/technical) beschreibt Schnittstellen und Konfiguration.
